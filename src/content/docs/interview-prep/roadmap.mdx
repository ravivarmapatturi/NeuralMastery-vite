# Interview Prep — Roadmap

Once you've covered the topic sections, this is where you drill for the actual interview loop. Structured after the modules used by FAANG-style AI/ML interviews.

## 1. [General Coding (DSA)](/docs/interview-prep/dsa-coding)
- [x] Arrays, strings, hash maps, two pointers, sliding window
- [x] Trees, graphs, BFS/DFS
- [x] Dynamic programming
- [x] Practice on LeetCode-style problems, timed

## 2. [ML Coding](/docs/interview-prep/ml-coding)
- [x] Implement classical algorithms from scratch (k-means, k-NN, logistic regression, decision tree)
- [x] Implement a neural network forward/backward pass without a framework
- [x] Implement attention from scratch

## 3. [ML/GenAI Knowledge Q&A](/docs/interview-prep/knowledge-qa-strategy)
- [x] Classical ML breadth questions (bias-variance, regularization, evaluation metrics)
- [x] Deep learning breadth questions (architectures, training dynamics)
- [x] LLM/GenAI breadth questions (transformers, RAG, fine-tuning, agents)
- [x] Inference engineering breadth questions (KV cache, batching, quantization, TTFT/TPOT)
- [x] Research-track questions (paper critique, ablation design, literature fluency)
- [x] Rapid-fire self-check: can you explain each topic in under 2 minutes, out loud?

## 3.5. [Technology Comparisons & Decision Trees](/docs/interview-prep/technology-comparisons)
- [x] vLLM vs SGLang vs TensorRT-LLM vs Triton vs llama.cpp
- [x] LangChain vs LangGraph
- [x] RAG vs fine-tuning
- [x] LoRA vs QLoRA vs full fine-tuning
- [x] SQL vs vector DB vs graph DB
- [x] DDP vs FSDP vs ZeRO
- [x] CUDA vs ROCm
- [x] PyTorch vs JAX

## 4. [System Design](/docs/interview-prep/system-design-practice)
- [x] Practice the 9-step ML system design formula on 5-10 different problems (see [ML System Design roadmap](/docs/ml-system-design/roadmap))
- [x] Practice LLM/RAG/agent system design specifically — increasingly common in 2026-era interviews
- [x] Time yourself: most system design rounds are 45 minutes

## 5. [Behavioral](/docs/interview-prep/behavioral)
- [x] Prepare stories using the STAR method (Situation, Task, Action, Result)
- [x] Have examples ready for: conflict with a teammate, a failed project, a time you influenced without authority
- [x] Research the specific company/team's ML maturity and tailor answers
