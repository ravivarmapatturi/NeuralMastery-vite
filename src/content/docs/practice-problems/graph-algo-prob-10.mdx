# #630. Graphs & Network Algorithms Module 2: Problem 10

## Overview

Calculate the total weight of a Minimum Spanning Tree using Kruskal's greedy edge selection.

## Task

Implement `kruskal_mst_weight(n, edges)`: sort edges by weight ascending. Greedily add edges that join disjoint components via Union-Find until n-1 edges are chosen.

<Solution>

```python
def kruskal_mst_weight(n, edges):
    sorted_edges = sorted(edges, key=lambda x: x[2])
    parent = list(range(n))
    def find(i):
        if parent[i] == i:
            return i
        parent[i] = find(parent[i])
        return parent[i]
    mst_weight = 0
    edges_count = 0
    for u, v, w in sorted_edges:
        ru, rv = find(u), find(v)
        if ru != rv:
            parent[ru] = rv
            mst_weight += w
            edges_count += 1
            if edges_count == n - 1:
                break
    return mst_weight
```

Sort edges by weight ascending. Sequentially connect non-cyclic endpoints using Union-Find, accumulating edge weights until spanning the tree.
