# Faithfulness Evaluation Score

**Track**: RAG Production Engineering | **Points**: 40 XP

## Overview

Implement the RAG faithfulness metric: what fraction of a generated answer's claims are actually grounded in retrieved sources.

## Task

Implement `faithfulness_score(answer_sentences, grounded_flags)`. Both lists are the same length (one flag per sentence, `True` meaning that sentence is grounded). Return `sum(grounded_flags) / len(answer_sentences)`. Return `1.0` for an empty answer (vacuously faithful).
