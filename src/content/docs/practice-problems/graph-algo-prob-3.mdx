# #623. Graphs & Network Algorithms Module 1: Problem 3

**Track**: Graphs & Network Algorithms | **Rank**: #623 of 1072 | **Points**

## Overview

Calculate vertex degrees across all nodes in an undirected graph.

## Task

Implement `compute_node_degrees(n, edges)`: initialize degree count 0 for every node 0..n-1, and increment degrees for both endpoints of each edge.

<PracticePlayground problemId="graph-algo-prob-3" />

<Solution>

```python
def compute_node_degrees(n, edges):
    degrees = {i: 0 for i in range(n)}
    for u, v in edges:
        degrees[u] += 1
        degrees[v] += 1
    return degrees
```

Initialize degree counts to zero for all n vertices, then iterate through edges incrementing the degree counter for both connected endpoints.
