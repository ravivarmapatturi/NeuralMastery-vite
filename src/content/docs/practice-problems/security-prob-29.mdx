# Global Kill Switch Check

**Track**: Agent Security & Reliability | **Points**: 40 XP

## Overview

Implement a global kill-switch check, the real, final safety gate every agent action should pass through -- a single operator-controlled flag that can halt all agent activity in an emergency.

## Task

Implement `should_proceed(kill_switch_active, action_is_critical)`: return `False` (halt) if `kill_switch_active` is `True`, REGARDLESS of `action_is_critical` -- a kill switch has no exceptions, by design. Otherwise return `True`.
