# Weighted Composite Eval Score

**Track**: Agent Evaluation & Observability | **Points**: 40 XP

## Overview

Implement weighted composite scoring, combining several individually-meaningful eval metrics (accuracy, latency, cost) into one real overall number for a leaderboard or gating decision.

## Task

Implement `composite_score(metric_scores, weights)`. Return `sum(metric_scores[k] * weights[k] for k in weights) / sum(weights.values())` -- a weighted average, normalized so the weights don't need to sum to 1 themselves.
