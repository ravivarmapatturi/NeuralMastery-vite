# #731. Classical Momentum Gradient Descent Step

**Track**: Mathematics & Numerical Computing | **Rank**: #731 of 1072 | **Points**: 60 XP

## Overview

Implement a single parameter update under Polyak momentum acceleration.

## Task

Implement `momentum_gd_step(w, grad, v, lr=0.01, beta=0.9)`: compute `v_next = beta * v + lr * grad` and `w_next = w - v_next`. Return `{"w": list[float], "v": list[float]}` rounded to 4 decimals.

<PracticePlayground problemId="math-num-prob-21" />

<Solution>

```python
def momentum_gd_step(w, grad, v, lr=0.01, beta=0.9):
    v_next = [beta * vi + lr * gi for vi, gi in zip(v, grad)]
    w_next = [wi - v_ni for wi, v_ni in zip(w, v_next)]
    return {'w': [round(float(x), 4) for x in w_next], 'v': [round(float(x), 4) for x in v_next]}
```

Evaluates Polyak heavy-ball recurrence for velocity and parameter updates.
