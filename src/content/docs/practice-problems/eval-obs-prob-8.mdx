# Compute Distributed Trace Span Duration

**Track**: Agent Evaluation & Observability | **Points**: 40 XP

## Overview

Implement trace-span duration calculation, the basic real building block of any observability trace visualization for an agent's multi-step execution.

## Task

Implement `span_duration_ms(start_ts, end_ts)` where both timestamps are in seconds: return `(end_ts - start_ts) * 1000` (converted to milliseconds).
