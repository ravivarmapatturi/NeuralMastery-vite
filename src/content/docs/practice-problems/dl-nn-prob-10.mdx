# #870. Categorical Cross-Entropy Loss

**Track**: Deep Learning & Neural Networks | **Rank**: #870 of 1072 | **Points**: 40 XP

## Overview

Calculate negative log-likelihood loss for multi-class classification from predicted softmax probability distributions.

## Task

Implement `categorical_cross_entropy(probs, targets, eps=1e-12)`: for each sample `i`, retrieve the predicted probability `p = max(probs[i][targets[i]], eps)` for ground truth class index `targets[i]`. The sample loss is `-log(p)`. Return the average loss across all `N` samples rounded to 4 decimal places.

<Solution>

```python
def categorical_cross_entropy(probs: list[list[float]], targets: list[int], eps: float = 1e-12) -> float:
    N = len(probs)
    total_loss = 0.0
    for i in range(N):
        c = targets[i]
        p = max(probs[i][c], eps)
        total_loss += -math.log(p)
    return round(total_loss / N, 4)
```

Because ground truth targets are one-hot, the cross-entropy collapses to the negative log-probability of the true target class.
