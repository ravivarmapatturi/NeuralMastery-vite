# #880. Swish / SiLU Activation Forward Pass

**Track**: Deep Learning & Neural Networks | **Rank**: #880 of 1072 | **Points**: 60 XP

## Overview

Compute the smooth, non-monotonic Swish/SiLU activation function popularized by Ramachandran et al. and used extensively in EfficientNet and LLaMA.

## Task

Implement `swish_forward(x, beta=1.0)`: for each scalar `v` in matrix `x`, compute `v * (1 / (1 + exp(-beta * v)))`. Round each resulting value to 4 decimal places.

<PracticePlayground problemId="dl-nn-prob-20" />

<Solution>

```python
def swish_forward(x: list[list[float]], beta: float = 1.0) -> list[list[float]]:
    out = []
    for row in x:
        r = []
        for v in row:
            sig = 1.0 / (1.0 + math.exp(-beta * v))
            y = v * sig
            r.append(round(float(y), 4))
        out.append(r)
    return out
```

Swish interpolates between the identity (when beta approaches 0) and ReLU (when beta approaches infinity), with beta=1 producing the standard SiLU function.
