# Vickrey Second-Price Auction

**Track**: Multi-Agent Systems | **Points**: 40 XP

## Overview

Implement a Vickrey (second-price) auction, a real mechanism-design pattern used in multi-agent resource allocation where truthful bidding is the dominant strategy.

## Task

Implement `second_price_auction(bids)`. The winner is the agent with the HIGHEST bid (ties broken by agent id ascending), but they pay the SECOND-highest bid value. Return `(winner_id, price_paid)`.
