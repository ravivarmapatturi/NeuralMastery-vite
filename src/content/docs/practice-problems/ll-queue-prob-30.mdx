# #590. Linked Lists / Stacks / Queues Module 6: Problem 30

## Overview

Track sliding window maximum values in strict O(n) linear time using a monotonic double-ended queue (deque).

## Task

Implement `sliding_window_max_queue(nums, k)`: compute the maximum element in every continuous window of length `k` as it slides across `nums`. Must achieve O(n) overall runtime using a monotonic deque.

<Solution>

```python
from collections import deque

def sliding_window_max_queue(nums, k):
    if not nums or k <= 0:
        return []
    deq = deque()
    res = []
    for i in range(len(nums)):
        if deq and deq[0] < i - k + 1:
            deq.popleft()
        while deq and nums[deq[-1]] < nums[i]:
            deq.pop()
        deq.append(i)
        if i >= k - 1:
            res.append(nums[deq[0]])
    return res
```

Each index is pushed and popped from the deque at most once, guaranteeing strict linear O(n) time.
