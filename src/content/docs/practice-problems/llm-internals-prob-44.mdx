# Standard LayerNorm Computation

**Track**: Transformers & LLMs | **Points**: 40 XP

## Overview

Implement standard LayerNorm, the original Transformer's real normalization layer, for direct comparison against RMSNorm's simplification.

## Task

Implement `layernorm(x, gamma, beta, eps)`. Compute `mean = mean(x)`, `var = mean((xi-mean)**2 for xi in x)`. Return `[(xi-mean)/sqrt(var+eps)*g + b for xi,g,b in zip(x,gamma,beta)]`.
