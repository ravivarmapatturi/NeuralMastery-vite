# Pandas Time-Series Resampling & Missing Gap Fill

**Rank #194** · Difficulty: **Easy** · Stage: **Stage 4: NumPy & Vectorized Data Processing** · Category: **NumPy & Pandas**

Standardize irregular sensor timestamps onto regular frequency intervals and fill gaps using Pandas. Prerequisite: `numpy-pandas-prob-13`.

```python
import pandas as pd

def resample_interpolate_timeseries(records, freq="1h", method="ffill"):
    if not records:
        return []
    df = pd.DataFrame(records)
    df["timestamp"] = pd.to_datetime(df["timestamp"])
    df = df.set_index("timestamp").sort_index()
    resampled = df.resample(freq).mean()
    if method == "ffill":
        resampled = resampled.ffill().bfill()
    elif method == "bfill":
        resampled = resampled.bfill().ffill()
    else:
        resampled = resampled.fillna(0.0)
    res = []
    for ts, row in resampled.iterrows():
        res.append({
            "timestamp": ts.strftime("%Y-%m-%d %H:%M:%S"),
            "value": round(float(row["value"]), 2)
        })
    return res
```

Pandas DatetimeIndex resampling aligns irregular asynchronous sensor measurements to equispaced grid intervals, imputing missing gaps via temporal forward/backward propagation.
