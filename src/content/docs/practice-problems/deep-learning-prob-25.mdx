# Luong Multiplicative Attention Score

**Track**: Deep Learning & Vision/NLP | **Points**: 40 XP

## Overview

Compute the general multiplicative attention alignment score score(s, h) = s^T * W_a * h.

## Task

Implement `luong_multiplicative_attention(decoder_hidden, encoder_hidden, W_a)`. Given decoder state vector `s` of length `d_dec`, encoder state vector `h` of length `d_enc`, and weight matrix `W_a` of shape `d_dec x d_enc`, compute the bilinear product `s^T * W_a * h`. Return the scalar rounded to 4 decimal places.
