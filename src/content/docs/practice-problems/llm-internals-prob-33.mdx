# Sliding Window Causal Attention Mask

**Track**: transformers-llms | **Points**: 40 XP

## Overview

Construct a sliding window causal attention mask matrix used in long-context models like Mistral.

## Task

Implement `sliding_window_mask(seq_len, window_size)`. Return a 2D integer matrix of size `seq_len x seq_len` where position `(i, j)` is `1` if `j <= i` and `(i - j) < window_size`, and `0` otherwise. Raise `ValueError` if `seq_len <= 0` or `window_size <= 0`.
