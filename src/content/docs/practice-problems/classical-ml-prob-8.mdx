# User-Item Jaccard Similarity

**Rank #248** · Difficulty: **Easy** · Stage: **Stage 5: Classical Machine Learning & Optimization** · Category: **Clustering / Recommenders** | **Points**: 40 XP

## Overview

Implement `user_jaccard_similarity(user_a_items, user_b_items)`, computing the Jaccard similarity coefficient between two users' binary interaction lists -- a core primitive in implicit-feedback recommender systems.

## Task

Implement `user_jaccard_similarity(user_a_items, user_b_items)`: convert item lists into sets, computing the ratio of intersection size to union size. Handle empty edge cases cleanly (1.0 if both empty, 0.0 if one empty).

<PracticePlayground problemId="classical-ml-prob-8" />

<Solution>

```python
def user_jaccard_similarity(user_a_items, user_b_items):
    sa = set(user_a_items)
    sb = set(user_b_items)
    union = sa | sb
    if not union:
        return 1.0
    inter = sa & sb
    return round(len(inter) / len(union), 6)
```

Jaccard similarity measures overlap of implicit binary feedback (clicks, purchases, views) without needing explicit rating scales.
