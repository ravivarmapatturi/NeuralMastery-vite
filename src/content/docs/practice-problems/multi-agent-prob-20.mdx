# Last-Writer-Wins State Sync Merge

**Track**: Multi-Agent Systems | **Points**: 40 XP

## Overview

Implement last-writer-wins state merging, a real, simple conflict-resolution strategy for synchronizing two agents' independently-updated shared state.

## Task

Implement `merge_agent_states(state_a, timestamp_a, state_b, timestamp_b)`. Merge the two dicts key by key. For a key present in only one, keep that value. For a key in BOTH, keep the value from whichever state has the LATER (larger) timestamp.
