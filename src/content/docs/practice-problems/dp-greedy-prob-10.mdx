# #660. Dynamic Programming & Greedy Module 2: Problem 10

**Track**: Dynamic Programming & Greedy | **Rank**: #660 of 1072 | **Points**

## Overview

Maximize unit capacity on a truck using greedy fractional knapsack ordering.

## Task

Implement `maximum_units_on_truck(boxTypes, truckSize)`: sort boxTypes descending by units per box. Greedily load boxes of highest unit density until truckSize is filled.

<PracticePlayground problemId="dp-greedy-prob-10" />

<Solution>

```python
def maximum_units_on_truck(boxTypes, truckSize):
    boxTypes.sort(key=lambda x: x[1], reverse=True)
    total_units = 0
    remaining = truckSize
    for count, units in boxTypes:
        take = min(count, remaining)
        total_units += take * units
        remaining -= take
        if remaining == 0:
            break
    return total_units
```

Sort boxes by units descending. At each step, take as many boxes of the highest remaining unit value as will fit in the truck.
