# Detect Unreachable Nodes From Entry

**Track**: Agent Graph Engineering | **Points**: 40 XP

## Overview

Implement unreachable-node detection via BFS/DFS from the entry point, a real structural validation check catching dead code in an agent graph definition.

## Task

Implement `find_unreachable_nodes(edges, entry_node)`. Return the sorted list of node names that CANNOT be reached from `entry_node` by following edges. All keys of `edges` are candidate nodes.
