# Lost-in-the-Middle: Flag Answer-Position Risk

**Track**: Advanced RAG & Agentic RAG | **Points**: 40 XP

## Overview

Implement a real, simple 'lost in the middle' risk flag, based on published research showing LLMs attend less reliably to information placed in the MIDDLE of a long context versus the beginning or end.

## Task

Implement `position_risk_flag(answer_chunk_index, total_chunks)`. Compute the relative position `answer_chunk_index / (total_chunks - 1)` if `total_chunks > 1` else `0.0`. Return `'low_risk'` if relative position `<= 0.15` or `>= 0.85` (near the start or end); otherwise return `'high_risk'` (in the middle).
