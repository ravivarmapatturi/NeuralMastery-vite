# Pandas Module 35: Problem 215

**Rank #215** · Difficulty: **Medium** · Stage: **Stage 4: NumPy & Vectorized Data Processing** · Category: **NumPy & Pandas**

## Overview

Score recency-weighted user engagement using exponential half-life decay.

## Task

Implement `exponential_decay_activity(events, half_life_seconds, current_time)`: each event has `user_id`, `timestamp`, and optional `weight` (default 1.0). Each event contributes `weight * 2 ** (-(current_time - timestamp) / half_life_seconds)`. Return dict of total decayed scores per user, rounded to 4 decimal places.

<Solution>

```python
from collections import defaultdict

def exponential_decay_activity(events, half_life_seconds, current_time):
    scores = defaultdict(float)
    for ev in events:
        uid = ev["user_id"]
        ts = ev["timestamp"]
        wt = ev.get("weight", 1.0)
        dt = current_time - ts
        decay = 2.0 ** (-dt / half_life_seconds)
        scores[uid] += wt * decay
    return {k: round(v, 4) for k, v in sorted(scores.items())}
```

Half-life decay provides continuous temporal weighting where activity value halves after every elapsed half-life window.
