# #671. Dynamic Programming & Greedy Module 5: Problem 21

**Track**: Dynamic Programming & Greedy | **Rank**: #671 of 1072 | **Points**

## Overview

Count valid alphabetic decodings of a numeric digit string using Fibonacci-like 1D dynamic programming.

## Task

Implement `num_decodings(s)`: dp[i] depends on valid single-digit decodings (s[i] != "0") and valid two-digit decodings (`"10" <= s[i-1:i+1] <= "26"`).

<PracticePlayground problemId="dp-greedy-prob-21" />

<Solution>

```python
def num_decodings(s):
    if not s or s[0] == '0':
        return 0
    n = len(s)
    dp0, dp1 = 1, 1
    for i in range(1, n):
        curr = 0
        if s[i] != '0':
            curr += dp1
        two_digit = int(s[i-1:i+1])
        if 10 <= two_digit <= 26:
            curr += dp0
        dp0, dp1 = dp1, curr
    return dp1
```

Track decode counts using two rolling variables. At each index, add contributions from valid 1-digit characters (1-9) and valid 2-digit characters (10-26).
