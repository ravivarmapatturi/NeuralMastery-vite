# #009. Transformer Internals Module 2: Problem 9

**Track**: Transformer Internals | **Rank**: #9 of 1072 | **Points**: 40 XP

## Overview

Apply causal attention masking to a matrix of raw attention logits. In autoregressive decoders, causal masking prevents tokens from attending to subsequent future positions by setting attention weights to 0.0 for all `j > i`.

## Task

Implement `causal_attention_weights(scores)`: for an `N x N` attention score matrix, mask all future positions `j > i` with `-inf`, then apply softmax along each row so that masked positions receive an attention weight of `0.0` and valid prior positions sum to `1.0`. Return probabilities rounded to 4 decimal places.
