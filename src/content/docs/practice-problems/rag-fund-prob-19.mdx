# #199. Semantic Chunking Engine

**Track**: RAG Fundamentals | **Rank**: #199 of 1072 | **Points**: 60 XP

## Overview

Split documents dynamically at natural semantic transitions rather than arbitrary character lengths.

## Task

Implement `semantic_chunking_engine(sentences, sentence_embeddings, similarity_threshold=0.75)`. Raise `ValueError` if `len(sentences) != len(sentence_embeddings)`. If `sentences` is empty, return `[]`. Compute cosine similarity between each consecutive pair of sentence embeddings `(i, i+1)`. If `cosine_sim < similarity_threshold`, split and begin a new chunk. Return the list of chunks, where each chunk is a list of its sentences.
