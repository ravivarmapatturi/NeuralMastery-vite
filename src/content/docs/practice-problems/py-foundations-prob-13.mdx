# Deep Merge Nested Dictionaries

**Rank #13** · Difficulty: **Easy** · Stage: **Stage 1: AI Foundations & Python Programming** · Category: **Python & Fundamentals** | **Points**: 40 XP

## Overview

Implement `deep_merge_dicts(base, update)`: recursively merge nested configuration structures without mutating the original dictionary objects.

## Task

Implement the function `deep_merge_dicts(base, update)`: return a new dictionary with `update` merged into `base`. When both `base` and `update` contain a dictionary at the same key, merge them recursively; otherwise, use `update`'s value.

<PracticePlayground problemId="py-foundations-prob-13" />

<Solution>

```python
def deep_merge_dicts(base, update):
    result = dict(base)
    for k, v in update.items():
        if k in result and isinstance(result[k], dict) and isinstance(v, dict):
            result[k] = deep_merge_dicts(result[k], v)
        else:
            result[k] = v
    return result
```

Deep merging allows software systems to define base default configurations and let users supply minimal override deltas without duplicating the whole tree.

</Solution>
