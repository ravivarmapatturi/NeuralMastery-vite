# Graphs: Flood Fill

**Rank #68** · Difficulty: **Easy** · Stage: **Stage 2: Data Structures & Algorithmic Foundations** · Category: **Data Structures & Algorithms**

## Overview

Implement `flood_fill(image, sr, sc, color)` -- the paint-bucket algorithm, a direct application of DFS/BFS on a 2D grid.

## Task

Implement the function `flood_fill(image, sr, sc, color)`. Starting from `(sr, sc)`, recolor all 4-directionally connected cells with the original starting color to `color`. Return the modified image.

<PracticePlayground problemId="ds-algo-prob-8" />

<Solution>

```python
import copy

def flood_fill(image, sr, sc, color):
    orig = image[sr][sc]
    if orig == color:
        return image
    img = copy.deepcopy(image)
    rows, cols = len(img), len(img[0])

    def dfs(r, c):
        if r < 0 or r >= rows or c < 0 or c >= cols or img[r][c] != orig:
            return
        img[r][c] = color
        dfs(r+1,c); dfs(r-1,c); dfs(r,c+1); dfs(r,c-1)

    dfs(sr, sc)
    return img
```

Early-exit when `orig == color` prevents infinite recursion. DFS marks each cell before recursing to avoid revisiting. O(m*n) time, O(m*n) recursion stack.

</Solution>
