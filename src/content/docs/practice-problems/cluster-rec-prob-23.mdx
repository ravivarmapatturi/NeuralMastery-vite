# Adjusted Rand Index Between Two Clusterings

**Track**: Clustering & Recommender Systems | **Points**: 40 XP

## Overview

Implement the Adjusted Rand Index, the standard chance-corrected metric for comparing two clusterings (or a clustering against ground truth).

## Task

Implement `adjusted_rand_index(labels_a, labels_b)` using the real contingency-table formula: build `n_ij` = count of points with label `i` in `labels_a` AND label `j` in `labels_b`; `a_i` = row sums, `b_j` = column sums, `n` = total points. `index = sum(C(n_ij,2))`, `expected = sum(C(a_i,2))*sum(C(b_j,2)) / C(n,2)`, `max_index = 0.5*(sum(C(a_i,2)) + sum(C(b_j,2)))`, where `C(x,2) = x*(x-1)/2`. Return `(index - expected) / (max_index - expected)`. If `max_index == expected`, return `1.0`.
