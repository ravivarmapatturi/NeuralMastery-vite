## Overview

Dissect classifier predictions into true/false positive and negative quadrants.

## Task

Implement `confusion_matrix_binary(y_true, y_pred)`: count occurrences of TP (1,1), FP (0,1), TN (0,0), and FN (1,0).

<PracticePlayground problemId="class-ml-prob-5" />

<Solution>

```python
def confusion_matrix_binary(y_true, y_pred):
    tp, fp, tn, fn = 0, 0, 0, 0
    for yt, yp in zip(y_true, y_pred):
        if yt == 1 and yp == 1:
            tp += 1
        elif yt == 0 and yp == 1:
            fp += 1
        elif yt == 0 and yp == 0:
            tn += 1
        else:
            fn += 1
    return {'tp': tp, 'fp': fp, 'tn': tn, 'fn': fn}
```

Iterate through matched label pairs, incrementing the corresponding quadrant count based on true and predicted values.
