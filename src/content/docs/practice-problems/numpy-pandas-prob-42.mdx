# Streaming systems Module 42: Problem 222

**Rank #222** · Difficulty: **Medium** · Stage: **Stage 4: NumPy & Vectorized Data Processing** · Category: **NumPy & Pandas**

## Overview

Track the running median over a fixed-length sliding window in a real-time data stream.

## Task

Implement `sliding_window_median(stream, window_size)`: for each window of length `window_size` ending at index `i` (for `i >= window_size - 1`), compute the median of the current window. For even window size, average the two middle values. Round each median to 4 decimal places.

<Solution>

```python
def sliding_window_median(stream, window_size):
    if not stream or window_size <= 0:
        return []
    res = []
    for i in range(window_size - 1, len(stream)):
        win = sorted(stream[i - window_size + 1 : i + 1])
        mid = len(win) // 2
        if len(win) % 2 == 1:
            med = win[mid]
        else:
            med = (win[mid - 1] + win[mid]) / 2.0
        res.append(round(float(med), 4))
    return res
```

Rolling medians filter out impulse noise and spikes in streaming sensor telemetry much more robustly than moving averages.
