# #576. Linked Lists / Stacks / Queues Module 4: Problem 16

**Track**: Linked Lists / Stacks / Queues | **Rank**: #576 of 1072 | **Points**: 60 XP

## Overview

Implement Next Greater Element with a monotonic (decreasing) stack -- computing "next greater to the right" for every element in a single O(n) pass, rather than an O(n^2) scan per element.

## Task

Implement the function `next_greater_element(nums1, nums2)`: for each value in `nums1`, find the first strictly-greater value to its right in `nums2`, or `-1` if none exists.
