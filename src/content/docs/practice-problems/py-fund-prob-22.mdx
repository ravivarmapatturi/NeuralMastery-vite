## Overview

Implement modular alphabetic rotational encryption preserving letter case and non-alphabetic characters.

## Task

Implement `string_character_offset_cipher(text, shift)`: shift every alphabetic letter in `text` by `shift` places along the alphabet, wrapping circularly around 26 letters. Preserves uppercase and lowercase casing. Non-alphabetic characters (digits, spaces, punctuation) remain unchanged.

<Solution>

```python
def string_character_offset_cipher(text, shift):
    res = []
    shift = shift % 26
    for ch in text:
        if ch.isupper():
            res.append(chr((ord(ch) - ord('A') + shift) % 26 + ord('A')))
        elif ch.islower():
            res.append(chr((ord(ch) - ord('a') + shift) % 26 + ord('a')))
        else:
            res.append(ch)
    return "".join(res)
```

Modular arithmetic with base offsets ord("A") and ord("a") wraps characters within their alphabet boundaries.
