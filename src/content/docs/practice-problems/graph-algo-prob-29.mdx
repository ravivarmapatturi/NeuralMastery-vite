## Overview

Determine the maximum cardinality matching in a bipartite graph using augmenting path DFS.

## Task

Implement `max_bipartite_matching(u_count, v_count, edges)`: maintain `match_v` array. For each vertex in partition U, search for an augmenting path using DFS, flipping matching assignments.

```python
from collections import defaultdict

def max_bipartite_matching(u_count, v_count, edges):
    adj = defaultdict(list)
    for u, v in edges:
        adj[u].append(v)
    match_v = [-1] * v_count
    def dfs(u, visited):
        for v in adj[u]:
            if not visited[v]:
                visited[v] = True
                if match_v[v] == -1 or dfs(match_v[v], visited):
                    match_v[v] = u
                    return True
        return False
    matches = 0
    for u in range(u_count):
        visited = [False] * v_count
        if dfs(u, visited):
            matches += 1
    return matches
```

Search for augmenting paths from each unmatched vertex in partition U. Finding an alternating chain re-pairs intermediate matches, expanding total matching cardinality.
