# #984. Vector Search & Index Optimization Module 2: Problem 9

**Track**: Vector Search & Index Optimization | **Rank**: #984 of 1072 | **Points**: 60 XP

## Overview

Implement `scalar_quantize(vector, num_bits)`, the memory-compression technique real vector databases (Qdrant, Milvus, FAISS's `ScalarQuantizer`) use to shrink float32 embeddings down to 8-bit (or fewer) integer codes so billions of vectors fit in RAM.

## Task

Implement the function `scalar_quantize(vector, num_bits)`: linearly map each float in `vector` from `[min(vector), max(vector)]` onto integer codes in `[0, 2**num_bits - 1]`, rounding to the nearest code. Raise `ValueError` if `num_bits <= 0`. If every element is identical (zero range), return all-zero codes instead of dividing by zero.
