# #797. Within-Group Transform Standardization and Rank

**Track**: Pandas & Data Processing Pipelines | **Rank**: #797 of 1072 | **Points**: 90 XP

## Overview

Compute group-relative standardized z-scores and ordinal ranks without collapsing the dataset row count.

## Task

Implement `transform_group_standardization(records, group_col, target_col)`: for each group in `group_col`, compute group mean and population standard deviation `sigma = sqrt(sum((x - mean)^2) / count)`. Assign `z_score = (val - mean) / sigma` (or `0.0` if sigma `<` 1e-12). Compute 1-indexed dense rank within the group (smallest value has rank 1). Return records in original order with new fields `z_score` (rounded to 4 decimals) and `group_rank`.

```python
import math
from collections import defaultdict

def transform_group_standardization(records, group_col, target_col):
    groups = defaultdict(list)
    for idx, r in enumerate(records):
        groups[r[group_col]].append((float(r[target_col]), idx))
    z_scores = [0.0] * len(records)
    ranks = [1] * len(records)
    for g, items in groups.items():
        vals = [it[0] for it in items]
        mean = sum(vals) / len(vals)
        std = math.sqrt(sum((x - mean)**2 for x in vals) / len(vals))
        val_to_rank = {v: rk + 1 for rk, v in enumerate(sorted(list(set(vals))))}
        for val, idx in items:
            z_scores[idx] = round(float((val - mean) / std if std > 1e-12 else 0.0), 4)
            ranks[idx] = val_to_rank[val]
    out = []
    for i, r in enumerate(records):
        row = dict(r)
        row['z_score'] = z_scores[i]
        row['group_rank'] = ranks[i]
        out.append(row)
    return out
```

Evaluates group-level mean, variance, and rank distributions and joins results back to each sample.
