# Classical ML Module 57: Problem 297

**Rank #297** · Difficulty: **Hard** · Stage: **Stage 5: Classical Machine Learning & Optimization** · Category: **Classical ML**

## Overview

Accelerate gradient descent trajectories using Polyak heavy-ball momentum.

## Task

Implement `sgd_momentum_step(weights, velocity, gradients, lr, momentum)`: update velocity as `v_next = momentum * v + lr * grad` and weights as `w_next = w - v_next`. Return dict with updated `"weights"` and `"velocity"`, rounded to 4 decimal places.

<PracticePlayground problemId="classical-ml-prob-57" />

<Solution>

```python
def sgd_momentum_step(weights, velocity, gradients, lr, momentum):
    new_v = []
    new_w = []
    for w, v, g in zip(weights, velocity, gradients):
        v_next = momentum * v + lr * g
        w_next = w - v_next
        new_v.append(round(float(v_next), 4))
        new_w.append(round(float(w_next), 4))
    return {"weights": new_w, "velocity": new_v}
```

Momentum dampens oscillations along high-curvature ravines while accelerating progress down consistent gradient directions.
