# #193. Contextual Compression Retriever

**Track**: RAG Fundamentals | **Rank**: #193 of 1072 | **Points**: 60 XP

## Overview

Strip conversational fluff and extraneous context to pack dense, relevant evidence into prompt windows.

## Task

Implement `contextual_compression_retriever(query, documents, min_relevance=0.5)`. For each document, segment `text` into sentences using sentence punctuation boundaries (`.`, `!`, `?`). For each sentence, compute its query keyword overlap ratio `len(query_words & sentence_words) / len(query_words)`. Retain only sentences where this ratio is `>= min_relevance`. If any sentences are retained, join them with spaces and record `{"id": doc_id, "compressed_text": joined_text, "retained_count": len(retained)}`. Discard documents with zero retained sentences.
