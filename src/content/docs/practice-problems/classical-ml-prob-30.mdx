# Clustering Module 30: Problem 270

**Rank #270** · Difficulty: **Medium** · Stage: **Stage 5: Classical Machine Learning & Optimization** · Category: **Classical ML**

## Overview

Evaluate the reconstruction sum of squared errors over observed rating matrix entries.

## Task

Implement `matrix_factorization_error(r_matrix, p_matrix, q_matrix)`: compute `sum((R[i][j] - dot(P[i], Q[j]))**2)` only over pairs `(i, j)` where `R[i][j] is not None`. `P` is of shape (N, K) and `Q` is of shape (M, K). Round result to 4 decimal places.

<Solution>

```python
def matrix_factorization_error(r_matrix, p_matrix, q_matrix):
    total_err = 0.0
    n = len(r_matrix)
    m = len(r_matrix[0])
    for i in range(n):
        for j in range(m):
            val = r_matrix[i][j]
            if val is not None:
                pred = sum(p_matrix[i][k] * q_matrix[j][k] for k in range(len(p_matrix[0])))
                total_err += (val - pred) ** 2
    return round(float(total_err), 4)
```
