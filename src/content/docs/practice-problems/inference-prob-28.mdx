# #058. INT8 Symmetric KV Cache Quantizer

**Track**: LLM Inference & Decoding | **Rank**: #58 of 1072 | **Points**: 90 XP

## Overview

Halve KV cache memory footprint using per-vector symmetric INT8 quantization. Autoregressive language models generate sequences token by token, evaluating next-token probability distributions at each decoding step.

## Task

Implement `quantize_kv_vector_int8(vector)`. Compute `M = \max_{x} |x|`. If `M == 0`, set `scale = 1.0`, `quantized = [0] * len(vector)`, and `mse = 0.0`. Otherwise, `\text{scale} = M / 127.0`. For each element, quantized integer is `q_i = \text{clamp}(\text{round}(x_i / \text{scale}), -127, 127)`. Dequantized value is `\hat{x}_i = q_i \times \text{scale}`. Compute Mean Squared Error `\text{MSE} = \frac{1}{N} \sum (x_i - \hat{x}_i)^2`. Return dict with `scale`, `quantized`, `dequantized`, and `mse` (floats rounded to 6 decimal places). If `vector` is empty, raise `ValueError`.
