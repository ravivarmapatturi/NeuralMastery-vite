# #012. Transformer Internals Module 3: Problem 12

**Track**: Transformer Internals | **Rank**: #12 of 1072 | **Points**: 60 XP

## Overview

Perform token embedding table lookups for an input sequence of token IDs. In transformer architectures, the embedding matrix maps discrete vocabulary indices into continuous dense vector representations.

## Task

Implement `token_embedding(token_ids, embedding_table)`: for each integer in `token_ids`, retrieve the corresponding row from `embedding_table`. Return the list of embedding vectors. If any token ID is negative or `>= len(embedding_table)`, raise `ValueError` or `IndexError`.
