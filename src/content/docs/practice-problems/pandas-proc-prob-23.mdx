# #793. Markov Navigation State Transition Matrix

**Track**: Pandas & Data Processing Pipelines | **Rank**: #793 of 1072 | **Points**: 90 XP

## Overview

Estimate discrete-time first-order Markov transition probabilities from sequential user session logs.

## Task

Implement `build_markov_transition_matrix(sequences)`: count bigram transitions `(s_from, s_to)` across all sequences. For each state `s_from`, normalize transition counts by total outgoing transitions to form probability distribution over all unique states. If a state has no outgoing transitions, probabilities are 0.0. Return nested dict `{s_from: {s_to: prob}}` sorted by state names with probabilities rounded to 4 decimals.

```python
from collections import defaultdict

def build_markov_transition_matrix(sequences):
    counts = defaultdict(lambda: defaultdict(int))
    states = set()
    for seq in sequences:
        for i in range(len(seq) - 1):
            counts[seq[i]][seq[i+1]] += 1
            states.add(seq[i])
            states.add(seq[i+1])
    sorted_states = sorted(list(states))
    mat = {}
    for sf in sorted_states:
        tot = sum(counts[sf].values())
        mat[sf] = {st: round(float(counts[sf][st] / tot if tot else 0.0), 4) for st in sorted_states}
    return mat
```

Tallies bigram state transitions and computes row-wise conditional probabilities.
