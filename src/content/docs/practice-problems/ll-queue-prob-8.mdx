# #568. Linked Lists / Stacks / Queues Module 2: Problem 8

**Track**: Linked Lists / Stacks / Queues | **Rank**: #568 of 1072 | **Points**

## Overview

Deduplicate adjacent elements in sorted singly linked lists in O(1) auxiliary memory.

## Task

Implement `delete_duplicates_sorted(head)`: delete duplicate values from a sorted singly linked list so that each element appears exactly once. Return the list head.

<PracticePlayground problemId="ll-queue-prob-8" />

<Solution>

```python
def delete_duplicates_sorted(head):
    curr = head
    while curr and curr.get('next'):
        if curr['val'] == curr['next']['val']:
            curr['next'] = curr['next']['next']
        else:
            curr = curr['next']
    return head
```

Skipping redundant adjacent nodes in-place retains distinct elements in a single linear sweep.
