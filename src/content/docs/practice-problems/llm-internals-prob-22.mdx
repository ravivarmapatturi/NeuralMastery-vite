# Attention Distribution Entropy

**Track**: transformers-llms | **Points**: 40 XP

## Overview

Compute the Shannon entropy of an attention weight distribution to measure how focused vs. diffuse the attention pattern is.

## Task

Implement `attention_entropy(attn_weights)` that computes Shannon entropy `H = -sum(p * log(p + eps))` over a list of attention weights, with `eps = 1e-9` to avoid `log(0)`. Return `abs(result)` rounded to 4 decimal places. Raise `ValueError` if `attn_weights` is empty.
