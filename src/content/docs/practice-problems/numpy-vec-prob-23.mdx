# #763. Vectorized Layer Normalization with Learnable Affine

**Track**: NumPy & Vectorized Computation | **Rank**: #763 of 1072 | **Points**: 90 XP

## Overview

Normalize activations across feature dimensions per sample with learnable scale and bias.

## Task

Implement `layer_norm(features, gamma, beta, eps)`: for each sample row `x` of dimension `D`, compute mean `mu = sum(x) / D` and variance `sigma^2 = sum((x - mu)^2) / D`. Standardize and apply affine transform `y = ((x - mu) / sqrt(sigma^2 + eps)) * gamma + beta`. Round each element to 4 decimals.

<Solution>

```python
import math

def layer_norm(features, gamma, beta, eps=1e-5):
    out = []
    for row in features:
        D = len(row)
        mu = sum(row) / D
        var = sum((x - mu) ** 2 for x in row) / D
        denom = math.sqrt(var + eps)
        normed = [round(float(((x - mu) / denom) * g + b), 4) for x, g, b in zip(row, gamma, beta)]
        out.append(normed)
    return out
```

Computes mean and variance across feature axis, scales by inverse standard deviation, and applies affine parameters.
