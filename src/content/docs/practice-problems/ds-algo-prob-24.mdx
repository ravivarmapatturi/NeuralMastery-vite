# DP: Unique Paths

**Rank #84** · Difficulty: **Medium** · Stage: **Stage 2: Data Structures & Algorithmic Foundations** · Category: **Data Structures & Algorithms**

## Overview

Implement `unique_paths(m, n)` -- a 2-D DP problem where dp[i][j] = dp[i-1][j] + dp[i][j-1]. The mathematical answer is C(m+n-2, m-1) but DP generalizes to obstacles.

## Task

Implement the function `unique_paths(m, n)`. Return the number of unique paths from the top-left to the bottom-right of an `m x n` grid, moving only right or down.

<PracticePlayground problemId="ds-algo-prob-24" />

<Solution>

```python
def unique_paths(m, n):
    dp = [[1] * n for _ in range(m)]
    for i in range(1, m):
        for j in range(1, n):
            dp[i][j] = dp[i-1][j] + dp[i][j-1]
    return dp[m-1][n-1]
```

2-D DP: first row and column are all 1s (only one way to reach them). Fill remaining cells as sum of cell above and cell to the left. O(m*n) time, reducible to O(n) space.

</Solution>
