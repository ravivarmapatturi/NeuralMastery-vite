# Render an MCP Prompt Template

**Rank #461** · Difficulty: **Easy** · Stage: **Stage 8: RAG, Agents, MCP & Distributed Systems** · Category: **Agents, MCP & Systems**

Implement `render_mcp_prompt(template, arguments)`, substituting `{{variable}}` placeholders with real argument values -- the rendering step behind MCP "prompts," the third core MCP primitive alongside tools and resources. Prerequisite: `agents-mcp-systems-prob-30`.

<PracticePlayground problemId="agents-mcp-systems-prob-31" />

<Solution>

```python
import re

def render_mcp_prompt(template, arguments):
    def repl(m):
        key = m.group(1)
        if key not in arguments:
            raise ValueError(f"missing required argument: {key!r}")
        return str(arguments[key])
    return re.sub(r"\{\{(\w+)\}\}", repl, template)
```

MCP prompts exist precisely because a raw prompt string checked into a server's code is not reusable across contexts -- the server declares named arguments, and the client (or the user, via an MCP-aware UI) supplies real values at call time, exactly like this rendering step.

</Solution>
