# Bounded Producer-Consumer Queue Simulator

**Rank #53** · Difficulty: **Hard** · Stage: **Stage 1: AI Foundations & Python Programming** · Category: **Python & Fundamentals**

## Overview

Simulate bounded producer-consumer FIFO queue mechanics with overflow backpressure and underflow detection.

## Task

Implement `simulate_producer_consumer(events, capacity)`: simulate a bounded queue. On `produce` event, if `len(queue) < capacity`, enqueue and log `"PRODUCED: <item>"`, else log `"DROPPED: <item>"`. On `consume` event, if queue is empty, log `"UNDERFLOW"`, else dequeue and log `"CONSUMED: <item>"`. Return the list of logged strings.

<Solution>

```python
from collections import deque

def simulate_producer_consumer(events, capacity):
    queue = deque()
    log = []
    for ev in events:
        action = ev.get('type')
        if action == 'produce':
            item = ev.get('item')
            if len(queue) >= capacity:
                log.append(f"DROPPED: {item}")
            else:
                queue.append(item)
                log.append(f"PRODUCED: {item}")
        elif action == 'consume':
            if not queue:
                log.append("UNDERFLOW")
            else:
                item = queue.popleft()
                log.append(f"CONSUMED: {item}")
    return log
```

Using double-ended queues maintains strict FIFO ordering with constant-time push and pull operations.
