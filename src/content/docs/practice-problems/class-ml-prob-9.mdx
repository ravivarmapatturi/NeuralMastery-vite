## Overview

Convert categorical string variables into indicator vectors ordered lexicographically.

## Task

Implement `one_hot_encode(labels)`: sort unique category labels alphabetically. Create a binary vector for each item with 1 at the matching category index and 0 elsewhere.

<PracticePlayground problemId="class-ml-prob-9" />

<Solution>

```python
def one_hot_encode(labels):
    unique = sorted(list(set(labels)))
    mapping = {cat: idx for idx, cat in enumerate(unique)}
    res = []
    for lbl in labels:
        row = [0] * len(unique)
        row[mapping[lbl]] = 1
        res.append(row)
    return res
```

Sort distinct categories to ensure deterministic feature columns. For each input label, produce a one-hot vector with a 1 in its designated category index.
