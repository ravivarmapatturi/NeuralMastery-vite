# Tool Cost-Latency Tradeoff Selection

**Track**: MCP Advanced & Agent Integration | **Points**: 40 XP

## Overview

Implement a real cost-latency tradeoff selection, picking the cheapest tool variant among several that all satisfy a hard latency requirement (e.g. a fast expensive API vs. a slow cheap one).

## Task

Implement `select_cheapest_within_latency(tool_options, max_latency_ms)`. `tool_options` is a list of `{"name": str, "cost": float, "latency_ms": float}`. Among options with `latency_ms <= max_latency_ms`, return the name of the one with the LOWEST cost (ties broken by name ascending). If none satisfy the latency constraint, return `''`.
