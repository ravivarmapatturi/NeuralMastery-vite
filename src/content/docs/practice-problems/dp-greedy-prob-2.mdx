# #652. Dynamic Programming & Greedy Module 1: Problem 2

**Track**: Dynamic Programming & Greedy | **Rank**: #652 of 1072 | **Points**

## Overview

Compute the N-th Tribonacci number efficiently using constant space iteration.

## Task

Implement `tribonacci(n)`: return T_n computed iteratively by sliding a 3-element rolling window across n steps.

<PracticePlayground problemId="dp-greedy-prob-2" />

<Solution>

```python
def tribonacci(n):
    if n == 0:
        return 0
    if n <= 2:
        return 1
    t0, t1, t2 = 0, 1, 1
    for _ in range(3, n + 1):
        t0, t1, t2 = t1, t2, t0 + t1 + t2
    return t2
```

Use three variables to store T(i-3), T(i-2), and T(i-1). Advance them one step per loop iteration in O(n) time and O(1) space.

</Solution>
