# #565. Linked Lists / Stacks / Queues Module 1: Problem 5

**Track**: Linked Lists / Stacks / Queues | **Rank**: #565 of 1072 | **Points**: 40 XP

## Overview

Implement a FIFO queue using only two LIFO stacks -- reversing a reversal gives back the original order, which is exactly what moving elements from an "in" stack to an "out" stack (only when the "out" stack runs dry) accomplishes.

## Task

Implement the function `run_queue_ops(ops, args)`: simulate a two-stack FIFO queue processing a sequence of `push`/`pop`/`peek` operations, returning one result per operation.
