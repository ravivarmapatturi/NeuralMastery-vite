# Verify RAG Citations and Token Overlap

Implement citation verification and lexical overlap scoring for evaluating hallucination rates in RAG generation systems. Prerequisite: `llm-internals-prob-13`.

<Solution>

```python
import re

def verify_citations(claims, source_documents):
    if not claims:
        return {"valid_citations_count": 0, "invalid_citations_count": 0, "avg_overlap_score": 0.0}
    valid_count = 0
    invalid_count = 0
    overlap_scores = []
    
    def tokenize(s):
        clean = re.sub(r'[^\w\s]', '', s.lower())
        return set(clean.split())
    
    for claim in claims:
        idx = claim.get("citation_index", -1)
        text = claim.get("text", "")
        if idx < 0 or idx >= len(source_documents):
            invalid_count += 1
            overlap_scores.append(0.0)
        else:
            valid_count += 1
            claim_words = tokenize(text)
            doc_words = tokenize(source_documents[idx])
            if not claim_words:
                overlap_scores.append(1.0)
            else:
                overlap = len(claim_words.intersection(doc_words)) / len(claim_words)
                overlap_scores.append(overlap)
                
    avg_score = round(sum(overlap_scores) / len(overlap_scores), 4) if overlap_scores else 0.0
    return {
        "valid_citations_count": valid_count,
        "invalid_citations_count": invalid_count,
        "avg_overlap_score": avg_score
    }
```

Verifying cited document indices and quantifying lexical overlap prevents hallucinated attribution in RAG systems where claims cite nonexistent chunks or fail to ground in source text.
