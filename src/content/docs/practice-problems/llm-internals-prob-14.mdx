# Verify RAG Citations and Token Overlap

**Track**: transformers-llms | **Points**: 40 XP

## Overview

Implement citation verification and lexical overlap scoring for evaluating hallucination rates in RAG generation systems.

## Task

Implement `verify_citations(claims, source_documents)`. For each claim, check whether its `citation_index` is valid. If valid, compute unique word overlap `len(claim_words & doc_words) / len(claim_words)`. Return summary metrics rounded to 4 decimal places.
