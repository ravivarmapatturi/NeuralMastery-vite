# Jailbreak Prompt Similarity Score

**Track**: Agent Security & Reliability | **Points**: 40 XP

## Overview

Implement a real, simple jailbreak-pattern similarity scorer, flagging a user prompt that closely resembles a known jailbreak template.

## Task

Implement `jailbreak_similarity(prompt, known_jailbreak_patterns)`. For each known pattern, compute word-set Jaccard similarity against `prompt` (both lowercased). Return the MAXIMUM similarity found across all patterns. Return `0.0` if `known_jailbreak_patterns` is empty.
