# Classify Action Reversibility

**Track**: Agent Security & Reliability | **Points**: 40 XP

## Overview

Implement action-reversibility classification, a real, foundational input to any agent risk-gating policy (a reversible mistake is far less costly than an irreversible one).

## Task

Implement `classify_reversibility(action_type)`. Return `'reversible'` for `'create_draft'`, `'read'`, `'search'`. Return `'irreversible'` for `'delete'`, `'send_email'`, `'execute_payment'`. Return `'unknown'` for anything else.
