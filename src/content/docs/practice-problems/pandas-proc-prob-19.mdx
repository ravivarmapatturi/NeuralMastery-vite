# #789. Population Stability Index (PSI) Drift Detector

**Track**: Pandas & Data Processing Pipelines | **Rank**: #789 of 1072 | **Points**: 60 XP

## Overview

Monitor production feature distribution shift using the Population Stability Index.

## Task

Implement `compute_population_stability_index(ref_counts, prod_counts)`: convert bin counts into proportions `ref_pct` and `prod_pct` (clamped to min `1e-6` to avoid division by zero). Compute `PSI = sum((prod_pct - ref_pct) * ln(prod_pct / ref_pct))`. Set `drift_detected = True` if `PSI >= 0.25`. Return dict with `psi` rounded to 4 decimals and `drift_detected` boolean.

<Solution>

```python
import math

def compute_population_stability_index(ref_counts, prod_counts):
    tot_r = sum(ref_counts)
    tot_p = sum(prod_counts)
    eps = 1e-6
    psi = 0.0
    for rc, pc in zip(ref_counts, prod_counts):
        r = max(eps, rc / tot_r) if tot_r else eps
        p = max(eps, pc / tot_p) if tot_p else eps
        psi += (p - r) * math.log(p / r)
    return {'psi': round(float(psi), 4), 'drift_detected': psi >= 0.25}
```

Normalizes frequencies and sums symmetric relative entropy across empirical bins.
