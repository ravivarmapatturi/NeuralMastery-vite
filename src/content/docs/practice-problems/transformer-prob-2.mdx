# #002. Transformer Internals Module 1: Problem 2

**Track**: Transformer Internals | **Rank**: #2 of 1072 | **Points**: 40 XP

## Overview

Convert unnormalized attention logits into a valid probability distribution using the softmax function. In transformer self-attention, softmax produces attention weights that sum to 1.0 across all key positions.

## Task

Implement `softmax(x)`: compute `exp(x_i - max(x)) / sum(exp(x_j - max(x)))` for each element in `x`. Subtracting the maximum logit ensures numerical stability against floating-point overflow. Return the probabilities rounded to 4 decimal places. If `x` is empty, raise `ValueError`.
