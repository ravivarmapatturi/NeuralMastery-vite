# LoRA Adapter Parameter Count

**Track**: transformers-llms | **Points**: 40 XP

## Overview

Count the number of trainable parameters introduced by a LoRA low-rank adapter for a given weight matrix.

## Task

Implement `lora_param_count(d_in, d_out, rank)` that returns the total trainable parameters in a LoRA adapter: matrix A of shape `(d_in, rank)` plus matrix B of shape `(rank, d_out)`. Raise `ValueError` if any argument is non-positive or if `rank > min(d_in, d_out)`.
