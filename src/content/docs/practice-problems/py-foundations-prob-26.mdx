# Merge Overlapping Intervals

**Rank #26** · Difficulty: **Medium** · Stage: **Stage 1: AI Foundations & Python Programming** · Category: **Python & Fundamentals**

## Overview

Combine overlapping temporal and numerical ranges into a minimal set of disjoint contiguous intervals.

## Task

Implement `merge_intervals(intervals)`: given an array of intervals `[start, end]`, merge all overlapping intervals and return a new array of non-overlapping intervals in ascending order.

<PracticePlayground problemId="py-foundations-prob-26" />

<Solution>

```python
def merge_intervals(intervals):
    if not intervals:
        return []
    sorted_int = sorted(intervals, key=lambda x: x[0])
    merged = [sorted_int[0]]
    for start, end in sorted_int[1:]:
        prev_start, prev_end = merged[-1]
        if start <= prev_end:
            merged[-1] = [prev_start, max(prev_end, end)]
        else:
            merged.append([start, end])
    return merged
```

Sorting intervals by start time reduces overlap resolution to comparing each interval start against the accumulated previous end.

</Solution>
