# #915. Focal Loss for Dense Object Detection Imbalance

**Track**: Computer Vision & CNN Architectures | **Rank**: #915 of 1072 | **Points**: 60 XP

## Overview

Resolve extreme foreground-background class imbalance in dense one-stage object detectors by dynamically scaling cross-entropy loss.

## Task

Implement `focal_loss(...)`. Clip predictions to `[eps, 1 - eps]`. For each sample `i`: let `p_t = p` if `y == 1` else `1 - p`; let `alpha_t = alpha` if `y == 1` else `1 - alpha`. Compute `loss_i = -alpha_t * ((1 - p_t) ** gamma) * ln(p_t)`. Return the mean across all samples rounded to 4 decimal places.

<Solution>

```python
def focal_loss(predictions: list[float], targets: list[int], alpha: float = 0.25, gamma: float = 2.0, eps: float = 1e-7) -> float:
    N = len(predictions)
    losses = []
    for i in range(N):
        p = max(eps, min(1.0 - eps, predictions[i]))
        y = targets[i]
        if y == 1:
            pt = p
            at = alpha
        else:
            pt = 1.0 - p
            at = 1.0 - alpha
        fl = -at * ((1.0 - pt) ** gamma) * math.log(pt)
        losses.append(fl)
    return round(sum(losses) / N, 4)
```

Modulating cross entropy by (1 - p_t)^gamma prevents vast quantities of easy background candidates from overwhelming the training gradients.
