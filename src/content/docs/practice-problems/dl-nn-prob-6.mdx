# #866. Leaky ReLU Activation Forward

**Track**: Deep Learning & Neural Networks | **Rank**: #866 of 1072 | **Points**: 40 XP

## Overview

Implement the Leaky ReLU non-linearity to prevent the 'dying ReLU' problem in deep neural networks.

## Task

Implement `leaky_relu(x, alpha=0.01)`: for each scalar `v` in matrix `x`, compute `v` if `v >= 0.0` else `alpha * v`. Round each value to 4 decimal places.

<PracticePlayground problemId="dl-nn-prob-6" />

<Solution>

```python
def leaky_relu(x: list[list[float]], alpha: float = 0.01) -> list[list[float]]:
    out = []
    for row in x:
        out.append([round(float(v if v >= 0.0 else alpha * v), 4) for v in row])
    return out
```

If v is non-negative, the identity is preserved. For negative values, multiplying by a small slope alpha maintains gradient flow during backpropagation.

</Solution>
