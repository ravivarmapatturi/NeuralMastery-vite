# Topological Execution Order of Agent Workflow Nodes

**Track**: Agent Graph Engineering | **Points**: 40 XP

## Overview

Implement topological execution ordering for an agent workflow graph (LangGraph-style), determining a valid node execution sequence from declared dependencies.

## Task

Implement `topo_execution_order(dependencies)` via Kahn's algorithm. `dependencies` maps each node to the list of nodes it depends on. Among nodes with zero remaining dependencies at any point, pick alphabetically smallest. Assume the graph is acyclic.
