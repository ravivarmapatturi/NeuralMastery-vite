# Token Embedding Lookup With Padding Handling

**Track**: Transformers & LLMs | **Points**: 40 XP

## Overview

Implement embedding lookup with correct padding-token handling, the real first layer of any transformer converting discrete token ids into continuous vectors.

## Task

Implement `embedding_lookup(token_ids, embedding_table, padding_idx, embed_dim)`. For each token id, return its embedding from `embedding_table`, EXCEPT if the id equals `padding_idx`, always return a zero vector of length `embed_dim` regardless of what's in the table.
