# K-Medoids Total Clustering Cost

**Track**: Clustering & Recommender Systems | **Points**: 40 XP

## Overview

Implement the k-medoids objective function -- like k-means but using real data points as cluster centers, more robust to outliers.

## Task

Implement `kmedoids_cost(points, medoids)`: for each point, find its nearest medoid by Euclidean distance, and return the SUM of those nearest distances (not squared, unlike k-means' WCSS).
