# Context Truncation by Score Priority

**Track**: RAG Production Engineering | **Points**: 40 XP

## Overview

Implement priority-based context truncation, keeping the highest-scored chunks first when the retrieved context exceeds the model's context window.

## Task

Implement `truncate_context(scored_chunks, max_tokens, tokens_per_chunk)`. `scored_chunks` is a list of `(chunk_id, score)` tuples. Every chunk costs the same `tokens_per_chunk`. Sort by score descending (ties by original order), then keep chunks from the front as long as the running token count (using `tokens_per_chunk` each) doesn't exceed `max_tokens`. Return the kept chunk ids IN THEIR ORIGINAL RELATIVE ORDER (not sorted by score).
