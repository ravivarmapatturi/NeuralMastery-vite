# Streaming systems Module 27: Problem 207

**Rank #207** · Difficulty: **Medium** · Stage: **Stage 4: NumPy & Vectorized Data Processing** · Category: **NumPy & Pandas**

## Overview

Track event-time progression and emit monotonic watermarks for out-of-order streams.

## Task

Implement `track_event_watermarks(event_times, max_lateness)`: process events in order. Maintain the maximum observed timestamp. At each event, calculate the watermark as `max(0, current_max - max_lateness)`. Return the watermark after each event.

<PracticePlayground problemId="numpy-pandas-prob-27" />

<Solution>

```python
def track_event_watermarks(event_times, max_lateness):
    cur_max = -1
    out = []
    for t in event_times:
        if t > cur_max:
            cur_max = t
        wm = max(0, cur_max - max_lateness)
        out.append(wm)
    return out
```

Watermarks inform streaming stream window engines that no further events older than the watermark are expected to arrive.

</Solution>
