## Overview

Implement recursive JSON serialization from scratch supporting nested objects, lists, escaping, and primitives.

## Task

Implement `custom_json_serializer(data)`: serialize Python primitives (`None -> null`, `bool -> true/false`, numbers, strings with escaped quotes/newlines, lists, and dicts) into standard JSON syntax without using the standard library `json` module.

<PracticePlayground problemId="py-fund-prob-25" />

<Solution>

```python
def custom_json_serializer(data):
    if data is None: return "null"
    if isinstance(data, bool): return "true" if data else "false"
    if isinstance(data, (int, float)): return str(data)
    if isinstance(data, str):
        escaped = data.replace('\\', '\\\\').replace('"', '\\"').replace('\n', '\\n').replace('\t', '\\t')
        return f'"{escaped}"'
    if isinstance(data, list):
        return f'[{", ".join(custom_json_serializer(x) for x in data)}]'
    if isinstance(data, dict):
        return f'{{{", ".join(f"\"{k}\": {custom_json_serializer(v)}" for k, v in data.items())}}}'
    return "null"
```

Checking booleans before integers and recursively formatting nested composites generates valid JSON text.
