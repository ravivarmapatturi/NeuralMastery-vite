# DP: Coin Change II (Count Combinations)

**Rank #104** · Difficulty: **Medium** · Stage: **Stage 2: Data Structures & Algorithmic Foundations** · Category: **Data Structures & Algorithms**

## Overview

Implement `change(amount, coins)` -- count the number of ways to make `amount` using unlimited coins. Unlike Coin Change (min coins), the order of coins does NOT matter here.

## Task

Implement the function `change(amount, coins)`. Return the number of distinct combinations of coins that sum to `amount`.

<PracticePlayground problemId="ds-algo-prob-44" />

<Solution>

```python
def change(amount, coins):
    dp = [0] * (amount + 1)
    dp[0] = 1
    for coin in coins:
        for i in range(coin, amount + 1):
            dp[i] += dp[i - coin]
    return dp[amount]
```

Unbounded knapsack counting variant: iterate coins in the outer loop so each coin can be used unlimited times without counting permutations. dp[0]=1 is the base (empty sum). O(amount * len(coins)) time.

</Solution>
