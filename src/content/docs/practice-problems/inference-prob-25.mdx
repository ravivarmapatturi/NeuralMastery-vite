# #055. Radix Tree Prefix Cache Lookup

**Track**: LLM Inference & Decoding | **Rank**: #55 of 1072 | **Points**: 90 XP

## Overview

Reuse precomputed KV caches across shared system prompts and multi-turn dialogues using Radix Attention. Autoregressive language models generate sequences token by token, evaluating next-token probability distributions at each decoding step.

## Task

Implement `radix_prefix_cache_lookup(tree, prompt_tokens)`. Start from the root node (`'0'`). At each node, search its `children` for a child node whose `token_seq` exactly matches the prefix of the current unmatched prompt tokens. If found, accumulate its `token_seq` length to `matched_token_count`, append its `kv_slot_indices` to `reusable_kv_slots`, advance the prompt search position, and continue from that child. Stop when no matching child edge exists. Return dict containing `matched_token_count`, `reusable_kv_slots`, and `remaining_prompt_tokens`.
