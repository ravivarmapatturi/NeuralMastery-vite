# Self-Ask: Parse Follow-Up Question Pattern

**Track**: Advanced RAG & Agentic RAG | **Points**: 40 XP

## Overview

Implement Self-Ask prompting's step-line parser, extracting structured meaning from the real, distinctive output format of the Self-Ask technique for decomposed multi-hop reasoning.

## Task

Implement `parse_self_ask_step(line)`. If `line` starts with `'Follow up: '`, return `{"type": "follow_up", "content": line[len('Follow up: '):]}`. If it starts with `'Intermediate answer: '`, return `{"type": "intermediate_answer", "content": line[len('Intermediate answer: '):]}`. If it starts with `'So the final answer is: '`, return `{"type": "final_answer", "content": line[len('So the final answer is: '):]}`. Otherwise return `{"type": "unknown", "content": line}`.
