# Practice Problems

Short, focused coding problems — implement the function yourself in a real, in-browser Python sandbox, run it against real test cases (pass/fail, no LLM grading), then reveal a reference solution with the reasoning behind it. Every problem links back to the full concept page on this site if you want the theory first.

Inspired by the format of sites like [deep-ml.com](https://www.deep-ml.com/problems) — original problems and original solutions, written for the concepts this site already teaches, not copied from anywhere.

## How to use these

1. Read the short problem statement — follow the concept link if you want the full derivation and intuition first.
2. Write your implementation directly in the sandbox and click **Run**. Each assertion reports pass or fail individually.
3. Once you've got it passing (or you're stuck), expand **Show solution** for a reference implementation and the reasoning behind it.

More problems — spanning DSA/coding-interview patterns as well as more math/ML/DL topics — are being added continuously; see [Interview Prep — DSA & Coding](/docs/interview-prep/dsa-coding) for the pattern-based prep strategy these will pair with.
