# #822. Classical Machine Learning Module 5: Problem 22

**Track**: Classical Machine Learning | **Rank**: #822 of 1072 | **Points**

## Overview

Convert unnormalized logit scores into calibrated probability distributions with numerical stability.

## Task

Implement `softmax_probabilities(logits)`: subtract row maximum from logits before exponentiating, then normalize each row to sum to 1.0, rounded to 4 decimals.

<PracticePlayground problemId="class-ml-prob-22" />

<Solution>

```python
import math

def softmax_probabilities(logits):
    res = []
    for row in logits:
        max_v = max(row)
        exps = [math.exp(v - max_v) for v in row]
        sum_exp = sum(exps)
        res.append([round(e / sum_exp, 4) for e in exps])
    return res
```

Subtract row maximums to avoid numerical overflow, exponentiate, and divide by the row sum to form normalized probability distributions.
