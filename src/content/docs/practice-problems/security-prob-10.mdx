# Content Moderation Keyword Filter

**Track**: Agent Security & Reliability | **Points**: 40 XP

## Overview

Implement a basic content-moderation keyword filter, a real, simple guardrail before an agent's output is shown to an end user.

## Task

Implement `contains_banned_term(text, banned_terms)`. Case-insensitively, check whether ANY term in `banned_terms` appears as a whole word (not a substring of a larger word) in `text`.
