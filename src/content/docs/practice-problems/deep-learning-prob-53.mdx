# Self-BLEU Corpus Diversity Evaluator

**Track**: Deep Learning & Vision/NLP | **Points**: 40 XP

## Overview

Evaluate mode collapse and diversity in text generation by measuring unigram overlap across generated samples.

## Task

Implement `self_bleu_1(generated_texts)`. For each text `i`, treat all other texts `j != i` as reference documents. Compute unigram precision: for each word in text `i`, count is clipped to the maximum frequency of that word in any single reference document. Score for text `i` is `clipped_unigram_matches / len(text_i)`. Return the average score across all texts rounded to 4 decimal places. If `len(generated_texts) <= 1`, return 0.0.
