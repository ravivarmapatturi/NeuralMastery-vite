# Fixed-Window Per-User Rate Limiting

**Track**: Agent Security & Reliability | **Points**: 40 XP

## Overview

Implement fixed-window rate limiting per user, a real, simple abuse-prevention mechanism protecting an agent-serving system from any single user overwhelming it.

## Task

Implement `allow_user_request(request_count_this_window, max_requests_per_window)`: return `True` if `request_count_this_window < max_requests_per_window` (allow the request that would bring the count to at most the max).
