# #071. Sequential LLM Pipeline Step Executor

**Track**: LLM Application Engineering | **Rank**: #71 of 1072 | **Points**: 60 XP

## Overview

Orchestrate sequential multi-step prompt chains with dynamic context accumulation and output transformations. In production LLM application engineering, reliable system components, deterministic interfaces, and defensive validation are paramount for production stability and cost efficiency.

## Task

Implement `execute_prompt_pipeline(steps, initial_inputs)`. Sequentially process each step in `steps`. Interpolate `{var}` variables in `step['template']` using current context variables. Apply optional `step['transform']` (`'uppercase'`, `'lowercase'`, `'strip'`, or None). Store the resulting string under `step['output_key']` in context. Return the final accumulated context dict. If any step references an unbound variable, raise `KeyError`.
