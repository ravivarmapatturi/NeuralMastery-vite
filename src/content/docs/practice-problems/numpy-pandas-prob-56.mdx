## Overview

Parse and structure raw access log text records into typed tabular records.

## Task

Implement `extract_log_features(log_lines)`: for each log line formatted like `'IP - - [TIMESTAMP] "METHOD PATH PROTOCOL" STATUS BYTES'`, extract `ip` (str), `timestamp` (str), `method` (str), `status` (int), and `bytes` (int). Skip non-matching lines.

<Solution>

```python
import re

def extract_log_features(log_lines):
    pattern = re.compile(r'^(\S+) - - \[(\S+)\] "([A-Z]+) [^"]*" (\d+) (\d+)')
    out = []
    for line in log_lines:
        m = pattern.match(line.strip())
        if m:
            out.append({
                "ip": m.group(1),
                "timestamp": m.group(2),
                "method": m.group(3),
                "status": int(m.group(4)),
                "bytes": int(m.group(5))
            })
    return out
```

Regex extraction pipelines ingest unstructured log text directly into structured tabular records for downstream ML feature engineering.
