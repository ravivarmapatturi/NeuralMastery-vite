# Speculative Decoding Draft Acceptance

**Track**: transformers-llms | **Points**: 40 XP

## Overview

Implement draft verification in speculative decoding to accelerate autoregressive inference.

## Task

Implement `speculative_draft_acceptance(draft_probs, target_probs, draft_tokens)`. For each draft token `t` at step `k`, accept token `t` if `target_probs[k][t] >= draft_probs[k][t]`. Return the list of accepted tokens up to the first rejected token.
