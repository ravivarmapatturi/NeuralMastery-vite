# #615. Trees / Binary Search Module 5: Problem 25

**Track**: Trees / Binary Search | **Rank**: #615 of 1072 | **Points**

## Overview

Search the value space using binary search to find the kth smallest product in an m x n multiplication table.

## Task

Implement `find_kth_number_multiplication_table(m, n, k)`: binary search the range [1, m * n]. For a candidate product x, count elements `<= x` across rows using min(x // i, n).

<Solution>

```python
def find_kth_number_multiplication_table(m, n, k):
    lo, hi = 1, m * n
    while lo < hi:
        mid = (lo + hi) // 2
        count = sum(min(mid // i, n) for i in range(1, m + 1))
        if count < k:
            lo = mid + 1
        else:
            hi = mid
    return lo
```
