# #088. Speculative Decoding Token Verifier

**Track**: LLM Application Engineering | **Rank**: #88 of 1072 | **Points**: 90 XP

## Overview

Accelerate inference latency by implementing speculative decoding rejection sampling verification. In production LLM application engineering, reliable system components, deterministic interfaces, and defensive validation are paramount for production stability and cost efficiency.

## Task

Implement `verify_speculative_draft_tokens(draft_tokens, draft_probs, target_probs, rand_uniforms)`. For each token `i` in `0..K-1`: acceptance probability is `min(1.0, target_probs[i] / draft_probs[i])`. Accept token if `rand_uniforms[i] < acceptance_probability`. If accepted, continue; if rejected, halt verification immediately, recording `rejection_index = i`. Compute `acceptance_rate = round(accepted_count / K, 4)` (1.0 if K=0). Return `{'accepted_tokens': list[int], 'accepted_count': int, 'acceptance_rate': float, 'rejection_index': int | None}`. Raise `ValueError` if input list lengths do not match.
