# Render an MCP Prompt Template

**Track**: MCP Core Engineering | **Points**: 40 XP

## Overview

Implement MCP prompt-template rendering, substituting user-supplied arguments into a server-defined reusable prompt.

## Task

Implement `render_prompt_template(template, arguments)`. Replace every `{{key}}` placeholder in `template` with `str(arguments[key])`. Raise `KeyError` if a placeholder references a key not present in `arguments`.
