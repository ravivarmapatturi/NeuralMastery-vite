# Evaluate an Edge Condition Against State

**Track**: Agent Graph Engineering | **Points**: 40 XP

## Overview

Implement edge-condition evaluation, the real predicate-checking primitive behind conditional routing in an agent graph.

## Task

Implement `evaluate_edge_condition(state, field, operator, value)`. Get `state.get(field)`. Support operators: `'eq'` (equals), `'ne'` (not equals), `'gt'`, `'lt'`, `'contains'` (value is `in` the field's value, e.g. a substring or list membership). Return the boolean result. If `field` is missing from `state`, `'eq'`/`'ne'` still work against `None`; other operators return `False`.
