# Cost-Aware Model Tier Selection

**Track**: Agent Performance & Production | **Points**: 40 XP

## Overview

Implement cost-aware model-tier routing, a real production pattern sending simple requests to a cheap small model and only complex ones to an expensive large model.

## Task

Implement `select_model_tier(task_complexity_score, low_threshold, high_threshold)`. Return `'small'` if `task_complexity_score < low_threshold`. Return `'large'` if `task_complexity_score >= high_threshold`. Otherwise return `'medium'`.
