## Overview

Track non-parametric sliding window percentile statistics over streaming latency and telemetry metrics.

## Task

Implement `stream_sliding_percentile(nums, window_size, percentile)`: compute the percentile over each sliding window of length `window_size` in `nums`. Use the nearest-rank method: index `max(0, ceil(percentile * window_size) - 1)` in the sorted window. Round output values to 4 decimal places. Return `[]` if `window_size <= 0` or `len(nums) < window_size`.

<Solution>

```python
import math

def stream_sliding_percentile(nums, window_size, percentile):
    if window_size <= 0 or len(nums) < window_size:
        return []
    res = []
    rank_idx = max(0, math.ceil(percentile * window_size) - 1)
    for i in range(len(nums) - window_size + 1):
        window = sorted(nums[i:i + window_size])
        res.append(round(float(window[rank_idx]), 4))
    return res
```

Nearest-rank indexing retrieves robust distribution quantiles across streaming intervals.
