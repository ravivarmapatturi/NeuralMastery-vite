# #765. Vectorized Rotary Position Embedding (RoPE) Rotation

**Track**: NumPy & Vectorized Computation | **Rank**: #765 of 1072 | **Points**: 90 XP

## Overview

Encode relative token positions using complex rotary coordinate transformations.

## Task

Implement `apply_rope_rotation(x, pos, theta)`: for even-dimension vector `x` of length `D`, iterate over coordinate pairs `(x[2k], x[2k+1])` for `k in 0..D//2 - 1`. Compute angle `theta_k = pos / (theta ** (2k / D))`. Rotate pair: `x0' = x0*cos(theta_k) - x1*sin(theta_k)` and `x1' = x0*sin(theta_k) + x1*cos(theta_k)`. Return transformed vector rounded to 4 decimals.

```python
import math

def apply_rope_rotation(x, pos, theta=10000.0):
    D = len(x)
    out = [0.0] * D
    for k in range(D // 2):
        angle = pos / (theta ** (2.0 * k / D))
        cos_a, sin_a = math.cos(angle), math.sin(angle)
        x0, x1 = x[2 * k], x[2 * k + 1]
        out[2 * k] = round(float(x0 * cos_a - x1 * sin_a), 4)
        out[2 * k + 1] = round(float(x0 * sin_a + x1 * cos_a), 4)
    return out
```

Applies 2D Givens rotation to consecutive coordinate pairs scaled by position frequencies.
