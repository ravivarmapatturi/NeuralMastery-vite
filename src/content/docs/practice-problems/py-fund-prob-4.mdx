## Overview

Filter adjacent duplicate elements in streaming sequences while preserving non-adjacent recurrences.

## Task

Implement `remove_consecutive_duplicates(items)`: remove any element that is identical to its immediate predecessor in `items`. Non-adjacent duplicates must be preserved. If `items` is empty, return `[]`.

<PracticePlayground problemId="py-fund-prob-4" />

<Solution>

```python
def remove_consecutive_duplicates(items):
    if not items:
        return []
    out = [items[0]]
    for x in items[1:]:
        if x != out[-1]:
            out.append(x)
    return out
```

Checking each incoming item against out[-1] enforces adjacency uniqueness in a single pass.

</Solution>
