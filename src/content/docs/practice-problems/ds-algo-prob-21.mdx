# Linked Lists: Palindrome Linked List

**Rank #81** · Difficulty: **Easy** · Stage: **Stage 2: Data Structures & Algorithmic Foundations** · Category: **Data Structures & Algorithms**

## Overview

Implement `is_palindrome_list(head)` -- find the middle, reverse the second half, compare both halves. Combines three foundational linked-list techniques.

## Task

Implement the function `is_palindrome_list(head)`. Each node is `{'val', 'next'}`. Return `True` if the linked list is a palindrome.

<PracticePlayground problemId="ds-algo-prob-21" />

<Solution>

```python
def is_palindrome_list(head):
    vals = []
    cur = head
    while cur:
        vals.append(cur['val'])
        cur = cur['next']
    return vals == vals[::-1]
```

Collect values into a list and check if the list equals its reverse. O(n) time, O(n) space. For O(1) space: reverse the second half and compare in-place.

</Solution>
