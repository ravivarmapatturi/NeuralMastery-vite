# #052. Speculative Tree Verification

**Track**: LLM Inference & Decoding | **Rank**: #52 of 1072 | **Points**: 60 XP

## Overview

Traverse and verify branching speculative candidate trees to maximize token acceptance rates. Autoregressive language models generate sequences token by token, evaluating next-token probability distributions at each decoding step.

## Task

Implement `verify_speculative_tree(tree_nodes, target_greedy_tokens)`. Find the root node (`parent_id is None`). A non-root node is accepted if and only if its parent was accepted AND its `token_id` equals `target_greedy_tokens[str(parent_id)]`. Traverse the tree to find the longest path of accepted nodes starting from root. Return dict containing `accepted_path_token_ids` (token IDs along the path), `num_accepted` (int), and `best_leaf_id` (node ID of the terminal node on the longest accepted path). Raise `ValueError` if tree has no root.
