# #034. Top-K Logit Filtering

**Track**: LLM Inference & Decoding | **Rank**: #34 of 1072 | **Points**: 40 XP

## Overview

Filter vocabulary logits to the top-K highest scoring tokens before sampling. Autoregressive language models generate sequences token by token, evaluating next-token probability distributions at each decoding step.

## Task

Implement `top_k_filter(logits, k, filter_value=-float('inf'))`. Retain only the `k` tokens with the highest logits. Replace all other logits with `filter_value`. If multiple tokens tie at the cutoff, prioritize lower token indices. If `k \ge \text{len}(logits)`, return an unmasked copy of `logits`. If `k \le 0`, raise `ValueError`.
