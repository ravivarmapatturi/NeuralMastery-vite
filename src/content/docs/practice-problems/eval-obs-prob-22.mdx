# Build a Real-Time Dashboard Rollup Window

**Track**: Agent Evaluation & Observability | **Points**: 40 XP

## Overview

Implement time-bucket assignment for dashboard rollups, the real primitive behind aggregating a high-volume event stream into fixed-size time windows for display.

## Task

Implement `rollup_bucket(event_timestamp, bucket_size_s)`: return the START timestamp of the bucket `event_timestamp` falls into: `floor(event_timestamp / bucket_size_s) * bucket_size_s`.
