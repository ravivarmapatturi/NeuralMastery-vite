# #065. Targeted Markdown Tag Extractor

**Track**: LLM Application Engineering | **Rank**: #65 of 1072 | **Points**: 40 XP

## Overview

Isolate reasoning chains, tool calls, and final answers enclosed inside XML-style markup tags in LLM responses. In production LLM application engineering, reliable system components, deterministic interfaces, and defensive validation are paramount for production stability and cost efficiency.

## Task

Implement `extract_tagged_content(text, tag)`. Search `text` for all occurrences enclosed between `<tag>` and `</tag>` (case-insensitive for tag names, matching across multiple lines). Return a list of whitespace-stripped strings of each match's contents. If no matching tags exist, return `[]`. If `tag` is empty or only whitespace, raise `ValueError`.
