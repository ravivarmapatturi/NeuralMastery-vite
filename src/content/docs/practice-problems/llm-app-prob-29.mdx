# #089. Entropy-Based Dynamic Temperature Controller

**Track**: LLM Application Engineering | **Rank**: #89 of 1072 | **Points**: 90 XP

## Overview

Optimize generation diversity and determinism on the fly by dynamically modulating sampling temperature based on token distribution entropy. In production LLM application engineering, reliable system components, deterministic interfaces, and defensive validation are paramount for production stability and cost efficiency.

## Task

Implement `compute_dynamic_temperature(logits, base_temp=0.7, min_temp=0.1, max_temp=1.5, entropy_scale=0.5)`. Compute numerically stable softmax probabilities over `logits`. Calculate Shannon entropy `H = -sum(p * ln(p))`. Normalize entropy by maximum possible entropy `ln(vocab_size)`: `norm_entropy = H / ln(vocab_size)`. Adjust temperature as `base_temp * (1.0 + entropy_scale * (norm_entropy - 0.5))`, clamped between `min_temp` and `max_temp`. Round `temperature`, `entropy`, and `normalized_entropy` to 4 decimal places. Return `{'temperature': float, 'entropy': float, 'normalized_entropy': float, 'vocab_size': int}`. Raise `ValueError` if `len(logits) < 2`.
