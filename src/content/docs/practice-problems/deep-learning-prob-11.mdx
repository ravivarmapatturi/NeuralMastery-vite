# InfoNCE / SimCLR Contrastive Loss

**Track**: Deep Learning & Vision/NLP | **Points**: 40 XP

## Overview

Compute the InfoNCE contrastive objective used in self-supervised representation learning (SimCLR, MoCo, CLIP).

## Task

Implement `infonce_contrastive_loss(queries, positives, temperature)`. Given `N` normalized queries and `N` normalized positive keys, for query `i`, `positives[i]` is its positive match and `positives[j]` (for all `j != i`) are negative distractors. Compute cosine similarity as dot product `sim(q, k) = sum(q_d * k_d)`. For each query `i`, loss is `-log(exp(sim(q_i, p_i) / tau) / sum_{j=0}^{N-1} exp(sim(q_i, p_j) / tau))`. Return the mean loss across all `N` queries, rounded to 4 decimal places.
