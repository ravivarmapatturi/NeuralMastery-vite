# Request Deduplication Window Check

**Track**: Agent Performance & Production | **Points**: 40 XP

## Overview

Implement idempotency-key-based request deduplication, a real production safeguard against a client's retry (after a timeout, before it got the original response) causing a duplicate side effect.

## Task

Implement `is_duplicate_request(idempotency_key, seen_keys_with_ts, current_time, dedup_window_s)`. Return `True` if `idempotency_key` is in `seen_keys_with_ts` AND `(current_time - seen_keys_with_ts[idempotency_key]) < dedup_window_s` (seen recently enough to still count as a duplicate).
