## Overview

Transform an adjacency list representation into a dense adjacency matrix.

## Task

Implement `adj_list_to_matrix(n, adj_list)`: create an n x n zero matrix, and set `matrix[u][v] = 1` for each neighbor in `adj_list`.

<PracticePlayground problemId="graph-algo-prob-4" />

<Solution>

```python
def adj_list_to_matrix(n, adj_list):
    matrix = [[0] * n for _ in range(n)]
    for u, nbrs in adj_list.items():
        u_int = int(u)
        for v in nbrs:
            matrix[u_int][v] = 1
    return matrix
```

Pre-allocate an n x n zero matrix and populate matrix entries corresponding to incident edges in the adjacency list.
