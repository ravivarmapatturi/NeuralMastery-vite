# Advanced DS: Maximum Frequency Stack

**Rank #110** · Difficulty: **Hard** · Stage: **Stage 2: Data Structures & Algorithmic Foundations** · Category: **Data Structures & Algorithms**

## Overview

Implement `freq_stack_ops(operations)` -- FreqStack tracks push counts per element and groups by frequency, enabling O(1) pop of the most frequent (breaking ties by recency).

## Task

Implement the function `freq_stack_ops(operations)`. Simulate a FreqStack supporting `push(val)` and `pop()` (removes and returns the most-frequent element; ties broken by most recent push).

<Solution>

```python
def freq_stack_ops(operations):
    class FreqStack:
        def __init__(self):
            self.freq = {}
            self.group = {}   # freq -> stack of elements at that frequency
            self.max_freq = 0

        def push(self, val):
            f = self.freq.get(val, 0) + 1
            self.freq[val] = f
            self.max_freq = max(self.max_freq, f)
            if f not in self.group:
                self.group[f] = []
            self.group[f].append(val)

        def pop(self):
            val = self.group[self.max_freq].pop()
            self.freq[val] -= 1
            if not self.group[self.max_freq]:
                self.max_freq -= 1
            return val

    fs = FreqStack()
    results = []
    for op in operations:
        name = op[0]
        if name == 'push':
            fs.push(op[1])
            results.append(None)
        elif name == 'pop':
            results.append(fs.pop())
    return results
```

Two maps: freq[val] = current frequency, group[freq] = stack of elements at that frequency. Push appends to group[new_freq]; pop takes from group[max_freq] and decrements. All O(1).
