# #037. Min-P Sampling Mask

**Track**: LLM Inference & Decoding | **Rank**: #37 of 1072 | **Points**: 40 XP

## Overview

Apply dynamic relative probability thresholding using the Min-P sampling heuristic. Autoregressive language models generate sequences token by token, evaluating next-token probability distributions at each decoding step.

## Task

Implement `min_p_filter(logits, min_p, filter_value=-float('inf'))`. Compute softmax probabilities. Let `p_{max}` be the maximum probability across vocabulary. Filter out (set to `filter_value`) any token `i` whose softmax probability is strictly less than `p_{max} \times min\_p`. If `min\_p < 0.0` or `min\_p > 1.0`, raise `ValueError`. Return the filtered logits.
