# Z-Score Feature Standardization

**Rank #245** · Difficulty: **Easy** · Stage: **Stage 5: Classical Machine Learning & Optimization** · Category: **Classical ML** | **Points**: 40 XP

## Overview

Implement `standard_scaler(X)`, performing column-wise Z-score standardization on 2D sample arrays -- a vital prerequisite for distance-based and regularized models like SVMs, PCA, Ridge/Lasso, and Neural Networks.

## Task

Implement `standard_scaler(X)`: transform matrix `X` so each feature has mean 0 and standard deviation 1. When a feature has zero variance, assign `0.0` to avoid division by zero. Return the transformed 2D list.

<Solution>

```python
import math

def standard_scaler(X):
    if not X or not X[0]:
        return []
    n = len(X)
    d = len(X[0])
    scaled = [[0.0] * d for _ in range(n)]
    for j in range(d):
        col = [X[i][j] for i in range(n)]
        mu = sum(col) / n
        var = sum((x - mu) ** 2 for x in col) / n
        std = math.sqrt(var)
        if std < 1e-12:
            for i in range(n):
                scaled[i][j] = 0.0
        else:
            for i in range(n):
                scaled[i][j] = round((X[i][j] - mu) / std, 6)
    return scaled
```

Z-score normalization ensures gradient descent steps progress symmetrically across features with vastly different natural scales.
