# #579. Linked Lists / Stacks / Queues Module 4: Problem 19

**Track**: Linked Lists / Stacks / Queues | **Rank**: #579 of 1072 | **Points**

## Overview

In-place pairwise pointer permutation of adjacent linked list node pairs.

## Task

Implement `swap_pairs(head)`: swap every two adjacent nodes in `head` and return the new head. You must swap the actual nodes themselves by updating pointers in O(1) space.

<PracticePlayground problemId="ll-queue-prob-19" />

<Solution>

```python
def swap_pairs(head):
    dummy = {'val': 0, 'next': head}
    prev = dummy
    while prev.get('next') and prev['next'].get('next'):
        first = prev['next']
        second = first['next']
        first['next'] = second['next']
        second['next'] = first
        prev['next'] = second
        prev = first
    return dummy['next']
```

Three pointer updates per pair invert adjacent nodes in-place without node re-allocation.
