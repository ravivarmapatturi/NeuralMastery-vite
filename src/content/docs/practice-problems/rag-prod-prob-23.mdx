# Merge Duplicate Retrieved Chunk IDs

**Track**: RAG Production Engineering | **Points**: 40 XP

## Overview

Implement duplicate-result merging, needed when the same chunk is returned by multiple retrieval passes (e.g. both dense and sparse legs of a hybrid search) with different scores.

## Task

Implement `merge_dedup_results(results)`. `results` is a list of `(chunk_id, score)` tuples, possibly with the same `chunk_id` appearing more than once. For each unique `chunk_id`, keep only its HIGHEST score. Return the deduplicated list sorted by score descending, ties broken by `chunk_id` ascending.
