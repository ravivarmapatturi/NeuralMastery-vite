# Identify Parallelizable Branches

**Track**: Agent Graph Engineering | **Points**: 40 XP

## Overview

Implement parallel-branch identification, grouping agent graph nodes into execution "waves" where every node in the same wave can run concurrently.

## Task

Implement `find_parallel_branches(dependencies)`. Return a list of waves (each a sorted list of node names), where wave 0 contains all nodes with no dependencies, wave 1 contains nodes whose dependencies are all satisfied by wave 0 (and not already placed), and so on. Each node appears in exactly one wave -- the EARLIEST wave where its dependencies are already satisfied.
