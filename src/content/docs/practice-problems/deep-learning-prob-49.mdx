# 1D Position Embedding Linear Interpolation Resampler

**Track**: Deep Learning & Vision/NLP | **Points**: 40 XP

## Overview

Resample a 1D positional embedding vector to a new sequence length via continuous linear interpolation.

## Task

Implement `linear_interpolation_1d(original_values, target_length)`. Given 1D list `original_values` of length `N` (indexed `0` to `N-1`), resample to `target_length` points evenly spaced from index `0` to `N-1`. For target point `j` in `0...target_length-1`, source position is `src_pos = j * (N - 1) / (target_length - 1)` (if `target_length == 1`, `src_pos = 0.0`). Let `low = int(src_pos)` and `high = min(N - 1, low + 1)`. Interpolated value is `original_values[low] * (1.0 - (src_pos - low)) + original_values[high] * (src_pos - low)`. Return list of floats rounded to 4 decimal places.
