# Detect Flaky Test Cases Across Repeated Eval Runs

**Track**: Agent Evaluation & Observability | **Points**: 40 XP

## Overview

Implement flaky-test detection across repeated eval runs, catching test cases whose result genuinely isn't deterministic -- a real, important distinction from tests that reliably pass or reliably fail.

## Task

Implement `find_flaky_tests(run_results)`. Each entry is `{"test_id": str, "passed": bool}`, with each test_id potentially appearing multiple times (once per run). Return the sorted list of test_ids that have BOTH at least one `True` AND at least one `False` result across their occurrences.
