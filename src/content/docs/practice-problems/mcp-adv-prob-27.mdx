# Compute Per-Tool Usage Statistics

**Track**: MCP Advanced & Agent Integration | **Points**: 40 XP

## Overview

Implement per-tool usage statistics aggregation, real operational monitoring data for understanding which tools an agent actually relies on and how reliably.

## Task

Implement `tool_usage_stats(call_log)`. `call_log` is a list of `{"tool": str, "success": bool}`. Return a dict mapping each distinct tool name to `{"calls": int, "success_rate": float}` (successes / total calls for that tool).
