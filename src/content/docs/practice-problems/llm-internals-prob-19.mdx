# Transformer FFN Inner Dimension

**Rank #379** · Difficulty: **Easy** · Stage: **Stage 7: Transformers, LLMs & Foundation Models** · Category: **Transformers & LLMs**

Implement `ffn_inner_dim(d_model, expansion_factor=4)` that returns `d_model * expansion_factor` -- the size of the intermediate dense layer in the transformer's position-wise FFN (`d_model -> d_ff -> d_model`). Raise `ValueError` for non-positive inputs. Prerequisite: `llm-internals-prob-18`.

<PracticePlayground problemId="llm-internals-prob-19" />

<Solution>

```python
def ffn_inner_dim(d_model, expansion_factor=4):
    if d_model <= 0 or expansion_factor <= 0:
        raise ValueError("d_model and expansion_factor must be positive")
    return d_model * expansion_factor
```

The original "Attention is All You Need" paper used `d_ff = 4 * d_model` (e.g. 512 -> 2048). Modern variants sometimes use 8/3 * d_model (LLaMA's SwiGLU variant which uses two matrices) or other ratios, but the fundamental idea is that the expanded hidden dimension gives the FFN capacity to learn complex non-linear feature transformations.

</Solution>
