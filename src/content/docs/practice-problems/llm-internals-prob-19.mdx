# Transformer FFN Inner Dimension

**Track**: transformers-llms | **Points**: 40 XP

## Overview

Compute the inner (hidden) dimension of the position-wise feed-forward network in a transformer block.

## Task

Implement `ffn_inner_dim(d_model, expansion_factor=4)` that returns `d_model * expansion_factor` -- the size of the intermediate dense layer in the transformer position-wise FFN (`d_model -> d_ff -> d_model`). Raise `ValueError` for non-positive inputs.
