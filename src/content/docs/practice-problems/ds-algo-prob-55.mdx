# Advanced DS: Find Median from Data Stream

**Rank #115** · Difficulty: **Hard** · Stage: **Stage 2: Data Structures & Algorithmic Foundations** · Category: **Data Structures & Algorithms**

## Overview

Implement `median_finder_ops(operations)` -- maintain a max-heap for the lower half and a min-heap for the upper half. Median is O(1) and each addNum is O(log n).

## Task

Implement the function `median_finder_ops(operations)`. Simulate a MedianFinder supporting `addNum(num)` and `findMedian()` (returns current median as a float).

<Solution>

```python
import heapq

def median_finder_ops(operations):
    small = []  # max-heap (negate values)
    large = []  # min-heap

    def add_num(num):
        heapq.heappush(small, -num)
        heapq.heappush(large, -heapq.heappop(small))
        if len(large) > len(small):
            heapq.heappush(small, -heapq.heappop(large))

    def find_median():
        if len(small) > len(large):
            return float(-small[0])
        return (-small[0] + large[0]) / 2.0

    results = []
    for op in operations:
        name = op[0]
        if name == 'addNum':
            add_num(op[1])
            results.append(None)
        elif name == 'findMedian':
            results.append(find_median())
    return results
```

Two heaps: small (max-heap of lower half), large (min-heap of upper half). Always maintain `|small| >= |large|` with `|small| - |large| <= 1`. Median = small[0] or average of both tops. O(log n) add, O(1) median.
