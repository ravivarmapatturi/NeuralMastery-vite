# RAG Answer Abstention Decision

**Track**: Advanced RAG & Agentic RAG | **Points**: 40 XP

## Overview

Implement RAG abstention, a real, honest 'I don't know' policy for when retrieval genuinely found nothing good enough to answer from, rather than forcing a generation from weak/irrelevant context.

## Task

Implement `should_abstain(top_retrieval_score, abstention_threshold)`: return `True` (abstain, don't answer) if `top_retrieval_score < abstention_threshold`.
