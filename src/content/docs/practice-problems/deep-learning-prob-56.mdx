# FPN 1x1 Lateral Convolution Alignment

**Track**: Deep Learning & Vision/NLP | **Points**: 40 XP

## Overview

Project multi-scale bottom-up feature channels to uniform channel dimension using 1x1 lateral convolutions in Feature Pyramid Networks.

## Task

Implement `fpn_lateral_1x1(feature_map, weights, bias)`. `feature_map` has shape `C_in x H x W`. `weights` has shape `C_out x C_in` and `bias` has length `C_out`. For each output channel `co`, output pixel `(r, c)` is `sum_{ci=0}^{C_in-1} weights[co][ci] * feature_map[ci][r][c] + bias[co]`. Return 3D list of shape `C_out x H x W` with values rounded to 4 decimal places.
