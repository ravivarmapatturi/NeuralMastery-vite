# Aggregate Multi-Turn Conversation Success Rate

**Track**: Agent Evaluation & Observability | **Points**: 40 XP

## Overview

Implement conversation-level (not turn-level) success rate computation, the real metric that actually matters for a multi-turn agent -- a conversation with even one broken turn is usually a real failed user experience overall.

## Task

Implement `conversation_success_rate(conversations)`. Each conversation is `{"turns": list[bool]}` (per-turn success flags). A conversation counts as successful ONLY if ALL its turns succeeded. Return the fraction of conversations that are fully successful.
