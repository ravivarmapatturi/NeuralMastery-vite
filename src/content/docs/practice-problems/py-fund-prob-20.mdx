# #520. Python & Programming Fundamentals Module 4: Problem 20

**Track**: Python & Programming Fundamentals | **Rank**: #520 of 1072 | **Points**

## Overview

Safely parse and coerce string/raw values in dictionary datasets into typed primitives.

## Task

Implement `safe_cast_dict(records, types)`: iterate over `records` and convert fields according to `types` (`"int"`, `"float"`, `"str"`, `"bool"`). Strings for boolean type evaluate to `True` for `"true"`, `"1"`, `"yes"` (case-insensitive). If a cast throws `ValueError` or `TypeError`, set the field to `None`. Return a new list of updated record dictionaries.

<Solution>

```python
def safe_cast_dict(records, types):
    out = []
    for r in records:
        new_r = dict(r)
        for field, target in types.items():
            if field in new_r:
                val = new_r[field]
                try:
                    if target == 'int': new_r[field] = int(val)
                    elif target == 'float': new_r[field] = float(val)
                    elif target == 'str': new_r[field] = str(val)
                    elif target == 'bool':
                        new_r[field] = val.lower() in ('true', '1', 'yes') if isinstance(val, str) else bool(val)
                except (ValueError, TypeError):
                    new_r[field] = None
        out.append(new_r)
    return out
```

Defensive type casting handles corrupted telemetry rows gracefully without terminating batch jobs.
