# Detect Hallucinated Citation Reference

**Track**: Agent Security & Reliability | **Points**: 40 XP

## Overview

Implement citation-reference validation, catching a real, common hallucination failure mode: an LLM citing a source number that doesn't actually exist in what was retrieved.

## Task

Implement `is_citation_valid(citation_number, num_real_sources)`: return `True` if `1 <= citation_number <= num_real_sources` (assuming 1-indexed citations).
