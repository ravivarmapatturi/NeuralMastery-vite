# #066. Robust JSON Fence Parser

**Track**: LLM Application Engineering | **Rank**: #66 of 1072 | **Points**: 40 XP

## Overview

Extract and repair structured JSON payloads from markdown code blocks or conversational wrappers. In production LLM application engineering, reliable system components, deterministic interfaces, and defensive validation are paramount for production stability and cost efficiency.

## Task

Implement `parse_json_markdown(text)`. Extract the JSON payload from ```` ```json ... ``` ```` or ```` ``` ... ``` ```` markdown fences, or find the outermost matching `{...}` or `[...]` in conversational text. Clean trailing commas before closing brackets or braces. Parse and return the resulting Python dict or list. If input is empty or valid JSON cannot be parsed, raise `ValueError`.
