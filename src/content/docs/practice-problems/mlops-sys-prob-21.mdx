# Latency Percentile Computation

**Track**: MLOps & Data Systems | **Points**: 40 XP

## Overview

Implement real p50/p95/p99 latency percentile computation, the standard way model-serving SLOs are measured (never use plain average latency for SLOs).

## Task

Implement `latency_percentile(samples_ms, p)`. Sort `samples_ms` ascending. Using the nearest-rank method, the index is `ceil(p/100 * n) - 1`, clamped to `[0, n-1]`. Return the value at that index. `p` is in `[0, 100]`.
