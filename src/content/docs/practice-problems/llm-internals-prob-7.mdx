# Sinusoidal Positional Encoding

**Track**: transformers-llms | **Points**: 40 XP

## Overview

Implement the classic Vaswani et al. (2017) sinusoidal positional encoding table inject position awareness into sequence embeddings.

## Task

Implement `sinusoidal_position_encoding(seq_len, d_model)`. For each position `pos` and dimension pair `(2i, 2i+1)`, compute `sin` and `cos` positional waves, returning a 2D list of shape `(seq_len, d_model)` rounded to 4 decimal places.
