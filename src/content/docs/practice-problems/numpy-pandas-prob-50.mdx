# Pandas Module 50: Problem 230

**Rank #230** · Difficulty: **Hard** · Stage: **Stage 4: NumPy & Vectorized Data Processing** · Category: **NumPy & Pandas**

## Overview

Impute missing values using forward-fill restricted by a maximum consecutive gap limit.

## Task

Implement `ffill_with_limit(series, limit)`: forward-fill `None` entries with the preceding valid non-None value, filling at most `limit` consecutive `None` entries. Any subsequent consecutive `None` values beyond `limit` remain `None`.

<PracticePlayground problemId="numpy-pandas-prob-50" />

<Solution>

```python
def ffill_with_limit(series, limit):
    out = []
    last_val = None
    consec = 0
    for x in series:
        if x is not None:
            last_val = x
            consec = 0
            out.append(x)
        else:
            if last_val is not None and consec < limit:
                consec += 1
                out.append(last_val)
            else:
                out.append(None)
    return out
```

Constrained forward-filling prevents stale observations from propagating through prolonged sensor outages.

</Solution>
