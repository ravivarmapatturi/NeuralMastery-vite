# Roman Numeral Parser

## Overview

Parse additive and subtractive Roman numeral expressions into decimal integers.

## Task

Implement `roman_to_int(s)`: convert standard Roman numerals (`I=1, V=5, X=10, L=50, C=100, D=500, M=1000`) to integer values, accurately processing subtractive instances like `IV` (4) and `IX` (9).

<Solution>

```python
def roman_to_int(s):
    vals = {'I': 1, 'V': 5, 'X': 10, 'L': 50, 'C': 100, 'D': 500, 'M': 1000}
    total = 0
    prev = 0
    for ch in reversed(s):
        curr = vals.get(ch, 0)
        if curr < prev:
            total -= curr
        else:
            total += curr
        prev = curr
    return total
```

Traversing backwards turns subtractive notation into a simple comparison against the previous maximum symbol.
