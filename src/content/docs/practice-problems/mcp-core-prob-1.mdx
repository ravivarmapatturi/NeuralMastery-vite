# MCP Tool Schema Field Type Validation

**Track**: MCP Core Engineering | **Points**: 40 XP

## Overview

Implement MCP tool-call argument validation against a declared JSON-schema-style type map, the real gate a server must run before executing any tool call.

## Task

Implement `validate_tool_schema(arguments, schema)`. `schema` maps arg name -> expected Python type name (`'str'`,`'int'`,`'float'`,`'bool'`,`'list'`,`'dict'`). Return a sorted list of error strings: `"missing: <name>"` if a schema field is absent from `arguments`, `"wrong type: <name>"` if present with the wrong type. Empty list means valid.
