# Model Serving Cost Per Successful Request

**Track**: Agent Performance & Production | **Points**: 40 XP

## Overview

Implement real cost-per-successful-request calculation, a metric that (unlike raw cost-per-request) correctly accounts for wasted spend on failed requests.

## Task

Implement `cost_per_success(total_cost, total_requests, error_rate)`. Successful requests: `total_requests * (1 - error_rate)`. Return `total_cost / successful_requests`. Return `float('inf')` if there are zero successful requests.
