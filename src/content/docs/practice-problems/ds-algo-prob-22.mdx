# Trees: Lowest Common Ancestor of BST

**Rank #82** · Difficulty: **Medium** · Stage: **Stage 2: Data Structures & Algorithmic Foundations** · Category: **Data Structures & Algorithms**

## Overview

Implement `lca_bst(root, p, q)` -- exploiting BST ordering for LCA without extra memory. The non-BST version (any binary tree) is harder and requires a different approach.

## Task

Implement the function `lca_bst(root, p, q)`. `root` is a BST node `{'val', 'left', 'right'}`. Return the value of the lowest common ancestor of nodes with values `p` and `q`.

<PracticePlayground problemId="ds-algo-prob-22" />

<Solution>

```python
def lca_bst(root, p, q):
    while root:
        if p < root['val'] and q < root['val']:
            root = root['left']
        elif p > root['val'] and q > root['val']:
            root = root['right']
        else:
            return root['val']
    return None
```

BST ordering: if both p, q are less than root.val, LCA is in the left subtree; if both greater, right subtree; otherwise root is the LCA. O(h) time, O(1) space.

</Solution>
