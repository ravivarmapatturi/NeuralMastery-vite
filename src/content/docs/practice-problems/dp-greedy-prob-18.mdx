# #668. Dynamic Programming & Greedy Module 4: Problem 18

**Track**: Dynamic Programming & Greedy | **Rank**: #668 of 1072 | **Points**

## Overview

Find the minimum number of intervals to remove to eliminate all overlaps using greedy interval scheduling.

## Task

Implement `erase_overlap_intervals(intervals)`: sort intervals by finish time ascending. Greedily keep intervals that finish earliest to leave maximum room for future intervals.

<PracticePlayground problemId="dp-greedy-prob-18" />

<Solution>

```python
def erase_overlap_intervals(intervals):
    if not intervals:
        return 0
    sorted_inv = sorted(intervals, key=lambda x: x[1])
    count = 0
    end = sorted_inv[0][1]
    for start, finish in sorted_inv[1:]:
        if start < end:
            count += 1
        else:
            end = finish
    return count
```

Sort intervals by end time. Always keep the interval that finishes earliest; if a subsequent interval starts before that end time, it must be removed to prevent overlap.
