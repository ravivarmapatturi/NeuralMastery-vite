## Overview

Compute token length frequency distributions for text corpus profiling.

## Task

Implement `word_length_histogram(words)`: count the frequency of each word length across list `words`. Return a dictionary mapping integer lengths to occurrence counts, with keys sorted in ascending order. Return `{}` for empty input.

<PracticePlayground problemId="py-fund-prob-5" />

<Solution>

```python
def word_length_histogram(words):
    hist = {}
    for w in words:
        length = len(w)
        hist[length] = hist.get(length, 0) + 1
    return dict(sorted(hist.items()))
```

Counting lengths into a dictionary and sorting items returns a canonical length frequency table.

</Solution>
