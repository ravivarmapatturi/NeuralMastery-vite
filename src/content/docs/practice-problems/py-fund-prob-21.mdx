# #521. Python & Programming Fundamentals Module 5: Problem 21

**Track**: Python & Programming Fundamentals | **Rank**: #521 of 1072 | **Points**

## Overview

Extract the top k frequent words with deterministic lexicographical tie-breaking.

## Task

Implement `top_k_frequent_words(words, k)`: identify the `k` most frequent words in `words`. Sort the results primarily by descending frequency, and break ties by ascending alphabetical order. Return at most `k` words.

<PracticePlayground problemId="py-fund-prob-21" />

<Solution>

```python
from collections import Counter

def top_k_frequent_words(words, k):
    counts = Counter(words)
    sorted_words = sorted(counts.keys(), key=lambda w: (-counts[w], w))
    return sorted_words[:k]
```

Python tuple sorting key `(-count, word)` sorts primarily by descending frequency and secondarily by lexicographical order.

</Solution>
