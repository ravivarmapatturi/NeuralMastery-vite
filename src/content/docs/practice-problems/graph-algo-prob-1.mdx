# #621. Graphs & Network Algorithms Module 1: Problem 1

**Track**: Graphs & Network Algorithms | **Rank**: #621 of 1072 | **Points**

## Overview

Identify the central hub node of a star graph in constant O(1) time.

## Task

Implement `find_star_center(edges)`: since the center node must connect to every other node, it is guaranteed to appear in both of the first two edges.

<PracticePlayground problemId="graph-algo-prob-1" />

<Solution>

```python
def find_star_center(edges):
    e0, e1 = edges[0], edges[1]
    return e0[0] if e0[0] in e1 else e0[1]
```

The central hub connects to all other vertices. Looking at just the first two edges, the node shared between them must be the center.

</Solution>
