# #895. RGB to Grayscale Luminance Conversion

**Track**: Computer Vision & CNN Architectures | **Rank**: #895 of 1072 | **Points**: 40 XP

## Overview

Convert multi-channel color images to single-channel intensity maps using human perceptual luminance weights.

## Task

Implement `rgb_to_grayscale(rgb_image)`: given a tensor of shape `(3, H, W)` where channel 0 is R, channel 1 is G, and channel 2 is B, compute the ITU-R BT.601 luminance at each coordinate `(i, j)`: `Y = 0.299 * R + 0.587 * G + 0.114 * B`. Return the `(H, W)` matrix with floats rounded to 4 decimal places.

<Solution>

```python
def rgb_to_grayscale(rgb_image: list[list[list[float]]]) -> list[list[float]]:
    H = len(rgb_image[0])
    W = len(rgb_image[0][0])
    gray = []
    for i in range(H):
        row = []
        for j in range(W):
            r = rgb_image[0][i][j]
            g = rgb_image[1][i][j]
            b = rgb_image[2][i][j]
            y = 0.299 * r + 0.587 * g + 0.114 * b
            row.append(round(float(y), 4))
        gray.append(row)
    return gray
```

Weighted linear combination of the color channels according to ITU-R BT.601 yields standard perceptual luminance.
