# Transpose a 2D Matrix

**Rank #9** · Difficulty: **Easy** · Stage: **Stage 1: AI Foundations & Python Programming** · Category: **Python & Fundamentals** | **Points**: 40 XP

## Overview

Implement `transpose_matrix(matrix)`: flip an M x N 2D list of lists across its diagonal into an N x M matrix, raising ValueError if the matrix has jagged rows.

## Task

Implement the function `transpose_matrix(matrix)`: return the transpose of `matrix`. If `matrix` is empty, return `[]`. If rows have inconsistent lengths, raise `ValueError`.

<PracticePlayground problemId="py-foundations-prob-9" />

<Solution>

```python
def transpose_matrix(matrix):
    if not matrix or not matrix[0]:
        return []
    rows, cols = len(matrix), len(matrix[0])
    for row in matrix:
        if len(row) != cols:
            raise ValueError('Inconsistent row lengths in matrix')
    return [[matrix[r][c] for r in range(rows)] for c in range(cols)]
```

Matrix transposition swaps feature axes and sample axes, representing column-oriented vs row-oriented data layouts in linear algebra.
