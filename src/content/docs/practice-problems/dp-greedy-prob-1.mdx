# #651. Dynamic Programming & Greedy Module 1: Problem 1

**Track**: Dynamic Programming & Greedy | **Rank**: #651 of 1072 | **Points**

## Overview

Compute the minimum cost to climb a staircase where each step incurs a specified cost using 1D dynamic programming.

## Task

Implement `min_cost_climbing_stairs(cost)`: let dp[i] be the minimum cost to reach step i. Transitions are dp[i] = min(dp[i-1] + cost[i-1], dp[i-2] + cost[i-2]), optimized to O(1) space.

<PracticePlayground problemId="dp-greedy-prob-1" />

<Solution>

```python
def min_cost_climbing_stairs(cost):
    f0, f1 = 0, 0
    for i in range(2, len(cost) + 1):
        f0, f1 = f1, min(f1 + cost[i - 1], f0 + cost[i - 2])
    return f1
```

Track the minimum cost to reach the two most recent steps. At each index, take the minimum of reaching from step i-1 or i-2 and paying the respective cost.
