# #658. Dynamic Programming & Greedy Module 2: Problem 8

**Track**: Dynamic Programming & Greedy | **Rank**: #658 of 1072 | **Points**

## Overview

Determine the winning player in a mathematical subtraction game using game theory DP.

## Task

Implement `divisor_game(n)`: return True if Alice has a winning strategy from state n. In game theory, even states are winning (choose x=1 to give opponent an odd state).

<PracticePlayground problemId="dp-greedy-prob-8" />

<Solution>

```python
def divisor_game(n):
    return n % 2 == 0
```

If n is even, Alice can always subtract 1 to pass Bob an odd number. An odd number only has odd divisors, so Bob must subtract an odd number, returning an even number to Alice. Eventually Bob receives 1 and loses.

</Solution>
