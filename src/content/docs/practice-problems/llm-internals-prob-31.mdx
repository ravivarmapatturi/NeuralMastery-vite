# Multi-Query Attention (MQA) Parameter Savings

**Track**: transformers-llms | **Points**: 40 XP

## Overview

Calculate the parameter savings achieved by Multi-Query Attention compared to standard Multi-Head Attention.

## Task

Implement `mqa_parameter_savings(d_model, num_heads)`. In standard MHA, Q, K, V, O projections each have `d_model * d_model` parameters (total `4 * d_model**2`). In MQA, K and V projections share 1 head with shape `(d_model, d_k)` where `d_k = d_model // num_heads`, while Q and O remain `(d_model, d_model)`. Return dict with `'mha_params'`, `'mqa_params'`, and `'saved_params'`. Raise `ValueError` if `d_model <= 0`, `num_heads <= 0`, or `d_model % num_heads != 0`.
