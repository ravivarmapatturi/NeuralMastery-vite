# One-Hot Encode a Categorical Feature

**Track**: MLOps & Data Systems | **Points**: 40 XP

## Overview

Implement one-hot encoding against a FIXED, pre-defined category vocabulary -- the real production-safe way to encode categoricals (never fit categories on live data).

## Task

Implement `one_hot_encode(value, categories)`. Return a list the same length as `categories`, with a `1` at the index matching `value` and `0` elsewhere. If `value` is not in `categories` (an unseen category), return an all-zero vector.
