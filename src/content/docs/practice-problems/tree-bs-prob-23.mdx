# #613. Trees / Binary Search Module 5: Problem 23

**Track**: Trees / Binary Search | **Rank**: #613 of 1072 | **Points**: 90 XP

## Overview

Implement the preorder-with-null-markers encoding scheme behind LeetCode's classic "Serialize and Deserialize Binary Tree" -- the same trick real systems use to flatten a tree into a string/byte stream that unambiguously reconstructs the exact original shape.

## Task

Implement the function `serialize_tree(root)`: return a comma-separated preorder encoding of the tree where every `None` child is written as the literal string `'#'`, so the tree's exact shape is fully recoverable from the string alone.
