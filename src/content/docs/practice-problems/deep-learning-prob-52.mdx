# METEOR Greedy Unigram Alignment Matcher

**Track**: Deep Learning & Vision/NLP | **Points**: 40 XP

## Overview

Match candidate unigrams to reference unigrams using greedy exact matching for METEOR machine translation evaluation.

## Task

Implement `meteor_unigram_match(candidate, reference)`. Match each token in `candidate` to the first available identical token in `reference` (each reference token may be matched at most once). Return `[match_count, len(candidate), len(reference)]`.
