# 2D Gaussian Smoothing Filter Kernel

**Track**: Deep Learning & Vision/NLP | **Points**: 40 XP

## Overview

Construct a normalized 2D Gaussian blur kernel for noise reduction and image preprocessing.

## Task

Implement `gaussian_kernel_2d(size, sigma)`. Generate a square `size x size` filter (where `size` is an odd integer). The center pixel is at `(center, center)` where `center = size // 2`. Unnormalized value at `(r, c)` is `exp(-((r - center)^2 + (c - center)^2) / (2 * sigma^2))`. Normalize so all entries sum to 1.0. Round each cell to 4 decimal places.
