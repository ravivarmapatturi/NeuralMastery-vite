# #753. Vectorized Tridiagonal Matrix Construction

**Track**: NumPy & Vectorized Computation | **Rank**: #753 of 1072 | **Points**: 60 XP

## Overview

Assemble compact sparse band representations into a full tridiagonal matrix.

## Task

Implement `construct_tridiagonal(main_diag, sub_diag, super_diag)`: construct an `n x n` matrix where `M[i][i] = main_diag[i]`, `M[i+1][i] = sub_diag[i]`, `M[i][i+1] = super_diag[i]`, and all other elements are 0.0. Round elements to 4 decimals.

<PracticePlayground problemId="numpy-vec-prob-13" />

<Solution>

```python
def construct_tridiagonal(main_diag, sub_diag, super_diag):
    n = len(main_diag)
    mat = [[0.0 for _ in range(n)] for _ in range(n)]
    for i in range(n):
        mat[i][i] = round(float(main_diag[i]), 4)
        if i < len(super_diag):
            mat[i][i + 1] = round(float(super_diag[i]), 4)
        if i > 0 and (i - 1) < len(sub_diag):
            mat[i][i - 1] = round(float(sub_diag[i - 1]), 4)
    return mat
```

Initializes zeros and assigns main, sub, and super diagonal elements.
