# Aspect-Ratio-Preserving Image Resize

**Rank #472** · Difficulty: **Easy** · Stage: **Stage 8: RAG, Agents, MCP & Distributed Systems** · Category: **Agents, MCP & Systems**

Implement `aspect_preserving_resize(width, height, max_dimension)`, the aspect-ratio-preserving resize every vision model's preprocessing pipeline runs before an image reaches a CNN or ViT -- distorting an image's proportions throws away real information the model was trained to expect. Prerequisite: `agents-mcp-systems-prob-41`.

<Solution>

```python
def aspect_preserving_resize(width, height, max_dimension):
    if width <= 0 or height <= 0 or max_dimension <= 0:
        raise ValueError("width, height, and max_dimension must be positive")
    if width >= height:
        new_w = max_dimension
        new_h = round(height * max_dimension / width)
    else:
        new_h = max_dimension
        new_w = round(width * max_dimension / height)
    return (new_w, new_h)
```

This is the same "letterbox to a max side length" resize used before feeding an image into most vision models -- the model then typically pads or crops the shorter side to reach a fixed square input, but that padding step is separate from (and downstream of) this proportional scaling.

</Solution>
