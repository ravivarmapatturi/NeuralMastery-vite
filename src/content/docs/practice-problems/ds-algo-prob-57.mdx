# Trees: Serialize and Deserialize Binary Tree

**Rank #117** · Difficulty: **Hard** · Stage: **Stage 2: Data Structures & Algorithmic Foundations** · Category: **Data Structures & Algorithms**

## Overview

Implement `serialize(root)` and `deserialize(data)` -- preorder encoding with 'null' markers. The same iterator-based approach works for any preorder/level-order encoding.

## Task

Implement the function `serialize_deserialize(root)`. Serialize the binary tree to a string, then deserialize back. Return the deserialized tree's root.

<PracticePlayground problemId="ds-algo-prob-57" />

<Solution>

```python
def serialize_deserialize(root):
    def serialize(node):
        if not node:
            return 'null'
        return f"{node['val']},{serialize(node['left'])},{serialize(node['right'])}"

    def deserialize(data):
        vals = iter(data.split(','))
        def build():
            v = next(vals)
            if v == 'null':
                return None
            return {'val': int(v), 'left': build(), 'right': build()}
        return build()

    data = serialize(root)
    return deserialize(data)
```

Preorder serialization with 'null' for absent nodes encodes the full structure. Deserialization uses an iterator over the comma-separated tokens and recurses in the same preorder. O(n) encode and decode.

</Solution>
