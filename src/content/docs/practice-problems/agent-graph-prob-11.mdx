# Build an Ordered Execution Trace

**Track**: Agent Graph Engineering | **Points**: 40 XP

## Overview

Implement execution-trace construction, the real, minimal record-keeping needed to debug or visualize how an agent graph actually executed for one run.

## Task

Implement `build_execution_trace(visited_nodes, timestamps)`. Both lists have the same length. Return a list of `{"step": int, "node": str, "timestamp": float}` dicts, `step` being the 0-indexed position.
