# Rotate List by K Positions

**Rank #2** · Difficulty: **Easy** · Stage: **Stage 1: AI Foundations & Python Programming** · Category: **Python & Fundamentals** | **Points**: 40 XP

## Overview

Implement `rotate_list(nums, k)`, shifting elements cyclically to the right or left using slicing and modulo arithmetic -- an essential technique for circular buffers and sequence windows.

## Task

Implement the function `rotate_list(nums, k)`: rotate `nums` to the right by `k` steps (or left if `k` is negative). When `k` exceeds `len(nums)`, wrap around using modulo arithmetic. Return a new list. If `nums` is empty, return `[]`.

<PracticePlayground problemId="py-foundations-prob-2" />

<Solution>

```python
def rotate_list(nums, k):
    if not nums:
        return []
    k = k % len(nums)
    if k == 0:
        return list(nums)
    return nums[-k:] + nums[:-k]
```

List slicing and modular index arithmetic are standard Python patterns for shifting sequences and implementing circular queues.

</Solution>
