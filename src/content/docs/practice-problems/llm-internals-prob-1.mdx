# Compute Scaled Dot-Product Attention Scores

**Track**: transformers-llms | **Points**: 40 XP

## Overview

Compute scaled dot-product attention logits between a query vector and a sequence of key vectors -- the foundational similarity calculation in transformer attention layers.

## Task

Implement `scaled_dot_product_scores(q, k)`. For query vector `q` of dimension `d` and key vectors `k`, compute `(q . k_i) / sqrt(d)` for each key vector, rounded to 4 decimal places.
