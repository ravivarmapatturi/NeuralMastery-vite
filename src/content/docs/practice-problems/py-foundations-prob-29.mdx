# Group Anagrams by Canonical Signature

**Rank #29** · Difficulty: **Medium** · Stage: **Stage 1: AI Foundations & Python Programming** · Category: **Python & Fundamentals**

## Overview

Partition words into anagram equivalence classes using canonical sorted-character hash keys.

## Task

Implement `group_anagrams(words)`: group words that have identical characters. Return the groups with each group sorted alphabetically, and the outer list of groups sorted by the first element of each group.

<PracticePlayground problemId="py-foundations-prob-29" />

<Solution>

```python
from collections import defaultdict

def group_anagrams(words):
    groups = defaultdict(list)
    for w in words:
        key = "".join(sorted(w))
        groups[key].append(w)
    res = [sorted(g) for g in groups.values()]
    res.sort(key=lambda g: g[0] if g else "")
    return res
```

Sorting each string gives a canonical key that clusters all anagrams into dictionary buckets in O(N * K log K) time.

</Solution>
