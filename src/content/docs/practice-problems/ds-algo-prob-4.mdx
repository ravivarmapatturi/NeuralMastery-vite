# DP: Climbing Stairs

**Rank #64** · Difficulty: **Easy** · Stage: **Stage 2: Data Structures & Algorithmic Foundations** · Category: **Data Structures & Algorithms**

## Overview

Implement `climb_stairs(n)`, the simplest DP problem: the count of ways is exactly Fibonacci(n+1). Perfect for learning the `recurrence -> memo -> bottom-up -> constant-space` progression.

## Task

Implement the function `climb_stairs(n)`: return the number of distinct ways to reach stair `n` by taking 1 or 2 steps at a time.

<PracticePlayground problemId="ds-algo-prob-4" />

<Solution>

```python
def climb_stairs(n):
    if n <= 2:
        return n
    a, b = 1, 2
    for _ in range(n - 2):
        a, b = b, a + b
    return b
```

Rolling Fibonacci: dp[n] = dp[n-1] + dp[n-2]. Reduce to O(1) space with two variables. O(n) time.

</Solution>
