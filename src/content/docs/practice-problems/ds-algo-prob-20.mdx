# Advanced DS: Implement Stack using Queues

**Rank #80** · Difficulty: **Easy** · Stage: **Stage 2: Data Structures & Algorithmic Foundations** · Category: **Data Structures & Algorithms**

## Overview

Implement `stack_using_queues(operations)` -- the inverse of Queue using Stacks. Push is O(n) but pop/top are O(1), showing that the choice of expensive operation matters.

## Task

Implement the function `stack_using_queues(operations)`. Simulate a LIFO stack using only queues. Return results of `pop`, `top`, and `empty` operations (None for `push`).

<Solution>

```python
from collections import deque

def stack_using_queues(operations):
    class MyStack:
        def __init__(self):
            self.q = deque()
        def push(self, x):
            self.q.append(x)
            for _ in range(len(self.q) - 1):
                self.q.append(self.q.popleft())
        def pop(self):
            return self.q.popleft()
        def top(self):
            return self.q[0]
        def empty(self):
            return not self.q

    s = MyStack()
    results = []
    for op in operations:
        name = op[0]
        if name == 'push':
            s.push(op[1])
            results.append(None)
        elif name == 'pop':
            results.append(s.pop())
        elif name == 'top':
            results.append(s.top())
        elif name == 'empty':
            results.append(s.empty())
    return results
```

After each push, rotate all older elements behind the new one so it sits at the front. Pop/top are then O(1) dequeue/peek. O(n) push, O(1) pop/top.
