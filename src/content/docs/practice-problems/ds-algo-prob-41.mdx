# Linked Lists: Rotate List

**Rank #101** · Difficulty: **Medium** · Stage: **Stage 2: Data Structures & Algorithmic Foundations** · Category: **Data Structures & Algorithms**

## Overview

Implement `rotate_right(head, k)` -- connect tail to head for a circular list, then cut at the right point. The modulo step handles `k >= length` efficiently.

## Task

Implement the function `rotate_right(head, k)`. Each node is `{'val', 'next'}`. Rotate the list to the right by `k` places and return the new head.

<PracticePlayground problemId="ds-algo-prob-41" />

<Solution>

```python
def rotate_right(head, k):
    if not head or not head['next'] or k == 0:
        return head
    # Count length and form a cycle
    length = 1
    cur = head
    while cur['next']:
        cur = cur['next']
        length += 1
    cur['next'] = head  # make circular
    k = k % length
    steps = length - k
    cur = head
    for _ in range(steps - 1):
        cur = cur['next']
    new_head = cur['next']
    cur['next'] = None
    return new_head
```

Form a circular list, then find the new tail at position `length - (k % length) - 1`. Cut there to open the list at the new head. O(n) time, O(1) space.

</Solution>
