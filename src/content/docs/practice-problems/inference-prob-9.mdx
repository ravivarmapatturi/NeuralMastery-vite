# #039. Token Ban and Suppress Filter

**Track**: LLM Inference & Decoding | **Rank**: #39 of 1072 | **Points**: 40 XP

## Overview

Enforce hard generation constraints by masking banned or forbidden vocabulary tokens. Autoregressive language models generate sequences token by token, evaluating next-token probability distributions at each decoding step.

## Task

Implement `suppress_banned_tokens(logits, banned_token_ids, filter_value=-float('inf'))`. Set the logit of each token ID in `banned_token_ids` to `filter_value`. If any token ID in `banned_token_ids` is negative or `\ge \text{len}(logits)`, raise `IndexError`. Return a copy of `logits` with banned tokens suppressed.
