# Random Projection Dimensionality Reduction

**Track**: Vector Search & Index Optimization | **Points**: 40 XP

## Overview

Implement the core linear-algebra step behind Johnson-Lindenstrauss random projection, used to cheaply shrink embedding dimensionality while approximately preserving pairwise distances.

## Task

Implement `random_project(v, projection)`. `projection` is a `k x d` matrix (k output dims, d input dims, given as a list of k rows). Return `projection @ v` as a list of k floats.
