# Detect Attention Entropy Collapse

**Track**: Transformers & LLMs | **Points**: 40 XP

## Overview

Implement attention-entropy computation, a real diagnostic metric for detecting when an attention head has collapsed to attending almost entirely to one position (a known real training pathology).

## Task

Implement `attention_entropy(attention_weights)`: return the Shannon entropy `-sum(p * log(p) for p in attention_weights if p > 0)` of the attention distribution (treat any zero weight as contributing 0, avoiding log(0)).
