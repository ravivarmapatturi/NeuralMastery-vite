# Clustering Module 56: Problem 296

**Rank #296** · Difficulty: **Hard** · Stage: **Stage 5: Classical Machine Learning & Optimization** · Category: **Classical ML**

## Overview

Identify the pair of closest clusters to merge in an agglomerative clustering step.

## Task

Implement `dendrogram_merge_step(dist_matrix, cluster_names)`: find the pair of distinct clusters `(i < j)` with the minimum distance. Return dict with keys `"cluster_1"`, `"cluster_2"`, and `"distance"` (rounded to 4 decimal places).

<Solution>

```python
def dendrogram_merge_step(dist_matrix, cluster_names):
    n = len(dist_matrix)
    min_d = float('inf')
    best_i, best_j = -1, -1
    for i in range(n):
        for j in range(i + 1, n):
            d = dist_matrix[i][j]
            if d < min_d:
                min_d = d
                best_i, best_j = i, j
    return {
        "cluster_1": cluster_names[best_i],
        "cluster_2": cluster_names[best_j],
        "distance": round(float(min_d), 4)
    }
```

Agglomerative clustering iteratively merges the two closest clusters in the active distance matrix to construct the dendrogram hierarchy.
