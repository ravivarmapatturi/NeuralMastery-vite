# Mathematics Module 41: Problem 161

**Rank #161** · Difficulty: **Medium** · Stage: **Stage 3: Mathematics & Numerical Computing** · Category: **Math & Numerical**

## Overview

Compute the optimal transport Earth Mover's distance between two discrete 1D probability histograms.

## Task

Implement `wasserstein_1d(p, q)`: compute cumulative distribution functions `CDF_p` and `CDF_q`. Calculate `W_1 = sum_i |CDF_p[i] - CDF_q[i]|`. Return float rounded to 4 decimals.

<PracticePlayground problemId="math-num-prob-41" />

<Solution>

```python
def wasserstein_1d(p, q):
    cdf_p = 0.0
    cdf_q = 0.0
    w1 = 0.0
    for i in range(len(p)):
        cdf_p += p[i]
        cdf_q += q[i]
        w1 += abs(cdf_p - cdf_q)
    return round(float(w1), 4)
```

Evaluates cumulative distribution functions and integrates absolute discrepancy along the real line.

</Solution>
