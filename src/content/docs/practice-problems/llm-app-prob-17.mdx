# #077. PII Detection and Token Anonymizer

**Track**: LLM Application Engineering | **Rank**: #77 of 1072 | **Points**: 60 XP

## Overview

Protect sensitive personal data by detecting and redacting emails, US phone numbers, and SSNs with reversible pseudonyms. In production LLM application engineering, reliable system components, deterministic interfaces, and defensive validation are paramount for production stability and cost efficiency.

## Task

Implement `anonymize_pii_entities(text)`. Detect US Social Security Numbers (`\b\d{3}-\d{2}-\d{4}\b`), email addresses (`\b[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Z|a-z]{2,}\b`), and US phone numbers (`(?:\(\d{3}\)\s*|\b\d{3}-)\d{3}-\d{4}\b`). Replace matches in that order with 1-indexed placeholder tokens `[SSN_k]`, `[EMAIL_k]`, `[PHONE_k]`. Return `{'sanitized_text': text, 'redactions': dict, 'entity_counts': {'email': int, 'phone': int, 'ssn': int}}` where `redactions` maps placeholder tag to original sensitive substring.
