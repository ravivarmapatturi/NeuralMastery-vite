# #786. Tabular Missingness Pattern Profiler

**Track**: Pandas & Data Processing Pipelines | **Rank**: #786 of 1072 | **Points**: 60 XP

## Overview

Catalog and count recurring co-occurring missingness combinations across database features.

## Task

Implement `profile_missing_patterns(records, columns)`: for each record in `records`, identify which of the specified `columns` are absent or set to `None`. Join missing column names in alphabetical order separated by `'+'` (e.g. `'age+salary'`). If no columns are missing, label as `'none'`. Return sorted dict mapping pattern to occurrence count.

<PracticePlayground problemId="pandas-proc-prob-16" />

<Solution>

```python
from collections import defaultdict

def profile_missing_patterns(records, columns):
    patterns = defaultdict(int)
    for r in records:
        missing = [c for c in columns if c not in r or r[c] is None]
        k = '+'.join(sorted(missing)) if missing else 'none'
        patterns[k] += 1
    return {k: patterns[k] for k in sorted(patterns.keys())}
```

Determines missing column sets per row and groups them by sorted canonical pattern strings.
