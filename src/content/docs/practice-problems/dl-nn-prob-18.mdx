# #878. Cosine Annealing Learning Rate Schedule

**Track**: Deep Learning & Neural Networks | **Rank**: #878 of 1072 | **Points**: 60 XP

## Overview

Smoothly decay learning rates over training epochs according to Loshchilov and Hutter's cosine schedule.

## Task

Implement `cosine_annealing_lr(initial_lr, min_lr, cur_epoch, max_epochs)`: compute `lr = min_lr + 0.5 * (initial_lr - min_lr) * (1 + cos(pi * cur_epoch / max_epochs))`. Return the computed learning rate rounded to 6 decimal places.

<Solution>

```python
def cosine_annealing_lr(initial_lr: float, min_lr: float, cur_epoch: int, max_epochs: int) -> float:
    cos_term = math.cos(math.pi * cur_epoch / max_epochs)
    lr = min_lr + 0.5 * (initial_lr - min_lr) * (1.0 + cos_term)
    return round(float(lr), 6)
```

The cosine schedule provides smooth continuous deceleration from eta_max down to eta_min across T_max epochs.
