# Bayesian Personalized Ranking (BPR) Pairwise Loss

**Track**: Clustering & Recommender Systems | **Points**: 40 XP

## Overview

Implement the Bayesian Personalized Ranking loss, a real pairwise objective used to train implicit-feedback recommenders directly for ranking rather than rating prediction.

## Task

Implement `bpr_loss(score_pos, score_neg)`. BPR's loss for one (positive item, negative item) pair is `-log(sigmoid(score_pos - score_neg))`, where `sigmoid(x) = 1/(1+exp(-x))`. Return the loss as a float.
