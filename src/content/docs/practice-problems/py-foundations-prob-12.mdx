# Chunk a List into Batches

**Rank #12** · Difficulty: **Easy** · Stage: **Stage 1: AI Foundations & Python Programming** · Category: **Python & Fundamentals** | **Points**: 40 XP

## Overview

Implement `chunk_list(items, chunk_size)`: partition a list into chunks of length `chunk_size`, handling uneven trailing batches and invalid chunk sizes.

## Task

Implement the function `chunk_list(items, chunk_size)`: split `items` into consecutive sublists of length at most `chunk_size`. If `chunk_size <= 0`, raise `ValueError`. If `items` is empty, return `[]`.

<PracticePlayground problemId="py-foundations-prob-12" />

<Solution>

```python
def chunk_list(items, chunk_size):
    if chunk_size <= 0:
        raise ValueError('chunk_size must be positive')
    if not items:
        return []
    return [items[i:i + chunk_size] for i in range(0, len(items), chunk_size)]
```

Batching divides large workloads into manageable chunks to respect rate limits, memory constraints, and vectorized hardware SIMD widths.

</Solution>
