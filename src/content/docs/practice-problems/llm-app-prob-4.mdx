# #064. Token Budget Context Truncation

**Track**: LLM Application Engineering | **Rank**: #64 of 1072 | **Points**: 40 XP

## Overview

Enforce model context window limits by evicting oldest historical dialogue turns while preserving system instructions and latest input. In production LLM application engineering, reliable system components, deterministic interfaces, and defensive validation are paramount for production stability and cost efficiency.

## Task

Implement `truncate_chat_by_token_budget(messages, max_tokens, chars_per_token=4.0)`. Calculate message tokens as `math.ceil(len(content) / chars_per_token)`. Always retain the system message (if present at index 0) and the final turn in `messages`. Evict older intermediate turns until `total_tokens <= max_tokens`. If mandatory messages alone exceed `max_tokens`, raise `ValueError`. Return the retained messages list in chronological order.
