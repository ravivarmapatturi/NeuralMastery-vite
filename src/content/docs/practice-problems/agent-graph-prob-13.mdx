# Validate State Against Expected Schema Keys

**Track**: Agent Graph Engineering | **Points**: 40 XP

## Overview

Implement state-schema validation, a real check catching a node that forgot to populate a required state field before the graph proceeds to a downstream node depending on it.

## Task

Implement `validate_state_schema(state, required_keys)`: return the sorted list of keys in `required_keys` that are MISSING from `state`. Empty list means the state is fully valid.
