# Mean Imputation for Missing Values

**Track**: MLOps & Data Systems | **Points**: 40 XP

## Overview

Implement mean imputation, the simplest real missing-value handling strategy in a production feature pipeline.

## Task

Implement `impute_mean(values)`. `values` is a list where missing entries are `None`. Compute the mean of the non-`None` entries, then return a new list with every `None` replaced by that mean (non-missing values unchanged, as floats).
