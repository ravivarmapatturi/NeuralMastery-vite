# Deduplicate Overlapping Resource Subscriptions

**Track**: MCP Core Engineering | **Points**: 40 XP

## Overview

Implement subscription deduplication, avoiding a server sending duplicate resource-change notifications to a client that subscribed to the same URI more than once.

## Task

Implement `dedupe_subscriptions(subscription_requests)`: return the DISTINCT URIs in `subscription_requests`, preserving the order of FIRST appearance.
