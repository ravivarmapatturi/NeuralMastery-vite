# Two Sum with Index Map

**Rank #16** · Difficulty: **Easy** · Stage: **Stage 1: AI Foundations & Python Programming** · Category: **Python & Fundamentals**

## Overview

Find the two array elements that sum to the target value in a single O(n) pass using a hash map lookup.

## Task

Implement `two_sum(nums, target)`: return the indices of the two elements in `nums` whose sum equals `target`. Each input is guaranteed to have at most one solution, and the same index may not be used twice.

<PracticePlayground problemId="py-foundations-prob-16" />

<Solution>

```python
def two_sum(nums, target):
    seen = {}
    for i, num in enumerate(nums):
        complement = target - num
        if complement in seen:
            return [seen[complement], i]
        seen[num] = i
    return []
```

Using a hash map allows looking up the required complement `target - num` in O(1) expected time, achieving overall O(n) runtime and O(n) auxiliary space.

</Solution>
