# Recommendation Catalog Coverage

**Track**: Clustering & Recommender Systems | **Points**: 40 XP

## Overview

Implement catalog coverage, a real diversity/business metric measuring what fraction of the entire catalog a recommender ever surfaces.

## Task

Implement `catalog_coverage(all_recommendations, catalog_size)`. `all_recommendations` is a list of per-user recommendation lists. Return `(number of DISTINCT items recommended to anyone) / catalog_size`.
