# #983. Vector Search & Index Optimization Module 2: Problem 8

**Track**: Vector Search & Index Optimization | **Rank**: #983 of 1072 | **Points**: 40 XP

## Overview

Implement `cosine_similarity_matrix(vectors)`, the pairwise similarity matrix used to build the candidate graph for graph-based ANN indexes like HNSW, and for offline semantic deduplication of an embedding collection before indexing.

## Task

Implement the function `cosine_similarity_matrix(vectors)`, returning the n x n matrix where entry `[i][j]` is the cosine similarity between `vectors[i]` and `vectors[j]`. The diagonal must be exactly `1.0`. Raise `ValueError` if any vector has zero magnitude.
