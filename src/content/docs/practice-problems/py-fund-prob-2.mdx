## Overview

Identify the second distinct maximum order statistic across unsorted numerical collections.

## Task

Implement `find_second_largest(nums)`: return the second largest distinct integer in `nums`. If `nums` contains fewer than two distinct numbers, return `None`.

<PracticePlayground problemId="py-fund-prob-2" />

<Solution>

```python
def find_second_largest(nums):
    unique = sorted(set(nums), reverse=True)
    return unique[1] if len(unique) >= 2 else None
```

Converting to a set removes duplicates before sorting to retrieve the second largest distinct value.

</Solution>
