# EmbeddingBag Sum Aggregator with Offsets

**Track**: Deep Learning & Vision/NLP | **Points**: 40 XP

## Overview

Aggregate embedding vectors by sum across variable-length bags defined by start offsets (PyTorch EmbeddingBag style).

## Task

Implement `embedding_bag_sum(indices, offsets, embedding_matrix)`. For `B = len(offsets)`, bag `i` spans slice `indices[offsets[i] : offsets[i+1]]` (for last bag, up to `len(indices)`). For each bag, sum the embedding vectors of all its indices. If a bag is empty, return a zero vector of dimension `D`. Return list of `B` summed vectors, each rounded to 4 decimal places.
