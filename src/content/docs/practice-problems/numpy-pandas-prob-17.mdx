# Pandas Module 17: Problem 197

**Rank #197** · Difficulty: **Easy** · Stage: **Stage 4: NumPy & Vectorized Data Processing** · Category: **NumPy & Pandas**

## Overview

Profile missing data rates across tabular record columns.

## Task

Implement `missingness_report(records, column_names)`: compute the count and ratio of missing values for each column. A value is considered missing if the key is not in the record, or if its value is `None` or empty string `""`. Round ratio to 4 decimal places.

<PracticePlayground problemId="numpy-pandas-prob-17" />

<Solution>

```python
def missingness_report(records, column_names):
    n = len(records)
    out = {}
    for col in column_names:
        missing = 0
        for r in records:
            if col not in r or r[col] is None or r[col] == "":
                missing += 1
        ratio = round(missing / n, 4) if n > 0 else 0.0
        out[col] = {"missing_count": missing, "missing_ratio": ratio}
    return out
```

Iterate through all columns and records, flagging absent keys, None values, and empty strings to compute exact column-level missingness metrics.
