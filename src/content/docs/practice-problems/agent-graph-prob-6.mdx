# Serialize State at a Checkpoint

**Track**: Agent Graph Engineering | **Points**: 40 XP

## Overview

Implement checkpoint state serialization, the real mechanism letting an agent graph resume from a saved point instead of restarting from scratch after an interruption.

## Task

Implement `checkpoint_state(state, step_id, checkpoints)`. Store a SHALLOW COPY of `state` under `checkpoints[step_id]` (so future mutations of `state` don't affect the saved checkpoint), and return the updated `checkpoints` dict.
