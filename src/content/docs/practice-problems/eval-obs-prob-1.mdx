# Exact-Match Task Accuracy

**Track**: Agent Evaluation & Observability | **Points**: 40 XP

## Overview

Implement exact-match accuracy, the simplest real agent-evaluation metric -- what fraction of outputs are byte-for-byte identical to the expected answer.

## Task

Implement `exact_match_accuracy(predictions, references)`: return the fraction of positions where `predictions[i] == references[i]`.
