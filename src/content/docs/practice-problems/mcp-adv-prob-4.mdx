# Cache Key From Tool Call Signature

**Track**: MCP Advanced & Agent Integration | **Points**: 40 XP

## Overview

Implement a deterministic tool-call cache key, letting an agent orchestrator skip a redundant tool call whose exact same arguments were already made.

## Task

Implement `tool_call_cache_key(tool_name, arguments)`. Serialize `arguments` with `json.dumps(arguments, sort_keys=True)` (so key order never affects the hash), combine with `tool_name`, and return the hex `hashlib.sha256` digest of `f'{tool_name}:{serialized}'`.
