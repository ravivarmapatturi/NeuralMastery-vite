# #723. Hessian Matrix of Quadratic Objective

**Track**: Mathematics & Numerical Computing | **Rank**: #723 of 1072 | **Points**: 60 XP

## Overview

Compute the symmetric Hessian matrix of second-order partial derivatives for a quadratic objective.

## Task

Implement `quadratic_hessian(A)`: for objective `f(x) = 0.5 * x^T A x`, the Hessian matrix of second partial derivatives is `H = 0.5 * (A + A^T)`. Return the n x n Hessian matrix with entries rounded to 4 decimals.

<PracticePlayground problemId="math-num-prob-13" />

<Solution>

```python
def quadratic_hessian(A):
    n = len(A)
    H = []
    for i in range(n):
        row = []
        for j in range(n):
            val = 0.5 * (A[i][j] + A[j][i])
            row.append(round(float(val), 4))
        H.append(row)
    return H
```

Averages off-diagonal transposes to extract the symmetric second derivative tensor.
