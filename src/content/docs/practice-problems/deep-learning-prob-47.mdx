# CTC Extended Target Sequence Generator

**Track**: Deep Learning & Vision/NLP | **Points**: 40 XP

## Overview

Interleave blank tokens into a target sequence to build the 2L + 1 extended label sequence for CTC loss alignment.

## Task

Implement `ctc_extend_targets(target_tokens, blank_token)`. For target sequence `target_tokens` of length `L`, construct the extended sequence of length `2 * L + 1` by placing `blank_token` before every label, between every adjacent pair, and after the final label (e.g. `[1, 2] -> [0, 1, 0, 2, 0]`). Return the extended list of integers.
