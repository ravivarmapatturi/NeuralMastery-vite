# #876. L2 Weight Decay Gradient Adjustment

**Track**: Deep Learning & Neural Networks | **Rank**: #876 of 1072 | **Points**: 60 XP

## Overview

Compute the combined gradient vector incorporating L2 regularization penalty to prevent large weight values.

## Task

Implement `l2_weight_decay(grads, weights, weight_decay)`: given raw objective gradients `grads` and parameters `weights`, the regularized objective is `L_total = L + 0.5 * weight_decay * sum(w_k^2)`. The adjusted gradient for each parameter is `g_adj[k] = grads[k] + weight_decay * weights[k]`. Return the adjusted gradients rounded to 6 decimal places.

<PracticePlayground problemId="dl-nn-prob-16" />

<Solution>

```python
def l2_weight_decay(grads: list[float], weights: list[float], weight_decay: float) -> list[float]:
    out = []
    for g, w in zip(grads, weights):
        val = g + weight_decay * w
        out.append(round(float(val), 6))
    return out
```

Adding lambda * w to the unregularized loss gradient implements weight decay in standard SGD optimizers.
