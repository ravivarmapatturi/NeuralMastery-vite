## Overview

Solve the symmetric Travelling Salesperson Problem exactly using the Held-Karp bitmask dynamic programming algorithm.

## Task

Implement `tsp_exact_cost(dist_matrix)`: memoize `tsp(mask, u)` representing the minimum cost to visit remaining unvisited cities starting from city u and returning to 0.

```python
def tsp_exact_cost(dist_matrix):
    n = len(dist_matrix)
    if n <= 1:
        return 0
    memo = {}
    def tsp(mask, u):
        if mask == (1 << n) - 1:
            return dist_matrix[u][0]
        state = (mask, u)
        if state in memo:
            return memo[state]
        ans = float('inf')
        for v in range(n):
            if not (mask & (1 << v)):
                ans = min(ans, dist_matrix[u][v] + tsp(mask | (1 << v), v))
        memo[state] = ans
        return ans
    return tsp(1, 0)
```

Use memoized bitmask recursion to find the minimal cost completion tour for each subset of visited cities and current endpoint, terminating with return to city 0.
