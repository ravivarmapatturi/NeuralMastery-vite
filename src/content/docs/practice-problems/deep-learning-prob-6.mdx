# Generalized Intersection over Union (GIoU)

**Track**: Deep Learning & Vision/NLP | **Points**: 40 XP

## Overview

Compute Generalized IoU between two bounding boxes to provide gradient signal even for non-overlapping boxes.

## Task

Implement `giou_2d(box1, box2)`. Bounding boxes are `[x1, y1, x2, y2]`. GIoU is `IoU - (area(C) - area(union)) / area(C)`, where `C` is the smallest convex enclosing box containing both boxes. If `area(C) == 0`, return 1.0. Round result to 4 decimal places.
