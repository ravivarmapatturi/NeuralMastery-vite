# Fixed-Size Chunking With Overlap

**Track**: RAG Production Engineering | **Points**: 40 XP

## Overview

Implement fixed-size character chunking with overlap, the baseline chunking strategy every RAG ingestion pipeline starts from.

## Task

Implement `chunk_with_overlap(text, chunk_size, overlap)`. Return chunks of `chunk_size` characters, advancing the start position by `chunk_size - overlap` each step, until the whole text is covered. The last chunk may be shorter.
