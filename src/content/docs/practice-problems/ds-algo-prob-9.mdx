# DP: House Robber

**Rank #69** · Difficulty: **Easy** · Stage: **Stage 2: Data Structures & Algorithmic Foundations** · Category: **Data Structures & Algorithms**

## Overview

Implement `rob(nums)` -- the classic 1-D DP problem with the recurrence `dp[i] = max(dp[i-1], dp[i-2] + nums[i])`, implementable in O(1) space.

## Task

Implement the function `rob(nums)`. Return the maximum sum you can collect without selecting two adjacent elements.

<PracticePlayground problemId="ds-algo-prob-9" />

<Solution>

```python
def rob(nums):
    if not nums:
        return 0
    prev2, prev1 = 0, 0
    for n in nums:
        prev2, prev1 = prev1, max(prev1, prev2 + n)
    return prev1
```

Rolling two variables: `prev2` is dp[i-2], `prev1` is dp[i-1]. Each step: `prev2, prev1 = prev1, max(prev1, prev2+n)`. O(n) time, O(1) space.

</Solution>
