# Flash Attention Block Count

**Track**: transformers-llms | **Points**: 40 XP

## Overview

Compute the number of tile blocks processed in Flash Attention block-sparse algorithm for a given sequence length and block size.

## Task

Implement `flash_attention_blocks(seq_len, block_size)` that returns `ceil(seq_len / block_size)` -- the number of SRAM-fitting tile blocks Flash Attention divides the query sequence into. Raise `ValueError` if either argument is non-positive.
