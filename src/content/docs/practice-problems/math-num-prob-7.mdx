# #717. Matrix Invariants: Trace, Frobenius Norm, and Symmetry

## Overview

Compute key algebraic and geometric matrix invariants.

## Task

Implement `matrix_properties(A)`: for an n x n matrix A, return `{"trace": float, "frobenius": float, "symmetric": bool}` where trace is sum of diagonal entries, Frobenius norm is sqrt of sum of squared entries, and symmetric is True iff `abs(A[i][j] - A[j][i]) < 1e-6` for all i, j. Round floats to 4 decimals.

<PracticePlayground problemId="math-num-prob-7" />

<Solution>

```python
import math

def matrix_properties(A):
    n = len(A)
    trace = sum(A[i][i] for i in range(n))
    frobenius = math.sqrt(sum(A[i][j] ** 2 for i in range(n) for j in range(n)))
    symmetric = all(abs(A[i][j] - A[j][i]) < 1e-6 for i in range(n) for j in range(n))
    return {'trace': round(float(trace), 4), 'frobenius': round(float(frobenius), 4), 'symmetric': symmetric}
```

Computes diagonal sum for trace, entry-wise root-sum-squares for Frobenius norm, and compares transpose entries.
