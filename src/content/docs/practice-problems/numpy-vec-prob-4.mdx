# #744. Vectorized Strided 2D Window Extraction

**Track**: NumPy & Vectorized Computation | **Rank**: #744 of 1072 | **Points**: 40 XP

## Overview

Extract 2D sliding image patches across a grid with specified stride.

## Task

Implement `extract_patches_2d(grid, patch_size, stride)`: slide a window of size `patch_size x patch_size` across `grid` in row-major order with step `stride`. Only include fully contained patches. Return a list of 2D patches.

<PracticePlayground problemId="numpy-vec-prob-4" />

<Solution>

```python
def extract_patches_2d(grid, patch_size, stride):
    H, W = len(grid), len(grid[0]) if grid else 0
    patches = []
    for i in range(0, H - patch_size + 1, stride):
        for j in range(0, W - patch_size + 1, stride):
            patches.append([row[j:j + patch_size] for row in grid[i:i + patch_size]])
    return patches
```

Step through grid row and column offsets by stride, extracting sub-grids.
