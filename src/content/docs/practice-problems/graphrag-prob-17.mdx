# Infer Entity Type From Attribute Keys

**Track**: Knowledge Graph & GraphRAG | **Points**: 40 XP

## Overview

Implement rule-based entity-type inference, assigning a node's schema type based on which attributes it has, when an extractor didn't explicitly tag a type.

## Task

Implement `infer_entity_type(attributes)`. If `attributes` contains `'founded_year'` or `'ticker_symbol'`, return `'ORGANIZATION'`. Elif it contains `'birth_date'` or `'occupation'`, return `'PERSON'`. Elif it contains `'population'` or `'country_code'`, return `'LOCATION'`. Otherwise return `'UNKNOWN'`. Check in the order listed.
