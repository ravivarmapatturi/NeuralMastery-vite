# #626. Graphs & Network Algorithms Module 2: Problem 6

**Track**: Graphs & Network Algorithms | **Rank**: #626 of 1072 | **Points**

## Overview

Identify a universal sink node with in-degree n-1 and out-degree 0 in a directed graph.

## Task

Implement `find_town_judge(n, trust)`: maintain trust score `in_degree - out_degree` for each person. The judge must have net score exactly `n - 1`.

<PracticePlayground problemId="graph-algo-prob-6" />

<Solution>

```python
def find_town_judge(n, trust):
    scores = [0] * (n + 1)
    for a, b in trust:
        scores[a] -= 1
        scores[b] += 1
    for i in range(1, n + 1):
        if scores[i] == n - 1:
            return i
    return -1
```

Track net in-degree minus out-degree for each person. Only a universal sink trusted by all other n-1 people and trusting nobody can achieve a net score of n-1.
