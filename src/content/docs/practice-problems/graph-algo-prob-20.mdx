# #640. Graphs & Network Algorithms Module 4: Problem 20

**Track**: Graphs & Network Algorithms | **Rank**: #640 of 1072 | **Points**

## Overview

Connect 2D geometric coordinates with minimum total Manhattan edge cost using Prim's algorithm.

## Task

Implement `min_cost_connect_all_points(points)`: grow a minimum spanning tree using a min-heap priority queue, adding the cheapest Manhattan connection to an unvisited point at each step.

<Solution>

```python
import heapq

def min_cost_connect_all_points(points):
    n = len(points)
    visited = set()
    pq = [(0, 0)]
    total_cost = 0
    while len(visited) < n:
        cost, u = heapq.heappop(pq)
        if u in visited:
            continue
        visited.add(u)
        total_cost += cost
        x1, y1 = points[u]
        for v in range(n):
            if v not in visited:
                x2, y2 = points[v]
                d = abs(x1 - x2) + abs(y1 - y2)
                heapq.heappush(pq, (d, v))
    return total_cost
```

Use Prim's algorithm to greedily expand the minimum spanning tree over complete Manhattan distance graphs.
