# Mean Squared Error

**Rank #241** · Difficulty: **Easy** · Stage: **Stage 5: Classical Machine Learning & Optimization** · Category: **Classical ML** | **Points**: 40 XP

## Overview

Implement `mean_squared_error(y_true, y_pred)`, calculating the Mean Squared Error (MSE) across target and prediction vectors -- the canonical regression loss in machine learning and gradient-based optimization.

## Task

Implement `mean_squared_error(y_true, y_pred)`: return the average squared difference between corresponding elements of `y_true` and `y_pred`. If `y_true` and `y_pred` are empty, return `0.0`.

<PracticePlayground problemId="classical-ml-prob-1" />

<Solution>

```python
def mean_squared_error(y_true, y_pred):
    if not y_true:
        return 0.0
    return sum((yt - yp) ** 2 for yt, yp in zip(y_true, y_pred)) / len(y_true)
```

Mean Squared Error heavily penalizes larger outliers due to squaring, making it standard for Gaussian likelihood estimation and ordinary least squares.

</Solution>
