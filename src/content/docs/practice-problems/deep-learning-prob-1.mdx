# RGB to HSV Color Space Conversion

**Track**: Deep Learning & Vision/NLP | **Points**: 40 XP

## Overview

Convert normalized RGB color channels to HSV representation, essential for color-invariant computer vision.

## Task

Implement `rgb_to_hsv(r, g, b)`. Given `r, g, b` in `[0.0, 1.0]`, compute `[h, s, v]` where `h` is in degrees `[0.0, 360.0)`, and `s, v` are in `[0.0, 1.0]`. If `max == min`, `h = 0.0`. Round each value to 4 decimal places.
