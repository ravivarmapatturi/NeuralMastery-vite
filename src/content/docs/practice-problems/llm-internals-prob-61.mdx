# Logit Lens: Project Intermediate Hidden State

**Track**: Transformers & LLMs | **Points**: 40 XP

## Overview

Implement the Logit Lens interpretability technique, projecting an INTERMEDIATE (not final) layer's hidden state through the model's final unembedding matrix to see what token that layer 'would predict' if generation stopped there.

## Task

Implement `logit_lens_top_token(hidden_state, unembed_matrix)`. `unembed_matrix` maps token id -> its unembedding row vector. Compute the dot product of `hidden_state` with each token's row, and return the token id with the HIGHEST dot product; ties broken by token id ascending.
