# Invert a Dictionary

**Rank #3** · Difficulty: **Easy** · Stage: **Stage 1: AI Foundations & Python Programming** · Category: **Python & Fundamentals** | **Points**: 40 XP

## Overview

Implement `invert_dictionary(mapping)`: transform a key-to-value map into a value-to-keys reverse index, the fundamental structure powering inverted indexes in information retrieval.

## Task

Implement the function `invert_dictionary(mapping)`: return a new dictionary mapping each unique value in `mapping` to a sorted list of keys that mapped to that value. If `mapping` is empty, return `{}`.

<PracticePlayground problemId="py-foundations-prob-3" />

<Solution>

```python
def invert_dictionary(mapping):
    inv = {}
    for k, v in mapping.items():
        if v not in inv:
            inv[v] = []
        inv[v].append(k)
    for v in inv:
        inv[v].sort()
    return inv
```

Inverting mappings to create multi-value lookups is the cornerstone of search engines (inverted index: term -> doc IDs) and clustering groupings.

</Solution>
