# Compact Range String Expansion Parser

**Rank #48** · Difficulty: **Medium** · Stage: **Stage 1: AI Foundations & Python Programming** · Category: **Python & Fundamentals**

## Overview

Parse compact human-readable range strings into deduplicated, sorted integer arrays.

## Task

Implement `parse_ranges(range_str)`: parse strings containing integers and dash-separated ranges (e.g. `"1-3,5,8-10"`). Return a sorted list of unique integers. Whitespace around tokens must be tolerated. If `range_str` is empty, return `[]`.

<Solution>

```python
def parse_ranges(range_str):
    if not range_str.strip():
        return []
    nums = set()
    parts = [p.strip() for p in range_str.split(',') if p.strip()]
    for p in parts:
        if '-' in p:
            sub = p.split('-')
            start, end = int(sub[0]), int(sub[1])
            for x in range(min(start, end), max(start, end) + 1):
                nums.add(x)
        else:
            nums.add(int(p))
    return sorted(nums)
```

Splitting comma-separated tokens and expanding ranges into a hash set guarantees uniqueness before a final sort.
