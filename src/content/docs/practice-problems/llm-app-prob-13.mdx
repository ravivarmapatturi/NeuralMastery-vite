# #073. Semantic Query Intent Router

**Track**: LLM Application Engineering | **Rank**: #73 of 1072 | **Points**: 60 XP

## Overview

Route user prompts to specialized domain handlers by comparing dense query embeddings against topic centroids. In production LLM application engineering, reliable system components, deterministic interfaces, and defensive validation are paramount for production stability and cost efficiency.

## Task

Implement `route_query_by_embedding(query_vector, route_centroids, threshold=0.5)`. Compute cosine similarity `dot(q, c) / (||q|| * ||c||)` between `query_vector` and each centroid in `route_centroids`. Round all similarities to 4 decimal places. Select the route with the highest similarity; if that similarity is below `threshold`, route to `'default_fallback'`. Return `{'route': route, 'similarity': chosen_similarity, 'all_scores': all_scores}`. Raise `ValueError` if `query_vector` is empty, has zero norm, or has dimension mismatch with any centroid.
