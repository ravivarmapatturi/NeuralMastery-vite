# Agent Heartbeat Liveness Check

**Track**: Multi-Agent Systems | **Points**: 40 XP

## Overview

Implement heartbeat-based liveness detection, the real, standard technique a multi-agent orchestrator uses to detect a crashed or hung agent.

## Task

Implement `is_agent_alive(last_heartbeat_ts, current_ts, timeout_s)`: return `True` if `(current_ts - last_heartbeat_ts) < timeout_s`, else `False` (considered dead).
