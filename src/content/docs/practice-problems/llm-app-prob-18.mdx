# #078. Sentence Grounding Attribution Check

**Track**: LLM Application Engineering | **Rank**: #78 of 1072 | **Points**: 60 XP

## Overview

Detect ungrounded hallucinations by evaluating word n-gram overlap between generated claim sentences and retrieved source passages. In production LLM application engineering, reliable system components, deterministic interfaces, and defensive validation are paramount for production stability and cost efficiency.

## Task

Implement `compute_sentence_attribution(claim_sentences, source_documents, n_gram_size=2, threshold=0.3)`. Extract lowercase word tokens using `\w+`. For each sentence in `claim_sentences`, compute its set of word n-grams of size `n_gram_size` (or all words if sentence has fewer than `n_gram_size` words). Calculate recall as `len(sentence_ngrams & source_ngrams) / len(sentence_ngrams)`. Sentence is grounded if `recall >= threshold`. Return `{'grounded_ratio': ratio, 'sentence_scores': list[dict], 'unsupported_sentences': list[str]}` with scores rounded to 4 decimals. If `claim_sentences` is empty, return `{'grounded_ratio': 1.0, 'sentence_scores': [], 'unsupported_sentences': []}`.
