# Command-Pattern Node Dispatch

**Track**: Agent Graph Engineering | **Points**: 40 XP

## Overview

Implement command-pattern dispatch, mapping a node's returned command type to the actual handler node it should invoke next -- a real, common indirection layer in agent graph frameworks.

## Task

Implement `dispatch_command(command_type, handlers)`: return `handlers[command_type]`, or `'__unhandled__'` if `command_type` isn't a key.
