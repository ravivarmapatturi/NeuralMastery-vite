# Blue-Green Deployment Traffic Cutover Check

**Track**: Agent Performance & Production | **Points**: 40 XP

## Overview

Implement blue-green deployment readiness checking, the real, automated gate deciding whether a new agent deployment version is healthy enough to receive full production traffic.

## Task

Implement `cutover_ready(green_error_rate, green_p99_ms, max_error_rate, max_p99_ms)`: return `True` only if BOTH `green_error_rate <= max_error_rate` AND `green_p99_ms <= max_p99_ms`.
