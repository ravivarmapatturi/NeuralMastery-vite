# Bounded Cycle Iteration Check

**Track**: Agent Graph Engineering | **Points**: 40 XP

## Overview

Implement bounded-cycle checking, allowing an agent graph's real, intentional loop (e.g. a 'retry until valid' cycle) while guaranteeing termination.

## Task

Implement `cycle_within_bound(current_iteration, max_iterations)`: return `True` (allowed to loop again) if `current_iteration < max_iterations`.
