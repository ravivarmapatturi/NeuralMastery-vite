# #070. Logprob Confidence Scorer

**Track**: LLM Application Engineering | **Rank**: #70 of 1072 | **Points**: 40 XP

## Overview

Quantify model generation certainty by aggregating token logprobs into sequence perplexity and geometric mean probability. In production LLM application engineering, reliable system components, deterministic interfaces, and defensive validation are paramount for production stability and cost efficiency.

## Task

Implement `compute_sequence_confidence(token_logprobs)`. Given a non-empty list of token natural log probabilities `ln(P)`, calculate: `avg_logprob = sum(token_logprobs) / N`, `perplexity = exp(-avg_logprob)`, and `geometric_mean_prob = exp(avg_logprob)`. Round all output values to 4 decimal places. Raise `ValueError` if `token_logprobs` is empty.
