# #036. Frequency and Presence Penalties

**Track**: LLM Inference & Decoding | **Rank**: #36 of 1072 | **Points**: 40 XP

## Overview

Differentiate between repeating tokens multiple times versus introducing new topics using frequency and presence penalties. Autoregressive language models generate sequences token by token, evaluating next-token probability distributions at each decoding step.

## Task

Implement `apply_frequency_presence_penalties(logits, token_counts, frequency_penalty, presence_penalty)`. For each token ID in `token_counts`: subtract `count * frequency_penalty + (presence_penalty if count > 0 else 0.0)` from its logit. Token IDs outside `[0, len(logits)-1]` should be safely ignored. If any token count is negative, raise `ValueError`. Return logits rounded to 4 decimal places.
