# LLM Inference FLOPs: Prefill vs Decode

**Track**: transformers-llms | **Points**: 40 XP

## Overview

Calculate computational complexity (FLOPs) for the prefill and decoding phases of LLM inference.

## Task

Implement `calculate_inference_flops(num_params, prompt_tokens, generated_tokens)`. Using standard model approximation `2 * num_params` FLOPs per token forward pass, compute `prefill_flops = 2 * num_params * prompt_tokens`, `decode_flops = 2 * num_params * generated_tokens`, and `total_flops = prefill_flops + decode_flops`. Return dict with `'prefill_flops'`, `'decode_flops'`, and `'total_flops'`.
