# #083. Sliding Window Conversation Summarizer

**Track**: LLM Application Engineering | **Rank**: #83 of 1072 | **Points**: 90 XP

## Overview

Maintain long-horizon conversational context by compressing older turns into an evolving synthetic summary message. In production LLM application engineering, reliable system components, deterministic interfaces, and defensive validation are paramount for production stability and cost efficiency.

## Task

Implement `compress_conversation_history(messages, max_active_messages=4)`. If conversational dialog turns (excluding index 0 system prompt if present) exceed `max_active_messages`, compress the older turns into a synthetic system message: `'role': 'system', 'content': 'System summary of prior context: ' + ' | '.join(f'{role}: {content}' for turn in summarized_turns)`. Retain the most recent `max_active_messages` turns untouched. Return `{'compressed_messages': list, 'summarized_turns_count': int, 'was_compressed': bool}`. If `max_active_messages < 2`, raise `ValueError`.
