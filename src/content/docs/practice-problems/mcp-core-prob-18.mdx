# Root Directory Scope Enforcement

**Track**: MCP Core Engineering | **Points**: 40 XP

## Overview

Implement filesystem-root scope enforcement, a real security boundary check for an MCP server exposing filesystem tools.

## Task

Implement `is_path_within_roots(path, allowed_roots)`. Normalize `path` via `os.path.normpath`. Return `True` if the normalized path starts with any normalized root in `allowed_roots` followed by a path separator (or equals it exactly) -- i.e. the path is genuinely inside (or equal to) an allowed root, not just string-prefixed by it (e.g. `/home/user2` must NOT match root `/home/user`).
