# #785. Exponentially Weighted Rolling Covariance

**Track**: Pandas & Data Processing Pipelines | **Rank**: #785 of 1072 | **Points**: 60 XP

## Overview

Track dynamic time-varying cross-asset covariance using online exponential weighting.

## Task

Implement `ewm_covariance_stream(returns_a, returns_b, alpha)`: calculate series means `mu_a` and `mu_b`. Initialize `cov_0 = 0.0`. For each time step `t`, update recursive covariance `cov_t = alpha * (returns_a[t] - mu_a) * (returns_b[t] - mu_b) + (1 - alpha) * cov_{t-1}`. Return list of covariance values at each step rounded to 4 decimals.

<Solution>

```python
def ewm_covariance_stream(returns_a, returns_b, alpha=0.1):
    n = len(returns_a)
    ma = sum(returns_a) / n if n else 0.0
    mb = sum(returns_b) / n if n else 0.0
    cov = 0.0
    res = []
    for ra, rb in zip(returns_a, returns_b):
        inst = (ra - ma) * (rb - mb)
        cov = alpha * inst + (1.0 - alpha) * cov
        res.append(round(float(cov), 4))
    return res
```

Applies recursive exponential smoothing to instantaneous cross-products of demeaned returns.
