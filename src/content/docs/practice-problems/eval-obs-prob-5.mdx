# Compute Eval Suite Pass Rate by Category

**Track**: Agent Evaluation & Observability | **Points**: 40 XP

## Overview

Implement per-category eval pass-rate breakdown, a real diagnostic step revealing WHICH kind of task an agent is actually weak on, rather than one opaque overall score.

## Task

Implement `pass_rate_by_category(results)`. Each result is `{"category": str, "passed": bool}`. Return a dict mapping each distinct category to its pass rate (fraction of that category's results with `passed==True`).
