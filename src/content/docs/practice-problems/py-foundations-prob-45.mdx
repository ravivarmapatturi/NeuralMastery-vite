# Longest Substring Without Repeating Characters

**Rank #45** · Difficulty: **Medium** · Stage: **Stage 1: AI Foundations & Python Programming** · Category: **Python & Fundamentals**

## Overview

Find the maximum span of unique consecutive characters using a dynamic sliding window.

## Task

Implement `length_of_longest_substring(s)`: find the length of the longest substring of `s` that contains no duplicate characters.

<PracticePlayground problemId="py-foundations-prob-45" />

<Solution>

```python
def length_of_longest_substring(s):
    seen = {}
    start = 0
    max_len = 0
    for end, ch in enumerate(s):
        if ch in seen and seen[ch] >= start:
            start = seen[ch] + 1
        seen[ch] = end
        max_len = max(max_len, end - start + 1)
    return max_len
```

Advancing start pointer directly to seen[ch] + 1 when a duplicate is found achieves strict O(n) time complexity.

</Solution>
