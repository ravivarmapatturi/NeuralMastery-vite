# Align Answer Sentences to Best Supporting Chunk

**Track**: Advanced RAG & Agentic RAG | **Points**: 40 XP

## Overview

Implement sentence-to-source citation alignment, finding which specific retrieved chunk best supports a given generated sentence -- the real work behind an inline-citation feature.

## Task

Implement `align_sentence_to_source(answer_sentence, chunks)`. `chunks` maps chunk id -> its text. For each chunk, count the number of the sentence's lowercase words also present in that chunk. Return the chunk id with the HIGHEST overlap count; ties broken by chunk id ascending.
