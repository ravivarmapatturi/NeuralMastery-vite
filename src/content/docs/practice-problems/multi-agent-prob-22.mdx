# Negotiation Zone of Agreement Check

**Track**: Multi-Agent Systems | **Points**: 40 XP

## Overview

Implement the zone-of-agreement check, a real precondition test in agent negotiation: is a deal even mathematically possible before wasting negotiation rounds.

## Task

Implement `has_zone_of_agreement(buyer_max_price, seller_min_price)`: return `True` if `buyer_max_price >= seller_min_price` (a real price range where both sides could agree exists).
