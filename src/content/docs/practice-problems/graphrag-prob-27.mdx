# Check Answer Entities Are Grounded in Retrieved Subgraph

**Track**: Knowledge Graph & GraphRAG | **Points**: 40 XP

## Overview

Implement GraphRAG answer-grounding validation, checking that every entity a generated answer names actually appeared in the retrieved subgraph (not hallucinated).

## Task

Implement `answer_entities_grounded(answer_entities, subgraph_entities)`: return `True` only if EVERY entity in `answer_entities` is present in `subgraph_entities`. An empty `answer_entities` list is trivially grounded.
