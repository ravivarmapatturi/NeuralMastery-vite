# #799. Stream Watermarking and Late-Arrival Filter

**Track**: Pandas & Data Processing Pipelines | **Rank**: #799 of 1072 | **Points**: 90 XP

## Overview

Track streaming watermarks and discard out-of-order records exceeding allowed event-time lag.

## Task

Implement `watermark_stream_filter(stream, max_delay)`: maintain `watermark = -infinity`. For each event in `stream`: if `event['timestamp'] < watermark`, place in `rejected_events`. Otherwise, place in `accepted_events` and advance watermark: `watermark = max(watermark, event['timestamp'] - max_delay)`. Return dict `{"accepted_events": list[dict], "rejected_events": list[dict]}`.

<PracticePlayground problemId="pandas-proc-prob-29" />

<Solution>

```python
def watermark_stream_filter(stream, max_delay):
    wm = -float('inf')
    accepted, rejected = [], []
    for ev in stream:
        ts = ev['timestamp']
        if ts < wm:
            rejected.append(ev)
        else:
            accepted.append(ev)
            wm = max(wm, ts - max_delay)
    return {'accepted_events': accepted, 'rejected_events': rejected}
```

Updates the low-watermark threshold and filters out late-arriving temporal events.
