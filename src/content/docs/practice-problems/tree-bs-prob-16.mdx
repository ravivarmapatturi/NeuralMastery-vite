# #606. Trees / Binary Search Module 4: Problem 16

**Track**: Trees / Binary Search | **Rank**: #606 of 1072 | **Points**: 60 XP

## Overview

Implement Diameter of Binary Tree -- the classic "compute a global answer while also computing a per-node height" problem, solved in one pass by updating a running best as a side effect of the height recursion.

## Task

Implement the function `diameter_of_binary_tree(root)`: return the length (in edges, not nodes) of the longest path between any two nodes in the tree -- this path may or may not pass through the root. Must run in O(n) time.
