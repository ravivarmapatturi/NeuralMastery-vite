# DBSCAN Core Point Check

**Track**: Clustering & Recommender Systems | **Points**: 40 XP

## Overview

Implement DBSCAN's core-point test, the primitive that makes density-based clustering possible without pre-specifying k.

## Task

Implement `is_core_point(point_idx, points, eps, min_pts)`. A point is a core point if at least `min_pts` OTHER points (excluding itself) lie within Euclidean distance `eps` (inclusive) of it.
