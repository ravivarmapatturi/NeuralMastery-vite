# Detect Stale Security-Patched Dependency

**Track**: Agent Security & Reliability | **Points**: 40 XP

## Overview

Implement security-patch staleness detection, a real check flagging when a dependency's applied security patch is far enough behind the latest known patch to warrant an update.

## Task

Implement `is_patch_stale(current_patch_date, latest_patch_date, staleness_threshold_days)`. Both dates are days-since-epoch floats. Return `True` if `(latest_patch_date - current_patch_date) > staleness_threshold_days`.
