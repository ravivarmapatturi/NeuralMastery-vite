# Construct Causal Attention Mask

**Rank #363** · Difficulty: **Easy** · Stage: **Stage 7: Transformers, LLMs & Foundation Models** · Category: **Transformers & LLMs**

Build a causal (autoregressive) attention mask matrix preventing query positions from attending to future key positions during decoding. Prerequisite: `llm-internals-prob-2`.

<PracticePlayground problemId="llm-internals-prob-3" />

<Solution>

```python
def causal_attention_mask(seq_len):
    if seq_len <= 0:
        raise ValueError("seq_len must be positive")
    return [[1 if j <= i else 0 for j in range(seq_len)] for i in range(seq_len)]
```

Causal masks enforce autoregressive generation by preventing positions from attending to future tokens, ensuring each token's representation depends only on preceding context.

</Solution>
