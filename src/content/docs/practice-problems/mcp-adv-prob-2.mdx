# Score Tool Relevance to a Task

**Track**: MCP Advanced & Agent Integration | **Points**: 40 XP

## Overview

Implement a real, simple keyword-overlap relevance scorer for tool selection, used when an agent has too many available tools to fit all descriptions in context.

## Task

Implement `score_tool_relevance(task_description, tool_description)`. Tokenize both into lowercase word sets. Return the Jaccard similarity `|A∩B|/|A∪B|` (0.0 if both empty).
