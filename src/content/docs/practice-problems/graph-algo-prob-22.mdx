## Overview

Reconstruct a complete travel itinerary visiting every ticket edge using Hierholzer's Eulerian path algorithm.

## Task

Implement `find_itinerary(tickets)`: sort adjacency lists lexicographically in reverse. Perform Hierholzer's postorder DFS, pushing airport to route when its outgoing edges are exhausted.

<Solution>

```python
from collections import defaultdict

def find_itinerary(tickets):
    adj = defaultdict(list)
    for src, dst in sorted(tickets, reverse=True):
        adj[src].append(dst)
    route = []
    def dfs(airport):
        while adj[airport]:
            next_dest = adj[airport].pop()
            dfs(next_dest)
        route.append(airport)
    dfs("JFK")
    return route[::-1]
```

Sort destinations in reverse lexical order so popping yields the smallest lexical neighbor. Postorder collection naturally stitches cycles into the Eulerian route.
