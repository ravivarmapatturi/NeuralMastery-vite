# #654. Dynamic Programming & Greedy Module 1: Problem 4

**Track**: Dynamic Programming & Greedy | **Rank**: #654 of 1072 | **Points**

## Overview

Find the maximum profit from a single buy-sell trade in an array of stock prices in O(n) time.

## Task

Implement `max_profit_stock(prices)`: iterate through prices, tracking the lowest price seen so far and maximizing price - min_price at each day.

<PracticePlayground problemId="dp-greedy-prob-4" />

<Solution>

```python
def max_profit_stock(prices):
    if not prices:
        return 0
    min_price = prices[0]
    max_prof = 0
    for p in prices[1:]:
        if p < min_price:
            min_price = p
        elif p - min_price > max_prof:
            max_prof = p - min_price
    return max_prof
```

Track the minimum price seen so far as the optimal purchase day, evaluating potential profit if selling at current day.
