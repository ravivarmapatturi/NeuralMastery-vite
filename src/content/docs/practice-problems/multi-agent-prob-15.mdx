# Bayesian Agent Trust Score Update

**Track**: Multi-Agent Systems | **Points**: 40 XP

## Overview

Implement a Beta-distribution trust update, the real Bayesian technique for tracking how much a multi-agent orchestrator should trust a given agent based on its track record.

## Task

Implement `update_trust_score(alpha, beta, success)`. This is a Beta(alpha, beta) trust distribution. If `success` is `True`, return `(alpha+1, beta)`; otherwise return `(alpha, beta+1)`.
