# Query Expansion via Synonym Injection

**Track**: RAG Production Engineering | **Points**: 40 XP

## Overview

Implement simple synonym-based query expansion, a real technique to improve sparse (keyword) retrieval recall.

## Task

Implement `expand_query(query, synonyms)`. Tokenize `query` on whitespace. For each token that's a key in `synonyms`, append all of its synonym values (space-separated) after the original query. Return the expanded query string with original tokens first, then all appended synonyms in token order.
