# #047. Length-Normalized Beam Ranker

**Track**: LLM Inference & Decoding | **Rank**: #47 of 1072 | **Points**: 60 XP

## Overview

Mitigate beam search length bias using GNMT length-penalty scoring. Autoregressive language models generate sequences token by token, evaluating next-token probability distributions at each decoding step.

## Task

Implement `rank_beams_by_length_penalty(beams, alpha=0.6)`. For each beam, calculate length penalty `LP(Y) = ((5 + |Y|) / 6)^\alpha`, where `|Y| = \text{len}(\text{sequence})`. Normalized score is `\text{score}_{norm} = \text{cumulative\_log\_prob} / LP(Y)`. Sort beams descending by normalized score (ties broken by shorter sequence length, then sequence tokens). Assign 1-indexed ranks (`rank: 1, 2, ...`). Scores must be rounded to 4 decimal places. If any beam sequence is empty or `alpha < 0.0`, raise `ValueError`.
