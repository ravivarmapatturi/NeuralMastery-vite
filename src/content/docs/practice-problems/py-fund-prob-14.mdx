## Overview

Count the total number of dictionary keys embedded in arbitrary combinations of nested dictionaries and lists.

## Task

Implement `nested_key_counter(data)`: traverse arbitrary JSON data structures and count how many dictionary keys exist across all nesting levels, including dictionaries inside lists.

<PracticePlayground problemId="py-fund-prob-14" />

<Solution>

```python
def nested_key_counter(data):
    count = 0
    def walk(obj):
        nonlocal count
        if isinstance(obj, dict):
            for k, v in obj.items():
                count += 1
                walk(v)
        elif isinstance(obj, list):
            for item in obj:
                walk(item)
    walk(data)
    return count
```

Recursively inspecting dicts and lists traverses all JSON tree nodes in linear time.
