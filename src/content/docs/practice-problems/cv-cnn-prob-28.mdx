# #918. FPN Top-Down Pathway Lateral Feature Fusion

**Track**: Computer Vision & CNN Architectures | **Rank**: #918 of 1072 | **Points**: 60 XP

## Overview

Construct rich multi-scale feature pyramids by propagating semantically strong high-level features downward to merge with spatially precise shallow features.

## Task

Implement `fpn_top_down_fusion(...)`. Upsample `higher_level` (shape `H x W`) by a factor of 2 along both spatial dimensions using nearest-neighbor interpolation: each element `(r, c)` expands to cover rows `2r, 2r+1` and columns `2c, 2c+1`. Add the upsampled result elementwise to `lower_level_lateral` (shape `2H x 2W`). Round each fused pixel value to 4 decimal places.

```python
def fpn_top_down_fusion(higher_level: list[list[float]], lower_level_lateral: list[list[float]]) -> list[list[float]]:
    H = len(higher_level)
    W = len(higher_level[0])
    fused = []
    for i in range(2 * H):
        row = []
        for j in range(2 * W):
            src_r = i // 2
            src_c = j // 2
            val = higher_level[src_r][src_c] + lower_level_lateral[i][j]
            row.append(round(val, 4))
        fused.append(row)
    return fused
```

Nearest-neighbor 2x upsampling doubles spatial dimensions to align with lateral features before element-wise summation.
