# Graphs: Word Ladder (BFS Shortest Transformation)

**Rank #113** · Difficulty: **Hard** · Stage: **Stage 2: Data Structures & Algorithmic Foundations** · Category: **Data Structures & Algorithms**

## Overview

Implement `ladder_length(begin_word, end_word, word_list)` -- BFS where edges connect words differing by one letter. The trick is generating all one-letter neighbors efficiently.

## Task

Implement the function `ladder_length(begin_word, end_word, word_list)`. Return the length of the shortest transformation sequence from `begin_word` to `end_word` (each step changes one letter), or `0` if impossible.

<Solution>

```python
from collections import deque

def ladder_length(begin_word, end_word, word_list):
    word_set = set(word_list)
    if end_word not in word_set:
        return 0
    q = deque([(begin_word, 1)])
    visited = {begin_word}
    while q:
        word, length = q.popleft()
        for i in range(len(word)):
            for c in 'abcdefghijklmnopqrstuvwxyz':
                new_word = word[:i] + c + word[i+1:]
                if new_word == end_word:
                    return length + 1
                if new_word in word_set and new_word not in visited:
                    visited.add(new_word)
                    q.append((new_word, length + 1))
    return 0
```

BFS where neighbors are all words reachable by changing one character. Check end_word membership first (early exit). O(M^2 * N) time where M = word length, N = word list size.
