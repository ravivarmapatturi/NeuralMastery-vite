# Trees: Symmetric Tree

**Rank #77** · Difficulty: **Easy** · Stage: **Stage 2: Data Structures & Algorithmic Foundations** · Category: **Data Structures & Algorithms**

## Overview

Implement `is_symmetric(root)` -- checking if a tree is its own mirror image. The base pattern for Subtree of Another Tree and Same Tree.

## Task

Implement the function `is_symmetric(root)`. Each node is `{'val', 'left', 'right'}`. Return `True` if the tree is a mirror of itself.

<PracticePlayground problemId="ds-algo-prob-17" />

<Solution>

```python
def is_symmetric(root):
    def check(l, r):
        if not l and not r:
            return True
        if not l or not r:
            return False
        return (l['val'] == r['val']
                and check(l['left'], r['right'])
                and check(l['right'], r['left']))
    if not root:
        return True
    return check(root['left'], root['right'])
```

Paired recursion: left.left mirrors right.right, and left.right mirrors right.left. An empty tree is symmetric. O(n) time.

</Solution>
