# Compute Real Token Usage Cost Attribution by User

**Track**: Agent Evaluation & Observability | **Points**: 40 XP

## Overview

Implement per-user cost attribution, a real observability requirement for any multi-tenant agent deployment needing to bill or budget-track individual users.

## Task

Implement `cost_by_user(request_costs)`. Each entry is `{"user_id": str, "cost": float}`. Return a dict mapping each distinct user id to the SUM of their costs.
