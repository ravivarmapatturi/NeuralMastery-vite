# Pandas Module 59: Problem 239

**Rank #239** · Difficulty: **Hard** · Stage: **Stage 4: NumPy & Vectorized Data Processing** · Category: **NumPy & Pandas**

## Overview

Encode periodic temporal features into continuous sinusoidal coordinates.

## Task

Implement `encode_cyclical_time(hours, period)`: for each value `h`, map onto the unit circle via angle `theta = 2 * pi * (h % period) / period`. Return `[sin(theta), cos(theta)]` for each hour, rounded to 4 decimal places.

<PracticePlayground problemId="numpy-pandas-prob-59" />

<Solution>

```python
import math

def encode_cyclical_time(hours, period):
    out = []
    for h in hours:
        angle = 2.0 * math.pi * (h % period) / period
        sin_val = round(float(math.sin(angle)), 4)
        cos_val = round(float(math.cos(angle)), 4)
        out.append([sin_val, cos_val])
    return out
```

Cyclical sine/cosine transformation preserves the boundary continuity of periodic variables such that hour 23 and hour 0 remain adjacent in Euclidean feature space.

</Solution>
