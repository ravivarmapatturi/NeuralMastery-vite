## Overview

Track continuous running median values across expanding numerical streams.

## Task

Implement `cumulative_moving_median(nums)`: after each number is ingested, compute the current median of all numbers seen so far. If the count of observed numbers is even, the median is the average of the two middle elements. Round each median to 4 decimal places. Return `[]` for empty input.

<PracticePlayground problemId="py-fund-prob-11" />

<Solution>

```python
import bisect

def cumulative_moving_median(nums):
    if not nums:
        return []
    medians = []
    window = []
    for x in nums:
        bisect.insort(window, x)
        m = len(window)
        if m % 2 == 1:
            med = float(window[m // 2])
        else:
            med = (window[m // 2 - 1] + window[m // 2]) / 2.0
        medians.append(round(med, 4))
    return medians
```

Inserting via bisect maintains sorted order so median extraction takes O(1) time per element.
