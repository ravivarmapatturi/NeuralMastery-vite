# Score RAG Answer Groundedness

**Rank #473** · Difficulty: **Medium** · Stage: **Stage 8: RAG, Agents, MCP & Distributed Systems** · Category: **Agents, MCP & Systems**

Implement `groundedness_score(answer, source_chunks)`, a cheap lexical proxy for the actively-discussed RAG problem of detecting hallucination -- what fraction of the answer's own vocabulary is even present anywhere in the retrieved sources. Prerequisite: `agents-mcp-systems-prob-42`.

<PracticePlayground problemId="agents-mcp-systems-prob-43" />

<Solution>

```python
import re

def groundedness_score(answer, source_chunks):
    answer_tokens = set(re.findall(r"[a-z0-9]+", answer.lower()))
    if not answer_tokens:
        raise ValueError("answer must contain at least one token")
    source_tokens = set()
    for chunk in source_chunks:
        source_tokens |= set(re.findall(r"[a-z0-9]+", chunk.lower()))
    return len(answer_tokens & source_tokens) / len(answer_tokens)
```

This score answers a different question than a relevance metric like Jaccard or cosine similarity: it is not "how similar are these two texts," but "how much of what the answer claims can even be traced back to the retrieved context" -- a real (simplified) building block toward automated RAG faithfulness evaluation.

</Solution>
