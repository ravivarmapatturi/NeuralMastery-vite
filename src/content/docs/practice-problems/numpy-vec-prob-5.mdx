# #745. Vectorized Pairwise Mahalanobis Distance

**Track**: NumPy & Vectorized Computation | **Rank**: #745 of 1072 | **Points**: 40 XP

## Overview

Compute the scale-invariant Mahalanobis distance using an inverse covariance matrix.

## Task

Implement `mahalanobis_distance(u, v, inv_cov)`: compute `D_M = sqrt((u - v)^T Sigma^{-1} (u - v))` where `inv_cov` is `Sigma^{-1}`. Return the distance rounded to 4 decimals.

<PracticePlayground problemId="numpy-vec-prob-5" />

<Solution>

```python
import math

def mahalanobis_distance(u, v, inv_cov):
    diff = [a - b for a, b in zip(u, v)]
    d = len(diff)
    temp = [sum(diff[j] * inv_cov[j][i] for j in range(d)) for i in range(d)]
    dist_sq = sum(temp[i] * diff[i] for i in range(d))
    return round(float(math.sqrt(max(0.0, dist_sq))), 4)
```

Calculates the quadratic form of the difference vector with the precision matrix and takes square root.
