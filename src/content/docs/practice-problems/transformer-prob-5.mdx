# #005. Transformer Internals Module 1: Problem 5

**Track**: Transformer Internals | **Rank**: #5 of 1072 | **Points**: 40 XP

## Overview

Generate sinusoidal positional encodings as introduced in Attention Is All You Need. Because standard self-attention is permutation-invariant, positional encodings inject sequence order information across embedding dimensions using sine and cosine frequencies.

## Task

Implement `positional_encoding(max_len, d_model)`: construct a 2D matrix of shape `[max_len, d_model]`. For position `pos` and dimension index `i`: compute `PE(pos, 2i) = sin(pos / (10000 ** (2i / d_model)))` and `PE(pos, 2i + 1) = cos(pos / (10000 ** (2i / d_model)))`. Return values rounded to 4 decimal places. If `max_len <= 0` or `d_model <= 0` or `d_model % 2 != 0`, raise `ValueError`.
