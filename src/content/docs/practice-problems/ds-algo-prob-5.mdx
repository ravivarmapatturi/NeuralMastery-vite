# Advanced DS: Valid Parentheses

**Rank #65** · Difficulty: **Easy** · Stage: **Stage 2: Data Structures & Algorithmic Foundations** · Category: **Data Structures & Algorithms**

## Overview

Implement `is_valid(s)` -- the canonical stack problem. Used verbatim in compilers, linters, and as a component of expression-evaluator problems.

## Task

Implement the function `is_valid(s)`. Return `True` if the bracket string has every opener matched by its correct closer in valid nesting order.

<PracticePlayground problemId="ds-algo-prob-5" />

<Solution>

```python
def is_valid(s):
    stack = []
    mapping = {')': '(', ']': '[', '}': '{'}
    for c in s:
        if c in '([{':
            stack.append(c)
        else:
            if not stack or stack[-1] != mapping[c]:
                return False
            stack.pop()
    return len(stack) == 0
```

Push openers; for closers check the stack top against a closing-to-opening mapping. A trailing non-empty stack means unmatched openers.

</Solution>
