# TF-IDF Document Vector Calculation

**Track**: Deep Learning & Vision/NLP | **Points**: 40 XP

## Overview

Compute the smooth TF-IDF feature representation of a text document across a predefined vocabulary.

## Task

Implement `tf_idf_vector(doc_tokens, corpus, vocabulary)`. For each term `t` in `vocabulary`, calculate `tf = count(t, doc_tokens) / len(doc_tokens)` (if `doc_tokens` empty, `tf = 0.0`). Document frequency `df` is the number of documents in `corpus` containing `t`. Compute `idf = ln((1 + N) / (1 + df)) + 1.0` where `N = len(corpus)`. The score is `tf * idf`. Return list of floats rounded to 4 decimal places.
