## Overview

Compute primary, secondary, and union diagonal sums for square matrices with central cell deduplication.

## Task

Implement `matrix_diagonal_sums(matrix)`: given an `n x n` square integer matrix, compute `{"main": main_sum, "anti": anti_sum, "total": total_sum}`. The `main` diagonal runs from `(0, 0)` to `(n-1, n-1)`; the `anti` diagonal runs from `(0, n-1)` to `(n-1, 0)`. The `total` sum includes all diagonal cells without double-counting the central element in odd-sized matrices.

<Solution>

```python
def matrix_diagonal_sums(matrix):
    if not matrix or not matrix[0]:
        return {'main': 0, 'anti': 0, 'total': 0}
    n = len(matrix)
    main_sum = sum(matrix[i][i] for i in range(n))
    anti_sum = sum(matrix[i][n - 1 - i] for i in range(n))
    total = main_sum + anti_sum
    if n % 2 == 1:
        total -= matrix[n // 2][n // 2]
    return {'main': main_sum, 'anti': anti_sum, 'total': total}
```

Computing diagonal coordinates simultaneously in a single loop visits diagonals in O(n) linear steps.
