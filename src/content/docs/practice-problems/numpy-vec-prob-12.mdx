# #752. Vectorized Tile and Repeat Array Broadcasting

**Track**: NumPy & Vectorized Computation | **Rank**: #752 of 1072 | **Points**: 60 XP

## Overview

Broadcast and replicate 2D matrices across row and column axes without nested copies.

## Task

Implement `tile_matrix_2d(mat, reps_row, reps_col)`: replicate `mat` of shape `(H, W)` to produce an expanded matrix of shape `(H * reps_row, W * reps_col)` by repeating the original block structure.

<PracticePlayground problemId="numpy-vec-prob-12" />

<Solution>

```python
def tile_matrix_2d(mat, reps_row, reps_col):
    tiled = []
    for _ in range(reps_row):
        for row in mat:
            tiled.append(row * reps_col)
    return tiled
```

Duplicates row items across columns then duplicates entire row blocks across rows.

</Solution>
