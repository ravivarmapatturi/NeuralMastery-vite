# Linked Lists: Sort Linked List (Merge Sort)

**Rank #96** · Difficulty: **Medium** · Stage: **Stage 2: Data Structures & Algorithmic Foundations** · Category: **Data Structures & Algorithms**

## Overview

Implement `sort_list(head)` using merge sort on a linked list -- O(n log n) time, O(log n) stack space. Merge sort fits linked lists perfectly because splitting at the middle is O(n) with slow/fast pointers.

## Task

Implement the function `sort_list(head)`. Each node is `{'val', 'next'}`. Sort the linked list in ascending order and return the new head.

<PracticePlayground problemId="ds-algo-prob-36" />

<Solution>

```python
def sort_list(head):
    if not head or not head['next']:
        return head
    # Split at middle
    slow, fast = head, head['next']
    while fast and fast['next']:
        slow = slow['next']
        fast = fast['next']['next']
    mid = slow['next']
    slow['next'] = None
    # Recurse
    left = sort_list(head)
    right = sort_list(mid)
    # Merge
    dummy = {'val': 0, 'next': None}
    cur = dummy
    while left and right:
        if left['val'] <= right['val']:
            cur['next'] = left
            left = left['next']
        else:
            cur['next'] = right
            right = right['next']
        cur = cur['next']
    cur['next'] = left or right
    return dummy['next']
```

Top-down merge sort: split at middle with slow/fast, recurse both halves, merge sorted halves. O(n log n) time, O(log n) recursion depth.
