# Classify Relation Type by Keyword Rule

**Track**: Knowledge Graph & GraphRAG | **Points**: 40 XP

## Overview

Implement rule-based relation-type classification, mapping a raw extracted predicate phrase into a normalized relation category for a knowledge graph schema.

## Task

Implement `classify_relation(predicate_text)`. Lowercase the input. If it contains `'ceo'` or `'founder'` or `'leads'`, return `'LEADERSHIP'`. If it contains `'located'` or `'based'`, return `'LOCATION'`. If it contains `'acquire'` or `'bought'` or `'owns'`, return `'OWNERSHIP'`. Otherwise return `'OTHER'`. Check categories in the order listed (first match wins).
