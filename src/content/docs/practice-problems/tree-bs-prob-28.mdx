## Overview

Sort binary tree nodes by column coordinates from left to right, tie-breaking by row and then node value.

## Task

Implement `vertical_order_traversal(root)`: assign (row, col) coordinates with root at (0, 0). Left child is at (row + 1, col - 1) and right at (row + 1, col + 1). Group nodes by col and sort within each column by (row, val).

```python
def vertical_order_traversal(root):
    if not root:
        return []
    from collections import defaultdict
    cols = defaultdict(list)
    queue = [(root, 0, 0)]
    while queue:
        node, col, row = queue.pop(0)
        cols[col].append((row, node['val']))
        if node.get('left'):
            queue.append((node['left'], col - 1, row + 1))
        if node.get('right'):
            queue.append((node['right'], col + 1, row + 1))
    res = []
    for c in sorted(cols.keys()):
        sorted_nodes = sorted(cols[c], key=lambda x: (x[0], x[1]))
        res.append([v for _, v in sorted_nodes])
    return res
```

Assign coordinate offsets (row, col) starting at (0, 0). Group nodes by column, sort columns from left to right, and sort nodes sharing a column by row and then value.
