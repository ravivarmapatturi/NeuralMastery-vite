# Vision Transformer Patch Projection Dimension Calculator

**Track**: Deep Learning & Vision/NLP | **Points**: 40 XP

## Overview

Calculate sequence length and linear projection parameter count for a Vision Transformer (ViT) patch embedding layer.

## Task

Implement `vit_patch_projection_dim(img_h, img_w, patch_size, in_channels, embed_dim)`. A Vision Transformer reshapes an image into `(num_patches_h, num_patches_w)` non-overlapping patches. Each patch has flattened dimension `patch_dim = patch_size * patch_size * in_channels`. A linear projection with bias projects each patch into `embed_dim`. Return a dict: `{'num_patches': int, 'patch_dim': int, 'linear_weights': int, 'linear_biases': int, 'total_params': int}`.
