# LLM-as-Judge Score Normalization

**Track**: Agent Evaluation & Observability | **Points**: 40 XP

## Overview

Implement judge-score normalization, converting an LLM-as-judge's raw rating (on whatever scale the judge prompt used) into a standard [0,1] range for aggregation across differently-scaled evaluations.

## Task

Implement `normalize_judge_score(raw_score, scale_min, scale_max)`: return `(raw_score - scale_min) / (scale_max - scale_min)`, clamped to `[0, 1]`.
