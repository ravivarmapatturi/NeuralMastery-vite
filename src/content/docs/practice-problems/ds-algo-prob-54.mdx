# DP: Regular Expression Matching

**Rank #114** · Difficulty: **Hard** · Stage: **Stage 2: Data Structures & Algorithmic Foundations** · Category: **Data Structures & Algorithms**

## Overview

Implement `is_match(s, p)` -- 2-D DP handling `.` (any char) and `*` (zero or more of preceding). A classic hard DP problem testing careful state-transition reasoning.

## Task

Implement the function `is_match(s, p)`. Return `True` if `s` matches pattern `p`. `.` matches any single character; `*` matches zero or more of the preceding element.

<PracticePlayground problemId="ds-algo-prob-54" />

<Solution>

```python
def is_match(s, p):
    m, n = len(s), len(p)
    dp = [[False]*(n+1) for _ in range(m+1)]
    dp[0][0] = True
    for j in range(2, n+1):
        if p[j-1] == '*':
            dp[0][j] = dp[0][j-2]
    for i in range(1, m+1):
        for j in range(1, n+1):
            if p[j-1] == '*':
                dp[i][j] = dp[i][j-2]  # zero occurrences of p[j-2]
                if p[j-2] == '.' or p[j-2] == s[i-1]:
                    dp[i][j] = dp[i][j] or dp[i-1][j]  # one more occurrence
            elif p[j-1] == '.' or p[j-1] == s[i-1]:
                dp[i][j] = dp[i-1][j-1]
    return dp[m][n]
```

dp[i][j] = does s[:i] match p[:j]. `*` has two cases: zero occurrences (copy dp[i][j-2]) or one more occurrence if the preceding pattern char matches (copy dp[i-1][j]). O(m*n) time and space.
