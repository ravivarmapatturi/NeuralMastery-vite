# Linked Lists: Add Two Numbers

**Rank #86** · Difficulty: **Medium** · Stage: **Stage 2: Data Structures & Algorithmic Foundations** · Category: **Data Structures & Algorithms**

## Overview

Implement `add_two_numbers(l1, l2)` -- ripple-carry addition on linked lists stored in reverse digit order. Tests carry propagation and list construction simultaneously.

## Task

Implement the function `add_two_numbers(l1, l2)`. Digits are stored in reverse order (least significant first). Return the head of the result linked list.

<PracticePlayground problemId="ds-algo-prob-26" />

<Solution>

```python
def add_two_numbers(l1, l2):
    dummy = {'val': 0, 'next': None}
    cur = dummy
    carry = 0
    while l1 or l2 or carry:
        s = carry
        if l1:
            s += l1['val']
            l1 = l1['next']
        if l2:
            s += l2['val']
            l2 = l2['next']
        carry, digit = divmod(s, 10)
        cur['next'] = {'val': digit, 'next': None}
        cur = cur['next']
    return dummy['next']
```

Ripple-carry: process digit-by-digit, carry forward. Continue until both lists and carry are exhausted. O(max(m,n)) time, O(max(m,n)) space for result.

</Solution>
