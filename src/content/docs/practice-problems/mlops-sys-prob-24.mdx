# Class Imbalance Ratio and Suggested Weights

**Track**: MLOps & Data Systems | **Points**: 40 XP

## Overview

Implement the real 'balanced' class-weight formula (matching scikit-learn's convention) used to counteract class imbalance during training.

## Task

Implement `class_weights(class_counts)`. For each class `c`, weight is `n_total / (n_classes * count[c])`, where `n_total` is the sum of all counts and `n_classes` is the number of distinct classes. Return a dict of class -> weight.
