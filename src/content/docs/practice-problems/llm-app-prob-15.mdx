# #075. Multi-Model Token Cost Meter

**Track**: LLM Application Engineering | **Rank**: #75 of 1072 | **Points**: 60 XP

## Overview

Track financial expenditure across multi-model LLM architectures using per-token pricing matrices. In production LLM application engineering, reliable system components, deterministic interfaces, and defensive validation are paramount for production stability and cost efficiency.

## Task

Implement `calculate_llm_costs(usage_logs, model_pricing)`. Sum `prompt_tokens` and `completion_tokens` across all logs. Calculate cost as `(prompt_tokens / 1e6) * prompt_per_million + (completion_tokens / 1e6) * completion_per_million`. Group by model and aggregate total USD cost, rounding all costs to 6 decimal places. Return `{'total_prompt_tokens': int, 'total_completion_tokens': int, 'total_cost_usd': float, 'by_model': dict}`. If a log references a model missing from `model_pricing`, raise `KeyError`.
