# Cold-Start Latency Amortization

**Track**: Agent Performance & Production | **Points**: 40 XP

## Overview

Implement cold-start latency amortization, the real calculation behind deciding how much a serverless agent deployment's cold-start penalty actually matters at scale.

## Task

Implement `amortized_latency(cold_start_ms, warm_latency_ms, requests_per_container_lifetime)`. The cold start happens once per container lifetime; amortize its cost across all requests served by that container: return `warm_latency_ms + (cold_start_ms / requests_per_container_lifetime)`.
