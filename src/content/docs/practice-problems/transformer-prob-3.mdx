# #003. Transformer Internals Module 1: Problem 3

**Track**: Transformer Internals | **Rank**: #3 of 1072 | **Points**: 40 XP

## Overview

Apply Layer Normalization across feature dimensions of hidden states. Layer Normalization standardizes activations across the embedding dimension independently for each sequence token, stabilizing forward activations and gradient backpropagation.

## Task

Implement `layer_norm(x, eps=1e-5)`: given a 1D vector `x`, compute its mean and variance. Normalize each element as `(x_i - mean) / sqrt(variance + eps)`. Return the normalized vector rounded to 4 decimal places. If `x` is empty, raise `ValueError`.
