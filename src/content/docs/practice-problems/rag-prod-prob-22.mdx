# Rule-Based Query Routing

**Track**: RAG Production Engineering | **Points**: 40 XP

## Overview

Implement a real, simple query router deciding between a cheap keyword-search path and an expensive dense-retrieval path -- a genuine cost-optimization pattern in production RAG.

## Task

Implement `route_query(query, keyword_threshold)`. Count `query`'s words (split on whitespace). If the word count is `<= keyword_threshold`, return `'sparse'` (short queries route to cheap keyword search); otherwise return `'dense'` (longer, more semantic queries route to embedding search).
