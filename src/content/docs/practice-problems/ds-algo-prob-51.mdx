# Linked Lists: Reverse Nodes in k-Group

**Rank #111** · Difficulty: **Hard** · Stage: **Stage 2: Data Structures & Algorithmic Foundations** · Category: **Data Structures & Algorithms**

## Overview

Implement `reverse_k_group(head, k)` -- reverse k nodes at a time, leaving remainders unchanged. Combines group-length checking, in-place reversal, and pointer re-wiring.

## Task

Implement the function `reverse_k_group(head, k)`. Each node is `{'val', 'next'}`. Reverse the list k nodes at a time. If fewer than k nodes remain at the end, leave them as-is.

<PracticePlayground problemId="ds-algo-prob-51" />

<Solution>

```python
def reverse_k_group(head, k):
    def get_kth(cur, k):
        while cur and k > 0:
            cur = cur['next']
            k -= 1
        return cur

    dummy = {'val': 0, 'next': head}
    group_prev = dummy

    while True:
        kth = get_kth(group_prev, k)
        if not kth:
            break
        group_next = kth['next']
        prev = group_next
        cur = group_prev['next']
        while cur != group_next:
            nxt = cur['next']
            cur['next'] = prev
            prev = cur
            cur = nxt
        tmp = group_prev['next']
        group_prev['next'] = kth
        group_prev = tmp

    return dummy['next']
```

Find the k-th node from group_prev; if it doesn't exist, stop (remaining nodes are fewer than k). Reverse the group in-place, then advance group_prev to what was the group's first node. O(n) time.

</Solution>
