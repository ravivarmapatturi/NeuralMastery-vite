# Gradient Clipping by Global Norm

**Track**: MLOps & Data Systems | **Points**: 40 XP

## Overview

Implement gradient clipping by global L2 norm, a real, standard technique to prevent exploding gradients from destabilizing training.

## Task

Implement `clip_grad_norm(gradients, max_norm)`. Compute the L2 norm of the full gradient vector. If it exceeds `max_norm`, scale EVERY component by `max_norm / norm` (preserving direction, only shrinking magnitude). If the norm is already `<= max_norm`, return the gradients unchanged.
