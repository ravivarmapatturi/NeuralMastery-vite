# Aggregate Health Across Multiple MCP Servers

**Track**: MCP Advanced & Agent Integration | **Points**: 40 XP

## Overview

Implement multi-server health aggregation, the real status-rollup logic an agent's server-management UI needs to show one overall health indicator.

## Task

Implement `aggregate_health(server_statuses)`. Each value is `'healthy'`, `'degraded'`, or `'down'`. Return `'down'` if ANY server is `'down'`; else `'degraded'` if ANY is `'degraded'`; else `'healthy'`.
