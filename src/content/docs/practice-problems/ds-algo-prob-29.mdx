# DP: Longest Increasing Subsequence

## Overview

Implement `length_of_lis(nums)` -- the patience-sort / binary-search approach gives O(n log n), far better than the naive O(n^2) DP.

## Task

Implement the function `length_of_lis(nums)`. Return the length of the longest strictly increasing subsequence.

<PracticePlayground problemId="ds-algo-prob-29" />

<Solution>

```python
import bisect

def length_of_lis(nums):
    dp = []  # dp[i] = smallest tail element of all LIS of length i+1
    for n in nums:
        pos = bisect.bisect_left(dp, n)
        if pos == len(dp):
            dp.append(n)
        else:
            dp[pos] = n
    return len(dp)
```

Patience sort: maintain a list of the smallest tails of increasing subsequences by length. Binary search for the insertion position. O(n log n) time, O(n) space.
