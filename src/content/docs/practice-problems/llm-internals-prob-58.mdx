# NTK-Aware RoPE Scaling for Context Extension

**Track**: Transformers & LLMs | **Points**: 40 XP

## Overview

Implement NTK-aware RoPE base scaling, a real, practical technique for extending a pretrained model's context length beyond what it was originally trained on, without full retraining.

## Task

Implement `ntk_scaled_base(original_base, scale_factor, dim)`: return `original_base * (scale_factor ** (dim / (dim - 2)))`.
