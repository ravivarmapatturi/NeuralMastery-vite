# Binary-Quantized Hamming Distance Search

**Rank #450** · Difficulty: **Medium** · Stage: **Stage 8: RAG, Agents, MCP & Distributed Systems** · Category: **Agents, MCP & Systems**

Implement `hamming_search(query, vectors, k)`: binary-quantize every vector (1 bit per dimension) and rank candidates by Hamming distance to the quantized query -- the real technique some vector databases use for an extremely fast, low-memory first-pass filter before a slower, precise re-ranking pass. Prerequisite: `agents-mcp-systems-prob-19`.

<Solution>

```python
def _sign_bits(v):
    return ''.join('1' if x >= 0 else '0' for x in v)

def hamming_search(query, vectors, k):
    if k <= 0:
        raise ValueError("k must be positive")
    if k > len(vectors):
        raise ValueError("k cannot exceed number of vectors")
    qbits = _sign_bits(query)
    dists = []
    for i, v in enumerate(vectors):
        if len(v) != len(query):
            raise ValueError("all vectors must have the same dimensionality as query")
        vbits = _sign_bits(v)
        d = sum(1 for a, b in zip(qbits, vbits) if a != b)
        dists.append((i, d))
    dists.sort(key=lambda p: (p[1], p[0]))
    return [i for i, _ in dists[:k]]
```

Hamming distance on bit-packed vectors can be computed with hardware-accelerated XOR + popcount, which is why binary quantization trades a large amount of precision for a large speedup -- it is deliberately a cheap first-pass filter, not the final ranking.
