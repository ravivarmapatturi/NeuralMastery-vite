# Nested Schema Validation Engine

**Rank #31** · Difficulty: **Medium** · Stage: **Stage 1: AI Foundations & Python Programming** · Category: **Python & Fundamentals**

## Overview

Validate unstructured dictionary payloads against expected types and required field constraints.

## Task

Implement `validate_schema(record, schema)`: ensure `record` is a dictionary, contains all fields in `schema.get("required", [])`, and matches expected property types specified in `schema.get("properties", {})` (supporting "str", "int", "float", "bool", "list", "dict"). Note: boolean values are not valid for integer fields.

<PracticePlayground problemId="py-foundations-prob-31" />

<Solution>

```python
def validate_schema(record, schema):
    type_map = {'str': str, 'int': int, 'float': float, 'bool': bool, 'list': list, 'dict': dict}
    if not isinstance(record, dict):
        return False
    for req in schema.get('required', []):
        if req not in record:
            return False
    props = schema.get('properties', {})
    for k, v in record.items():
        if k in props:
            t = type_map.get(props[k])
            if t is not None:
                if t is int and isinstance(v, bool):
                    return False
                if not isinstance(v, t):
                    return False
    return True
```

Checking key presence and validating types against Python primitive classes provides safe schema enforcement.

</Solution>
