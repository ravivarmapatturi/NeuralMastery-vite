# Validate a Sampling Request Shape

**Track**: MCP Core Engineering | **Points**: 40 XP

## Overview

Implement sampling-request validation, the check an MCP client runs before honoring a server's request to sample (call an LLM) on the client's behalf.

## Task

Implement `validate_sampling_request(request)`. Required: `messages` is a non-empty list, `maxTokens` is a positive int. If present, `temperature` must be a number in `[0, 2]`. Return `True` only if all present/required constraints hold.
