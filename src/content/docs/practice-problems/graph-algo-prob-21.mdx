## Overview

Locate all articulation points (cut vertices) in a network using Tarjan's low-link discovery time DFS.

## Task

Implement `find_all_articulation_points(n, edges)`: compute discovery time `tin[u]` and lowest reachable time `low[u]`. A non-root node u is a cut vertex if it has a child v with `low[v] >= tin[u]`.

```python
from collections import defaultdict

def find_all_articulation_points(n, edges):
    adj = defaultdict(list)
    for u, v in edges:
        adj[u].append(v)
        adj[v].append(u)
    tin = [-1] * n
    low = [-1] * n
    timer = 0
    is_cut = [False] * n
    def dfs(u, p=-1):
        nonlocal timer
        tin[u] = low[u] = timer
        timer += 1
        children = 0
        for v in adj[u]:
            if v == p:
                continue
            if tin[v] != -1:
                low[u] = min(low[u], tin[v])
            else:
                dfs(v, u)
                low[u] = min(low[u], low[v])
                if low[v] >= tin[u] and p != -1:
                    is_cut[u] = True
                children += 1
        if p == -1 and children > 1:
            is_cut[u] = True
    for i in range(n):
        if tin[i] == -1:
            dfs(i)
    return [i for i in range(n) if is_cut[i]]
```

Use Tarjan's low-link values during DFS. A vertex u is an articulation point if removing it isolates a subtree that lacks a back-edge to an ancestor of u.
