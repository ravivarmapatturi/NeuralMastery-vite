# Semantic Version Comparison for Model Registry

**Track**: MLOps & Data Systems | **Points**: 40 XP

## Overview

Implement real semantic-version comparison, needed whenever a model registry decides which registered model version is actually the latest.

## Task

Implement `semver_is_newer(version_a, version_b)`. Both are `'MAJOR.MINOR.PATCH'` strings (e.g. `'1.4.2'`). Return `True` if `version_a` is strictly newer than `version_b`, comparing MAJOR first, then MINOR, then PATCH as integers.
