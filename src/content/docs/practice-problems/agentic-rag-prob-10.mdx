# Parent-Document Retrieval: Map Chunk Hit to Parent

**Track**: Advanced RAG & Agentic RAG | **Points**: 40 XP

## Overview

Implement parent-document retrieval's core lookup: retrieve using small precise chunks for search accuracy, but return the LARGER parent chunk for generation context.

## Task

Implement `resolve_parent_chunk(child_chunk_id, child_to_parent)`: return `child_to_parent.get(child_chunk_id, child_chunk_id)` -- if no parent mapping exists, the chunk itself has no parent (it's already top-level).
