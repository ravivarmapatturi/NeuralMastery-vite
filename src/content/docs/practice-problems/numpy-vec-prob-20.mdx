# #760. Vectorized Matrix 1-Norm and Condition Number Estimate

**Track**: NumPy & Vectorized Computation | **Rank**: #760 of 1072 | **Points**: 60 XP

## Overview

Estimate the numerical stability and sensitivity of a linear system via the matrix 1-norm condition number.

## Task

Implement `matrix_condition_number_1norm(mat, inv_mat)`: compute the maximum column sum of absolute values `||M||_1 = max_j sum_i |M_{i, j}|` for both `mat` and its inverse `inv_mat`. Calculate the condition number `kappa_1 = ||mat||_1 * ||inv_mat||_1`. Return a dict `{"norm_A": float, "norm_inv": float, "condition_number": float}` rounded to 4 decimals.

```python
def matrix_condition_number_1norm(mat, inv_mat):
    n = len(mat)
    norm_A = max(sum(abs(mat[i][j]) for i in range(n)) for j in range(n))
    norm_inv = max(sum(abs(inv_mat[i][j]) for i in range(n)) for j in range(n))
    cond = norm_A * norm_inv
    return {'norm_A': round(float(norm_A), 4), 'norm_inv': round(float(norm_inv), 4), 'condition_number': round(float(cond), 4)}
```

Finds max column absolute sums for A and A_inv and multiplies them to obtain condition number.
