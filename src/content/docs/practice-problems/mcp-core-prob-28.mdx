# Client Reconnect Backoff Schedule

**Track**: MCP Core Engineering | **Points**: 40 XP

## Overview

Implement exponential reconnect backoff for an MCP client that's lost its transport connection to a server, avoiding a hot retry loop.

## Task

Implement `reconnect_delay(attempt, base_delay_s, max_delay_s)`: return `min(base_delay_s * (2 ** attempt), max_delay_s)`.
