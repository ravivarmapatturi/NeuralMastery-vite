# Document Recency Decay Score

**Track**: RAG Production Engineering | **Points**: 40 XP

## Overview

Implement recency-weighted relevance decay, a real technique to make RAG retrieval prefer fresher documents (e.g. news, changing docs) without discarding older ones entirely.

## Task

Implement `recency_decay_score(relevance_score, days_old, half_life_days)`. Return `relevance_score * (0.5 ** (days_old / half_life_days))` -- an exponential half-life decay applied to the base relevance score.
