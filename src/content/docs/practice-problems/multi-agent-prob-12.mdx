# Swarm Flocking: Average Heading Alignment

**Track**: Multi-Agent Systems | **Points**: 40 XP

## Overview

Implement circular-mean heading averaging, the real 'alignment' rule of Reynolds' boids flocking model (a naive arithmetic mean of angles is mathematically wrong).

## Task

Implement `average_heading(headings_rad)`. Convert each heading to a unit vector `(cos(theta), sin(theta))`, average the vectors component-wise, then return `atan2(avg_y, avg_x)` -- the circular mean, which correctly handles wraparound (e.g. averaging 0.1 rad and 2*pi-0.1 rad gives ~0, not ~pi).
