# Trees: Binary Tree Level Order Traversal

**Rank #62** · Difficulty: **Easy** · Stage: **Stage 2: Data Structures & Algorithmic Foundations** · Category: **Data Structures & Algorithms**

## Overview

Implement `level_order(root)` using BFS -- the foundational tree traversal every breadth-first tree algorithm (zigzag level order, right-side view, connect next pointers) is built on.

## Task

Implement the function `level_order(root)`. Each node is a dict `{'val', 'left', 'right'}`. Return a list of lists, one per level of the tree from root to leaves.

<PracticePlayground problemId="ds-algo-prob-2" />

<Solution>

```python
from collections import deque

def level_order(root):
    if not root:
        return []
    result = []
    q = deque([root])
    while q:
        level = []
        for _ in range(len(q)):
            node = q.popleft()
            level.append(node['val'])
            if node['left']:
                q.append(node['left'])
            if node['right']:
                q.append(node['right'])
        result.append(level)
    return result
```

Snapshot `len(q)` before the inner loop -- that count equals one level's nodes. Enqueue children for the next level. O(n) time, O(n) space.

</Solution>
