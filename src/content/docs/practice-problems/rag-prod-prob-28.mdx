# Multi-Hop Missing-Entity Follow-Up Query

**Track**: RAG Production Engineering | **Points**: 40 XP

## Overview

Implement a real, simple deterministic multi-hop retrieval trigger: deciding whether a follow-up retrieval is needed and what to search for.

## Task

Implement `next_hop_query(original_query, answer_so_far, required_entities)`. Find the required entities (case-insensitive whole-word match) NOT yet mentioned in `answer_so_far`, in the order they appear in `required_entities`. If none are missing, return `''` (no further hop needed). Otherwise return `f'{original_query} {missing_entities[0]}'` -- a follow-up query targeting the first still-missing entity.
