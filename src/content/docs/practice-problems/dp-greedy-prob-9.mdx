# #659. Dynamic Programming & Greedy Module 2: Problem 9

**Track**: Dynamic Programming & Greedy | **Rank**: #659 of 1072 | **Points**

## Overview

Generate a single row of Pascal's triangle using in-place 1D dynamic programming.

## Task

Implement `pascals_triangle_row(rowIndex)`: allocate a list of length rowIndex + 1 filled with 1s. Update elements backwards from j = i-1 down to 1 using row[j] += row[j-1].

<PracticePlayground problemId="dp-greedy-prob-9" />

<Solution>

```python
def pascals_triangle_row(rowIndex):
    row = [1] * (rowIndex + 1)
    for i in range(2, rowIndex + 1):
        for j in range(i - 1, 0, -1):
            row[j] += row[j - 1]
    return row
```

Initialize an array of 1s of size rowIndex + 1. For each successive row level, iterate backwards from right to left, adding the adjacent left entry.
