# CenterNet Gaussian Target Radius Calculator

**Track**: Deep Learning & Vision/NLP | **Points**: 40 XP

## Overview

Compute the Gaussian splatter radius for object center heatmap targets in anchor-free detectors.

## Task

Implement `centernet_gaussian_radius(h, w, min_overlap)`. In CenterNet/CornerNet, the target radius `r` ensures any bounding box with shifted corners has at least `min_overlap` IoU. Compute `r1`, `r2`, `r3` from the 3 quadratic roots for the three cases: Case 1: `a=1, b=-(h+w), c=w*h*(1-min_overlap)/(1+min_overlap)`. Case 2: `a=4, b=-2*(h+w), c=(1-min_overlap)*w*h`. Case 3: `a=4*min_overlap, b=2*min_overlap*(h+w), c=(min_overlap-1)*w*h`. In each case, take the positive root: `(-b - sqrt(b^2 - 4*a*c)) / (2*a)` for Cases 1 and 2; `(-b + sqrt(b^2 - 4*a*c)) / (2*a)` for Case 3. Return `max(0, int(min(r1, r2, r3)))`.
