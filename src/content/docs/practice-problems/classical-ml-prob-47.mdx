# Classical ML Module 47: Problem 287

**Rank #287** · Difficulty: **Medium** · Stage: **Stage 5: Classical Machine Learning & Optimization** · Category: **Classical ML**

## Overview

Evaluate outlier-resilient Huber loss combining quadratic and linear penalty regimes.

## Task

Implement `huber_loss(y_true, y_pred, delta)`: for absolute residual `e = |y - pred|`, if `e <= delta`, loss is `0.5 * e**2`; otherwise loss is `delta * (e - 0.5 * delta)`. Return mean loss across samples, rounded to 4 decimal places.

<PracticePlayground problemId="classical-ml-prob-47" />

<Solution>

```python
def huber_loss(y_true, y_pred, delta):
    n = len(y_true)
    if n == 0:
        return 0.0
    total = 0.0
    for yt, yp in zip(y_true, y_pred):
        err = abs(yt - yp)
        if err <= delta:
            total += 0.5 * (err ** 2)
        else:
            total += delta * (err - 0.5 * delta)
    return round(float(total / n), 4)
```

Huber loss transitions smoothly from quadratic MSE for small residuals to linear MAE for large residuals, ensuring robust gradients under heavy-tailed noise.
