# #796. Financial Tick-to-OHLCV Bar Aggregator

**Track**: Pandas & Data Processing Pipelines | **Rank**: #796 of 1072 | **Points**: 90 XP

## Overview

Compress continuous irregular financial transaction tick feeds into standardized OHLCV candlestick bars.

## Task

Implement `aggregate_ohlcv_bars(ticks, bar_seconds)`: group trades by time window bucket `(timestamp // bar_seconds) * bar_seconds`. For each bucket, compute `open` (first price), `high` (max price), `low` (min price), `close` (last price), and `volume` (total volume). Return list of bar dictionaries ordered chronologically with floats rounded to 4 decimals.

<Solution>

```python
from collections import defaultdict

def aggregate_ohlcv_bars(ticks, bar_seconds):
    buckets = defaultdict(list)
    for t in sorted(ticks, key=lambda x: x['timestamp']):
        b = (t['timestamp'] // bar_seconds) * bar_seconds
        buckets[b].append(t)
    bars = []
    for b in sorted(buckets.keys()):
        b_ticks = buckets[b]
        p = [x['price'] for x in b_ticks]
        bars.append({
            'bucket': b,
            'open': round(float(p[0]), 4),
            'high': round(float(max(p)), 4),
            'low': round(float(min(p)), 4),
            'close': round(float(p[-1]), 4),
            'volume': round(float(sum(x['volume'] for x in b_ticks)), 4)
        })
    return bars
```

Groups chronological transactions by time floor and extracts extreme and boundary price points.
