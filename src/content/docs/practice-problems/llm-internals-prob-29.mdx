# Cross-Entropy Loss from Logits

**Rank #389** · Difficulty: **Easy** · Stage: **Stage 7: Transformers, LLMs & Foundation Models** · Category: **Transformers & LLMs**

Implement `cross_entropy_loss(logits, target_idx)` that computes the cross-entropy loss for a single classification step. Apply numerically stable softmax (subtract max before exp), then return `-log(softmax[target_idx])` rounded to 4 decimal places. This is the per-token loss during LLM next-token prediction training. Prerequisite: `llm-internals-prob-28`.

<PracticePlayground problemId="llm-internals-prob-29" />

<Solution>

```python
import math

def cross_entropy_loss(logits, target_idx):
    if not logits:
        raise ValueError("logits must be non-empty")
    if target_idx < 0 or target_idx >= len(logits):
        raise IndexError("target_idx out of range")
    max_l = max(logits)
    exps = [math.exp(l - max_l) for l in logits]
    total = sum(exps)
    prob = exps[target_idx] / total
    return round(-math.log(prob), 4)
```

Cross-entropy loss is the negative log-likelihood of the true token: minimizing it maximizes the probability the model assigns to correct completions. Combined with the log-sum-exp trick for numerical stability, this single function is at the core of every LLM pretraining and fine-tuning loop.

</Solution>
