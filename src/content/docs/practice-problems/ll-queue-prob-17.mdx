## Overview

Find the waiting time until the next strictly greater value in an array using a monotonic decreasing stack.

## Task

Implement `daily_temperatures(temperatures)`: for each day `i`, find the number of days you would have to wait until a warmer temperature occurs. If no warmer day exists in the future, set `answer[i] = 0`.

<PracticePlayground problemId="ll-queue-prob-17" />

<Solution>

```python
def daily_temperatures(temperatures):
    n = len(temperatures)
    ans = [0] * n
    stack = []
    for i, t in enumerate(temperatures):
        while stack and temperatures[stack[-1]] < t:
            prev = stack.pop()
            ans[prev] = i - prev
        stack.append(i)
    return ans
```

Each index enters and leaves the stack at most once, guaranteeing strict O(n) linear execution time.
