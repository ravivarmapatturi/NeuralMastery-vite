# #756. Vectorized Batch Collator with Sequence Padding

**Track**: NumPy & Vectorized Computation | **Rank**: #756 of 1072 | **Points**: 60 XP

## Overview

Collate variable-length token sequences into a uniform dense matrix with binary attention masks.

## Task

Implement `collate_padded_batch(sequences, pad_val)`: determine `max_len = max(len(s))` across input sequences. Pad shorter sequences on the right with `pad_val`. Concurrently create `attention_mask` where original tokens are 1 and padding tokens are 0. Return a dict `{"padded_batch": ..., "attention_mask": ...}`.

<PracticePlayground problemId="numpy-vec-prob-16" />

<Solution>

```python
def collate_padded_batch(sequences, pad_val):
    max_len = max(len(s) for s in sequences) if sequences else 0
    padded = []
    masks = []
    for s in sequences:
        p = max_len - len(s)
        padded.append(list(s) + [pad_val] * p)
        masks.append([1] * len(s) + [0] * p)
    return {'padded_batch': padded, 'attention_mask': masks}
```

Pads each list with pad_val to max sequence length and creates corresponding binary indicator mask.
