## Overview

Determine graph reachability between two vertices using BFS or DFS traversal.

## Task

Implement `valid_path_exists(n, edges, source, destination)`: construct an adjacency list and use BFS with a visited set to determine if destination is reachable from source.

<Solution>

```python
from collections import deque, defaultdict

def valid_path_exists(n, edges, source, destination):
    if source == destination:
        return True
    adj = defaultdict(list)
    for u, v in edges:
        adj[u].append(v)
        adj[v].append(u)
    visited = {source}
    q = deque([source])
    while q:
        curr = q.popleft()
        if curr == destination:
            return True
        for nbr in adj[curr]:
            if nbr not in visited:
                visited.add(nbr)
                q.append(nbr)
    return False
```

Use BFS starting from source. Traverse all unvisited neighbors. If destination is dequeued, return True; if the queue empties without reaching destination, return False.
