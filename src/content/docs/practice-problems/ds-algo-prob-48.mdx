# Graphs: Cheapest Flights Within K Stops (Bellman-Ford)

**Rank #108** · Difficulty: **Medium** · Stage: **Stage 2: Data Structures & Algorithmic Foundations** · Category: **Data Structures & Algorithms**

## Overview

Implement `find_cheapest_price(n, flights, src, dst, k)` -- Bellman-Ford with at most k+1 iterations, modified to respect the stops constraint.

## Task

Implement the function `find_cheapest_price(n, flights, src, dst, k)`. Return the cheapest price from `src` to `dst` with at most `k` stops, or `-1` if impossible.

<PracticePlayground problemId="ds-algo-prob-48" />

<Solution>

```python
def find_cheapest_price(n, flights, src, dst, k):
    prices = [float('inf')] * n
    prices[src] = 0
    for _ in range(k + 1):
        tmp = prices[:]
        for u, v, price in flights:
            if prices[u] != float('inf') and prices[u] + price < tmp[v]:
                tmp[v] = prices[u] + price
        prices = tmp
    return prices[dst] if prices[dst] != float('inf') else -1
```

Bellman-Ford limited to k+1 relaxation rounds (k stops = k+1 edges). Snapshot `prices` before each round to prevent using more than one new edge per round. O(k * E) time.

</Solution>
