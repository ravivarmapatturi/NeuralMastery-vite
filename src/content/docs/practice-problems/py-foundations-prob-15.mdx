# Safe Nested Dictionary Traversal

**Rank #15** · Difficulty: **Easy** · Stage: **Stage 1: AI Foundations & Python Programming** · Category: **Python & Fundamentals** | **Points**: 40 XP

## Overview

Implement `safe_nested_get(data, keys, default=None)`: safely traverse hierarchical dictionary structures along a path of keys without throwing KeyError or TypeError.

## Task

Implement the function `safe_nested_get(data, keys, default=None)`: sequentially look up each key in `keys` within `data`. If any key is absent or an intermediate value is not a dictionary, return `default`. If `keys` is empty, return `data`.

<PracticePlayground problemId="py-foundations-prob-15" />

<Solution>

```python
def safe_nested_get(data, keys, default=None):
    curr = data
    for key in keys:
        if not isinstance(curr, dict) or key not in curr:
            return default
        curr = curr[key]
    return curr
```

Defensive navigation prevents catastrophic crashes when parsing semi-structured schema-less responses from external APIs and agent tools.

</Solution>
