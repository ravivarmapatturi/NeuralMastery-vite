# Tool Call Timeout Check

**Track**: MCP Core Engineering | **Points**: 40 XP

## Overview

Implement a real tool-call timeout check, protecting an MCP client from hanging forever on a server tool call that never responds.

## Task

Implement `is_tool_call_timed_out(started_at, current_time, timeout_s)`: return `True` if `(current_time - started_at) >= timeout_s`.
