# Mathematics Module 58: Problem 178

**Rank #178** · Difficulty: **Medium** · Stage: **Stage 3: Mathematics & Numerical Computing** · Category: **Math & Numerical**

## Overview

Solve a diagonally dominant linear system iteratively using immediate in-place Gauss-Seidel updates.

## Task

Implement `gauss_seidel_iteration(A, b, x0, num_iters=5)`: for `num_iters` cycles, update each coordinate `i` from 0 to n-1 via `x[i] = (b[i] - sum_{j != i} A[i][j] * x[j]) / A[i][i]`, immediately utilizing updated values `x[j]` for `j < i`. Return solution vector `x` rounded to 4 decimals.

<Solution>

```python
def gauss_seidel_iteration(A, b, x0, num_iters=5):
    n = len(b)
    x = list(x0)
    for _ in range(num_iters):
        for i in range(n):
            sum_known = sum(A[i][j] * x[j] for j in range(n) if j != i)
            x[i] = (b[i] - sum_known) / A[i][i]
    return [round(float(v), 4) for v in x]
```

Updates state vector in place so subsequent coordinate updates within the same iteration benefit from newer estimates.
