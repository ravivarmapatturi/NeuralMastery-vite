# #207. Vector Distance Threshold Filter

**Track**: RAG Fundamentals | **Rank**: #207 of 1072 | **Points**: 90 XP

## Overview

Implement score threshold pruning to eliminate low-confidence vector search noise.

## Task

Implement `vector_distance_threshold_filter(query_vector, doc_vectors, metric="cosine", threshold=0.5)`. Raise `ValueError` if metric is not one of `"cosine"`, `"euclidean"`, `"dot_product"`, or if any vector dimension differs from `len(query_vector)`. Compute distance: for `"cosine"`, `dist = 1 - cosine_sim` (keep `dist <= threshold`); for `"euclidean"`, `dist = sqrt(sum((a-b)^2))` (keep `dist <= threshold`); for `"dot_product"`, `score = sum(a*b)` (keep `score >= threshold`). Return matching entries with `{"doc_id": id, "distance": round(val, 4)}` sorted best-match first (ascending for distances, descending for dot product).
