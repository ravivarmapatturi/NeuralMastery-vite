# #079. Multi-Metric Output Guardrail Gate

**Track**: LLM Application Engineering | **Rank**: #79 of 1072 | **Points**: 60 XP

## Overview

Enforce production safety and formatting policies on generated responses before returning them to client applications. In production LLM application engineering, reliable system components, deterministic interfaces, and defensive validation are paramount for production stability and cost efficiency.

## Task

Implement `evaluate_guardrail_gate(text, rules)`. Split `text` into words using `text.split()`. Evaluate rules: `min_words` (violation `'word_count_below_min_{min_words}'`), `max_words` (violation `'word_count_above_max_{max_words}'`), `prohibited_terms` (case-insensitive substring check, violation `'contains_prohibited_term_{term}'`), `must_contain_terms` (case-insensitive substring check, violation `'missing_required_term_{term}'`), and `max_repetition_ratio` where ratio is `1.0 - len(unique_words)/len(words)` (violation `'repetition_ratio_{ratio}_exceeds_{max}'`). Return `{'passed': bool, 'violations': sorted_violations, 'word_count': int, 'metrics': {'repetition_ratio': float}}`.
