# Linked Lists: Reverse Linked List

**Rank #61** · Difficulty: **Easy** · Stage: **Stage 2: Data Structures & Algorithmic Foundations** · Category: **Data Structures & Algorithms**

## Overview

Implement `reverse_list(head)`, the classic linked-list warmup that every subsequent list problem (palindrome detection, k-group reversal, merge operations) depends on.

## Task

Implement the function `reverse_list(head)`. Each node is a dict `{'val': int, 'next': node | None}`. Reverse the list in-place and return the new head.

<PracticePlayground problemId="ds-algo-prob-1" />

<Solution>

```python
def reverse_list(head):
    prev = None
    cur = head
    while cur:
        nxt = cur['next']
        cur['next'] = prev
        prev = cur
        cur = nxt
    return prev
```

Three-pointer iterative reversal: save `next`, redirect `cur.next` to `prev`, advance both pointers. O(n) time, O(1) space.

</Solution>
