# Word Error Rate (WER) for Speech and NLP

**Track**: Deep Learning & Vision/NLP | **Points**: 40 XP

## Overview

Compute the industry-standard Word Error Rate (WER = (S + D + I) / N) between reference and predicted token sequences.

## Task

Implement `word_error_rate(reference, hypothesis)`. Using token-level Levenshtein alignment (substitutions S, deletions D, insertions I each with cost 1), compute `WER = (S + D + I) / N` where `N = len(reference)`. If `N == 0` and hypothesis is empty, return 0.0; if `N == 0` and hypothesis is non-empty, return float(len(hypothesis)). Round result to 4 decimal places.
