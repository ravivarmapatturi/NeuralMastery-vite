## Overview

Simulate an enterprise pub/sub message broker dispatching topics with wildcards (* and #).

## Task

Implement `event_bus_dispatcher_simulator(subscriptions, events)`: match event topics against subscription filters. A single asterisk `*` matches exactly one dot-separated segment; hash `#` matches zero or more segments. When an event matches a subscription, log `"<sub_id>:<topic>:<payload>"`. Return all delivery logs in dispatch order.

```python
import re

def event_bus_dispatcher_simulator(subscriptions, events):
    def to_regex(pat):
        parts = pat.split('.')
        reg = []
        for p in parts:
            if p == '*': reg.append(r'[^.]+')
            elif p == '#': reg.append(r'.*')
            else: reg.append(re.escape(p))
        return '^' + r'\.'.join(reg) + '$'

    subs = [(s['id'], re.compile(to_regex(s['topic']))) for s in subscriptions]
    out = []
    for ev in events:
        top = ev.get('topic', '')
        payload = ev.get('payload', '')
        for sub_id, reg in subs:
            if reg.match(top):
                out.append(f"{sub_id}:{top}:{payload}")
    return out
```

Pre-compiling pattern wildcards into regular expressions matches high-throughput event topics efficiently.
