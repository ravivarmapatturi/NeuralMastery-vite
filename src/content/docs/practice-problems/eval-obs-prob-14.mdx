# Detect Silent Eval Harness Failures

**Track**: Agent Evaluation & Observability | **Points**: 40 XP

## Overview

Implement silent-failure detection in an eval harness, catching test cases that neither clearly passed nor clearly failed -- a real, common eval-infrastructure bug that silently inflates or deflates reported scores.

## Task

Implement `has_silent_failures(results)`. Each result is `{"id": str, "output": str, "error": str|None}`. Return the sorted list of ids where `error is None` AND `output == ''` (empty output but no reported error -- a suspicious 'passed silently with nothing to show' case).
