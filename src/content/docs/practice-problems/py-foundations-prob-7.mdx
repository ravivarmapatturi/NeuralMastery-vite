# Merge Dictionaries with Value Aggregation

**Rank #7** · Difficulty: **Easy** · Stage: **Stage 1: AI Foundations & Python Programming** · Category: **Python & Fundamentals** | **Points**: 40 XP

## Overview

Implement `merge_dicts_with_sum(dict_a, dict_b)`: merge two frequency count dictionaries, summing counts for shared keys without mutating the input structures.

## Task

Implement the function `merge_dicts_with_sum(dict_a, dict_b)`: return a new dictionary containing all keys from both input dictionaries. When a key exists in both, sum their numeric values. If a key exists in only one dictionary, keep its original value.

<PracticePlayground problemId="py-foundations-prob-7" />

<Solution>

```python
def merge_dicts_with_sum(dict_a, dict_b):
    res = dict(dict_a)
    for k, v in dict_b.items():
        res[k] = res.get(k, 0) + v
    return res
```

Dictionary merging with reduction (like sum or max) is the fundamental reduce operation in MapReduce architectures and distributed gradient all-reduce simulation.

</Solution>
