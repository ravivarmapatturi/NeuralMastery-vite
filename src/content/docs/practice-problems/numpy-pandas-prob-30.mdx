# Streaming systems Module 30: Problem 210

**Rank #210** · Difficulty: **Medium** · Stage: **Stage 4: NumPy & Vectorized Data Processing** · Category: **NumPy & Pandas**

## Overview

Measure sliding window event arrival velocity in a real-time event stream.

## Task

Implement `sliding_window_event_rate(timestamps, window_seconds)`: given sorted timestamps, for each event arrival calculate the number of events in the half-open interval `(timestamp - window_seconds, timestamp]`.

<PracticePlayground problemId="numpy-pandas-prob-30" />

<Solution>

```python
from collections import deque

def sliding_window_event_rate(timestamps, window_seconds):
    q = deque()
    out = []
    for t in timestamps:
        q.append(t)
        cutoff = t - window_seconds
        while q and q[0] <= cutoff:
            q.popleft()
        out.append(len(q))
    return out
```

A monotonic timestamp queue efficiently maintains sliding window membership by evicting timestamps older than the window cutoff.

</Solution>
