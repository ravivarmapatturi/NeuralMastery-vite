# #792. Categorical Frequency Pruning and Binning

**Track**: Pandas & Data Processing Pipelines | **Rank**: #792 of 1072 | **Points**: 60 XP

## Overview

Reduce categorical cardinality by collapsing infrequently observed tail categories into an aggregate bin.

## Task

Implement `prune_rare_categories(series, min_frequency, other_label)`: compute occurrence frequency of each unique category in `series`. Retain categories whose proportion `count / len(series) >= min_frequency`. Replace all other categories with `other_label`. Return dictionary `{"pruned_series": list[str], "retained_categories": sorted_list[str]}`.

<Solution>

```python
from collections import defaultdict

def prune_rare_categories(series, min_frequency=0.05, other_label='Other'):
    n = len(series)
    counts = defaultdict(int)
    for c in series: counts[c] += 1
    thresh = min_frequency * n
    res = [c if counts[c] >= thresh else other_label for c in series]
    retained = sorted([c for c, cnt in counts.items() if cnt >= thresh])
    return {'pruned_series': res, 'retained_categories': retained}
```

Calculates category proportions, keeps frequent classes, and remaps rare elements to an aggregate label.
