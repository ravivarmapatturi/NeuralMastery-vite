# Numerically Stable Softmax

**Track**: transformers-llms | **Points**: 40 XP

## Overview

Implement numerically stable softmax by subtracting the max logit before exponentiation to prevent overflow.

## Task

Implement `stable_softmax(logits)` that applies the max-subtraction trick before exponentiation. Subtract `max(logits)` before calling `exp`, normalize by the sum of exponentials, and return a list of floats rounded to 4 decimal places. Return empty list if logits is empty.
