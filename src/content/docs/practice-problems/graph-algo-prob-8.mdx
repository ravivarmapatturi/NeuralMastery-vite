# #628. Graphs & Network Algorithms Module 2: Problem 8

**Track**: Graphs & Network Algorithms | **Rank**: #628 of 1072 | **Points**

## Overview

Compute the transpose (edge reversal) of a directed graph.

## Task

Implement `transpose_directed_graph(n, edges)`: invert the direction of every edge from `[u, v]` to `[v, u]`, returning the sorted edge list.

<PracticePlayground problemId="graph-algo-prob-8" />

<Solution>

```python
def transpose_directed_graph(n, edges):
    return sorted([[v, u] for u, v in edges])
```

Reverse the start and end vertices of each directed edge to create the transpose graph and sort for deterministic output.

</Solution>
