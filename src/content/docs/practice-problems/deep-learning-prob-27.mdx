# Unpad Sequences via Length Vector

**Track**: Deep Learning & Vision/NLP | **Points**: 40 XP

## Overview

Restore original ragged token sequences from a padded batch tensor using original sequence lengths.

## Task

Implement `unpad_sequence_batch(padded_batch, lengths)`. Given a 2D matrix `padded_batch` of shape `B x T` and a list of integers `lengths` of length `B`, slice each row `i` from index `0` to `lengths[i]`. Return list of variable-length lists.
