# #655. Dynamic Programming & Greedy Module 1: Problem 5

**Track**: Dynamic Programming & Greedy | **Rank**: #655 of 1072 | **Points**

## Overview

Maximize the number of satisfied children by greedily assigning the smallest acceptable cookie to each child.

## Task

Implement `assign_cookies(g, s)`: sort both greed factors and cookie sizes ascending. Use two pointers to match the smallest valid cookie to the child with smallest greed.

<PracticePlayground problemId="dp-greedy-prob-5" />

<Solution>

```python
def assign_cookies(g, s):
    g.sort()
    s.sort()
    child_i, cookie_j = 0, 0
    while child_i < len(g) and cookie_j < len(s):
        if s[cookie_j] >= g[child_i]:
            child_i += 1
        cookie_j += 1
    return child_i
```

Sort both arrays. If the current cookie satisfies the current least-greedy child, allocate it and move to the next child; otherwise try the next larger cookie.
