# #191. Parent Document Retriever

**Track**: RAG Fundamentals | **Rank**: #191 of 1072 | **Points**: 60 XP

## Overview

Map high-granularity vector search hits back to comprehensive parent context documents.

## Task

Implement `parent_document_retriever(child_matches, child_to_parent, parent_docs, top_k=3)`. Given a list of granular chunk search hits `child_matches`, map each chunk to its parent document via `child_to_parent`. Aggregate each parent's score as the maximum score among its matched child chunks. Sort unique parent documents descending by score (ties broken by `parent_id` ascending), and return the top `top_k` documents formatted with `parent_id`, `text`, and `score` (rounded to 4 decimal places).
