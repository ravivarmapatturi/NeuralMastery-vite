# Structural Similarity Index (SSIM) Components

**Track**: Deep Learning & Vision/NLP | **Points**: 40 XP

## Overview

Compute the luminance, contrast-structure, and composite SSIM index between two image patches.

## Task

Implement `image_ssim_components(mu_x, mu_y, var_x, var_y, cov_xy, c1, c2)`. Luminance comparison is `l = (2 * mu_x * mu_y + c1) / (mu_x**2 + mu_y**2 + c1)`. Contrast-structure comparison is `cs = (2 * cov_xy + c2) / (var_x + var_y + c2)`. Total SSIM is `ssim = l * cs`. Return `[round(l, 4), round(cs, 4), round(ssim, 4)]`.
