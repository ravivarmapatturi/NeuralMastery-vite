# Streaming Token Buffer Until Stop Sequence

**Track**: RAG Production Engineering | **Points**: 40 XP

## Overview

Implement streaming-token buffering with stop-sequence detection, needed because a stop sequence can be split across multiple streamed tokens and must be detected on the growing buffer, not per-token.

## Task

Implement `buffer_until_stop(tokens, stop_sequence)`. Concatenate `tokens` one at a time into a running buffer. The moment the buffer CONTAINS `stop_sequence` as a substring, stop consuming further tokens. Return a tuple `(text_before_stop_sequence, stopped: bool)` -- the buffer content up to (not including) the stop sequence, and whether it was found at all. If never found, return `(full_concatenated_text, False)`.
