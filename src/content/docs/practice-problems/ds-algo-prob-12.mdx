# Trees: Range Sum of BST

**Rank #72** · Difficulty: **Easy** · Stage: **Stage 2: Data Structures & Algorithmic Foundations** · Category: **Data Structures & Algorithms**

## Overview

Implement `range_sum_bst(root, low, high)` -- a BST range query that prunes entire subtrees using BST ordering, far more efficient than a plain DFS that visits every node.

## Task

Implement the function `range_sum_bst(root, low, high)`. Return the sum of all BST node values in the inclusive range `[low, high]`.

<PracticePlayground problemId="ds-algo-prob-12" />

<Solution>

```python
def range_sum_bst(root, low, high):
    if not root:
        return 0
    total = root['val'] if low <= root['val'] <= high else 0
    if root['val'] > low:
        total += range_sum_bst(root['left'], low, high)
    if root['val'] < high:
        total += range_sum_bst(root['right'], low, high)
    return total
```

BST ordering lets you skip the left subtree when `root.val <= low` and the right subtree when `root.val >= high`. O(n) worst case, much better in practice.

</Solution>
