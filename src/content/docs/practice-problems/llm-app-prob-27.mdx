# #087. DAG Tool Call Dependency Dispatcher

**Track**: LLM Application Engineering | **Rank**: #87 of 1072 | **Points**: 90 XP

## Overview

Resolve execution waves for complex tool calling plans by sorting dependencies into parallel topological generations. In production LLM application engineering, reliable system components, deterministic interfaces, and defensive validation are paramount for production stability and cost efficiency.

## Task

Implement `dispatch_tool_call_dag(tool_specs, step_results=None)`. Given `tool_specs` where each item specifies `name` and `dependencies` (list of tool names required before execution), calculate topological execution generations (`waves: list[list[str]]`). Tools in each wave have all dependencies fulfilled by earlier waves and can execute in parallel. Sort tool names within each wave alphabetically. Calculate `parallelism_factor = round(total_steps / len(waves), 2)` (0.0 if empty). Detect dependency cycles or undefined dependencies and raise `ValueError`. Return `{'waves': waves, 'total_steps': total_steps, 'parallelism_factor': parallelism_factor}`.
