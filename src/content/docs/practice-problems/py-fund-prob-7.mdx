## Overview

Invert key-value mappings where multiple keys map to the same value, producing an inverted index list.

## Task

Implement `dict_invert_multi(d)`: invert dictionary `d` so each distinct value becomes a key mapping to a sorted list of original keys that mapped to it. Return the inverted dictionary with its keys sorted in ascending order.

<PracticePlayground problemId="py-fund-prob-7" />

<Solution>

```python
def dict_invert_multi(d):
    inv = {}
    for k, v in d.items():
        inv.setdefault(v, []).append(k)
    return {k: sorted(v) for k, v in sorted(inv.items())}
```

Grouping by value and sorting inner lists produces a canonical multi-value inverted map.
