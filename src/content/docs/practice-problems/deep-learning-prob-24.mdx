# Bahdanau Additive Attention Alignment Score

**Track**: Deep Learning & Vision/NLP | **Points**: 40 XP

## Overview

Compute the additive alignment score e = v^T * tanh(W_d * s + W_e * h) in sequence-to-sequence models.

## Task

Implement `bahdanau_additive_attention(decoder_hidden, encoder_hidden, W_d, W_e, v)`. Given decoder state `s` (dim `d_dec`) and encoder state `h` (dim `d_enc`), compute projections `proj_d = W_d * s` and `proj_e = W_e * h` (where `W_d` is `d_att x d_dec` and `W_e` is `d_att x d_enc`). For each coordinate `k` in `0...d_att-1`, compute `tanh(proj_d[k] + proj_e[k])`. Take dot product with vector `v` of length `d_att`. Return scalar rounded to 4 decimal places.
