# Graceful Degradation Model Fallback Selection

**Track**: Agent Performance & Production | **Points**: 40 XP

## Overview

Implement graceful-degradation model selection, deciding whether to use the primary (usually higher-quality) model or fall back to a faster/cheaper one under real production constraints.

## Task

Implement `select_fallback_model(primary_available, primary_latency_ms, latency_budget_ms, fallback_model, primary_model)`. Return `fallback_model` if EITHER `not primary_available` OR `primary_latency_ms > latency_budget_ms`. Otherwise return `primary_model`.
