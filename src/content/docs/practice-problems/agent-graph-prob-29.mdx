# Synthesize Final Answer From Worker Results

**Track**: Agent Graph Engineering | **Points**: 40 XP

## Overview

Implement worker-result synthesis, the real final aggregation step of a supervisor-worker multi-agent graph combining each specialist worker's contribution into one coherent labeled answer.

## Task

Implement `synthesize_worker_results(worker_outputs)`. For each worker (sorted by name for determinism), format `f'[{worker}]: {output}'`, and join all lines with `'\n'`.
