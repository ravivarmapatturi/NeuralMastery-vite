# Otsu Binarization Global Thresholding

**Track**: Deep Learning & Vision/NLP | **Points**: 40 XP

## Overview

Calculate the optimal image threshold maximizing between-class variance across an intensity histogram.

## Task

Implement `otsu_threshold(hist)`. Given a 256-bin pixel intensity histogram `hist` (frequencies for intensities 0 to 255), find the threshold `t` (where `0 <= t < 255`) that maximizes the between-class variance `sigma_b^2 = w0 * w1 * (mu0 - mu1)^2`. `w0` and `w1` are probabilities of background (`<= t`) and foreground (`> t`). In case of ties, choose the smallest `t`.
