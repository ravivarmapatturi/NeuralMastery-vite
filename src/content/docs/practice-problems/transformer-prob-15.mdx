# #015. Transformer Internals Module 3: Problem 15

**Track**: Transformer Internals | **Rank**: #15 of 1072 | **Points**: 60 XP

## Overview

Map query attention heads to their corresponding Key-Value (KV) heads in Grouped Query Attention (GQA). GQA shares KV heads across multiple query heads, cutting KV cache memory requirements while preserving model expressive power.

## Task

Implement `assign_kv_groups(num_heads, num_kv_heads)`: assign each query head index `0 <= h < num_heads` to a KV head index `0 <= g < num_kv_heads` where group size is `group_size = num_heads // num_kv_heads` and `g = h // group_size`. Return the list of assigned KV head indices. If `num_heads % num_kv_heads != 0` or parameters are non-positive, raise `ValueError`.
