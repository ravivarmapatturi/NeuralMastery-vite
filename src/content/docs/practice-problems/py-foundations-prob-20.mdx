# Longest Common Prefix

**Rank #20** · Difficulty: **Easy** · Stage: **Stage 1: AI Foundations & Python Programming** · Category: **Python & Fundamentals**

## Overview

Extract the shared initial substring across a collection of candidate strings.

## Task

Implement `longest_common_prefix(strs)`: find the longest common prefix string shared by all strings in `strs`. If `strs` is empty or there is no common prefix, return `""`.

<PracticePlayground problemId="py-foundations-prob-20" />

<Solution>

```python
def longest_common_prefix(strs):
    if not strs:
        return ""
    prefix = strs[0]
    for s in strs[1:]:
        while not s.startswith(prefix):
            prefix = prefix[:-1]
            if not prefix:
                return ""
    return prefix
```

Horizontally scanning and truncating the candidate prefix against each string in sequence ensures linear time proportional to total character comparisons.

</Solution>
