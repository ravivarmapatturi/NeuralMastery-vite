# Multi-Class Focal Loss Forward Pass

**Track**: Deep Learning & Vision/NLP | **Points**: 40 XP

## Overview

Compute multi-class focal loss with modulating factor (1 - p_t)^gamma to focus training on hard examples.

## Task

Implement `focal_loss_multiclass(probs, target_class, gamma, alpha)`. Let `p_t = probs[target_class]`. Compute `FL = -alpha * ((1.0 - p_t) ** gamma) * math.log(max(1e-15, p_t))`. Round result to 4 decimal places.
