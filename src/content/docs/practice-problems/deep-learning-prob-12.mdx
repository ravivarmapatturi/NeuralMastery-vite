# Triplet Margin Loss Forward Pass

**Track**: Deep Learning & Vision/NLP | **Points**: 40 XP

## Overview

Compute triplet margin loss to enforce distance ordering between metric embeddings (FaceNet style).

## Task

Implement `triplet_margin_loss(anchor, positive, negative, margin)`. Compute Euclidean distance `d_pos = sqrt(sum((a - p)^2))` and `d_neg = sqrt(sum((a - n)^2))`. The loss is `max(0.0, d_pos - d_neg + margin)`. Round result to 4 decimal places.
