# INT8 Quantization Error

**Track**: transformers-llms | **Points**: 40 XP

## Overview

Compute the quantization error introduced by symmetric/asymmetric quantization.

## Task

Implement `quantization_error(x, scale, zero_point=0, n_bits=8)` that computes the absolute difference between `x` and its dequantized reconstruction `x_hat`. Quantize `q = max(q_min, min(q_max, round(x / scale) + zero_point))`, then `x_hat = (q - zero_point) * scale`. Return `round(abs(x - x_hat), 6)`. Raise `ValueError` if `scale <= 0`.
