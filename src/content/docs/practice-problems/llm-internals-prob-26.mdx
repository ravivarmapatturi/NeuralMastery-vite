# INT8 Quantization Error

**Rank #386** · Difficulty: **Medium** · Stage: **Stage 7: Transformers, LLMs & Foundation Models** · Category: **Transformers & LLMs**

Implement `quantization_error(x, scale, zero_point=0, n_bits=8)` that computes the absolute quantization error for a single float value using symmetric INT8 quantization. Steps: quantize `q = clip(round(x / scale) + zero_point, -(2^(n_bits-1)), 2^(n_bits-1) - 1)`, then dequantize `x_hat = (q - zero_point) * scale`, then return `round(abs(x - x_hat), 6)`. Prerequisite: `llm-internals-prob-25`.

<Solution>

```python
def quantization_error(x, scale, zero_point=0, n_bits=8):
    if scale <= 0:
        raise ValueError("scale must be positive")
    q_min = -(2 ** (n_bits - 1))
    q_max = 2 ** (n_bits - 1) - 1
    q = max(q_min, min(q_max, round(x / scale) + zero_point))
    x_hat = (q - zero_point) * scale
    return round(abs(x - x_hat), 6)
```

INT8 quantization maps 32-bit floats to 8-bit integers, reducing memory 4x and enabling faster integer math on dedicated hardware. The quantization error (also called rounding error) is bounded by `scale / 2` for values within the representable range. Choosing a scale that minimizes this error across the weight distribution is the key challenge in post-training quantization.
