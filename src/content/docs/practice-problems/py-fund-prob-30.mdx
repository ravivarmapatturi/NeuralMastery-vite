## Overview

Simulate fully persistent immutable stack versioning supporting historical branching and inspection.

## Task

Implement `immutable_persistent_stack_simulator(operations)`: maintain a persistent stack where past states are never overwritten. Version `0` is the initial empty stack. Support `push` (creates and returns a new version ID), `pop` (returns `{"val": top, "version": new_ver}` without mutating parent version), and `peek` (returns top value of specified version). Return results list of all operations.

<Solution>

```python
def immutable_persistent_stack_simulator(operations):
    versions = {0: ()}
    next_ver = 1
    out = []
    for op in operations:
        action = op.get('op')
        v = op.get('version', 0)
        curr = versions.get(v, ())
        if action == 'push':
            new_stack = curr + (op.get('val'),)
            versions[next_ver] = new_stack
            out.append(next_ver)
            next_ver += 1
        elif action == 'pop':
            if curr:
                val = curr[-1]
                new_stack = curr[:-1]
                versions[next_ver] = new_stack
                out.append({'val': val, 'version': next_ver})
                next_ver += 1
            else:
                out.append({'val': None, 'version': v})
        elif action == 'peek':
            out.append(curr[-1] if curr else None)
    return out
```

Using immutable tuples preserves past state snapshots while enabling O(1) branching without side effects.
