## Overview

Interleave two sequences in alternating turn order with trailing tail preservation.

## Task

Implement `interleave_lists(a, b)`: merge lists `a` and `b` alternating elements: `a[0], b[0], a[1], b[1], ...`. When one list is exhausted, append all remaining items from the longer list.

<PracticePlayground problemId="py-fund-prob-10" />

<Solution>

```python
def interleave_lists(a, b):
    res = []
    n = max(len(a), len(b))
    for i in range(n):
        if i < len(a):
            res.append(a[i])
        if i < len(b):
            res.append(b[i])
    return res
```

Alternating bounds-checked insertions guarantee safe tail concatenation in O(len(a) + len(b)) time.
