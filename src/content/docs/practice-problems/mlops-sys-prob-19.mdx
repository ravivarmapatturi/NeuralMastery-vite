# Pipeline DAG Topological Sort

**Track**: MLOps & Data Systems | **Points**: 40 XP

## Overview

Implement topological sort for a data/ML pipeline DAG, determining a valid stage execution order from declared dependencies.

## Task

Implement `topological_sort(dependencies)`. `dependencies` maps each stage name to a list of stages it depends on (must run first). Return a valid execution order (a list of ALL stage names, including those with no dependents) such that every stage appears after all of its dependencies. Use Kahn's algorithm; among stages with no remaining dependencies at a given point, process them in sorted (alphabetical) order for a deterministic result. Assume the graph is acyclic.
