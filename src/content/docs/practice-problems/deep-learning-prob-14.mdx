# WordPiece Greedy Subword Tokenization

**Track**: Deep Learning & Vision/NLP | **Points**: 40 XP

## Overview

Segment a word into subwords using BERT WordPiece longest-prefix matching with '##' continuation prefixes.

## Task

Implement `wordpiece_tokenize_word(word, vocab, unk_token)`. `vocab` is a list of allowed subwords. Start at index 0. Find the longest substring `word[start:end]` in `vocab` (if `start > 0`, prepend `'##'` to the candidate before checking `vocab`). If found, add the matched token and advance `start = end`. If at any point no valid subword prefix exists, return `[unk_token]`. Return the list of subword tokens.
