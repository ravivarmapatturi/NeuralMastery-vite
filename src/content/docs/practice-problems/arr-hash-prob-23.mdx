# #553. Arrays / Hashing / Two Pointers Module 5: Problem 23

**Track**: Arrays / Hashing / Two Pointers | **Rank**: #553 of 1072 | **Points**: 90 XP

## Overview

Implement `four_sum(nums, target)`, the generalization of Two Sum/Three Sum to four numbers via sort + two fixed outer indices + a two-pointer inner scan, plus the duplicate-quadruple-avoidance logic that keeps it correct on inputs with repeated values.

## Task

Implement the function `four_sum(nums, target)`: return every unique quadruple `[a, b, c, d]` from `nums` (each element used at most once per quadruple, by index) such that `a+b+c+d == target`. Each quadruple's numbers must be listed in ascending order, and there must be no duplicate quadruples.
