# NumPy Vectorized One-Hot Matrix Encoding

**Rank #187** · Difficulty: **Easy** · Stage: **Stage 4: NumPy & Vectorized Data Processing** · Category: **NumPy & Pandas**

Transform integer class label vectors into vectorized binary one-hot matrices using NumPy. Prerequisite: `numpy-pandas-prob-6`.

<PracticePlayground problemId="numpy-pandas-prob-7" />

<Solution>

```python
import numpy as np

def vectorized_one_hot(labels, num_classes):
    if not labels or num_classes <= 0:
        return []
    arr = np.array(labels, dtype=int)
    one_hot = np.zeros((len(labels), num_classes), dtype=int)
    one_hot[np.arange(len(labels)), arr] = 1
    return one_hot.tolist()
```

Advanced fancy indexing in NumPy allows scattering 1s across coordinate pairs (row, class) in a single vectorized memory write operation.
