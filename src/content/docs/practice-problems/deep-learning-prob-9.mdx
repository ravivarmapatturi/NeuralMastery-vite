# 2D Binary Morphological Dilation

**Track**: Deep Learning & Vision/NLP | **Points**: 40 XP

## Overview

Implement binary morphological dilation to expand foreground boundaries in binary segmentation masks.

## Task

Implement `morphological_dilate_2d(grid, kernel)`. `grid` is an `H x W` binary matrix (0 or 1). `kernel` is an odd-sized `kH x kW` binary matrix with center at `(kH//2, kW//2)`. Output cell `(r, c)` is `1` if there is ANY offset `(dr, dc)` where `kernel[kH//2 + dr][kW//2 + dc] == 1` and `grid[r + dr][c + dc] == 1` (within grid bounds); otherwise `0`.
