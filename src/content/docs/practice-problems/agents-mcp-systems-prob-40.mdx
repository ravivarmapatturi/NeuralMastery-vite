# Find Replica Divergence for Anti-Entropy Repair

**Rank #470** · Difficulty: **Medium** · Stage: **Stage 8: RAG, Agents, MCP & Distributed Systems** · Category: **Agents, MCP & Systems**

Implement `find_replica_divergence(replica_a, replica_b)`, the divergence-detection step behind anti-entropy repair -- the background process a Dynamo-style eventually-consistent store runs to find and reconcile keys where two replicas have drifted apart. Prerequisite: `agents-mcp-systems-prob-39`.

<PracticePlayground problemId="agents-mcp-systems-prob-40" />

<Solution>

```python
def find_replica_divergence(replica_a, replica_b):
    keys = set(replica_a) | set(replica_b)
    diff = [k for k in keys if replica_a.get(k) != replica_b.get(k)]
    return sorted(diff)
```

A real anti-entropy process uses a Merkle tree instead of comparing every key directly, so two replicas can find their point of divergence by comparing O(log n) hash values instead of the full keyspace -- but the thing being detected is exactly what this function computes directly: which keys actually disagree.

</Solution>
