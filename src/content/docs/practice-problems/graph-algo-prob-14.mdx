## Overview

Simulate synchronous disease propagation in a grid using multi-source Breadth-First Search.

## Task

Implement `oranges_rotting(grid)`: seed BFS queue with all initially rotten oranges at t=0. Propagate contamination to adjacent fresh oranges level-by-level.

```python
from collections import deque

def oranges_rotting(grid):
    grid = [list(row) for row in grid]
    m, n = len(grid), len(grid[0])
    q = deque()
    fresh = 0
    for r in range(m):
        for c in range(n):
            if grid[r][c] == 2:
                q.append((r, c, 0))
            elif grid[r][c] == 1:
                fresh += 1
    if fresh == 0:
        return 0
    minutes = 0
    while q:
        r, c, d = q.popleft()
        minutes = d
        for dr, dc in [(-1, 0), (1, 0), (0, -1), (0, 1)]:
            nr, nc = r + dr, c + dc
            if 0 <= nr < m and 0 <= nc < n and grid[nr][nc] == 1:
                grid[nr][nc] = 2
                fresh -= 1
                q.append((nr, nc, d + 1))
    return minutes if fresh == 0 else -1
```

Initialize the BFS queue with all rotten oranges. Each level models 1 minute of contagion spread across adjacent fresh oranges until all reachable oranges rot.
