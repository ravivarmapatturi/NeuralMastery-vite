# Near-Duplicate Chunk Detection

**Track**: RAG Production Engineering | **Points**: 40 XP

## Overview

Implement near-duplicate chunk detection via Jaccard similarity of word sets, needed to prevent a RAG index from retrieving multiple nearly-identical chunks that waste context budget.

## Task

Implement `find_near_duplicates(chunks, threshold)`. `chunks` maps chunk id -> a set of its words. For every UNIQUE pair of chunk ids (i, j) with `i < j` alphabetically, compute Jaccard similarity `|A∩B|/|A∪B|`. Return the sorted list of `(id_i, id_j)` tuples whose similarity is `>= threshold`.
