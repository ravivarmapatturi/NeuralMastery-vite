# #670. Dynamic Programming & Greedy Module 4: Problem 20

**Track**: Dynamic Programming & Greedy | **Rank**: #670 of 1072 | **Points**

## Overview

Rob non-adjacent houses along a circular street by decomposing the cycle into two linear dynamic programming subproblems.

## Task

Implement `house_robber_ii(nums)`: since house 0 and house n-1 cannot both be robbed, take max(rob_linear(nums[:-1]), rob_linear(nums[1:])).

<PracticePlayground problemId="dp-greedy-prob-20" />

<Solution>

```python
def house_robber_ii(nums):
    if not nums:
        return 0
    if len(nums) == 1:
        return nums[0]
    def rob_linear(houses):
        rob1, rob2 = 0, 0
        for h in houses:
            rob1, rob2 = rob2, max(rob2, rob1 + h)
        return rob2
    return max(rob_linear(nums[:-1]), rob_linear(nums[1:]))
```

Break the circle into two linear instances: excluding the last house (0 to n-2) or excluding the first house (1 to n-1). Return the maximum of both linear DP solutions.
