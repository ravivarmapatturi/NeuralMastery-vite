## Overview

Implement `first_missing_positive(nums)` via in-place cyclic placement -- the key realization that the answer is always in `[1, n+1]`, so the array itself can be reused as its own O(1)-extra-space hash table.

## Task

Implement the function `first_missing_positive(nums)`: return the smallest positive integer (at least `1`) that does not appear in `nums`. Must run in O(n) time using O(1) extra space.
