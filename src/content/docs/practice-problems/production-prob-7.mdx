# Estimate Monthly Agent API Spend

**Track**: Agent Performance & Production | **Points**: 40 XP

## Overview

Implement a real monthly-spend estimator for an agent deployment, the direct budgeting calculation before signing off on a production launch.

## Task

Implement `estimate_monthly_spend(avg_daily_requests, avg_tokens_per_request, price_per_1k_tokens)`: return `avg_daily_requests * avg_tokens_per_request / 1000 * price_per_1k_tokens * 30`.
