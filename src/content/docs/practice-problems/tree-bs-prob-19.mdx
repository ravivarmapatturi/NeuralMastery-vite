## Overview

Count the number of nodes in a complete binary tree in O((log n)^2) time by leveraging its structural completeness.

## Task

Implement `count_complete_tree_nodes(root)`: measure the leftmost and rightmost depths. If equal, the tree is full (2^d - 1 nodes); otherwise recursively count left and right subtrees.

<PracticePlayground problemId="tree-bs-prob-19" />

<Solution>

```python
def count_complete_tree_nodes(root):
    if not root:
        return 0
    def left_depth(node):
        d = 0
        while node:
            d += 1
            node = node.get('left')
        return d
    def right_depth(node):
        d = 0
        while node:
            d += 1
            node = node.get('right')
        return d
    ld = left_depth(root)
    rd = right_depth(root)
    if ld == rd:
        return (1 << ld) - 1
    return 1 + count_complete_tree_nodes(root.get('left')) + count_complete_tree_nodes(root.get('right'))
```

Compute left and right extreme heights. When they match, the subtree is perfect, so its node count is computed in O(1) via (2^h - 1). Otherwise, recurse on both subtrees.
