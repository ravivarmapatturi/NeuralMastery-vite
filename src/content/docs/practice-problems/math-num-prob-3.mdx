# #713. Vector Projection and Rejection

**Track**: Mathematics & Numerical Computing | **Rank**: #713 of 1072 | **Points**: 40 XP

## Overview

Decompose vector u into orthogonal components parallel and perpendicular to v.

## Task

Implement `vector_projection(u, v)`: compute `proj = (u . v / (v . v)) * v` and `rej = u - proj`. Return `{"proj": list[float], "rej": list[float]}` with all numbers rounded to 4 decimals.

<PracticePlayground problemId="math-num-prob-3" />

<Solution>

```python
def vector_projection(u, v):
    dot_uv = sum(x * y for x, y in zip(u, v))
    dot_vv = sum(y * y for y in v)
    if dot_vv == 0:
        proj = [0.0] * len(u)
    else:
        scalar = dot_uv / dot_vv
        proj = [scalar * y for y in v]
    rej = [x - p for x, p in zip(u, proj)]
    return {'proj': [round(float(x), 4) for x in proj], 'rej': [round(float(x), 4) for x in rej]}
```

Computes scalar projection onto v, multiplies by v, and subtracts from u for orthogonal rejection.
