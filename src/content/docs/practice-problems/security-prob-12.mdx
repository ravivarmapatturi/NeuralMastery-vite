# Check Dependency Version Is Pinned

**Track**: Agent Security & Reliability | **Points**: 40 XP

## Overview

Implement dependency-pinning validation, a real supply-chain security check flagging unpinned dependencies an agent (or its generated code) might introduce.

## Task

Implement `is_version_pinned(version_spec)`. Return `False` if `version_spec` is `'*'`, `'latest'`, or empty. Return `False` if it contains any of `'>='`, `'<='`, `'>'`, `'<'`, `'^'`, `'~'` (a range/floating spec). Otherwise (looks like an exact version, e.g. `'1.2.3'`) return `True`.
