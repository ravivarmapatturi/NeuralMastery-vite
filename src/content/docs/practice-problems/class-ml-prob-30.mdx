## Overview

Fit an L1-regularized sparse linear model using cyclical coordinate descent with soft thresholding.

## Task

Implement `lasso_coordinate_descent(X, y, alpha, max_iter)`: iteratively update each coordinate `w_j` using soft thresholding on partial residuals, inducing feature sparsity.

<Solution>

```python
def lasso_coordinate_descent(X, y, alpha, max_iter):
    n, p = len(X), len(X[0])
    w = [0.0] * p
    z = [sum(X[i][j] ** 2 for i in range(n)) for j in range(p)]
    for _ in range(max_iter):
        for j in range(p):
            if z[j] == 0:
                continue
            rho = sum(X[i][j] * (y[i] - sum(X[i][k] * w[k] for k in range(p) if k != j)) for i in range(n))
            if rho < -alpha:
                w[j] = (rho + alpha) / z[j]
            elif rho > alpha:
                w[j] = (rho - alpha) / z[j]
            else:
                w[j] = 0.0
    return [round(val, 4) for val in w]
```

Cycle through coordinates, isolating each parameter by removing its effect from residuals, and applying the soft-thresholding operator to achieve sparsity.
