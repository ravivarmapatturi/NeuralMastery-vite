# DP: Coin Change (Minimum Coins)

**Rank #79** · Difficulty: **Easy** · Stage: **Stage 2: Data Structures & Algorithmic Foundations** · Category: **Data Structures & Algorithms**

## Overview

Implement `coin_change(coins, amount)` -- the canonical unbounded-knapsack DP problem. Same recurrence as Climbing Stairs but with arbitrary step sizes.

## Task

Implement the function `coin_change(coins, amount)`. Return the minimum number of coins needed to make `amount`, or `-1` if impossible.

<PracticePlayground problemId="ds-algo-prob-19" />

<Solution>

```python
def coin_change(coins, amount):
    dp = [float('inf')] * (amount + 1)
    dp[0] = 0
    for i in range(1, amount + 1):
        for c in coins:
            if c <= i:
                dp[i] = min(dp[i], dp[i - c] + 1)
    return dp[amount] if dp[amount] != float('inf') else -1
```

Bottom-up DP: dp[i] = min(dp[i-c]+1) over all valid coins c. dp[0]=0 is the base case. O(amount * len(coins)) time, O(amount) space.

</Solution>
