# Validate Session Token Not Expired

**Track**: Agent Security & Reliability | **Points**: 40 XP

## Overview

Implement session-token expiry validation, a real, basic authentication check before honoring any agent action taken on behalf of an authenticated session.

## Task

Implement `is_session_valid(issued_at, current_time, ttl_seconds)`: return `True` if `(current_time - issued_at) < ttl_seconds`.
