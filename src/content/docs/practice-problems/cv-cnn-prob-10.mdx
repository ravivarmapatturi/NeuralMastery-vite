# #900. Cumulative Receptive Field Tracker

**Track**: Computer Vision & CNN Architectures | **Rank**: #900 of 1072 | **Points**: 40 XP

## Overview

Track how deep convolutional feature representations expand their field of view over input image coordinates.

## Task

Implement `receptive_field_1d(kernel_sizes, strides)`: start with receptive field `rf = 1` and cumulative stride `stride = 1`. For each layer `l` with kernel size `k` and stride `s`, update: `rf = rf + (k - 1) * stride`, and then `stride = stride * s`. Return `{'receptive_field': rf, 'cumulative_stride': stride}`.

<PracticePlayground problemId="cv-cnn-prob-10" />

<Solution>

```python
def receptive_field_1d(kernel_sizes: list[int], strides: list[int]) -> dict:
    rf = 1
    stride = 1
    for k, s in zip(kernel_sizes, strides):
        rf = rf + (k - 1) * stride
        stride = stride * s
    return {"receptive_field": rf, "cumulative_stride": stride}
```

Each successive layer broadens the effective input patch by its kernel extent scaled by the preceding cumulative feature map stride.
