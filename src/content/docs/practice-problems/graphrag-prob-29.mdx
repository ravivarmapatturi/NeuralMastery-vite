# GraphRAG Retrieval Recall Against Ground-Truth Entities

**Track**: Knowledge Graph & GraphRAG | **Points**: 40 XP

## Overview

Implement GraphRAG retrieval recall, measuring what fraction of the entities genuinely needed to answer a question were actually pulled into the retrieved subgraph.

## Task

Implement `graph_retrieval_recall(retrieved_entities, ground_truth_entities)`: return `|retrieved ∩ ground_truth| / |ground_truth|`. Return `1.0` if `ground_truth_entities` is empty (vacuously complete).
