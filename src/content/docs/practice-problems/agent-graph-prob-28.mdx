# Enforce Maximum Graph Depth From Entry

**Track**: Agent Graph Engineering | **Points**: 40 XP

## Overview

Implement a maximum-depth enforcement check, a real structural safety bound distinct from a loop-iteration bound -- limiting how many total sequential nodes a graph execution may traverse from entry before being forcibly halted.

## Task

Implement `exceeds_max_depth(current_depth, max_depth)`: return `True` if `current_depth > max_depth`.
