# Greedy Word Wrap Formatter

**Rank #32** · Difficulty: **Medium** · Stage: **Stage 1: AI Foundations & Python Programming** · Category: **Python & Fundamentals**

## Overview

Break unstructured paragraphs into cleanly wrapped lines constrained to a maximum display column width.

## Task

Implement `word_wrap(text, max_width)`: split `text` into whitespace-separated words and greedily pack as many words onto each line as possible without exceeding `max_width`. Words within a line must be separated by a single space. If `text` contains no words, return `[]`.

<PracticePlayground problemId="py-foundations-prob-32" />

<Solution>

```python
def word_wrap(text, max_width):
    words = text.split()
    if not words:
        return []
    lines = []
    curr_line = [words[0]]
    curr_len = len(words[0])
    for w in words[1:]:
        if curr_len + 1 + len(w) <= max_width:
            curr_line.append(w)
            curr_len += 1 + len(w)
        else:
            lines.append(" ".join(curr_line))
            curr_line = [w]
            curr_len = len(w)
    lines.append(" ".join(curr_line))
    return lines
```

Greedy packing checks whether the next token fits within the column limit before advancing to a new line.
