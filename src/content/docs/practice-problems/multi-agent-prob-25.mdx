# Supervisor Restart Policy Decision

**Track**: Multi-Agent Systems | **Points**: 40 XP

## Overview

Implement a real supervisor restart-policy decision (matching Erlang/OTP-style supervision trees), deciding whether a failed agent process should be restarted.

## Task

Implement `should_restart_agent(failure_count, max_retries, strategy)`. If `strategy == 'always'`, always return `True`. If `strategy == 'never'`, always return `False`. If `strategy == 'max_retries'`, return `True` only if `failure_count < max_retries`.
