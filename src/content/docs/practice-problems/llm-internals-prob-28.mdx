# RoPE Frequency Band Computation

**Track**: transformers-llms | **Points**: 40 XP

## Overview

Compute the Rotary Position Embedding (RoPE) base frequencies for each pair of dimensions in a transformer head.

## Task

Implement `rope_frequencies(d_head, base=10000)` that returns a list of `d_head // 2` frequencies: `theta_i = base ** (-(2*i) / d_head)` for `i = 0, 1, ..., d_head//2 - 1`. Round each frequency to 6 decimal places. Raise `ValueError` if `d_head <= 0`, `d_head % 2 != 0`, or `base <= 0`.
