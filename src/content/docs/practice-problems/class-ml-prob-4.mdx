## Overview

Compute fundamental regression error metrics MSE, MAE, and RMSE from scratch.

## Task

Implement `regression_metrics(y_true, y_pred)`: calculate mean squared error, mean absolute error, and square root of MSE, rounding all returned values to 4 decimal places.

<PracticePlayground problemId="class-ml-prob-4" />

<Solution>

```python
import math

def regression_metrics(y_true, y_pred):
    n = len(y_true)
    mse = sum((yt - yp) ** 2 for yt, yp in zip(y_true, y_pred)) / n
    mae = sum(abs(yt - yp) for yt, yp in zip(y_true, y_pred)) / n
    return {
        'mse': round(mse, 4),
        'mae': round(mae, 4),
        'rmse': round(math.sqrt(mse), 4)
    }
```

Compute pointwise squared and absolute deviations between predicted and true targets, average across samples, and take square root of MSE for RMSE.
