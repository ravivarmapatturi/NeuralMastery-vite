# Build a Subject-Indexed Triple Store

**Track**: Knowledge Graph & GraphRAG | **Points**: 40 XP

## Overview

Implement subject-indexed triple storage, the real, simple indexing structure that makes 'find all facts about entity X' an O(1) lookup instead of a full scan.

## Task

Implement `build_subject_index(triples)`: return a dict mapping each distinct `subject` to the list of ALL triples with that subject, preserving each group's original relative order.
