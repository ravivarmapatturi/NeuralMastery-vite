# #800. Scalable Pipeline DAG Execution Engine

**Track**: Pandas & Data Processing Pipelines | **Rank**: #800 of 1072 | **Points**: 90 XP

## Overview

Orchestrate composable, verifiable data transformation DAG pipelines over tabular column state.

## Task

Implement `execute_pipeline_dag(initial_state, stages)`: execute each stage in `stages` sequentially on `initial_state`. Supported stage types: `'scale'` (`x * factor`), `'add'` (`x + value`), and `'clip'` (`max(min, min(max, x))`). Round all column float values to 4 decimals after each operation. Return dict with `final_state` and list `stages_executed`.

<Solution>

```python
def execute_pipeline_dag(initial_state, stages):
    state = dict(initial_state)
    executed = []
    for st in stages:
        p = st['params']
        col = p['column']
        ft = st['func_type']
        if ft == 'scale':
            state[col] = [round(float(x * p['factor']), 4) for x in state[col]]
        elif ft == 'add':
            state[col] = [round(float(x + p['value']), 4) for x in state[col]]
        elif ft == 'clip':
            state[col] = [round(float(max(p['min'], min(p['max'], x))), 4) for x in state[col]]
        executed.append(st['name'])
    return {'final_state': state, 'stages_executed': executed}
```

Executes series of parameterized column-wise transformations in topological sequence.
