# Inline a Subgraph Into the Parent Graph

**Track**: Agent Graph Engineering | **Points**: 40 XP

## Overview

Implement subgraph inlining, composing a reusable sub-workflow's nodes into a parent agent graph with namespaced node ids to avoid collisions.

## Task

Implement `inline_subgraph(parent_edges, subgraph_edges, prefix)`. Rename every subgraph node and edge target by prepending `f'{prefix}.'`. Merge the renamed subgraph edges into `parent_edges` (a copy, don't mutate the input) and return the combined dict.
