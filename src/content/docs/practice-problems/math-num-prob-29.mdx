# #739. Solving Triangular Systems via Forward and Backward Substitution

**Track**: Mathematics & Numerical Computing | **Rank**: #739 of 1072 | **Points**: 90 XP

## Overview

Solve triangular systems in O(n^2) operations via forward or backward substitution.

## Task

Implement `solve_triangular_system(L, b, lower=True)`: if `lower` is True, perform forward substitution: `x[i] = (b[i] - sum_{j<i} L[i][j]*x[j]) / L[i][i]`. If `lower` is False, perform backward substitution from row n-1 down to 0: `x[i] = (b[i] - sum_{j>i} L[i][j]*x[j]) / L[i][i]`. Return solution vector x rounded to 4 decimals.

```python
def solve_triangular_system(L, b, lower=True):
    n = len(b)
    x = [0.0] * n
    if lower:
        for i in range(n):
            sum_known = sum(L[i][j] * x[j] for j in range(i))
            x[i] = (b[i] - sum_known) / L[i][i]
    else:
        for i in range(n - 1, -1, -1):
            sum_known = sum(L[i][j] * x[j] for j in range(i + 1, n))
            x[i] = (b[i] - sum_known) / L[i][i]
    return [round(float(val), 4) for val in x]
```

Substitutes solved variables into successive equations, operating in O(n^2) time.
