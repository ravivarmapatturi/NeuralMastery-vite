# Token Bucket Rate Limiter Check

**Track**: MCP Core Engineering | **Points**: 40 XP

## Overview

Implement a token-bucket rate limiter, the real, standard algorithm an MCP server uses to bound how fast a client can issue tool calls.

## Task

Implement `allow_request(tokens_available, tokens_needed, refill_rate, elapsed_s, bucket_capacity)`. First refill: `refilled = min(bucket_capacity, tokens_available + refill_rate*elapsed_s)`. If `refilled >= tokens_needed`, the request is allowed: return `(True, refilled - tokens_needed)`. Otherwise return `(False, refilled)` (denied, bucket unchanged by the failed request).
