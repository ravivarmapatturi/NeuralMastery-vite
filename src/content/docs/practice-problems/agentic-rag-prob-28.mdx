# Determine Multi-Hop Reasoning Chain Completion

**Track**: Advanced RAG & Agentic RAG | **Points**: 40 XP

## Overview

Implement multi-hop reasoning-chain completion checking, the real stopping condition for an agentic RAG loop performing iterative multi-hop retrieval.

## Task

Implement `is_chain_complete(collected_entities, required_entities)`: return `True` if `required_entities` is a SUBSET of `collected_entities` (every entity needed to answer has been found across all hops so far).
