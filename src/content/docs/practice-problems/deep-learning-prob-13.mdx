# Byte-Pair Encoding (BPE) Merge Step

**Track**: Deep Learning & Vision/NLP | **Points**: 40 XP

## Overview

Execute one merge iteration of the Byte-Pair Encoding algorithm on tokenized word frequencies.

## Task

Implement `bpe_merge_pair(vocab_frequencies, pair_to_merge)`. `vocab_frequencies` maps space-separated token sequences (e.g. `'l o w </w>': 5`) to counts. `pair_to_merge` is `[sym1, sym2]`. For each key in `vocab_frequencies`, replace every adjacent occurrence of `sym1` and `sym2` with `sym1sym2` (concatenated without space). Keep frequencies unchanged. Return the new dictionary.
