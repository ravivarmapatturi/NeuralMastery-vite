# KV-Cache Memory Footprint Estimate

**Track**: Agent Performance & Production | **Points**: 40 XP

## Overview

Implement KV-cache memory estimation, the real, standard calculation an LLM-serving engineer runs before deciding how many concurrent sequences fit on a given GPU.

## Task

Implement `kv_cache_memory_mb(num_layers, num_heads, head_dim, seq_len, batch_size, bytes_per_value=2.0)`. Total elements: `2 (K and V) * num_layers * num_heads * head_dim * seq_len * batch_size`. Multiply by `bytes_per_value`, convert bytes to MB (divide by `1024*1024`).
