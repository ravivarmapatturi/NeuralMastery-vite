# Longest Palindromic Substring

**Rank #30** · Difficulty: **Medium** · Stage: **Stage 1: AI Foundations & Python Programming** · Category: **Python & Fundamentals**

## Overview

Locate the longest symmetric substring using optimal expand-around-center pointer traversal.

## Task

Implement `longest_palindrome(s)`: find and return the longest substring of `s` that reads identically forward and backward. If multiple palindromes share the maximum length, return the one with the earliest starting index.

<PracticePlayground problemId="py-foundations-prob-30" />

<Solution>

```python
def longest_palindrome(s):
    if not s:
        return ""
    start, max_len = 0, 1
    for i in range(len(s)):
        for l, r in [(i, i), (i, i + 1)]:
            while l >= 0 and r < len(s) and s[l] == s[r]:
                if r - l + 1 > max_len:
                    start = l
                    max_len = r - l + 1
                l -= 1
                r += 1
    return s[start:start + max_len]
```

Expanding around all 2n-1 potential centers discovers the longest symmetric window in O(n^2) time with O(1) auxiliary space.
