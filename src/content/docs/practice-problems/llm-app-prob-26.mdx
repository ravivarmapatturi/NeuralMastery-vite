# #086. LLM-as-a-Judge Weighted Rubric Evaluator

**Track**: LLM Application Engineering | **Rank**: #86 of 1072 | **Points**: 90 XP

## Overview

Standardize and aggregate qualitative model assessments across multiple LLM judges using weighted rubric criteria. In production LLM application engineering, reliable system components, deterministic interfaces, and defensive validation are paramount for production stability and cost efficiency.

## Task

Implement `evaluate_llm_judge_rubric(judge_outputs, rubric_weights)`. Verify that `sum(rubric_weights.values()) == 1.0` (tolerance 1e-4). For each judge, compute their individual weighted score `sum(score[c] * weight[c])`. Average each criterion score across judges. Calculate overall weighted score `sum(criterion_avg[c] * weight[c])`, and inter-judge variance across individual judges' weighted scores. Round all float metrics to 4 decimal places. Set `passed: True` if `overall_score >= 3.5`. Raise `ValueError` if `judge_outputs` is empty, weights do not sum to 1.0, or any judge is missing a required criterion.
