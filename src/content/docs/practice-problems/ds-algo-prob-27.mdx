# Trees: Binary Tree Right Side View

**Rank #87** · Difficulty: **Medium** · Stage: **Stage 2: Data Structures & Algorithmic Foundations** · Category: **Data Structures & Algorithms**

## Overview

Implement `right_side_view(root)` -- BFS level order but only recording the last node at each level. This is the view you would see standing to the right of the tree.

## Task

Implement the function `right_side_view(root)`. Each node is `{'val', 'left', 'right'}`. Return the values of the rightmost node at each level, from top to bottom.

<PracticePlayground problemId="ds-algo-prob-27" />

<Solution>

```python
from collections import deque

def right_side_view(root):
    if not root:
        return []
    result = []
    q = deque([root])
    while q:
        n = len(q)
        for i in range(n):
            node = q.popleft()
            if i == n - 1:
                result.append(node['val'])
            if node['left']:
                q.append(node['left'])
            if node['right']:
                q.append(node['right'])
    return result
```

Level-order BFS; the last node dequeued at each level is the rightmost. Record it with `if i == n-1`. O(n) time.

</Solution>
