# #607. Trees / Binary Search Module 4: Problem 17

**Track**: Trees / Binary Search | **Rank**: #607 of 1072 | **Points**

## Overview

Find the lowest common ancestor of two nodes in an arbitrary binary tree without BST ordering guarantees.

## Task

Implement `lowest_common_ancestor_bt(root, p, q)`: perform a bottom-up postorder traversal. If a node matches p or q, return it. If both left and right recursive calls return non-null nodes, the current node is the LCA.

<PracticePlayground problemId="tree-bs-prob-17" />

<Solution>

```python
def lowest_common_ancestor_bt(root, p, q):
    def dfs(node):
        if not node:
            return None
        if node['val'] == p or node['val'] == q:
            return node
        left = dfs(node.get('left'))
        right = dfs(node.get('right'))
        if left and right:
            return node
        return left if left else right
    res = dfs(root)
    return res['val'] if res else -1
```

Recursively search both subtrees. If both return a target, the current node is their convergence point (the LCA). Otherwise, propagate up whichever target was found.

</Solution>
