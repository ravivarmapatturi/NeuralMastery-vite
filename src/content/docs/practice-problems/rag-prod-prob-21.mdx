# Deterministic Embedding Cache Key

**Track**: RAG Production Engineering | **Points**: 40 XP

## Overview

Implement a real embedding cache key, correctly scoped so a cache never serves a stale embedding computed by a different model or model version.

## Task

Implement `embedding_cache_key(text, model_name, model_version)`. Return the hex `hashlib.sha256` digest of the string `f'{model_name}:{model_version}:{text}'` (UTF-8 encoded).
