# Batch Inference Throughput vs Latency Tradeoff

**Track**: Agent Performance & Production | **Points**: 40 XP

## Overview

Implement batch-inference throughput calculation, the real arithmetic behind sizing a production LLM serving batch for maximum requests-per-second.

## Task

Implement `batch_throughput(batch_size, per_batch_latency_ms)`: return `(batch_size / per_batch_latency_ms) * 1000` -- requests served per second, given that a whole batch of `batch_size` requests takes `per_batch_latency_ms` to complete together.
