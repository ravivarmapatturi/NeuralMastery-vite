# #057. Medusa Multi-Head Speculative Acceptance

**Track**: LLM Inference & Decoding | **Rank**: #57 of 1072 | **Points**: 90 XP

## Overview

Select the highest-yield speculative candidate sequence generated by parallel Medusa prediction heads. Autoregressive language models generate sequences token by token, evaluating next-token probability distributions at each decoding step.

## Task

Implement `medusa_verify_candidates(candidates, target_greedy_tokens)`. For each candidate sequence, compute the length of its longest contiguous prefix that matches `target_greedy_tokens` starting from index 0. Select the candidate with the maximum matching length. Break ties by choosing the candidate with the lower index in `candidates`. Return dict containing `best_candidate_index`, `accepted_tokens` (list of accepted prefix tokens), and `acceptance_length` (int). If `candidates` is empty, raise `ValueError`.
