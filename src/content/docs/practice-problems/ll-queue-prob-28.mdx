# #588. Linked Lists / Stacks / Queues Module 6: Problem 28

**Track**: Linked Lists / Stacks / Queues | **Rank**: #588 of 1072 | **Points**

## Overview

Permute linked list structures by reversing consecutive blocks of K nodes in-place in O(1) space.

## Task

Implement `reverse_k_group(head, k)`: reverse nodes in `head` `k` at a time. If the number of remaining nodes at the end is less than `k`, leave them un-reversed in their original order. Modifies pointers in-place in O(1) memory.

<Solution>

```python
def reverse_k_group(head, k):
    if not head or k <= 1:
        return head
    dummy = {'val': 0, 'next': head}
    prev_group = dummy
    while True:
        kth = prev_group
        for _ in range(k):
            kth = kth.get('next')
            if not kth: return dummy['next']
        group_next = kth.get('next')

        prev = group_next
        curr = prev_group['next']
        while curr != group_next:
            nxt = curr.get('next')
            curr['next'] = prev
            prev = curr
            curr = nxt

        temp = prev_group['next']
        prev_group['next'] = kth
        prev_group = temp
```

Checking for K nodes before reversing ensures incomplete terminal blocks remain untouched while earlier segments invert in O(n).
