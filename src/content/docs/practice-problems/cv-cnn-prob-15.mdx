# #905. Dilated Convolution Receptive Field Analyzer

**Track**: Computer Vision & CNN Architectures | **Rank**: #905 of 1072 | **Points**: 60 XP

## Overview

Expand receptive field exponentially without downsampling or parameter explosion via atrous (dilated) convolutions.

## Task

Implement `dilated_conv2d_receptive_field(dilations, kernel_size=3)`: for each layer with dilation rate `d`, the effective kernel footprint is `k_eff = 1 + (kernel_size - 1) * d`. Assuming unit stride, each layer expands the total receptive field by `k_eff - 1`. Starting with initial `rf = 1`, compute the cumulative receptive field and the list of effective kernel sizes. Return `{'receptive_field': rf, 'effective_kernels': effective_kernels}`.

<PracticePlayground problemId="cv-cnn-prob-15" />

<Solution>

```python
def dilated_conv2d_receptive_field(dilations: list[int], kernel_size: int = 3) -> dict:
    rf = 1
    effective_kernels = []
    for d in dilations:
        k_eff = 1 + (kernel_size - 1) * d
        effective_kernels.append(k_eff)
        rf += (k_eff - 1)
    return {"receptive_field": rf, "effective_kernels": effective_kernels}
```

Dilating kernels spaces out the weights by (d - 1) zeros, geometrically widening the receptive field without adding learned parameters.
