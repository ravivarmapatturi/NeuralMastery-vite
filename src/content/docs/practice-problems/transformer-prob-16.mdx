# #016. Transformer Internals Module 4: Problem 16

**Track**: Transformer Internals | **Rank**: #16 of 1072 | **Points**: 60 XP

## Overview

Apply Rotary Positional Embedding (RoPE) to an activation vector. RoPE encodes relative positional information by rotating pairs of coordinates in the complex plane by position-dependent frequencies, used widely in LLaMA, Mistral, and modern architectures.

## Task

Implement `rope_embedding(x, position, theta=10000.0)`: for consecutive coordinate pairs `(x[2i], x[2i+1])`, compute angle `omega_i = position / (theta ** (2i / d))`. Apply 2D rotation matrix `[[cos(omega_i), -sin(omega_i)], [sin(omega_i), cos(omega_i)]]`. Return the rotated vector rounded to 4 decimal places.
