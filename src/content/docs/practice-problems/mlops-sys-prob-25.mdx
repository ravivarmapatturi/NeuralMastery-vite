# Content-Based Dataset Version Hash

**Track**: MLOps & Data Systems | **Points**: 40 XP

## Overview

Implement content-based dataset versioning: a deterministic fingerprint that changes if and only if the dataset's actual content changes.

## Task

Implement `dataset_version_hash(record_hashes)`. Sort `record_hashes` (so row order doesn't affect the result), join them with `','`, and return the hex `hashlib.sha256` digest of that joined string (UTF-8 encoded).
