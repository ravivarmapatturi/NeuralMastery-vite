# Adaptive Retrieval K Based on Query Complexity

**Track**: Advanced RAG & Agentic RAG | **Points**: 40 XP

## Overview

Implement adaptive top-k selection, retrieving more chunks for genuinely complex queries and fewer for simple ones instead of a fixed k for every query.

## Task

Implement `adaptive_k(complexity_score, base_k, max_k)`. `complexity_score` is in `[0,1]`. Return `round(base_k + (max_k - base_k) * complexity_score)`, an int.
