# #816. Classical Machine Learning Module 4: Problem 16

**Track**: Classical Machine Learning | **Rank**: #816 of 1072 | **Points**: 60 XP

## Overview

Implement `k_fold_splits(n_samples, k)`, the actual index bookkeeping behind k-fold cross-validation -- the fold-size arithmetic and train/validation partitioning every CV loop is built on top of.

## Task

Implement the function `k_fold_splits(n_samples, k)`: partition range(n_samples) into k contiguous folds of size n_samples//k (the first n_samples % k folds get one extra sample), then return k [train_indices, val_indices] pairs, one per fold held out as validation. Raise `ValueError` if `k <= 1` or `k > n_samples`.
