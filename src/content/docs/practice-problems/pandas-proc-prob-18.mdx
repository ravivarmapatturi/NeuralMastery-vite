# #788. Dual DataFrame Reconciliation Auditor

**Track**: Pandas & Data Processing Pipelines | **Rank**: #788 of 1072 | **Points**: 60 XP

## Overview

Audit differences between historical and current tabular snapshots to detect modified, inserted, and deleted records.

## Task

Implement `reconcile_dataframes(source_df, target_df, primary_key)`: compare two datasets indexed by `primary_key`. Identify `added_keys` (in target but not source) and `removed_keys` (in source but not target). For keys present in both, identify field-level mismatches as `{"key": k, "field": col, "source": s_val, "target": t_val}`. Return dictionary with keys `added_keys`, `removed_keys`, and `discrepancies`.

```python
def reconcile_dataframes(source_df, target_df, primary_key):
    src = {r[primary_key]: r for r in source_df}
    tgt = {r[primary_key]: r for r in target_df}
    added = sorted([k for k in tgt if k not in src])
    removed = sorted([k for k in src if k not in tgt])
    discrepancies = []
    for k in sorted(src.keys()):
        if k in tgt:
            cols = sorted(set(src[k].keys()) | set(tgt[k].keys()))
            for c in cols:
                if c != primary_key and src[k].get(c) != tgt[k].get(c):
                    discrepancies.append({'key': k, 'field': c, 'source': src[k].get(c), 'target': tgt[k].get(c)})
    return {'added_keys': added, 'removed_keys': removed, 'discrepancies': discrepancies}
```

Builds key lookup dictionaries and conducts two-way differential audit of keys and attributes.
