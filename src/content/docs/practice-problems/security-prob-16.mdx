# Detect Shell Metacharacters in Tool Arguments

**Track**: Agent Security & Reliability | **Points**: 40 XP

## Overview

Implement shell-metacharacter detection, a real, critical input check before a tool argument is EVER passed to a shell command (the exact class of bug behind real command-injection vulnerabilities).

## Task

Implement `has_shell_metacharacters(arg)`: return `True` if `arg` contains any of these characters: `;`, `|`, `&`, `$`, backtick, `>`, `<`, `\n`, `(`, `)`.
