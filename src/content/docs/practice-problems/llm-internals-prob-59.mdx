# Check Weight Tying Validity

**Track**: Transformers & LLMs | **Points**: 40 XP

## Overview

Implement weight-tying shape validation, checking whether a model's input embedding and output (unembedding) layer weights can legally share the same underlying tensor.

## Task

Implement `weight_tying_valid(embedding_shape, output_layer_shape)`: return `True` if `embedding_shape == output_layer_shape` (weight tying requires the exact same shape since it's literally the same tensor used in both places, just transposed in one direction).
