# #755. Vectorized Fast Cosine Similarity Matrix

**Track**: NumPy & Vectorized Computation | **Rank**: #755 of 1072 | **Points**: 60 XP

## Overview

Compute all pairwise cosine similarities between query embeddings and target document embeddings.

## Task

Implement `cosine_similarity_matrix(queries, targets)`: given `queries` of shape `(Q, D)` and `targets` of shape `(T, D)`, return similarity matrix `S` of shape `(Q, T)` where `S[i][j] = (q_i . t_j) / (||q_i||_2 * ||t_j||_2)`. Round each entry to 4 decimals.

<Solution>

```python
import math

def cosine_similarity_matrix(queries, targets):
    q_norms = [math.sqrt(sum(x * x for x in q)) for q in queries]
    t_norms = [math.sqrt(sum(y * y for y in t)) for t in targets]
    res = []
    for i, q in enumerate(queries):
        row = []
        for j, t in enumerate(targets):
            dot = sum(a * b for a, b in zip(q, t))
            denom = q_norms[i] * t_norms[j]
            sim = dot / denom if denom > 1e-12 else 0.0
            row.append(round(float(sim), 4))
        res.append(row)
    return res
```

Precomputes L2 norms and calculates normalized pairwise dot products.
