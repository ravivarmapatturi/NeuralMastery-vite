# Multi-Region Failover Target Selection

**Track**: Agent Performance & Production | **Points**: 40 XP

## Overview

Implement multi-region failover selection, choosing the next healthy region to route traffic to in priority order when the primary region fails.

## Task

Implement `select_failover_region(primary_region, region_health, region_priority)`. `region_priority` is the ordered list of candidate regions (may or may not include `primary_region`). If `region_health.get(primary_region, False)` is `True`, return `primary_region` unchanged. Otherwise return the FIRST region in `region_priority` (excluding `primary_region`) that is healthy. Return `''` if none are healthy.
