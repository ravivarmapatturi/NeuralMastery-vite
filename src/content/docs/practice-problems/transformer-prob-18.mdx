# #018. Transformer Internals Module 4: Problem 18

**Track**: Transformer Internals | **Rank**: #18 of 1072 | **Points**: 60 XP

## Overview

Clip gradient tensors by global Euclidean norm. Gradient clipping limits the maximum norm of parameter updates, preventing exploding gradients during training of deep transformer networks.

## Task

Implement `clip_grad_norm(grads, max_norm)`: compute global norm `total_norm = sqrt(sum(g_i**2))` across all elements in `grads`. If `total_norm > max_norm`, scale all gradients by `max_norm / total_norm`. Return `(clipped_grads, total_norm)` with values rounded to 4 decimal places.
