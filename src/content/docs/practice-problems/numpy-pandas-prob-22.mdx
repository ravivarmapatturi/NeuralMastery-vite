# NumPy Module 22: Problem 202

**Rank #202** · Difficulty: **Medium** · Stage: **Stage 4: NumPy & Vectorized Data Processing** · Category: **NumPy & Pandas**

## Overview

Transform a 1D feature array into polynomial power basis features.

## Task

Implement `polynomial_features_1d(x, degree)`: for each float in `x`, generate powers `[val**0, val**1, ..., val**degree]`. Round each value to 4 decimal places.

<PracticePlayground problemId="numpy-pandas-prob-22" />

<Solution>

```python
def polynomial_features_1d(x, degree):
    out = []
    for val in x:
        row = [round(float(val ** d), 4) for d in range(degree + 1)]
        out.append(row)
    return out
```

Polynomial feature transformation allows linear models to capture non-linear relationships by computing explicit power interaction terms.

</Solution>
