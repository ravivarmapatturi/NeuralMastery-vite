# #032. Temperature Scaled Softmax

**Track**: LLM Inference & Decoding | **Rank**: #32 of 1072 | **Points**: 40 XP

## Overview

Control the sharpness of output probability distributions via temperature-scaled softmax. Autoregressive language models generate sequences token by token, evaluating next-token probability distributions at each decoding step.

## Task

Implement `temperature_scaled_softmax(logits, temperature)`. Divide each logit by `temperature`. Then compute stable softmax probabilities by subtracting the maximum scaled logit before exponentiating. Return probabilities rounded to 4 decimal places. If `temperature <= 0.0`, raise `ValueError`. If `logits` is empty, return `[]`.
