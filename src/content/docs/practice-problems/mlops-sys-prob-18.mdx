# Normalize Feature Importances

**Track**: MLOps & Data Systems | **Points**: 40 XP

## Overview

Implement feature-importance normalization, needed to make raw model importance scores comparable and interpretable as relative contribution percentages.

## Task

Implement `normalize_importances(raw_importances)`: return a new dict where every value is divided by the sum of all values (so they sum to 1.0). If all raw importances are 0, return the input unchanged (all zeros).
