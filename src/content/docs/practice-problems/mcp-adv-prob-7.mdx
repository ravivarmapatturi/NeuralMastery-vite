# Tool Schema Version Compatibility Check

**Track**: MCP Advanced & Agent Integration | **Points**: 40 XP

## Overview

Implement tool-schema version compatibility checking using semantic versioning rules, deciding whether a client can safely call a tool exposed under a given schema version.

## Task

Implement `is_schema_compatible(client_supported_version, server_schema_version)`. Both are `'MAJOR.MINOR'` strings. Compatible means SAME major version AND `client_supported_version`'s minor `>= server_schema_version`'s minor (the client understands at least as many fields as the server's schema uses).
