# Combine Retrieval Score With Cross-Encoder Rerank Score

**Track**: Advanced RAG & Agentic RAG | **Points**: 40 XP

## Overview

Implement retrieval/rerank score blending, the real final scoring step of a two-stage retrieval pipeline (cheap bi-encoder retrieval, then expensive cross-encoder reranking of the top candidates).

## Task

Implement `combine_rerank_score(retrieval_score, rerank_score, rerank_weight)`: return `(1-rerank_weight)*retrieval_score + rerank_weight*rerank_score`.
