# K-Means Centroid Update Step

**Track**: Clustering & Recommender Systems | **Points**: 40 XP

## Overview

Implement the update (M) step of Lloyd's k-means algorithm.

## Task

Implement `kmeans_update_centroids(points, assignments, k)`. Return a list of k centroids, each the element-wise mean of the points assigned to it. If a cluster has zero points, its centroid is the zero vector of the same dimensionality.
