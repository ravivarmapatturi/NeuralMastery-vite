# Split a JSON-RPC Batch Request

**Track**: MCP Core Engineering | **Points**: 40 XP

## Overview

Implement JSON-RPC batch-request splitting, normalizing a message that may be a single request or an array of requests into a uniform list.

## Task

Implement `split_batch_request(payload)`: if `payload` is a `list`, return it as-is; if it's a `dict` (a single request), return `[payload]`.
