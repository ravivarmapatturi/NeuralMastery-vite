# #080. Self-Consistency Majority Voting

**Track**: LLM Application Engineering | **Rank**: #80 of 1072 | **Points**: 60 XP

## Overview

Boost reasoning accuracy on difficult queries by sampling multiple reasoning paths and aggregating majority vote consensus. In production LLM application engineering, reliable system components, deterministic interfaces, and defensive validation are paramount for production stability and cost efficiency.

## Task

Implement `aggregate_self_consistency_votes(samples, answer_key='final_answer')`. Extract `sample[answer_key]` from each item. Normalize string answers by stripping leading/trailing whitespace and converting to lowercase. Count votes for each candidate answer. Select the modal winner; in the event of a tie, choose the candidate that appeared earliest in `samples`. Compute `consensus_ratio = vote_count / total_votes` rounded to 4 decimal places. Return `{'winner': winner, 'vote_count': count, 'total_votes': total, 'consensus_ratio': ratio, 'all_votes': dict}`. Raise `ValueError` if `samples` is empty.
