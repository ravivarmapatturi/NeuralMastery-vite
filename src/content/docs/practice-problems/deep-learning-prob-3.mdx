# CutMix Bounding Box Coordinate Generator

**Track**: Deep Learning & Vision/NLP | **Points**: 40 XP

## Overview

Compute the rectangular crop coordinates for CutMix data augmentation preserving target area ratio.

## Task

Implement `cutmix_bbox(W, H, lam, cx, cy)`. Given image dimensions `W, H`, combination factor `lam` in `[0.0, 1.0]`, and center point `(cx, cy)`, compute the cut bounding box `[x1, y1, x2, y2]`. Calculate `cut_w = int(round(W * math.sqrt(1.0 - lam)))` and `cut_h = int(round(H * math.sqrt(1.0 - lam)))`. Then `x1 = max(0, cx - cut_w // 2)`, `y1 = max(0, cy - cut_h // 2)`, `x2 = min(W, cx + cut_w // 2)`, `y2 = min(H, cy + cut_h // 2)`. Return `[x1, y1, x2, y2]`.
