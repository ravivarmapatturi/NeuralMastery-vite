# Detect a Cycle in a Directed Knowledge Graph

**Track**: Knowledge Graph & GraphRAG | **Points**: 40 XP

## Overview

Implement directed-cycle detection over a knowledge graph, useful for catching logically impossible relation chains (e.g. a hierarchical 'parent_company_of' relation that loops back on itself).

## Task

Implement `has_cycle(graph)` via DFS with recursion-stack tracking, matching the standard directed-cycle-detection algorithm. Return `True` if any cycle exists anywhere in the graph.
