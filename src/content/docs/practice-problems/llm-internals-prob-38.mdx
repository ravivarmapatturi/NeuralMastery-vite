# KV Cache Memory Footprint with INT4 Quantization

**Track**: transformers-llms | **Points**: 40 XP

## Overview

Calculate the exact memory capacity in bytes needed for a quantized key-value cache.

## Task

Implement `kv_cache_quantized_bytes(num_layers, num_kv_heads, head_dim, seq_len, batch_size, bits=4)`. Total elements stored in KV cache is `num_layers * 2 * num_kv_heads * head_dim * seq_len * batch_size`. Bytes required is `int(elements * (bits / 8.0))`. Return the total byte count as integer.
