# #727. Multivariate Diagonal Gaussian Log-Likelihood

**Track**: Mathematics & Numerical Computing | **Rank**: #727 of 1072 | **Points**: 60 XP

## Overview

Compute the exact log-probability density of an observation under a multivariate normal distribution.

## Task

Implement `gaussian_log_likelihood(x, mean, variances)`: for a d-dimensional Gaussian with independent dimensions, compute `log p(x) = -0.5 * sum_i (log(2 * pi * variances[i]) + (x[i] - mean[i])^2 / variances[i])`. Round to 4 decimals.

<PracticePlayground problemId="math-num-prob-17" />

<Solution>

```python
import math

def gaussian_log_likelihood(x, mean, variances):
    d = len(x)
    log_lik = 0.0
    for i in range(d):
        v = variances[i]
        diff = x[i] - mean[i]
        log_lik -= 0.5 * (math.log(2.0 * math.pi * v) + (diff ** 2) / v)
    return round(float(log_lik), 4)
```

Sums independent dimensional log Gaussian probabilities using logarithmic laws to preserve precision.
