# Round-Robin Agent Scheduler

**Track**: Multi-Agent Systems | **Points**: 40 XP

## Overview

Implement round-robin scheduling, the simplest real fair-turn-taking policy for a multi-agent system.

## Task

Implement `next_agent_round_robin(agents, last_index)`. Return `(agent_id, new_index)` for the agent after `last_index` (wrapping to 0 past the end). `last_index` of `-1` means no agent has run yet.
