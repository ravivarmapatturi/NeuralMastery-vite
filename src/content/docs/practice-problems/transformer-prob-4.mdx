# #004. Transformer Internals Module 1: Problem 4

**Track**: Transformer Internals | **Rank**: #4 of 1072 | **Points**: 40 XP

## Overview

Compute the Gaussian Error Linear Unit (GELU) activation function commonly used in modern transformer models such as BERT, GPT-2, and RoBERTa. GELU weights inputs by their probability under a Gaussian distribution rather than gating strictly at zero.

## Task

Implement `gelu(x)`: compute the standard GELU approximation `0.5 * x * (1.0 + tanh(sqrt(2.0 / pi) * (x + 0.044715 * x**3)))`. Return the result rounded to 4 decimal places.
