# Resolve a Resource Link Reference

**Track**: MCP Advanced & Agent Integration | **Points**: 40 XP

## Overview

Implement resource-link resolution, expanding a relative reference found inside one resource's content into a fully-qualified URI another tool can fetch.

## Task

Implement `resolve_resource_link(base_uri, relative_ref)`. If `relative_ref` already contains `'://'` (it's already absolute), return it unchanged. Otherwise, take everything in `base_uri` up to and including the LAST `'/'`, and append `relative_ref` to it.
