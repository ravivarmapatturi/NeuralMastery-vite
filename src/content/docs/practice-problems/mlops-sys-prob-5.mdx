# Min-Max Feature Normalization

**Track**: MLOps & Data Systems | **Points**: 40 XP

## Overview

Implement min-max normalization using fixed training-set bounds, scaling features to [0,1] for models sensitive to feature magnitude.

## Task

Implement `min_max_normalize(values, data_min, data_max)`: return `[(v - data_min) / (data_max - data_min) for v in values]`.
