# #667. Dynamic Programming & Greedy Module 4: Problem 17

**Track**: Dynamic Programming & Greedy | **Rank**: #667 of 1072 | **Points**

## Overview

Determine if an array can be split into two subsets with identical sum using 0/1 knapsack dynamic programming.

## Task

Implement `can_partition_equal_subset(nums)`: if total sum is odd, return False. Otherwise solve 0/1 knapsack for target = sum // 2 using a boolean DP array traversed in reverse.

<Solution>

```python
def can_partition_equal_subset(nums):
    total = sum(nums)
    if total % 2 != 0:
        return False
    target = total // 2
    dp = [False] * (target + 1)
    dp[0] = True
    for x in nums:
        for j in range(target, x - 1, -1):
            if dp[j - x]:
                dp[j] = True
        if dp[target]:
            return True
    return dp[target]
```

Compute half of the total sum. If total is odd, return False. Run 1D reverse 0/1 knapsack to determine if any subset sums exactly to target.
