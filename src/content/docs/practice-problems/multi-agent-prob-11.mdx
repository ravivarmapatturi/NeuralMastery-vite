# ACK-Timeout Message Delivery State Machine

**Track**: Multi-Agent Systems | **Points**: 40 XP

## Overview

Implement a real message-delivery state classifier used by reliable agent-to-agent communication (deciding when to retry a message).

## Task

Implement `message_delivery_state(sent, ack_received, elapsed_ms, timeout_ms)`. Return `'not_sent'` if `not sent`. If `sent` and `ack_received`, return `'delivered'`. If `sent`, not acked, and `elapsed_ms >= timeout_ms`, return `'timed_out'`. Otherwise return `'pending'`.
