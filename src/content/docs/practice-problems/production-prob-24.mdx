# Adaptive Timeout From Historical Latency

**Track**: Agent Performance & Production | **Points**: 40 XP

## Overview

Implement adaptive timeout calculation derived from real observed latency, avoiding both a too-tight timeout (killing legitimately slow-but-successful calls) and a too-loose one (holding resources on genuinely hung calls far too long).

## Task

Implement `adaptive_timeout(p99_latency_ms, safety_multiplier, floor_ms)`: return `max(floor_ms, p99_latency_ms * safety_multiplier)`.
