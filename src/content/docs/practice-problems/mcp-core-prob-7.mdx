# Classify JSON-RPC Error Code

**Track**: MCP Core Engineering | **Points**: 40 XP

## Overview

Implement JSON-RPC error-code classification per the real reserved-range convention MCP inherits from JSON-RPC 2.0.

## Task

Implement `classify_error_code(code)`. Return `'parse_error'` for `-32700`, `'invalid_request'` for `-32600`, `'method_not_found'` for `-32601`, `'invalid_params'` for `-32602`, `'internal_error'` for `-32603`. For any other code in `[-32099, -32000]`, return `'server_error'`. For anything else, return `'application_error'`.
