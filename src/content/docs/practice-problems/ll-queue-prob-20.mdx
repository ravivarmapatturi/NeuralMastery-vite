## Overview

Normalize Unix filesystem paths resolving dot (.), double-dot (..), and redundant slashes.

## Task

Implement `simplify_path(path)`: convert an absolute Unix path into its canonical normalized form. Handle `.` (current dir), `..` (parent dir), and multiple consecutive slashes `//`. Root is `"/"`.

<PracticePlayground problemId="ll-queue-prob-20" />

<Solution>

```python
def simplify_path(path):
    tokens = path.split('/')
    stack = []
    for t in tokens:
        if t == '' or t == '.':
            continue
        elif t == '..':
            if stack: stack.pop()
        else:
            stack.append(t)
    return '/' + '/'.join(stack)
```

Splitting on slash and managing directory push/pop operations normalizes paths in linear time.
