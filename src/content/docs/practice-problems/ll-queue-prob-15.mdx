# #575. Linked Lists / Stacks / Queues Module 3: Problem 15

**Track**: Linked Lists / Stacks / Queues | **Rank**: #575 of 1072 | **Points**: 60 XP

## Overview

Implement the classic two-pointer "switch heads" technique for finding where two linked lists merge -- an O(1)-space alternative to a hash set of visited nodes.

## Task

Implement the function `get_intersection_node(listA, listB, skipA, skipB)`: build both lists (sharing real node objects on the intersecting tail), then find the intersection node's value via the two-pointer head-swap technique, or `None` if there is no intersection.
