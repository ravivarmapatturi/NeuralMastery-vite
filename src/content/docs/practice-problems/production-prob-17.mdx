# Request Queue Wait-Time Estimate (Little's Law)

**Track**: Agent Performance & Production | **Points**: 40 XP

## Overview

Implement a queueing-theory wait-time estimate using Little's Law, giving a production agent-serving system a real basis for predicting how long a newly-arrived request will wait.

## Task

Implement `estimate_wait_time(queue_length, avg_service_time_ms, num_servers)`. Assuming requests are served `num_servers` at a time in parallel, the expected wait for a request at the BACK of the queue is `(queue_length / num_servers) * avg_service_time_ms`.
