# #019. Transformer Internals Module 4: Problem 19

**Track**: Transformer Internals | **Rank**: #19 of 1072 | **Points**: 60 XP

## Overview

Compute the learning rate at a given training step using a Cosine Annealing learning rate schedule. Cosine annealing smoothly decreases the learning rate from an initial maximum down to a minimum value over the course of training.

## Task

Implement `cosine_lr(step, total_steps, base_lr, min_lr=0.0)`: for `step <= total_steps`, compute `lr = min_lr + 0.5 * (base_lr - min_lr) * (1 + cos(pi * step / total_steps))`. If `step > total_steps`, return `min_lr`. Return the learning rate rounded to 6 decimal places.
