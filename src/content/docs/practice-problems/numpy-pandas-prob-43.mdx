# NumPy Module 43: Problem 223

**Rank #223** · Difficulty: **Medium** · Stage: **Stage 4: NumPy & Vectorized Data Processing** · Category: **NumPy & Pandas**

## Overview

Evaluate the non-parametric empirical CDF from observed data samples.

## Task

Implement `empirical_cdf(samples, query_points)`: for each query point `q`, evaluate `F(q) = (count of samples <= q) / len(samples)`. Return list of probabilities rounded to 4 decimal places.

<PracticePlayground problemId="numpy-pandas-prob-43" />

<Solution>

```python
import bisect

def empirical_cdf(samples, query_points):
    if not samples:
        return [0.0] * len(query_points)
    n = len(samples)
    sorted_s = sorted(samples)
    out = []
    for q in query_points:
        count = bisect.bisect_right(sorted_s, q)
        out.append(round(count / n, 4))
    return out
```

The empirical CDF converges uniformly to the true underlying CDF by the Glivenko-Cantelli theorem, providing non-parametric quantile estimation.
