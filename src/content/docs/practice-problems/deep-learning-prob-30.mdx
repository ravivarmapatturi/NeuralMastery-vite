# Bidirectional RNN Hidden State Concatenation

**Track**: Deep Learning & Vision/NLP | **Points**: 40 XP

## Overview

Merge forward and backward hidden state sequences along the feature dimension to form bidirectional representations.

## Task

Implement `bidirectional_rnn_concat(forward_states, backward_states)`. Given two sequences of hidden states of length `T`: `forward_states` (where row `t` is `h_fwd[t]`) and `backward_states` (where row `t` is `h_bwd[t]`), concatenate the two vectors at each position `t`: `h_bi[t] = h_fwd[t] + h_bwd[t]`. Return the 2D list of shape `T x (dim_fwd + dim_bwd)`.
