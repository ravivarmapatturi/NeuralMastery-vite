# Best Checkpoint Selection by Validation Metric

**Track**: MLOps & Data Systems | **Points**: 40 XP

## Overview

Implement real checkpoint-selection logic for a training pipeline, supporting both 'higher is better' and 'lower is better' metrics.

## Task

Implement `select_best_checkpoint(checkpoints, metric, mode)`. `checkpoints` is a list of `{"id": str, <metric>: float, ...}` dicts. If `mode == 'max'`, return the id with the HIGHEST value of `metric`; if `mode == 'min'`, return the id with the LOWEST. Ties broken by the earliest occurrence (first in the list).
