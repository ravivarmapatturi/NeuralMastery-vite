# Mathematics Module 39: Problem 159

**Rank #159** · Difficulty: **Medium** · Stage: **Stage 3: Mathematics & Numerical Computing** · Category: **Math & Numerical**

## Overview

Select a step size satisfying the Armijo condition to guarantee global convergence in line search.

## Task

Implement `armijo_line_search(f_curr, grad_norm_sq, candidate_evals, alpha=1.0, beta=0.5, c=1e-4)`: iterate through candidate objective evaluations `f_step`. At each step, test if `f_step <= f_curr - c * curr_alpha * grad_norm_sq`. If satisfied, return `curr_alpha`. Otherwise multiply `curr_alpha *= beta`. Round return value to 4 decimals.

<PracticePlayground problemId="math-num-prob-39" />

<Solution>

```python
def armijo_line_search(f_curr, grad_norm_sq, candidate_evals, alpha=1.0, beta=0.5, c=1e-4):
    curr_alpha = alpha
    for f_step in candidate_evals:
        if f_step <= f_curr - c * curr_alpha * grad_norm_sq:
            return round(float(curr_alpha), 4)
        curr_alpha *= beta
    return round(float(curr_alpha), 4)
```

Iteratively shrinks step size until objective decrease exceeds linear threshold fraction.

</Solution>
