# Per-Resource Tool Execution Lock

**Track**: MCP Advanced & Agent Integration | **Points**: 40 XP

## Overview

Implement a per-resource execution lock, preventing two concurrent tool calls from racing on the same underlying resource (e.g. two agents editing the same file simultaneously).

## Task

Implement `try_acquire_tool_lock(resource_id, locked_resources)`. If `resource_id` is already in `locked_resources`, return `False` (lock denied, resource busy) WITHOUT modifying the set. Otherwise add it to `locked_resources` and return `True` (lock acquired).
