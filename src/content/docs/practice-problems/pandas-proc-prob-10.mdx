# #780. Fuzzy Jaccard Record Deduplication

**Track**: Pandas & Data Processing Pipelines | **Rank**: #780 of 1072 | **Points**: 40 XP

## Overview

Cluster near-duplicate tabular records using tokenized set Jaccard similarity metrics.

## Task

Implement `deduplicate_fuzzy_records(records, key_field, threshold)`: partition records into clusters. For each candidate record, compare its lower-cased word set in `key_field` against the representative (first item) of each existing cluster. If Jaccard similarity `|w1 & w2| / |w1 | w2| >= threshold`, add to that cluster; otherwise create a new cluster. Return list of clusters.

<Solution>

```python
def deduplicate_fuzzy_records(records, key_field, threshold=0.6):
    clusters = []
    for r in records:
        w = set(r.get(key_field, '').lower().split())
        matched = False
        for cl in clusters:
            w_rep = set(cl[0].get(key_field, '').lower().split())
            u = len(w | w_rep)
            sim = len(w & w_rep) / u if u > 0 else 1.0
            if sim >= threshold:
                cl.append(r)
                matched = True
                break
        if not matched:
            clusters.append([r])
    return clusters
```

Compares word tokens using Jaccard index against cluster prototypes and assigns matching records.
