# #031. Greedy Decoding Step

**Track**: LLM Inference & Decoding | **Rank**: #31 of 1072 | **Points**: 40 XP

## Overview

Implement standard greedy autoregressive decoding by selecting the argmax logit with stable softmax confidence. Autoregressive language models generate sequences token by token, evaluating next-token probability distributions at each decoding step.

## Task

Implement `greedy_decoding_step(logits)`. Find the token index with the highest logit (breaking ties by lower index). Compute its softmax probability using numerically stable subtraction of the maximum logit, rounded to 4 decimal places. Return a dict with keys `chosen_token` (int), `is_deterministic` (bool, True), and `confidence` (float). Raise `ValueError` if `logits` is empty.
