# #985. Vector Search & Index Optimization Module 2: Problem 10

**Track**: Vector Search & Index Optimization | **Rank**: #985 of 1072 | **Points**: 60 XP

## Overview

Implement `reciprocal_rank_fusion(rankings, k=60)` (RRF), the standard technique production hybrid-search systems use to merge a dense vector-search ranking with a sparse BM25/keyword-search ranking into a single fused ranking, without needing to normalize scores from two different scales.

## Task

Implement the function `reciprocal_rank_fusion(rankings, k=60)`, where `rankings` is a list of ranked document-ID lists (best-first, 1-indexed rank). For every document, sum `1 / (k + rank)` across every list it appears in, then return document IDs sorted by descending total score, ties broken by ascending document ID.
