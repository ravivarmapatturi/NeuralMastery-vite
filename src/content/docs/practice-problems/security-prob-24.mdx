# Sanitize User Input Before Tool Use

**Track**: Agent Security & Reliability | **Points**: 40 XP

## Overview

Implement basic input sanitization, stripping control characters and excess whitespace before user-supplied text flows into a tool argument.

## Task

Implement `sanitize_input(raw_input)`. Remove all ASCII control characters (code points 0-31, except plain space 32) from the string, then strip leading/trailing whitespace, then collapse any run of internal whitespace to a single space.
