# #023. Transformer Internals Module 5: Problem 23

**Track**: Transformer Internals | **Rank**: #23 of 1072 | **Points**: 90 XP

## Overview

Compute scaled dot-product attention using the Online Softmax algorithm that powers Flash Attention. Online Softmax maintains running maximums and normalizers across chunks, eliminating the need to store the full quadratic attention matrix in memory.

## Task

Implement `flash_attention_online(Q, K, V)`: compute exact attention output for queries `Q` over keys `K` and values `V` by iterating through key-value pairs sequentially, updating running maximums `m_i`, running sums `l_i`, and running unnormalized accumulators `o_i`. Return the final normalized output matrix rounded to 4 decimal places.
