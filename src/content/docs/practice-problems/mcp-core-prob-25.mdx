# Select Transport Based on Environment

**Track**: MCP Core Engineering | **Points**: 40 XP

## Overview

Implement a real transport-selection rule for an MCP client deciding between stdio and HTTP/SSE transports based on its runtime environment.

## Task

Implement `select_transport(has_tty, http_url_configured)`. If `http_url_configured` is `True`, return `'http'` (explicit configuration wins). Otherwise, if `has_tty` is `False` (i.e. running as a subprocess with piped stdio, the common local-server case), return `'stdio'`. Otherwise return `'stdio'` as well -- stdio is the safe default whenever no explicit HTTP URL is configured.
