## Overview

Simulate space-efficient probabilistic set membership testing using an m-bit Bloom filter array.

## Task

Implement `bloom_filter_simulator(elements, test_elements, m, num_hashes)`: initialize an `m`-bit array of zeros. For each inserted string in `elements`, set bits at `(val * b + ord(c)) % m` using prime bases `[31, 37, 41, 43, 47, 53, 59, 61][:num_hashes]`. Then test each item in `test_elements`, returning `True` if all corresponding bit positions are set (1), and `False` otherwise.

```python
def bloom_filter_simulator(elements, test_elements, m, num_hashes):
    bit_array = [0] * m
    bases = [31, 37, 41, 43, 47, 53, 59, 61][:num_hashes]
    for el in elements:
        for b in bases:
            val = 0
            for c in el:
                val = (val * b + ord(c)) % m
            bit_array[val] = 1
    results = []
    for test in test_elements:
        present = True
        for b in bases:
            val = 0
            for c in test:
                val = (val * b + ord(c)) % m
            if bit_array[val] == 0:
                present = False
                break
        results.append(present)
    return results
```

Hashing strings into bit positions tests set membership with zero false negatives and constant bit memory.
