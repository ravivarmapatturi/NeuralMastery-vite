# Pandas Module 26: Problem 206

**Rank #206** · Difficulty: **Medium** · Stage: **Stage 4: NumPy & Vectorized Data Processing** · Category: **NumPy & Pandas**

## Overview

Unnest a list-valued column across tabular records into separate rows.

## Task

Implement `explode_column(records, list_column)`: for each record, create a new record for every element in the list under `list_column`, copying all other key-value pairs. Rows with empty lists are omitted.

<PracticePlayground problemId="numpy-pandas-prob-26" />

<Solution>

```python
def explode_column(records, list_column):
    out = []
    for r in records:
        items = r.get(list_column, [])
        for item in items:
            c = dict(r)
            c[list_column] = item
            out.append(c)
    return out
```

Exploding list columns flattens nested one-to-many relationship structures into standard first normal form relational records.

</Solution>
