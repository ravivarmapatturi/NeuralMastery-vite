# Pandas Module 41: Problem 221

**Rank #221** · Difficulty: **Medium** · Stage: **Stage 4: NumPy & Vectorized Data Processing** · Category: **NumPy & Pandas**

## Overview

Discretize continuous numerical features into equal-frequency quantile bins.

## Task

Implement `quantile_bin_data(values, num_bins)`: partition sorted values into `num_bins` bins. For each bin cutoff `b` from 1 to `num_bins - 1`, the threshold is `sorted_vals[ceil(b * N / num_bins) - 1]`. Assign each original value the count of thresholds it strictly exceeds (bin index `0 .. num_bins - 1`).

<Solution>

```python
import math

def quantile_bin_data(values, num_bins):
    if not values:
        return []
    n = len(values)
    sorted_vals = sorted(values)
    thresholds = []
    for b in range(1, num_bins):
        idx = int(math.ceil(b * n / num_bins)) - 1
        thresholds.append(sorted_vals[idx])
    res = []
    for v in values:
        b_idx = 0
        for thresh in thresholds:
            if v > thresh:
                b_idx += 1
        res.append(b_idx)
    return res
```

Quantile binning ensures roughly equal counts per bin, normalizing skewed feature distributions into uniform categorical buckets.
