# Calculate Perplexity from Cross-Entropy Loss

**Rank #364** · Difficulty: **Easy** · Stage: **Stage 7: Transformers, LLMs & Foundation Models** · Category: **Transformers & LLMs**

Compute language model perplexity from token-level cross-entropy loss values -- the gold-standard evaluation metric for generative language modeling. Prerequisite: `llm-internals-prob-3`.

<PracticePlayground problemId="llm-internals-prob-4" />

<Solution>

```python
import math

def calculate_perplexity(loss_values):
    if not loss_values:
        raise ValueError("loss_values must be non-empty")
    for val in loss_values:
        if val < 0:
            raise ValueError("loss cannot be negative")
    avg_loss = sum(loss_values) / len(loss_values)
    return round(math.exp(avg_loss), 4)
```

Perplexity is the exponentiated cross-entropy loss, representing the geometric mean branching factor of predictions; lower perplexity indicates the language model assigns higher likelihood to test tokens.
