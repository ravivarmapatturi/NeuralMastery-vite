## Overview

Measure the longest dependency path in directed execution graphs with cyclic deadlock detection.

## Task

Implement `dependency_graph_depth(graph)`: find the maximum depth (number of edges in the longest directed path) in `graph` (mapping node to list of neighbors). If any directed cycle exists, return `-1`. If `graph` is empty or has no edges, return `0`.

```python
def dependency_graph_depth(graph):
    memo = {}
    visiting = set()
    def dfs(u):
        if u in visiting: return -1
        if u in memo: return memo[u]
        visiting.add(u)
        max_d = 0
        for v in graph.get(u, []):
            sub = dfs(v)
            if sub == -1: return -1
            max_d = max(max_d, 1 + sub)
        visiting.remove(u)
        memo[u] = max_d
        return max_d

    max_depth = 0
    for n in graph:
        d = dfs(n)
        if d == -1: return -1
        max_depth = max(max_depth, d)
    return max_depth
```

Memoized depth-first search computes the critical path length in linear time while catching cycles.
