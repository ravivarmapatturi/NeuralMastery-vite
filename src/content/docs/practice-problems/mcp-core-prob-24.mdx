# Validate Elicitation Response Against Schema

**Track**: MCP Core Engineering | **Points**: 40 XP

## Overview

Implement elicitation-response validation, checking that user-supplied answers to a server's elicitation request match the fields and types it actually asked for.

## Task

Implement `validate_elicitation_response(response, requested_fields)`. `requested_fields` maps field name -> expected type (`'str'`,`'int'`,`'bool'`). Return `True` only if `response` has EXACTLY the same set of keys as `requested_fields` (no extra, none missing) and every value's Python type matches.
