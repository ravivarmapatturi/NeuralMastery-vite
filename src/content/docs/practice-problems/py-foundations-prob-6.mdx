# Compute Cumulative Prefix Sum

**Rank #6** · Difficulty: **Easy** · Stage: **Stage 1: AI Foundations & Python Programming** · Category: **Python & Fundamentals** | **Points**: 40 XP

## Overview

Implement `cumulative_sum(nums)`, constructing the prefix sum array in a single O(n) scan -- fundamental for constant-time range queries and empirical CDF construction.

## Task

Implement the function `cumulative_sum(nums)`: return a list where each element at index `i` is the sum of all elements in `nums` up to index `i`. If `nums` is empty, return `[]`.

<PracticePlayground problemId="py-foundations-prob-6" />

<Solution>

```python
def cumulative_sum(nums):
    if not nums:
        return []
    res = []
    curr = 0
    for x in nums:
        curr += x
        res.append(curr)
    return res
```

A prefix sum transforms range sum calculations from O(k) per query to O(1), and converting probability mass functions (PMFs) to cumulative distribution functions (CDFs) enables inverse transform sampling.

</Solution>
