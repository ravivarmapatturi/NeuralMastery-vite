# Group Dictionaries by Key

**Rank #11** · Difficulty: **Easy** · Stage: **Stage 1: AI Foundations & Python Programming** · Category: **Python & Fundamentals** | **Points**: 40 XP

## Overview

Implement `group_by_key(items, key)`: group a collection of dictionary records by the value of a chosen attribute, omitting entries that lack the key.

## Task

Implement the function `group_by_key(items, key)`: return a dictionary where each key is a unique value of `item[key]`, and each value is a list of items belonging to that group in original encounter order. Skip items that do not contain `key`.

<PracticePlayground problemId="py-foundations-prob-11" />

<Solution>

```python
def group_by_key(items, key):
    grouped = {}
    for item in items:
        if key in item:
            val = item[key]
            if val not in grouped:
                grouped[val] = []
            grouped[val].append(dict(item))
    return grouped
```

Grouping records into buckets by key is the universal data organization primitive behind sharding, faceted search, and multi-class dataset splits.

</Solution>
