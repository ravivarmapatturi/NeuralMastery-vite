# #043. Prefill vs Decode FLOPs & Bandwidth

**Track**: LLM Inference & Decoding | **Rank**: #43 of 1072 | **Points**: 60 XP

## Overview

Distinguish between compute-bound prefill and memory-bandwidth-bound decode phases using arithmetic intensity. Autoregressive language models generate sequences token by token, evaluating next-token probability distributions at each decoding step.

## Task

Implement `compute_inference_arithmetic_intensity(batch_size, seq_len, num_layers, hidden_dim, bytes_per_param=2)`. Assume standard transformer with `N_{params} = 12 \times \text{num\_layers} \times \text{hidden\_dim}^2`. For prefill: `\text{FLOPs} = 2 \times N_{params} \times \text{seq\_len} \times \text{batch\_size}`, reading weights once. For decode: `\text{FLOPs} = 2 \times N_{params} \times \text{batch\_size}`, reading weights and KV cache (`2 \times \text{num\_layers} \times \text{batch\_size} \times \text{seq\_len} \times \text{hidden\_dim} \times \text{bytes\_per\_param}`). Compute arithmetic intensities (FLOPs / bytes), rounded to 2 decimal places. Raise `ValueError` on non-positive arguments.
