# #181. Multi-Hop Retrieval

**Track**: RAG Fundamentals | **Rank**: #181 of 1072 | **Points**: 40 XP

## Overview

Retrieve connected evidence across multiple hops to answer relational, multi-document questions.

## Task

Implement `multi_hop_retrieval(query, corpus, max_hops=2)`. Identify initial seed documents matching any query keyword (case-insensitive), sorted descending by keyword match count (ties broken alphabetically by doc ID). From these seeds, perform a breadth-first search traversing `links` up to `max_hops` depth. Return the ordered list of unique document IDs visited.
