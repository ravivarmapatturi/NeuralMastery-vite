# Request Queue Backpressure Check

**Track**: MLOps & Data Systems | **Points**: 40 XP

## Overview

Implement a real backpressure trigger for a model-serving request queue, protecting a serving system from cascading overload.

## Task

Implement `should_apply_backpressure(queue_depth, max_queue_depth, avg_latency_ms, latency_budget_ms)`. Return `True` (start rejecting/throttling new requests) if EITHER `queue_depth >= max_queue_depth` OR `avg_latency_ms > latency_budget_ms`. Otherwise `False`.
