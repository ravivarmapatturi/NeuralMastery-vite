# Route a Tool Call to Its Backend Server

**Track**: MCP Advanced & Agent Integration | **Points**: 40 XP

## Overview

Implement tool-to-server routing, the core dispatch step of an MCP client aggregating multiple servers into one unified tool surface.

## Task

Implement `route_tool_call(tool_name, tool_to_server)`: return `tool_to_server[tool_name]`, or raise `KeyError` if `tool_name` isn't registered by any connected server.
