# Grouped Query Attention KV Head Count

**Rank #385** · Difficulty: **Easy** · Stage: **Stage 7: Transformers, LLMs & Foundation Models** · Category: **Transformers & LLMs**

Implement `gqa_kv_heads(num_q_heads, num_groups)` that returns `num_q_heads // num_groups` -- the number of key/value heads in Grouped Query Attention. GQA groups `num_groups` query heads to share a single K/V head, reducing KV-cache memory by a factor of `num_groups`. Raise `ValueError` if `num_q_heads` is not divisible by `num_groups`. Prerequisite: `llm-internals-prob-24`.

<PracticePlayground problemId="llm-internals-prob-25" />

<Solution>

```python
def gqa_kv_heads(num_q_heads, num_groups):
    if num_q_heads <= 0 or num_groups <= 0:
        raise ValueError("num_q_heads and num_groups must be positive")
    if num_q_heads % num_groups != 0:
        raise ValueError("num_q_heads must be divisible by num_groups")
    return num_q_heads // num_groups
```

Multi-Head Attention (MHA) has equal Q/K/V heads; Multi-Query Attention (MQA) uses a single K/V head for all queries. GQA is the middle ground: Llama-3 70B uses 8 KV heads with 64 Q heads (8 groups of 8), cutting KV-cache by 8x vs MHA while retaining most of MHA's quality over MQA.

</Solution>
