# #787. User Cohort Retention Matrix Engine

**Track**: Pandas & Data Processing Pipelines | **Rank**: #787 of 1072 | **Points**: 60 XP

## Overview

Track customer cohort lifecycles and retention decay over elapsed time periods.

## Task

Implement `build_cohort_retention_matrix(events)`: each event contains `user_id`, `cohort_month`, and `activity_month`. Calculate `period = activity_month - cohort_month`. The base size of a cohort is its total unique users. Compute retention percentage `(active_users_in_period / cohort_base_size) * 100.0`. Return nested dictionary `{str(cohort): {'period_0': pct, ...}}` with percentages rounded to 4 decimals.

```python
from collections import defaultdict

def build_cohort_retention_matrix(events):
    cohort_users = defaultdict(set)
    cohort_period = defaultdict(lambda: defaultdict(set))
    for ev in events:
        u, c, a = ev['user_id'], ev['cohort_month'], ev['activity_month']
        p = a - c
        cohort_users[c].add(u)
        cohort_period[c][p].add(u)
    table = {}
    for c in sorted(cohort_users.keys()):
        base = len(cohort_users[c])
        p_dict = {}
        for p in sorted(cohort_period[c].keys()):
            pct = (len(cohort_period[c][p]) / base) * 100.0 if base else 0.0
            p_dict[f'period_{p}'] = round(float(pct), 4)
        table[str(c)] = p_dict
    return table
```

Groups unique users per cohort and relative elapsed period, dividing by initial cohort size.
