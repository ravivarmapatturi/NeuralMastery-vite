# #059. FlashDecoding Split-K Work Partition

**Track**: LLM Inference & Decoding | **Rank**: #59 of 1072 | **Points**: 90 XP

## Overview

Saturate GPU Streaming Multiprocessors (SMs) during long-context decode using FlashDecoding Split-K partitioning. Autoregressive language models generate sequences token by token, evaluating next-token probability distributions at each decoding step.

## Task

Implement `flash_decoding_partition(seq_len, num_heads, batch_size, split_size=128)`. Calculate number of sequence splits per head `S = \lceil \text{seq\_len} / \text{split\_size} \rceil`. Total GPU thread blocks launched is `\text{batch\_size} \times \text{num\_heads} \times S`. The reduction factor is `S` (the number of partial attention results reduced in the final pass). Calculate `last_chunk_tokens`: the number of tokens assigned to the final split (equals `split_size` if cleanly divisible). Return dict containing `num_splits_per_head`, `total_thread_blocks`, `reduction_factor`, and `last_chunk_tokens`. Raise `ValueError` on non-positive arguments.
