# Popularity-Based Baseline Recommender

**Track**: Clustering & Recommender Systems | **Points**: 40 XP

## Overview

Implement the popularity baseline every real recommender system is measured against, and the standard cold-start fallback.

## Task

Implement `popularity_topk(interactions, k)`. `interactions` is a flat list of item ids (one entry per interaction, possibly repeated). Return the `k` most frequently occurring item ids, sorted descending by frequency; ties broken by item id ascending.
