# CTC Greedy Best-Path Collapse

**Track**: Deep Learning & Vision/NLP | **Points**: 40 XP

## Overview

Implement Connectionist Temporal Classification (CTC) greedy collapse to decode speech and handwriting alignments.

## Task

Implement `ctc_collapse_repeats(tokens, blank_token)`. Given a sequence of frame-level predicted token IDs `tokens`: first, collapse consecutive duplicate tokens into a single token (e.g. `[1, 1, 0, 2, 2] -> [1, 0, 2]`). Then, remove all occurrences of `blank_token` (e.g. `[1, 0, 2] -> [1, 2]`). Return the resulting list of token IDs.
