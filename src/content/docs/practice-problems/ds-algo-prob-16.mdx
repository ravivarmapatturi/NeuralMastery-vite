# Linked Lists: Remove Nth Node From End of List

**Rank #76** · Difficulty: **Easy** · Stage: **Stage 2: Data Structures & Algorithmic Foundations** · Category: **Data Structures & Algorithms**

## Overview

Implement `remove_nth_from_end(head, n)` -- the two-pointer gap trick for single-pass removal, applicable to any 'find the k-th from the end' problem.

## Task

Implement the function `remove_nth_from_end(head, n)`. Each node is `{'val', 'next'}`. Remove the `n`-th node from the end and return the new head.

<PracticePlayground problemId="ds-algo-prob-16" />

<Solution>

```python
def remove_nth_from_end(head, n):
    dummy = {'val': 0, 'next': head}
    fast = slow = dummy
    for _ in range(n + 1):
        fast = fast['next']
    while fast:
        fast = fast['next']
        slow = slow['next']
    slow['next'] = slow['next']['next']
    return dummy['next']
```

Advance fast n+1 steps; then move both until fast is None. slow.next is the node to remove. Dummy head handles edge cases cleanly. O(L) time, O(1) space.

</Solution>
