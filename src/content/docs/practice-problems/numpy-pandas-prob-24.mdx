# Streaming systems Module 24: Problem 204

**Rank #204** · Difficulty: **Medium** · Stage: **Stage 4: NumPy & Vectorized Data Processing** · Category: **NumPy & Pandas**

## Overview

Maintain a uniform random sample of size k over an unbounded streaming sequence.

## Task

Implement `deterministic_reservoir_sample(stream, k, random_floats)`. First k elements of stream populate the reservoir. For each subsequent element at index `i` (from k to len(stream)-1), let `p = random_floats[i - k]`. If `p < k / (i + 1)`, replace reservoir element at `int(p * (i + 1))` with `stream[i]`. Return the final reservoir.

<PracticePlayground problemId="numpy-pandas-prob-24" />

<Solution>

```python
def deterministic_reservoir_sample(stream, k, random_floats):
    if not stream or k <= 0:
        return []
    res = list(stream[:k])
    for i in range(k, len(stream)):
        p = random_floats[i - k]
        if p < (k / (i + 1)):
            target_idx = int(p * (i + 1))
            if target_idx < k:
                res[target_idx] = stream[i]
    return res
```

Algorithm R guarantees every stream element has equal probability k/N of selection without knowing total stream length N in advance.
