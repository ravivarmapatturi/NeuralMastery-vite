# Extract Structured Tool-Call Events From a Trace

**Track**: Agent Evaluation & Observability | **Points**: 40 XP

## Overview

Implement tool-call event extraction from a raw agent execution trace, the real filtering step behind a 'show me every tool this agent called' observability view.

## Task

Implement `extract_tool_events(trace_events)`. Each event is `{"type": str, "tool_name": str|None}`. Return the list of `tool_name`s (preserving order) for every event with `type == 'tool_call'`.
