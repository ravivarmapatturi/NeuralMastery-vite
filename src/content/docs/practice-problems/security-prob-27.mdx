# Least-Privilege Capability Set Check

**Track**: Agent Security & Reliability | **Points**: 40 XP

## Overview

Implement a least-privilege check, flagging when an agent is requesting MORE capabilities than the task genuinely requires -- a real security-review finding, not just an access-denied case.

## Task

Implement `is_least_privilege(requested_capabilities, minimal_required_capabilities)`: return `True` only if `requested_capabilities` EQUALS `minimal_required_capabilities` exactly (requesting extra, unused capabilities violates least privilege, even if they'd technically be granted).
