## Overview

Normalize, validate, and enrich multimodal assets into a unified multimodal vector space.

## Task

Implement `multimodal_rag_ingestion(elements, expected_dim=4)`. For each element, verify `len(elem["vector"]) == expected_dim` (raising `ValueError` on mismatch). Return the list of standardized element dicts.
