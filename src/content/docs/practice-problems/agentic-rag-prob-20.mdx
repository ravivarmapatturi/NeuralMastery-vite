# Extractive Document Compression by Top Sentences

**Track**: Advanced RAG & Agentic RAG | **Points**: 40 XP

## Overview

Implement extractive document compression, keeping only the highest-scored sentences of a retrieved chunk (in original reading order) before passing it to the generator -- a real, cheap alternative to abstractive (LLM-rewritten) compression.

## Task

Implement `extractive_compress(sentences, sentence_scores, max_sentences)`. Pick the `max_sentences` HIGHEST-scored sentence indices, then return their sentences IN THEIR ORIGINAL RELATIVE ORDER (not sorted by score).
