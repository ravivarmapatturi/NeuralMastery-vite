# Regression Detection Between Two Eval Runs

**Track**: Agent Evaluation & Observability | **Points**: 40 XP

## Overview

Implement eval regression detection, finding SPECIFIC test cases that flipped from passing to failing between two versions -- more actionable than comparing aggregate scores alone.

## Task

Implement `detect_regressions(baseline_results, new_results)`. Both map test-case id -> pass/fail bool. Return the sorted list of test ids present in BOTH that were `True` in `baseline_results` but `False` in `new_results`.
