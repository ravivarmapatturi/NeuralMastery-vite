# #769. Vectorized 2D Affine Point Transformation

**Track**: NumPy & Vectorized Computation | **Rank**: #769 of 1072 | **Points**: 90 XP

## Overview

Vectorize 2D affine geometric mappings (rotation, scaling, translation) over batches of coordinates.

## Task

Implement `apply_affine_2d(points, transform_mat, translation)`: given `points` of shape `(N, 2)`, 2x2 matrix `transform_mat`, and translation vector `[tx, ty]`, compute `p_new = transform_mat @ p + translation` for each point. Return the list of transformed `[x', y']` points rounded to 4 decimals.

<PracticePlayground problemId="numpy-vec-prob-29" />

<Solution>

```python
def apply_affine_2d(points, transform_mat, translation):
    out = []
    for px, py in points:
        x_new = transform_mat[0][0] * px + transform_mat[0][1] * py + translation[0]
        y_new = transform_mat[1][0] * px + transform_mat[1][1] * py + translation[1]
        out.append([round(float(x_new), 4), round(float(y_new), 4)])
    return out
```

Multiplies each point coordinate with transformation matrix and adds translation offsets.
