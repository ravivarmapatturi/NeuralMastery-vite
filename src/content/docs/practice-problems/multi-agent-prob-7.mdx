# Greedy Load-Balanced Task Allocation

**Track**: Multi-Agent Systems | **Points**: 40 XP

## Overview

Implement greedy load-balanced task allocation (the LPT heuristic), assigning tasks across agents to minimize the maximum agent workload.

## Task

Implement `allocate_tasks_greedy(task_costs, num_agents)`. Process tasks in DESCENDING cost order; assign each to whichever agent currently has the LOWEST total assigned cost so far (ties broken by lowest agent index). Return a list the same length as `task_costs`, where entry `i` is the agent index assigned to the task that was ORIGINALLY at position `i`.
