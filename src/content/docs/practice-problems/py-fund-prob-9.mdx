# #509. Python & Programming Fundamentals Module 2: Problem 9

**Track**: Python & Programming Fundamentals | **Rank**: #509 of 1072 | **Points**

## Overview

Concatenate nested lists one level deep into a continuous 1D list.

## Task

Implement `flatten_shallow(lists)`: flatten a 2D list of sublists into a 1D sequence containing all elements in order. Empty sublists are omitted cleanly. Return `[]` for empty input.

<PracticePlayground problemId="py-fund-prob-9" />

<Solution>

```python
def flatten_shallow(lists):
    out = []
    for sub in lists:
        out.extend(sub)
    return out
```

Iterating through sublists with extend avoids creating intermediate copy buffers.

</Solution>
