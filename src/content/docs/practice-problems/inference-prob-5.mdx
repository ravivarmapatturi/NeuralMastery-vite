# #035. Top-P (Nucleus) Filtering

**Track**: LLM Inference & Decoding | **Rank**: #35 of 1072 | **Points**: 40 XP

## Overview

Dynamically adapt sampling vocabulary width using Holtzman et al. Nucleus (Top-P) filtering. Autoregressive language models generate sequences token by token, evaluating next-token probability distributions at each decoding step.

## Task

Implement `top_p_filter(logits, p, filter_value=-float('inf'))`. Compute softmax probabilities. Sort token indices descending by probability (breaking ties by lower index). Accumulate probabilities until the cumulative sum is `\ge p`. Retain this nucleus of tokens and mask all other tokens with `filter_value`. If `p \le 0.0` or `p > 1.0`, raise `ValueError`. At least one token (the top token) must always be retained.
