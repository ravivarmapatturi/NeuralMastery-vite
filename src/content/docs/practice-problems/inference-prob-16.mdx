# #046. Contrastive Decoding Mask & Score

**Track**: LLM Inference & Decoding | **Rank**: #46 of 1072 | **Points**: 60 XP

## Overview

Amplify expert model reasoning and suppress superficial artifacts using Contrastive Decoding. Autoregressive language models generate sequences token by token, evaluating next-token probability distributions at each decoding step.

## Task

Implement `contrastive_decoding_step(expert_logits, amateur_logits, alpha, tau)`. Compute softmax probabilities `P_{exp}`. Form the plausible candidate set `V_{head} = \{ v \mid P_{exp}(v) \ge \tau \times \max_w P_{exp}(w) \}`. For each token `v \in V_{head}`, compute contrastive score `S(v) = \text{expert\_logits}[v] - \alpha \times \text{amateur\_logits}[v]`. Select the token maximizing `S(v)` (ties broken by lowest token index). Return dict with `chosen_token`, `contrastive_score` (rounded to 4 decimals), and `plausible_set_size`. Raise `ValueError` on invalid arguments or mismatched lengths.
