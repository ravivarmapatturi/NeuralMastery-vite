# Speculative Decoding: Accept or Reject a Draft Token

**Track**: Transformers & LLMs | **Points**: 40 XP

## Overview

Implement speculative decoding's real acceptance test, the exact rejection-sampling rule that makes speculative decoding's output distribution IDENTICAL to standard autoregressive decoding from the target model (not merely a fast approximation).

## Task

Implement `spec_decode_accept(draft_prob, target_prob, random_draw)`. Accept the drafted token if `random_draw < min(1, target_prob / draft_prob)`.
