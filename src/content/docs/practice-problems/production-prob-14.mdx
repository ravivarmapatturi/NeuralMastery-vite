# Model Endpoint Load-Balancing Weight

**Track**: Agent Performance & Production | **Points**: 40 XP

## Overview

Implement a real load-aware endpoint scoring function, used to route each new agent request to the least-loaded of several model-serving endpoints (rather than pure round-robin).

## Task

Implement `weighted_endpoint_score(current_load, capacity, base_priority)`. Compute utilization `current_load/capacity`. Return `base_priority * (1 - utilization)` -- higher score means more preferred (lower utilization, higher base priority). Return `0.0` if utilization `>= 1` (at or over capacity, never route here).
