# #813. Classical Machine Learning Module 3: Problem 13

**Track**: Classical Machine Learning | **Rank**: #813 of 1072 | **Points**: 60 XP

## Overview

Implement `information_gain(parent, left, right, criterion)`, the exact split-quality scoring a decision tree evaluates at every candidate split during training -- the single number CART/ID3-style tree builders use to greedily pick which feature and threshold to split on.

## Task

Implement the function `information_gain(parent, left, right, criterion='gini')`: compute the chosen impurity measure (Gini or Shannon entropy) of `parent`, then subtract the size-weighted average of the same measure over `left` and `right`. Raise `ValueError` for any criterion other than 'gini' or 'entropy'.
