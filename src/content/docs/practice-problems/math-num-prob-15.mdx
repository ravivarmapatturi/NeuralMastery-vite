# #725. Directional Derivative along Unit Vector

**Track**: Mathematics & Numerical Computing | **Rank**: #725 of 1072 | **Points**: 60 XP

## Overview

Compute the rate of change of a multivariable function along an arbitrary vector direction.

## Task

Implement `directional_derivative(grad, direction)`: normalize `direction` to unit vector `u = direction / ||direction||` and calculate the inner product `grad . u`. If `||direction|| < 1e-9`, return `0.0`. Round result to 4 decimals.

<PracticePlayground problemId="math-num-prob-15" />

<Solution>

```python
import math

def directional_derivative(grad, direction):
    norm_v = math.sqrt(sum(d ** 2 for d in direction))
    if norm_v < 1e-9:
        return 0.0
    u = [d / norm_v for d in direction]
    val = sum(g * d for g, d in zip(grad, u))
    return round(float(val), 4)
```

Normalizes search vector to unit length and takes dot product with gradient.

</Solution>
