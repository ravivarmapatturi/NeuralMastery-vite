# Coalition Value With Overlap Penalty

**Track**: Multi-Agent Systems | **Points**: 40 XP

## Overview

Implement a simplified coalition-value function accounting for real diminishing returns when agents' contributions overlap.

## Task

Implement `coalition_value(individual_values, overlap_penalty)`. Raw combined value is `sum(individual_values)`. Apply a penalty proportional to the number of PAIRS of agents in the coalition: `penalty = overlap_penalty * (n*(n-1)/2)` where `n = len(individual_values)`. Return `max(0.0, sum(individual_values) - penalty)`.
