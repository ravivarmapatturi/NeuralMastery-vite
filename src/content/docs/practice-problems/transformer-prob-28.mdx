# #028. Transformer Internals Module 6: Problem 28

**Track**: Transformer Internals | **Rank**: #28 of 1072 | **Points**: 90 XP

## Overview

Measure the Attention Sink Fraction across generated token sequences. In streaming LLMs, initial tokens (attention sinks) absorb an outsized portion of attention mass regardless of their semantic relevance; measuring this fraction guides cache eviction policies.

## Task

Implement `attention_sink_fraction(attn_weights, sink_tokens=1)`: given an `N x N` attention weight matrix, compute the sum of attention weights on the first `sink_tokens` keys for each query token, and return the average fraction across all query positions rounded to 4 decimal places.
