# Tool Chain Output-to-Input Piping

**Track**: MCP Advanced & Agent Integration | **Points**: 40 XP

## Overview

Implement tool-chaining, where one tool call's real output becomes the next tool call's real input -- the actual execution pattern behind an agent's multi-step plan.

## Task

Implement `pipe_tool_chain(chain, initial_value)`. `chain` is a list of operation names, each one of `'increment'` (add 1), `'double'` (multiply by 2), or `'negate'` (multiply by -1), representing a sequence of tool calls. Starting from `initial_value`, apply each named operation in order, feeding each one's output as the next one's input. Return the list of ALL intermediate outputs (including the final one), in order -- NOT including `initial_value` itself.
