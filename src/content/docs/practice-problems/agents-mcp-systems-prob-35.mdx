# Non-Maximum Suppression for Detection Boxes

**Rank #465** · Difficulty: **Hard** · Stage: **Stage 8: RAG, Agents, MCP & Distributed Systems** · Category: **Agents, MCP & Systems**

Implement `non_max_suppression(boxes, scores, iou_threshold)`, the algorithm every real object detector (YOLO, Faster R-CNN, DETR included) runs as its final post-processing step to collapse many overlapping, redundant detections of the same object down to one confident box. Prerequisite: `agents-mcp-systems-prob-34`.

```python
def _iou(a, b):
    xa1, ya1, xa2, ya2 = a
    xb1, yb1, xb2, yb2 = b
    ix1, iy1 = max(xa1, xb1), max(ya1, yb1)
    ix2, iy2 = min(xa2, xb2), min(ya2, yb2)
    inter = max(0, ix2 - ix1) * max(0, iy2 - iy1)
    area_a = (xa2 - xa1) * (ya2 - ya1)
    area_b = (xb2 - xb1) * (yb2 - yb1)
    union = area_a + area_b - inter
    return inter / union if union > 0 else 0.0

def non_max_suppression(boxes, scores, iou_threshold):
    if len(boxes) != len(scores):
        raise ValueError("boxes and scores must have the same length")
    if not (0 <= iou_threshold <= 1):
        raise ValueError("iou_threshold must be between 0 and 1")
    order = sorted(range(len(boxes)), key=lambda i: -scores[i])
    keep = []
    suppressed = set()
    for i in order:
        if i in suppressed:
            continue
        keep.append(i)
        for j in order:
            if j == i or j in suppressed:
                continue
            if _iou(boxes[i], boxes[j]) >= iou_threshold:
                suppressed.add(j)
    return keep
```

NMS is greedy and score-driven on purpose -- the highest-confidence detection in a cluster of overlapping boxes almost always represents the real object best, so suppressing its lower-confidence overlapping neighbors is what turns a raw detector's dense box proposals into one clean detection per object.
