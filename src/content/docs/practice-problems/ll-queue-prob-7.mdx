# #567. Linked Lists / Stacks / Queues Module 2: Problem 7

## Overview

Locate the exact midpoint of a linked list in a single pass using Floyd's tortoise-and-hare two-pointer method.

## Task

Implement `middle_node(head)`: find the middle node of the singly linked list. If there are two middle nodes (even length), return the second middle node.

<PracticePlayground problemId="ll-queue-prob-7" />

<Solution>

```python
def middle_node(head):
    slow = head
    fast = head
    while fast and fast.get('next'):
        slow = slow.get('next')
        fast = fast['next'].get('next')
    return slow
```

Because fast travels twice as fast as slow, slow lands exactly on the midpoint when fast reaches the end.

</Solution>
