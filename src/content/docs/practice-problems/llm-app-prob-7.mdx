# #067. JSON Schema Type & Required Field Validator

**Track**: LLM Application Engineering | **Rank**: #67 of 1072 | **Points**: 40 XP

## Overview

Validate parsed LLM structured outputs against schema requirements, data types, and field completeness. In production LLM application engineering, reliable system components, deterministic interfaces, and defensive validation are paramount for production stability and cost efficiency.

## Task

Implement `validate_json_schema(data, schema)`. Inspect `data` against `schema` which specifies `required` (list of mandatory keys) and `properties` (dict mapping field names to types: `'string'`, `'integer'`, `'number'`, `'boolean'`, `'list'`, `'dict'`). Identify missing required fields and type mismatches (distinguishing bool from integer). Return `{'valid': bool, 'missing_fields': list[str], 'type_errors': list[str]}` with both lists sorted alphabetically.
