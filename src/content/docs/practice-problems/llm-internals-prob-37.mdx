# RoPE 2D Vector Rotation

**Track**: transformers-llms | **Points**: 40 XP

## Overview

Apply the 2D rotary embedding transformation to a pair of coordinate features.

## Task

Implement `apply_rope_2d(x1, x2, theta)`. Compute 2D rotation: `rot_x1 = x1 * cos(theta) - x2 * sin(theta)` and `rot_x2 = x1 * sin(theta) + x2 * cos(theta)`. Return `[round(rot_x1, 4), round(rot_x2, 4)]`.
