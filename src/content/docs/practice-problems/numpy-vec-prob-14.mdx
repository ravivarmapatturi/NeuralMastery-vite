# #754. Vectorized Gram-Schmidt Orthonormalization

**Track**: NumPy & Vectorized Computation | **Rank**: #754 of 1072 | **Points**: 60 XP

## Overview

Transform a set of linearly independent vectors into an orthonormal basis using the Gram-Schmidt process.

## Task

Implement `gram_schmidt_orthonormal(vectors)`: for each vector `v_k`, subtract projections onto previous orthonormal vectors `q_1..q_{k-1}`, and normalize the remainder to unit length `L2 = 1.0`. Round all elements to 4 decimals.

<Solution>

```python
import math

def gram_schmidt_orthonormal(vectors):
    ortho = []
    for v in vectors:
        proj_sum = [0.0] * len(v)
        for u in ortho:
            dot_vu = sum(a * b for a, b in zip(v, u))
            dot_uu = sum(b * b for b in u)
            if dot_uu > 1e-12:
                c = dot_vu / dot_uu
                proj_sum = [p + c * b for p, b in zip(proj_sum, u)]
        u_new = [a - b for a, b in zip(v, proj_sum)]
        norm_u = math.sqrt(sum(a * a for a in u_new))
        if norm_u > 1e-10:
            ortho.append([round(float(a / norm_u), 4) for a in u_new])
        else:
            ortho.append([0.0] * len(v))
    return ortho
```

Progressively subtracts projections onto established orthonormal vectors and normalizes residuals.
