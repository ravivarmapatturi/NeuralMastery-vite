# Sliding Window Attention Mask

**Track**: Transformers & LLMs | **Points**: 40 XP

## Overview

Implement sliding-window attention masking, used in Mistral and Longformer-style models to bound attention cost for very long sequences.

## Task

Implement `sliding_window_mask(seq_len, window_size)`. Position `i` may attend to position `j` if `j <= i` (causal) AND `i - j < window_size` (within the recent window). Return the `seq_len x seq_len` boolean matrix.
