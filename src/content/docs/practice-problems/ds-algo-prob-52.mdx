# Trees: Binary Tree Maximum Path Sum

**Rank #112** · Difficulty: **Hard** · Stage: **Stage 2: Data Structures & Algorithmic Foundations** · Category: **Data Structures & Algorithms**

## Overview

Implement `max_path_sum(root)` -- track the best 'pass-through' path at each node. A path can go through root, only left, only right, or just root itself.

## Task

Implement the function `max_path_sum(root)`. A path is any sequence of nodes from some starting node to some ending node along parent-child connections, used at most once. Return the maximum path sum.

<PracticePlayground problemId="ds-algo-prob-52" />

<Solution>

```python
def max_path_sum(root):
    res = [float('-inf')]

    def dfs(node):
        if not node:
            return 0
        left = max(dfs(node['left']), 0)   # ignore negative contributions
        right = max(dfs(node['right']), 0)
        res[0] = max(res[0], node['val'] + left + right)  # path through root
        return node['val'] + max(left, right)             # contribution to parent

    dfs(root)
    return res[0]
```

Post-order DFS: clamp negative subtree contributions to 0 (don't extend a path downward if it hurts). Update global max with the sum passing through this node. Return the best single-arm to the parent. O(n) time.

</Solution>
