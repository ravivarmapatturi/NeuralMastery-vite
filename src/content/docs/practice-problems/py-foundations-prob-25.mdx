# Unflatten Dotted Dictionary to Hierarchical Object

**Rank #25** · Difficulty: **Medium** · Stage: **Stage 1: AI Foundations & Python Programming** · Category: **Python & Fundamentals**

## Overview

Reconstruct hierarchical nested objects from flat delimited property paths (the exact inverse of flatten_dict).

## Task

Implement `unflatten_dict(flat, sep=".")`: split each key in `flat` by `sep` and reconstruct the corresponding nested dictionary tree structure with the given leaf values.

<PracticePlayground problemId="py-foundations-prob-25" />

<Solution>

```python
def unflatten_dict(flat, sep="."):
    nested = {}
    for k, v in flat.items():
        parts = k.split(sep)
        curr = nested
        for part in parts[:-1]:
            if part not in curr or not isinstance(curr[part], dict):
                curr[part] = {}
            curr = curr[part]
        curr[parts[-1]] = v
    return nested
```

Iterating through split path tokens and maintaining pointer references down the dictionary tree builds nested maps in linear time.

</Solution>
