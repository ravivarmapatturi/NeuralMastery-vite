# #639. Graphs & Network Algorithms Module 4: Problem 19

**Track**: Graphs & Network Algorithms | **Rank**: #639 of 1072 | **Points**

## Overview

Find the cheapest flight path bounded by at most k intermediate stops using Bellman-Ford step relaxation.

## Task

Implement `find_cheapest_flight(n, flights, src, dst, k)`: run at most `k + 1` iterations of Bellman-Ford using a cloned distance buffer to prevent multi-hop cascades within a single round.

<PracticePlayground problemId="graph-algo-prob-19" />

<Solution>

```python
def find_cheapest_flight(n, flights, src, dst, k):
    prices = [float('inf')] * n
    prices[src] = 0
    for _ in range(k + 1):
        tmp = list(prices)
        for u, v, w in flights:
            if prices[u] != float('inf') and prices[u] + w < tmp[v]:
                tmp[v] = prices[u] + w
        prices = tmp
    return prices[dst] if prices[dst] != float('inf') else -1
```

Execute k+1 edge relaxation rounds using a snapshot array to ensure each round models exactly one flight leg without cascading.
