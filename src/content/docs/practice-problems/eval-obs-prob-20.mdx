# Compute Real Answer Diversity Across Sampled Generations

**Track**: Agent Evaluation & Observability | **Points**: 40 XP

## Overview

Implement self-consistency rate calculation, a real reliability signal from sampling an agent's answer to the SAME question multiple times -- high agreement across samples correlates with genuine confidence.

## Task

Implement `self_consistency_rate(sampled_answers)`: return the fraction of samples equal to the SINGLE most common answer (the mode). Return `1.0` for a single-element list.
