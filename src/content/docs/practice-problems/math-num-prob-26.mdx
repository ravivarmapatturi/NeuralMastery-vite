# #736. Numerically Stable Softmax and Cross-Entropy

**Track**: Mathematics & Numerical Computing | **Rank**: #736 of 1072 | **Points**: 90 XP

## Overview

Compute the softmax probability vector and negative log likelihood loss without floating-point overflow.

## Task

Implement `stable_softmax_and_ce(logits, target_idx)`: subtract `m = max(logits)` to calculate `p_i = exp(z_i - m) / sum_j exp(z_j - m)`. Compute cross entropy `loss = -log(max(p_target, 1e-15))`. Return `{"probs": list[float], "loss": float}` rounded to 4 decimals.

<Solution>

```python
import math

def stable_softmax_and_ce(logits, target_idx):
    m = max(logits)
    exp_shifted = [math.exp(z - m) for z in logits]
    sum_exp = sum(exp_shifted)
    probs = [e / sum_exp for e in exp_shifted]
    p_target = max(probs[target_idx], 1e-15)
    loss = -math.log(p_target)
    return {'probs': [round(float(p), 4) for p in probs], 'loss': round(float(loss), 4)}
```

Applies max-shift invariance: softmax(z) = softmax(z - c) with c = max(z).
