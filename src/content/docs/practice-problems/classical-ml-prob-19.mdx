# Classical ML Module 19: Problem 259

**Rank #259** · Difficulty: **Easy** · Stage: **Stage 5: Classical Machine Learning & Optimization** · Category: **Classical ML**

## Overview

Calculate the total objective loss for L2 regularized Ridge regression.

## Task

Implement `ridge_loss(y_true, y_pred, weights, alpha)`: compute `MSE + alpha * sum(w**2)` where `MSE = (1/N) * sum((y_true[i] - y_pred[i])**2)`. Round result to 4 decimal places.

<PracticePlayground problemId="classical-ml-prob-19" />

<Solution>

```python
def ridge_loss(y_true, y_pred, weights, alpha):
    n = len(y_true)
    mse = sum((yt - yp) ** 2 for yt, yp in zip(y_true, y_pred)) / n if n > 0 else 0.0
    penalty = alpha * sum(w ** 2 for w in weights)
    return round(float(mse + penalty), 4)
```

L2 regularization penalizes large weight magnitudes, stabilizing model conditioning against multicollinear features.

</Solution>
