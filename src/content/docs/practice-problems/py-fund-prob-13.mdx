## Overview

Simulate network call retries with exponential backoff delays and maximum retry exhaustion limits.

## Task

Implement `retry_with_backoff_simulator(failure_count, max_retries)`: an operation fails `failure_count` times before succeeding. The first execution is attempt 1. If it fails, delay by `1.0 * (2 ** 0) = 1.0s` before attempt 2, `2.0s` before attempt 3, etc. Up to `max_retries` retries are allowed. Return `{"attempts": int, "succeeded": bool, "total_delay": float}` (delay rounded to 2 decimals).

<Solution>

```python
def retry_with_backoff_simulator(failure_count, max_retries):
    attempts = 0
    total_delay = 0.0
    succeeded = False
    base_delay = 1.0
    for i in range(max_retries + 1):
        attempts += 1
        if i < failure_count:
            if i < max_retries:
                total_delay += base_delay * (2 ** i)
        else:
            succeeded = True
            break
    return {'attempts': attempts, 'succeeded': succeeded, 'total_delay': round(total_delay, 2)}
```

Simulating attempts sequentially models exact production retry budget limits and total sleep time.
