# ALiBi Position Bias

**Track**: transformers-llms | **Points**: 40 XP

## Overview

Compute the ALiBi (Attention with Linear Biases) position bias added to attention logits before softmax.

## Task

Implement `alibi_bias(query_pos, key_pos, slope)` that computes the linear attention penalty `-slope * abs(query_pos - key_pos)`. Return the value rounded to 4 decimal places. Raise `ValueError` if `slope < 0`.
