# #008. Transformer Internals Module 2: Problem 8

**Track**: Transformer Internals | **Rank**: #8 of 1072 | **Points**: 40 XP

## Overview

Execute the forward pass of a transformer Position-wise Feed-Forward Network (FFN). The FFN consists of two linear transformations with a non-linear activation (ReLU) in between, applied independently to each sequence token representation.

## Task

Implement `ffn_forward(x, W1, b1, W2, b2)`: compute hidden activations `h = relu(x @ W1 + b1)`, then output `y = h @ W2 + b2`. Return the output vector rounded to 4 decimal places. Validate dimensions and raise `ValueError` on shape mismatches.
