# Exponential Backoff Delay Schedule

**Rank #39** · Difficulty: **Medium** · Stage: **Stage 1: AI Foundations & Python Programming** · Category: **Python & Fundamentals**

## Overview

Compute truncated exponential backoff intervals for network resilience and API retry handlers.

## Task

Implement `calculate_backoff_delays(base_delay, max_delay, attempts, factor=2.0)`: generate a list of delays for `attempts` consecutive retry attempts (indexed 0 to attempts - 1). The delay for attempt `i` is `min(max_delay, base_delay * (factor ** i))` rounded to 2 decimal places. Return `[]` if `attempts <= 0`.

<PracticePlayground problemId="py-foundations-prob-39" />

<Solution>

```python
def calculate_backoff_delays(base_delay, max_delay, attempts, factor=2.0):
    delays = []
    for i in range(attempts):
        d = min(float(max_delay), float(base_delay) * (float(factor) ** i))
        delays.append(round(d, 2))
    return delays
```

Computing geometric progression capped at max_delay generates predictable and bounded retry schedules.

</Solution>
