# #184. Self-RAG Decision Loop

**Track**: RAG Fundamentals | **Rank**: #184 of 1072 | **Points**: 40 XP

## Overview

Implement Self-RAG reflection tokens to dynamically decide when to retrieve and critique output quality.

## Task

Implement `self_rag_decision_loop(retrieval_need_score, initial_generation, candidate_generations, retrieval_threshold=0.5)`. If `retrieval_need_score < retrieval_threshold`, return `{"retrieved": False, "chosen_generation": initial_generation, "support_score": 1.0, "usefulness_score": 1.0}`. Otherwise set `retrieved = True` and score each candidate using composite score `round(0.6 * support_score + 0.4 * usefulness_score, 4)`. Select the candidate with the highest composite score (breaking ties with higher support score).
