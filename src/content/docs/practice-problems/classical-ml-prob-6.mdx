# Within-Cluster Sum of Squares (Inertia)

**Rank #246** · Difficulty: **Easy** · Stage: **Stage 5: Classical Machine Learning & Optimization** · Category: **Clustering / Recommenders** | **Points**: 40 XP

## Overview

Implement `wcss_inertia(points, centroids, assignments)`, calculating the objective function minimized by K-Means -- used directly in the Elbow heuristic for hyperparameter selection.

## Task

Implement `wcss_inertia(points, centroids, assignments)`: return the sum over all points `i` of the squared Euclidean distance between `points[i]` and `centroids[assignments[i]]`.

<PracticePlayground problemId="classical-ml-prob-6" />

<Solution>

```python
def wcss_inertia(points, centroids, assignments):
    total = 0.0
    for p, c_idx in zip(points, assignments):
        c = centroids[c_idx]
        total += sum((pi - ci) ** 2 for pi, ci in zip(p, c))
    return round(total, 6)
```
