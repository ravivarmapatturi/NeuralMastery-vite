# #757. Vectorized Discounted Cumulative Rewards

**Track**: NumPy & Vectorized Computation | **Rank**: #757 of 1072 | **Points**: 60 XP

## Overview

Calculate discounted cumulative returns for reinforcement learning trajectories.

## Task

Implement `compute_discounted_returns(rewards, gamma)`: compute the return `G_t = R_t + gamma * G_{t+1}` for each time step `t` in reverse. Return array of returns rounded to 4 decimals.

<PracticePlayground problemId="numpy-vec-prob-17" />

<Solution>

```python
def compute_discounted_returns(rewards, gamma):
    n = len(rewards)
    returns = [0.0] * n
    running = 0.0
    for t in reversed(range(n)):
        running = rewards[t] + gamma * running
        returns[t] = round(float(running), 4)
    return returns
```

Sweeps backwards through time applying Bellman recursive return formulation.

</Solution>
