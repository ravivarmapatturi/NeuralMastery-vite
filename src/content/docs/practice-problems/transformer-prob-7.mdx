# #007. Transformer Internals Module 2: Problem 7

**Track**: Transformer Internals | **Rank**: #7 of 1072 | **Points**: 40 XP

## Overview

Compute Root Mean Square Normalization (RMSNorm), the efficient normalization layer used in LLaMA, Mistral, and Gemma. RMSNorm modifies LayerNorm by omitting the mean centering step, reducing memory bandwidth requirements while retaining training stability.

## Task

Implement `rms_norm(x, eps=1e-8)`: compute `RMS(x) = sqrt(mean(x_i**2) + eps)`, then normalize each element as `x_i / RMS(x)`. Return the normalized vector with elements rounded to 4 decimal places. If `x` is empty, raise `ValueError`.
