# Extract Subgraph Around Seed Entities

**Track**: Knowledge Graph & GraphRAG | **Points**: 40 XP

## Overview

Implement seed-entity subgraph extraction, pulling only the triples relevant to a query's entities out of a much larger knowledge graph.

## Task

Implement `extract_subgraph(triples, seed_entities)`. `triples` is a list of `{"subject": str, "predicate": str, "object": str}`. Return the sublist of triples where EITHER `subject` or `object` is in `seed_entities`, preserving original order.
