# DP: Maximum Subarray (Kadane's Algorithm)

**Rank #74** · Difficulty: **Easy** · Stage: **Stage 2: Data Structures & Algorithmic Foundations** · Category: **Data Structures & Algorithms**

## Overview

Implement `max_subarray(nums)` using Kadane's algorithm -- the O(n), O(1) 'extend or restart' DP pattern. Foundation for Maximum Product Subarray and circular maximum subarray variants.

## Task

Implement the function `max_subarray(nums)`. Return the maximum sum of any contiguous subarray of `nums`.

<PracticePlayground problemId="ds-algo-prob-14" />

<Solution>

```python
def max_subarray(nums):
    cur = max_sum = nums[0]
    for n in nums[1:]:
        cur = max(n, cur + n)
        max_sum = max(max_sum, cur)
    return max_sum
```

Kadane's: `cur = max(n, cur+n)` -- restart when `cur` went negative. Track global max alongside. O(n) time, O(1) space.

</Solution>
