# Find When a Write Quorum Is Reached

**Rank #449** · Difficulty: **Easy** · Stage: **Stage 8: RAG, Agents, MCP & Distributed Systems** · Category: **Agents, MCP & Systems**

Implement `quorum_reached_at(acks, quorum)`, finding the earliest index at which a running count of replica acks first reaches quorum -- the moment a distributed write path (Dynamo-style replication, Raft commit) can safely acknowledge back to the client without waiting for every replica. Prerequisite: `agents-mcp-systems-prob-18`.

<PracticePlayground problemId="agents-mcp-systems-prob-19" />

<Solution>

```python
def quorum_reached_at(acks, quorum):
    if quorum <= 0:
        raise ValueError("quorum must be positive")
    count = 0
    for i, ack in enumerate(acks):
        if ack:
            count += 1
            if count >= quorum:
                return i
    return -1
```

A quorum write deliberately does not wait for ALL replicas to ack -- requiring only a majority (or configured W) is what lets the system stay available and low-latency even when some replicas are slow or temporarily unreachable.

</Solution>
