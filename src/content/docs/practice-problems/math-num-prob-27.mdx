# #737. Log-Sum-Exp Numerical Function

**Track**: Mathematics & Numerical Computing | **Rank**: #737 of 1072 | **Points**: 90 XP

## Overview

Compute the smooth maximum log-sum-exp function without overflow or catastrophic cancellation.

## Task

Implement `log_sum_exp(logits)`: evaluate `LSE(x) = m + log(sum_i exp(x_i - m))` where `m = max(logits)`. Return float rounded to 4 decimals.

<PracticePlayground problemId="math-num-prob-27" />

<Solution>

```python
import math

def log_sum_exp(logits):
    m = max(logits)
    lse = m + math.log(sum(math.exp(z - m) for z in logits))
    return round(float(lse), 4)
```

Factors out max scalar from exponential sum to prevent exponent overflow.

</Solution>
