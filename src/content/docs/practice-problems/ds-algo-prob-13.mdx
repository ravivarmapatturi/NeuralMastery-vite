# Graphs: BFS Shortest Path in Unweighted Graph

**Rank #73** · Difficulty: **Easy** · Stage: **Stage 2: Data Structures & Algorithmic Foundations** · Category: **Data Structures & Algorithms**

## Overview

Implement `bfs_shortest_path(graph, start, end)` -- BFS is the correct shortest-path algorithm for unweighted graphs. This pattern appears in Word Ladder, Jump Game II, and Minimum Knight Moves.

## Task

Implement the function `bfs_shortest_path(graph, start, end)`. Return the minimum edge-count path from `start` to `end`, or `-1` if unreachable.

<PracticePlayground problemId="ds-algo-prob-13" />

<Solution>

```python
from collections import deque

def bfs_shortest_path(graph, start, end):
    if start == end:
        return 0
    visited = {start}
    q = deque([(start, 0)])
    while q:
        node, dist = q.popleft()
        for neighbor in graph.get(node, []):
            if neighbor == end:
                return dist + 1
            if neighbor not in visited:
                visited.add(neighbor)
                q.append((neighbor, dist + 1))
    return -1
```

BFS explores all nodes at distance d before d+1. First time `end` is reached gives the shortest path. O(V+E) time and space.

</Solution>
