# Runtime Tool Registry Add/Remove

**Track**: MCP Advanced & Agent Integration | **Points**: 40 XP

## Overview

Implement dynamic tool registration, letting an MCP server add or remove tools at runtime (e.g. tools that only become available once a user connects an integration).

## Task

Implement `update_tool_registry(registry, tool_name, action)`. If `action == 'add'`, add `tool_name` as a key with value `True` (no-op if already present). If `action == 'remove'`, delete `tool_name` if present (no-op if absent). Return the mutated registry.
