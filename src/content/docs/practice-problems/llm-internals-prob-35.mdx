# Repetition Penalty on Logits

**Track**: transformers-llms | **Points**: 40 XP

## Overview

Penalize logits of previously generated tokens to discourage loops in text generation.

## Task

Implement `apply_repetition_penalty(logits, generated_token_ids, penalty=1.2)`. For each token ID present in `generated_token_ids`: if `logit > 0`, divide by `penalty`; if `logit <= 0`, multiply by `penalty`. Leave ungenerated token logits unchanged. Return rounded to 4 decimal places.
