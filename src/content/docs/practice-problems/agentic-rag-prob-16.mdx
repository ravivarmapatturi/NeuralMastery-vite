# Detect Ambiguous Query Needing Clarification

**Track**: Advanced RAG & Agentic RAG | **Points**: 40 XP

## Overview

Implement query-ambiguity detection, catching a real case where an agentic RAG system should ask a clarifying question rather than silently guessing which real-world entity the user meant.

## Task

Implement `is_query_ambiguous(entity_name, entity_candidates)`. `entity_candidates` maps an entity name to the list of distinct real-world entities it could refer to (e.g. `'Washington' -> ['George Washington', 'Washington State', 'Washington D.C.']`). Return `True` if `entity_name` maps to MORE THAN ONE candidate.
