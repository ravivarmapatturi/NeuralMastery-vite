# #596. Trees / Binary Search Module 2: Problem 6

**Track**: Trees / Binary Search | **Rank**: #596 of 1072 | **Points**

## Overview

Combine two binary trees by summing overlapping node values into a single merged tree structure.

## Task

Implement `merge_trees(root1, root2)`: if either root is None, return the other. Otherwise create a node with val = root1["val"] + root2["val"], merging their left and right subtrees recursively.

<PracticePlayground problemId="tree-bs-prob-6" />

<Solution>

```python
def merge_trees(root1, root2):
    if root1 is None:
        return root2
    if root2 is None:
        return root1
    return {
        'val': root1['val'] + root2['val'],
        'left': merge_trees(root1.get('left'), root2.get('left')),
        'right': merge_trees(root1.get('right'), root2.get('right'))
    }
```

Recurse simultaneously on both trees. If either subtree is None, the remaining subtree is attached directly. Otherwise, sum their values and recurse on their left and right children.

</Solution>
