# Fallback Tool Chain Resolution

**Track**: MCP Advanced & Agent Integration | **Points**: 40 XP

## Overview

Implement fallback-tool-chain resolution, letting an agent gracefully degrade to a lower-priority tool when its preferred one is unavailable.

## Task

Implement `resolve_fallback_tool(tool_priority_list, tool_availability)`: return the FIRST tool name in `tool_priority_list` (in order) whose `tool_availability` value is `True`. Return `''` if none are available.
