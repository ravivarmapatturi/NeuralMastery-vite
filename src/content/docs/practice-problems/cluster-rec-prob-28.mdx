# Gaussian Mixture Model: Responsibility Computation

**Track**: Clustering & Recommender Systems | **Points**: 40 XP

## Overview

Implement the E-step responsibility calculation of a 1D Gaussian Mixture Model, the soft-clustering generalization of k-means.

## Task

Implement `gmm_responsibility(x, means, variances, weights)`. For each component `k`, compute its weighted Gaussian density at `x`: `weights[k] * N(x; means[k], variances[k])` where `N(x;m,v) = (1/sqrt(2*pi*v)) * exp(-(x-m)**2/(2*v))`. Return the normalized responsibilities (each divided by the sum over all components) as a list of floats.
