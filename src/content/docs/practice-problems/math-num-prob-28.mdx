# #738. Cholesky Decomposition of Positive-Definite Matrices

**Track**: Mathematics & Numerical Computing | **Rank**: #738 of 1072 | **Points**: 90 XP

## Overview

Decompose a symmetric positive-definite matrix into the product of a lower triangular matrix and its transpose.

## Task

Implement `cholesky_decomposition(A)`: for symmetric positive-definite matrix A, compute lower triangular matrix L where `L[j][j] = sqrt(A[j][j] - sum_{k<j} L[j][k]^2)` and `L[i][j] = (A[i][j] - sum_{k<j} L[i][k]*L[j][k]) / L[j][j]`. If any diagonal term `<=` 0, return `None`. Return n x n lower triangular matrix rounded to 4 decimals.

<Solution>

```python
import math

def cholesky_decomposition(A):
    n = len(A)
    L = [[0.0] * n for _ in range(n)]
    for j in range(n):
        sum_sq = sum(L[j][k] ** 2 for k in range(j))
        diag_val = A[j][j] - sum_sq
        if diag_val <= 0:
            return None
        L[j][j] = math.sqrt(diag_val)
        for i in range(j + 1, n):
            sum_cross = sum(L[i][k] * L[j][k] for k in range(j))
            L[i][j] = (A[i][j] - sum_cross) / L[j][j]
    return [[round(float(x), 4) for x in row] for row in L]
```

Constructs the Cholesky factor column by column via Banachiewicz algorithm.
