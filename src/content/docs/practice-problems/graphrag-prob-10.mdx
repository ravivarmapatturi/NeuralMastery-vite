# Score a Path by Edge Weight Product

**Track**: Knowledge Graph & GraphRAG | **Points**: 40 XP

## Overview

Implement path-confidence scoring by multiplying edge confidences, the real way a multi-hop graph reasoning chain's overall reliability degrades with each additional hop.

## Task

Implement `score_path(path, edge_weights)`. For each consecutive pair `(path[i], path[i+1])`, look up its weight in `edge_weights` under the key `f'{path[i]}->{path[i+1]}'`. Return the PRODUCT of all edge weights along the path. Return `1.0` for a path with 0 or 1 nodes (no edges to traverse).
