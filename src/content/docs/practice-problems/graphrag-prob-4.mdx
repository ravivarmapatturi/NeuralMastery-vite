# K-Hop Neighbor Expansion

**Track**: Knowledge Graph & GraphRAG | **Points**: 40 XP

## Overview

Implement k-hop neighbor expansion, the real subgraph-retrieval primitive GraphRAG uses to pull local context around a query entity.

## Task

Implement `k_hop_neighbors(graph, start, k)`: return the sorted list of all DISTINCT nodes reachable from `start` within `k` hops (not including `start` itself), via BFS layer-by-layer expansion.
