# #879. GELU Activation Function Forward

**Track**: Deep Learning & Neural Networks | **Rank**: #879 of 1072 | **Points**: 60 XP

## Overview

Implement the Gaussian Error Linear Unit (GELU) activation standard in modern Transformer architectures like BERT and GPT.

## Task

Implement `gelu_forward(x, approximate=True)`: if `approximate=True`, compute `0.5 * v * (1 + tanh(sqrt(2/pi) * (v + 0.044715 * v^3)))`. If `approximate=False`, compute `0.5 * v * (1 + erf(v / sqrt(2)))` using `math.erf`. Round all resulting values to 4 decimal places.

```python
def gelu_forward(x: list[list[float]], approximate: bool = True) -> list[list[float]]:
    out = []
    for row in x:
        r = []
        for v in row:
            if approximate:
                inner = math.sqrt(2.0 / math.pi) * (v + 0.044715 * (v ** 3))
                y = 0.5 * v * (1.0 + math.tanh(inner))
            else:
                y = 0.5 * v * (1.0 + math.erf(v / math.sqrt(2.0)))
            r.append(round(float(y), 4))
        out.append(r)
    return out
```

GELU replaces deterministic thresholding with stochastic regularization expectations, yielding superior empirical results in large language models.
