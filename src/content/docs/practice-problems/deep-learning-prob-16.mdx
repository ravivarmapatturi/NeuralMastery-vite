# Word2Vec Skip-Gram Negative Sampling Loss

**Track**: Deep Learning & Vision/NLP | **Points**: 40 XP

## Overview

Calculate the negative sampling objective for Word2Vec training on a positive pair and sampled negative words.

## Task

Implement `skipgram_negative_sampling_loss(target_emb, context_emb, negative_embs)`. For target vector `v_w` and context vector `v_c`, compute dot product `s_pos = dot(v_w, v_c)`. For each negative vector `v_n`, compute `s_neg = dot(v_w, v_n)`. Objective is `-log(sigmoid(s_pos)) - sum(log(sigmoid(-s_neg)))`. Use `sigmoid(x) = 1.0 / (1.0 + exp(-x))`. Return float rounded to 4 decimal places.
