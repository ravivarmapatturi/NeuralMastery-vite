# Viterbi Trellis Decoding for POS Tagging

**Track**: Deep Learning & Vision/NLP | **Points**: 40 XP

## Overview

Implement dynamic programming trellis search to find the most probable sequence of hidden states in an HMM tagger.

## Task

Implement `viterbi_pos_tagger(tokens, states, init_prob, trans_prob, emit_prob)`. For observation sequence `tokens`, compute highest probability path through hidden `states`. At `t=0`, `V[0][s] = init_prob[s] * emit_prob[s].get(tokens[0], 1e-6)`. At step `t`, `V[t][s] = max_{s'} (V[t-1][s'] * trans_prob[s'][s]) * emit_prob[s].get(tokens[t], 1e-6)`. Trace back best path from `argmax_s V[T-1][s]`. Return list of state strings.
