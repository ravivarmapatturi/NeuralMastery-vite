# #022. Transformer Internals Module 5: Problem 22

**Track**: Transformer Internals | **Rank**: #22 of 1072 | **Points**: 60 XP

## Overview

Generate a sliding window causal attention mask matrix. Sliding window attention (used in Mistral and Longformer) restricts self-attention to a local receptive field of `window_size` preceding tokens, reducing memory and computation from quadratic to linear.

## Task

Implement `sliding_window_attention_mask(seq_len, window_size)`: return a binary matrix of shape `seq_len x seq_len` where element `[i][j]` is `1` if `max(0, i - window_size + 1) <= j <= i`, and `0` otherwise. Raise `ValueError` if `seq_len <= 0` or `window_size <= 0`.
