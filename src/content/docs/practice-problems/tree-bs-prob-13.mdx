# #603. Trees / Binary Search Module 3: Problem 13

**Track**: Trees / Binary Search | **Rank**: #603 of 1072 | **Points**: 60 XP

## Overview

Implement Search Insert Position -- a small but important variant of binary search, where "not found" means something (the exact insertion point) instead of just -1.

## Task

Implement the function `search_insert(nums, target)`: return the index of `target` if present, otherwise the index where it would be inserted to keep `nums` sorted. Must run in O(log n) time.
