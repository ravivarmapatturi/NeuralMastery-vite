# #612. Trees / Binary Search Module 5: Problem 22

**Track**: Trees / Binary Search | **Rank**: #612 of 1072 | **Points**: 60 XP

## Overview

Implement tree reconstruction from preorder + inorder traversals -- using the fact that preorder always names the current subtree's root first, and inorder then tells you exactly how many of the remaining values belong to the left vs. right subtree.

## Task

Implement the function `build_tree_from_traversals(preorder, inorder)`: reconstruct and return the original binary tree (all values distinct) that produced these two traversals.
