# #605. Trees / Binary Search Module 3: Problem 15

**Track**: Trees / Binary Search | **Rank**: #605 of 1072 | **Points**: 60 XP

## Overview

Implement Path Sum -- a root-to-leaf-only search (not any path between any two nodes, which is the much harder Maximum Path Sum problem) that carries a shrinking "remaining budget" down the recursion.

## Task

Implement the function `has_path_sum(root, target_sum)`: return `True` if some root-to-leaf path exists whose node values sum to exactly `target_sum`. An empty tree always returns `False`, even for `target_sum = 0`.
