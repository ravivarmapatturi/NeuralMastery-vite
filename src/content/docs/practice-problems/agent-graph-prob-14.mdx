# Loop Iteration Counter With Max Bound

**Track**: Agent Graph Engineering | **Points**: 40 XP

## Overview

Implement per-node loop-iteration counting, the real state a graph executor tracks to enforce each individual loop's own bound (distinct loops in the same graph need independent counters).

## Task

Implement `increment_loop_counter(counters, loop_node, max_iterations)`. Increment `counters.get(loop_node, 0)` by 1. Return `(updated_counters, still_allowed)` where `still_allowed` is `True` if the NEW count is `<= max_iterations`.
