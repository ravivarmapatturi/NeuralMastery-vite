# Recommendation Novelty Score

**Track**: Clustering & Recommender Systems | **Points**: 40 XP

## Overview

Implement self-information-based novelty, a real metric that scores a recommendation list on how non-obvious (unpopular) its items are.

## Task

Implement `novelty_score(recommended_items, item_popularity)`. `item_popularity` maps item id -> its popularity as a probability in (0, 1] (fraction of all users who've interacted with it). Each item's novelty (self-information) is `-log2(item_popularity[item])`. Return the AVERAGE novelty over `recommended_items`. If the list is empty, return `0.0`.
