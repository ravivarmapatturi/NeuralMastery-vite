# Compute Token-Level F1 for QA Evaluation

**Rank #362** · Difficulty: **Easy** · Stage: **Stage 7: Transformers, LLMs & Foundation Models** · Category: **Transformers & LLMs**

Implement SQuAD-standard token-level Precision, Recall, and F1 evaluation metrics for extractive question answering and LLM response evaluation. Prerequisite: `llm-internals-prob-1`.

<Solution>

```python
import re
from collections import Counter

def compute_token_f1(prediction, ground_truth):
    def tokenize(s):
        clean = re.sub(r'[^\w\s]', '', s.lower())
        return clean.split()
    pred_tokens = tokenize(prediction)
    gold_tokens = tokenize(ground_truth)
    if not pred_tokens and not gold_tokens:
        return {"precision": 1.0, "recall": 1.0, "f1": 1.0}
    if not pred_tokens or not gold_tokens:
        return {"precision": 0.0, "recall": 0.0, "f1": 0.0}
    
    pred_counts = Counter(pred_tokens)
    gold_counts = Counter(gold_tokens)
    overlap = sum(min(pred_counts[w], gold_counts[w]) for w in pred_counts)
    
    precision = overlap / len(pred_tokens)
    recall = overlap / len(gold_tokens)
    f1 = (2 * precision * recall) / (precision + recall) if precision + recall > 0 else 0.0
    return {
        "precision": round(precision, 4),
        "recall": round(recall, 4),
        "f1": round(f1, 4)
    }
```

Token-level F1 measures bag-of-words multiset overlap between predictions and reference text, penalizing both omissions (recall) and hallucinated extra words (precision).
