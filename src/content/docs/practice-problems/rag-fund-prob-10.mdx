# #190. Dense-Sparse Hybrid Ranker

**Track**: RAG Fundamentals | **Rank**: #190 of 1072 | **Points**: 40 XP

## Overview

Fuse semantic dense embeddings with lexical BM25 keyword search using normalized hybrid ranking.

## Task

Implement `dense_sparse_hybrid_ranker(dense_scores, sparse_scores, alpha=0.5)`. Apply min-max normalization independently to `dense_scores` and `sparse_scores` scaling them to `[0.0, 1.0]` (if min == max, assign 1.0 if `value > 0` else 0.0). For every document across both sets, compute `score = round(alpha * norm_dense + (1 - alpha) * norm_sparse, 4)` (missing scores default to 0.0). Return the list of `[doc_id, score]` pairs sorted descending by score, breaking ties by `doc_id` alphabetically.
