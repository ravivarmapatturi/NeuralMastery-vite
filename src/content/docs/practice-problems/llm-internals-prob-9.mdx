# Compute Rotary Position Embedding (RoPE) Angles

**Track**: transformers-llms | **Points**: 40 XP

## Overview

Implement Rotary Position Embedding (RoPE) angle calculation -- the modern positional representation powering LLaMA, Mistral, and modern open-weights LLMs.

## Task

Implement `rope_angles(seq_len, head_dim, base=10000.0)`. For each token index `m in [0, seq_len - 1]` and frequency channel `i in [0, head_dim // 2 - 1]`, calculate `angle = m * base**(-2i / head_dim)`, rounded to 4 decimal places.
