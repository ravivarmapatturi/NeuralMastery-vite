```python
def rope_angles(seq_len, head_dim, base=10000.0):
    if seq_len <= 0 or head_dim <= 0 or head_dim % 2 != 0 or base <= 0:
        raise ValueError("Invalid parameters for rope_angles")
    angles = []
    for m in range(seq_len):
        row = []
        for i in range(head_dim // 2):
            theta = base ** (-2 * i / head_dim)
            row.append(round(m * theta, 4))
        angles.append(row)
    return angles
```

Rotary Position Embeddings (RoPE) represent token positions as complex coordinate rotations in head-dimension subspace pairs, decaying attention scores smoothly over distance without absolute position lookup tables.
