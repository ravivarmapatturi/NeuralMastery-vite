# Classical ML Module 29: Problem 269

**Rank #269** · Difficulty: **Medium** · Stage: **Stage 5: Classical Machine Learning & Optimization** · Category: **Classical ML**

## Overview

Apply the classical Rosenblatt Perceptron mistake-driven parameter update.

## Task

Implement `perceptron_step(x, y, weights, bias, lr)`. Given label `y in {-1, 1}`, compute activation `z = sum(w_i * x_i) + bias`. If `y * z <= 0` (misclassification), update `w_i = w_i + lr * y * x_i` and `bias = bias + lr * y`, set `updated=True`. Else keep parameters unchanged and set `updated=False`. Round floats to 4 decimal places.

<PracticePlayground problemId="classical-ml-prob-29" />

<Solution>

```python
def perceptron_step(x, y, weights, bias, lr):
    act = sum(w * a for w, a in zip(weights, x)) + bias
    if y * act <= 0.0:
        new_w = [round(w + lr * y * a, 4) for w, a in zip(weights, x)]
        new_b = round(bias + lr * y, 4)
        updated = True
    else:
        new_w = [round(w, 4) for w in weights]
        new_b = round(bias, 4)
        updated = False
    return {"weights": new_w, "bias": new_b, "updated": updated}
```

Perceptron learning updates parameters only when an error occurs, rotating the decision hyperplane toward the misclassified sample.
