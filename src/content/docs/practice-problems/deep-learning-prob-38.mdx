# Sørensen-Dice Coefficient for Binary Masks

**Track**: Deep Learning & Vision/NLP | **Points**: 40 XP

## Overview

Compute the Sørensen-Dice similarity coefficient (F1 score) between predicted and ground-truth segmentation masks.

## Task

Implement `dice_coefficient_binary(pred_mask, gt_mask, smooth)`. Given two binary matrices of identical shape `H x W` (cells are 0 or 1), compute intersection `inter = sum(p * g)`, and total active pixels `total = sum(p) + sum(g)`. Dice coefficient is `(2 * inter + smooth) / (total + smooth)`. Round result to 4 decimal places.
