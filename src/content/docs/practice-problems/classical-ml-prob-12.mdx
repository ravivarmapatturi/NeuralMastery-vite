# Hierarchical Clustering Single-Linkage Distance

**Rank #252** · Difficulty: **Easy** · Stage: **Stage 5: Classical Machine Learning & Optimization** · Category: **Clustering / Recommenders** | **Points**: 40 XP

## Overview

Implement `single_linkage_distance(cluster_a, cluster_b)`, the proximity criterion for single-link agglomerative hierarchical clustering.

## Task

Implement `single_linkage_distance(cluster_a, cluster_b)`: find the minimum Euclidean distance between any point in `cluster_a` and any point in `cluster_b`. Return `0.0` if either cluster is empty.

<PracticePlayground problemId="classical-ml-prob-12" />

<Solution>

```python
import math

def single_linkage_distance(cluster_a, cluster_b):
    if not cluster_a or not cluster_b:
        return 0.0
    min_dist = float("inf")
    for pa in cluster_a:
        for pb in cluster_b:
            d = math.sqrt(sum((x - y) ** 2 for x, y in zip(pa, pb)))
            if d < min_dist:
                min_dist = d
    return round(min_dist, 6)
```

Single linkage can construct non-elliptical cluster chains, though it is susceptible to the chaining effect in noisy data.
