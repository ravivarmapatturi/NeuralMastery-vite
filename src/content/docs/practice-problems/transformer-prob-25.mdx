# #025. Transformer Internals Module 5: Problem 25

**Track**: Transformer Internals | **Rank**: #25 of 1072 | **Points**: 90 XP

## Overview

Implement Top-K expert routing for Mixture-of-Experts (MoE) architectures. MoE routers compute gating logits across candidate experts, select the top `k` experts with highest scores, and normalize their weights via softmax.

## Task

Implement `moe_router(x, W_gate, k)`: compute routing logits `g = x @ W_gate`, identify the indices of the `k` largest logits, and apply softmax over these `k` selected logits to compute their routing weights. Return `(selected_expert_indices, routing_weights)` rounded to 4 decimal places.
