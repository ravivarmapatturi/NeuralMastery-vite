# Mathematics Module 43: Problem 163

**Rank #163** · Difficulty: **Medium** · Stage: **Stage 3: Mathematics & Numerical Computing** · Category: **Math & Numerical**

## Overview

Re-estimate Gaussian Mixture Model parameters via maximum likelihood in the M-step.

## Task

Implement `gmm_m_step(X, responsibilities)`: for each component k, compute effective sample size `N_k = sum_i gamma_ik`. Update `weights[k] = N_k / N`, `means[k] = sum_i (gamma_ik * x_i) / N_k`, and `variances[k] = sum_i (gamma_ik * (x_i - means[k])^2) / N_k`. Return `{"weights": list, "means": list, "variances": list}` rounded to 4 decimals.

<Solution>

```python
def gmm_m_step(X, responsibilities):
    N = len(X)
    K = len(responsibilities[0])
    weights = []
    means = []
    variances = []
    for k in range(K):
        N_k = sum(responsibilities[i][k] for i in range(N))
        pi_k = N_k / N
        mu_k = sum(responsibilities[i][k] * X[i] for i in range(N)) / N_k if N_k > 1e-12 else 0.0
        var_k = sum(responsibilities[i][k] * ((X[i] - mu_k) ** 2) for i in range(N)) / N_k if N_k > 1e-12 else 1.0
        weights.append(round(float(pi_k), 4))
        means.append(round(float(mu_k), 4))
        variances.append(round(float(var_k), 4))
    return {'weights': weights, 'means': means, 'variances': variances}
```

Updates mixture parameters using responsibility-weighted first and second empirical moments.
