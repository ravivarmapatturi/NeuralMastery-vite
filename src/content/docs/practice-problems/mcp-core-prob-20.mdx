# Build Server Capabilities Advertisement

**Track**: MCP Core Engineering | **Points**: 40 XP

## Overview

Implement server capability advertisement, converting internal feature flags into the capabilities object a server sends during initialization.

## Task

Implement `build_capabilities(enabled_features)`. Return a dict containing ONLY the keys from `enabled_features` whose value is `True`, each mapped to an empty dict `{}` (matching MCP's real `{"tools": {}, "resources": {}}`-style capabilities shape).
