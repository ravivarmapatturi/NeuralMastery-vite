# Mathematics Module 38: Problem 158

**Rank #158** · Difficulty: **Medium** · Stage: **Stage 3: Mathematics & Numerical Computing** · Category: **Math & Numerical**

## Overview

Execute a second-order Newton-Raphson optimization step.

## Task

Implement `newton_raphson_step(x, f_prime, f_double_prime)`: calculate `x_next = x - f_prime / f_double_prime`. If `abs(f_double_prime) < 1e-9`, return `x` unchanged. Return float rounded to 4 decimals.

<PracticePlayground problemId="math-num-prob-38" />

<Solution>

```python
def newton_raphson_step(x, f_prime, f_double_prime):
    if abs(f_double_prime) < 1e-9:
        return round(float(x), 4)
    x_next = x - f_prime / f_double_prime
    return round(float(x_next), 4)
```

Computes curvature-scaled step to jump directly to the local quadratic minimum.

</Solution>
