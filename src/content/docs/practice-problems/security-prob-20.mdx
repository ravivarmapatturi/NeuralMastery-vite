# Block Agent Self-Modification of Config

**Track**: Agent Security & Reliability | **Points**: 40 XP

## Overview

Implement a self-modification guard, preventing an agent from editing its own system prompt, config, or permission files -- a real, important boundary for maintaining a stable safety posture.

## Task

Implement `blocks_self_modification(file_path, protected_paths)`: return `True` (block the write) if `file_path` exactly matches any entry in `protected_paths`.
