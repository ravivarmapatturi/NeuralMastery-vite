# DBSCAN Epsilon Neighborhood Query

**Rank #254** · Difficulty: **Easy** · Stage: **Stage 5: Classical Machine Learning & Optimization** · Category: **Clustering / Recommenders** | **Points**: 40 XP

## Overview

Implement `dbscan_region_query(points, point_idx, eps)`, the fundamental neighborhood search operation powering DBSCAN density-based spatial clustering.

## Task

Implement `dbscan_region_query(points, point_idx, eps)`: compute Euclidean distances from `points[point_idx]` to all points. Return a sorted list of integer indices whose distance is less than or equal to `eps` (including `point_idx`).

<PracticePlayground problemId="classical-ml-prob-14" />

<Solution>

```python
def dbscan_region_query(points, point_idx, eps):
    target = points[point_idx]
    neighbors = []
    eps_sq = eps * eps
    for idx, p in enumerate(points):
        dist_sq = sum((pi - ti) ** 2 for pi, ti in zip(p, target))
        if dist_sq <= eps_sq + 1e-12:
            neighbors.append(idx)
    neighbors.sort()
    return neighbors
```

The epsilon-neighborhood cardinality determines whether a point is a core point, border point, or noise point in DBSCAN.
