# Extract Citation Markers From a Generated Answer

**Track**: RAG Production Engineering | **Points**: 40 XP

## Overview

Implement citation-marker extraction, needed to map an LLM's generated answer back to the specific source chunks it claims to have used.

## Task

Implement `extract_citations(answer)`. Find every `[N]` marker (N is one or more digits) in `answer`, and return the sorted list of unique integers found.
