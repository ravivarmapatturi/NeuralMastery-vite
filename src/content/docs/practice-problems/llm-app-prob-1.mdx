# #061. Prompt Template Variable Interpolation

**Track**: LLM Application Engineering | **Rank**: #61 of 1072 | **Points**: 40 XP

## Overview

Implement safe prompt template variable interpolation supporting literal brace escapes and missing key policies. In production LLM application engineering, reliable system components, deterministic interfaces, and defensive validation are paramount for production stability and cost efficiency.

## Task

Implement `interpolate_prompt_template(template, variables, strict=True)`. Substitute `{var}` placeholders with values from `variables`. Treat `{{` and `}}` as escaped literal `{` and `}` without interpolation. If `strict` is True and a placeholder is not found in `variables`, raise `KeyError`. If `strict` is False, leave unresolved placeholders untouched. Return the interpolated string.
