# #020. Transformer Internals Module 4: Problem 20

**Track**: Transformer Internals | **Rank**: #20 of 1072 | **Points**: 60 XP

## Overview

Implement a combined Linear Warmup with Cosine Decay learning rate schedule. Warmup increases the learning rate linearly from 0 to `base_lr` to stabilize early optimization, followed by cosine decay for smooth final convergence.

## Task

Implement `warmup_cosine_lr(step, warmup_steps, total_steps, base_lr)`: if `step < warmup_steps`, return `base_lr * (step / warmup_steps)`. If `step >= warmup_steps`, decay `base_lr` using cosine decay down to 0 at `total_steps`. Return the computed learning rate rounded to 6 decimal places.
