# Sliding Window Error Rate Monitoring

**Track**: Agent Evaluation & Observability | **Points**: 40 XP

## Overview

Implement sliding-window error-rate monitoring, giving a real-time observability dashboard a responsive, recency-weighted error signal instead of an all-time cumulative average that reacts too slowly to a fresh incident.

## Task

Implement `sliding_window_error_rate(recent_outcomes, window_size)`. `recent_outcomes` is `True`=success, `False`=error, in chronological order (oldest first). Consider only the LAST `window_size` entries (or all of them if fewer exist). Return the fraction of those that are `False` (errors).
