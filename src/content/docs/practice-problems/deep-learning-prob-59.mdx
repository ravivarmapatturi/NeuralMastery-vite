# Optical Flow Average Endpoint Error (EPE)

**Track**: Deep Learning & Vision/NLP | **Points**: 40 XP

## Overview

Compute the Average Endpoint Error (EPE) metric between predicted and ground-truth optical flow fields.

## Task

Implement `optical_flow_aee(flow_pred, flow_gt)`. Given flow fields of shape `H x W x 2` (where `[u, v]` is the displacement vector at pixel `(r, c)`), compute the Euclidean distance `sqrt((u_pred - u_gt)^2 + (v_pred - v_gt)^2)` at each pixel. Return the mean error across all `H * W` pixels rounded to 4 decimal places.
