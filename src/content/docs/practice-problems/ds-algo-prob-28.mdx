## Task

Implement the function `can_finish(numCourses, prerequisites)`. Return `True` if all courses can be finished (no circular prerequisite dependency).

<Solution>

```python
def can_finish(numCourses, prerequisites):
    graph = {i: [] for i in range(numCourses)}
    for a, b in prerequisites:
        graph[b].append(a)
    visited = [0] * numCourses  # 0=unvisited, 1=visiting, 2=done

    def dfs(node):
        if visited[node] == 1:
            return False  # back edge -> cycle
        if visited[node] == 2:
            return True
        visited[node] = 1
        for nb in graph[node]:
            if not dfs(nb):
                return False
        visited[node] = 2
        return True

    return all(dfs(i) for i in range(numCourses))
```

Three-color DFS: gray (1) = currently on the recursion stack; encountering a gray node means a cycle. Black (2) = fully processed, safe to skip. O(V+E) time.
