# Parse a Resource URI Into Components

**Track**: MCP Core Engineering | **Points**: 40 XP

## Overview

Implement MCP resource URI parsing, breaking a `scheme://path?query` resource identifier into its structural parts.

## Task

Implement `parse_resource_uri(uri)`. Split on `'://'` to get `scheme` and the rest. Split the rest on the first `'?'` to separate `path` from a query string (`''` if no `?`). Parse the query string into a dict by splitting on `'&'` then `'='` per pair (empty dict if the query string is empty). Return `{"scheme": str, "path": str, "query": dict}`.
