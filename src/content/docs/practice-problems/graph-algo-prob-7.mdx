## Overview

Count the number of connected components in an undirected graph using Disjoint Set Union (Union-Find).

## Task

Implement `count_connected_components_undirected(n, edges)`: initialize n components with path-compressed find(). For each edge uniting distinct components, decrement component count.

<Solution>

```python
def count_connected_components_undirected(n, edges):
    parent = list(range(n))
    def find(i):
        if parent[i] == i:
            return i
        parent[i] = find(parent[i])
        return parent[i]
    components = n
    for u, v in edges:
        ru, rv = find(u), find(v)
        if ru != rv:
            parent[ru] = rv
            components -= 1
    return components
```

Initialize n disjoint sets. For each edge, if the endpoints belong to different sets, union them and decrement the remaining component count.
