# ALiBi Positional Bias

**Track**: Transformers & LLMs | **Points**: 40 XP

## Overview

Implement ALiBi (Attention with Linear Biases), a real alternative to RoPE/sinusoidal encoding that biases attention scores directly by distance instead of modifying the query/key vectors.

## Task

Implement `alibi_bias(query_pos, key_pos, head_slope)`. Return `-head_slope * (query_pos - key_pos)` (assumes `key_pos <= query_pos`, a causal setting, so the bias is always `<= 0`, penalizing more distant keys).
