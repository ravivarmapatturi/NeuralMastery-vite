# FastText Character N-Gram Extractor

**Track**: Deep Learning & Vision/NLP | **Points**: 40 XP

## Overview

Extract character n-grams with word boundary tags for FastText subword embedding models.

## Task

Implement `fasttext_ngrams(word, min_n, max_n)`. Enclose the word with boundary characters: `wrapped = '<' + word + '>'`. For every length `n` from `min_n` to `max_n` (inclusive), extract all substrings of length `n` in order of increasing `n` and left-to-right position. Finally, append the special full wrapped token `wrapped` if it was not already included. Return the list of unique n-grams in order of first appearance.
