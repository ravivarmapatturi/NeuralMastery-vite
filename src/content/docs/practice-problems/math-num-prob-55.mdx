# Mathematics Module 55: Problem 175

**Rank #175** · Difficulty: **Hard** · Stage: **Stage 3: Mathematics & Numerical Computing** · Category: **Math & Numerical**

## Overview

Solve an equality-constrained quadratic program by forming and solving the Karush-Kuhn-Tucker linear block system.

## Task

Implement `lagrange_quadratic_equality(A, b, C, d)`: form the augmented `(n + m) x (n + m)` KKT system `[[A, C^T], [C, 0]] * [x, lambda]^T = [b, d]^T`. Invert the KKT matrix via Gauss-Jordan elimination and extract the primal solution vector `x`. Return `x` rounded to 4 decimals.

```python
def lagrange_quadratic_equality(A, b, C, d):
    n = len(A)
    m = len(C)
    total_dim = n + m
    KKT = [[0.0] * total_dim for _ in range(total_dim)]
    rhs = [0.0] * total_dim
    for i in range(n):
        for j in range(n):
            KKT[i][j] = A[i][j]
        rhs[i] = b[i]
    for i in range(m):
        for j in range(n):
            KKT[n + i][j] = C[i][j]
            KKT[j][n + i] = C[i][j]
        rhs[n + i] = d[i]
    aug = [list(KKT[i]) + [1.0 if i == j else 0.0 for j in range(total_dim)] for i in range(total_dim)]
    for col in range(total_dim):
        pivot = max(range(col, total_dim), key=lambda r: abs(aug[r][col]))
        if abs(aug[pivot][col]) < 1e-9:
            return [0.0] * n
        aug[col], aug[pivot] = aug[pivot], aug[col]
        pv = aug[col][col]
        aug[col] = [x / pv for x in aug[col]]
        for r in range(total_dim):
            if r != col:
                f = aug[r][col]
                aug[r] = [aug[r][c] - f * aug[col][c] for c in range(2 * total_dim)]
    inv_KKT = [[aug[i][total_dim + j] for j in range(total_dim)] for i in range(total_dim)]
    x_sol = [sum(inv_KKT[i][j] * rhs[j] for j in range(total_dim)) for i in range(n)]
    return [round(float(v), 4) for v in x_sol]
```

Assembles the KKT saddle-point matrix and inverts it to extract optimal primal variables.
