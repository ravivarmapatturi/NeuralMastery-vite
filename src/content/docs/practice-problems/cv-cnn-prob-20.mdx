# #910. Pixel Brightness and Contrast Linear Transform

**Track**: Computer Vision & CNN Architectures | **Rank**: #910 of 1072 | **Points**: 40 XP

## Overview

Apply standard photometric jittering by scaling contrast and shifting brightness while enforcing dynamic range clamping.

## Task

Implement `adjust_brightness_contrast(...)`. For each pixel value `p`, compute `p_new = max(min_val, min(max_val, alpha * p + beta))`. Round each transformed pixel value to 4 decimal places and return the 2D grid.

<PracticePlayground problemId="cv-cnn-prob-20" />

<Solution>

```python
def adjust_brightness_contrast(image: list[list[float]], alpha: float, beta: float, min_val: float = 0.0, max_val: float = 255.0) -> list[list[float]]:
    out = []
    for row in image:
        new_row = []
        for val in row:
            adj = alpha * val + beta
            clamped = max(min_val, min(max_val, adj))
            new_row.append(round(clamped, 4))
        out.append(new_row)
    return out
```

Linear scaling by alpha modifies the dynamic contrast range, and beta offsets overall brightness prior to clamping.
