# Feature Store Cache TTL Expiry Check

**Track**: MLOps & Data Systems | **Points**: 40 XP

## Overview

Implement TTL expiry checking for an online feature store's cache -- deciding whether a cached feature value is fresh enough to serve or needs recomputation.

## Task

Implement `is_feature_expired(cached_at_ts, current_ts, ttl_seconds)`: return `True` if `(current_ts - cached_at_ts) >= ttl_seconds`, else `False`.
