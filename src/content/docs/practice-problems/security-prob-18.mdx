# Role-Based Access Control Check

**Track**: Agent Security & Reliability | **Points**: 40 XP

## Overview

Implement role-based access control checking, the real, standard mechanism gating which agent actions a given user's role may authorize.

## Task

Implement `rbac_allows(user_role, required_permission, role_permissions)`: return `True` if `user_role` is a key in `role_permissions` AND `required_permission` is in that role's permission list.
