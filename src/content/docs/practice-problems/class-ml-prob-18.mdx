## Overview

Optimize linear regression weights using batch gradient descent.

## Task

Implement `batch_gradient_descent_linear(X, y, lr, epochs)`: start with zero weights, iteratively compute predictions `X*w`, errors `pred - y`, and gradient `(2/n) * X^T * err`, updating weights each epoch.

```python
def batch_gradient_descent_linear(X, y, lr, epochs):
    n_features = len(X[0])
    w = [0.0] * n_features
    n = len(X)
    for _ in range(epochs):
        grads = [0.0] * n_features
        for i in range(n):
            pred = sum(X[i][j] * w[j] for j in range(n_features))
            err = pred - y[i]
            for j in range(n_features):
                grads[j] += err * X[i][j]
        for j in range(n_features):
            w[j] -= lr * (2.0 / n) * grads[j]
    return [round(val, 4) for val in w]
```
