# #767. Vectorized Householder Reflection Transformation

**Track**: NumPy & Vectorized Computation | **Rank**: #767 of 1072 | **Points**: 90 XP

## Overview

Apply an elementary Householder reflection to a vector without explicitly building the full projection matrix.

## Task

Implement `apply_householder_reflection(v, x)`: compute `H x = x - 2 * (v^T x / v^T v) * v`. If `v^T v < 1e-12`, return `x`. Round entries of the reflected vector to 4 decimals.

<PracticePlayground problemId="numpy-vec-prob-27" />

<Solution>

```python
def apply_householder_reflection(v, x):
    dot_vv = sum(a * a for a in v)
    if dot_vv < 1e-12:
        return [round(float(a), 4) for a in x]
    scalar = 2.0 * sum(a * b for a, b in zip(v, x)) / dot_vv
    return [round(float(a - scalar * b), 4) for a, b in zip(x, v)]
```

Directly computes the linear combination x - 2*(v.x/v.v)*v in O(n) time.

</Solution>
