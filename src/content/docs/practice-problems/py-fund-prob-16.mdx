## Overview

Merge two independently sorted lists into a unified sorted sequence in linear time.

## Task

Implement `merge_sorted_streams(stream1, stream2)`: given two sorted integer lists in non-decreasing order, merge them into a single sorted list using a two-pointer scan. Must run in O(len(stream1) + len(stream2)) time.

<Solution>

```python
def merge_sorted_streams(stream1, stream2):
    i, j = 0, 0
    merged = []
    while i < len(stream1) and j < len(stream2):
        if stream1[i] <= stream2[j]:
            merged.append(stream1[i])
            i += 1
        else:
            merged.append(stream2[j])
            j += 1
    if i < len(stream1):
        merged.extend(stream1[i:])
    if j < len(stream2):
        merged.extend(stream2[j:])
    return merged
```

Advancing pointers simultaneously produces an O(n + m) sorted union without full sorting recomputation.
