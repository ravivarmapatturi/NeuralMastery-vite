# Degree Centrality Computation

**Track**: Knowledge Graph & GraphRAG | **Points**: 40 XP

## Overview

Implement degree centrality, the simplest real graph-importance metric used to rank which entities in a knowledge graph are most connected.

## Task

Implement `degree_centrality(graph)` for a directed graph. Each node's degree is its OUT-degree (`len(graph[node])`) PLUS its IN-degree (count of other nodes whose adjacency list contains it). Return a dict of node -> total degree, covering every node that appears anywhere (as a key or in any adjacency list).
