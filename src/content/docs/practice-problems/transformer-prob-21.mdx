# #021. Transformer Internals Module 5: Problem 21

**Track**: Transformer Internals | **Rank**: #21 of 1072 | **Points**: 60 XP

## Overview

Perform one step of Beam Search decoding across candidate token hypotheses. Beam search expands each active beam hypothesis with candidate tokens, scores cumulative log-probabilities, and retains the top `beam_width` sequences.

## Task

Implement `beam_search_step(beam_scores, log_probs, beam_width)`: for each existing beam score `beam_scores[b]` and candidate next-token log-probability `log_probs[b][v]`, compute candidate score `beam_scores[b] + log_probs[b][v]`. Return the top `beam_width` candidates as a list of `(new_score, beam_index, token_index)` tuples sorted in descending order of score.
