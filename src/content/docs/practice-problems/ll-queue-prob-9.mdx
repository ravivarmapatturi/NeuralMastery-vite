# #569. Linked Lists / Stacks / Queues Module 2: Problem 9

**Track**: Linked Lists / Stacks / Queues | **Rank**: #569 of 1072 | **Points**

## Overview

Design a stack that retrieves the current minimum element in constant O(1) time.

## Task

Implement `min_stack_ops(operations)`: simulate a stack supporting operations `push`, `pop`, `top`, and `get_min`. Each must operate in O(1) time. Return a list of results for all `top` and `get_min` operations.

<PracticePlayground problemId="ll-queue-prob-9" />

<Solution>

```python
def min_stack_ops(operations):
    stack = []
    min_stack = []
    out = []
    for op in operations:
        action = op.get('op')
        if action == 'push':
            v = op.get('val')
            stack.append(v)
            min_stack.append(min(v, min_stack[-1]) if min_stack else v)
        elif action == 'pop':
            if stack:
                stack.pop()
                min_stack.pop()
        elif action == 'top':
            out.append(stack[-1] if stack else None)
        elif action == 'get_min':
            out.append(min_stack[-1] if min_stack else None)
    return out
```

Maintaining parallel value and prefix-minimum stacks guarantees constant O(1) query time for get_min.
