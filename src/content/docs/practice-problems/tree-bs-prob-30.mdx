# #620. Trees / Binary Search Module 6: Problem 30

**Track**: Trees / Binary Search | **Rank**: #620 of 1072 | **Points**

## Overview

Identify the two node values in a corrupted Binary Search Tree that were accidentally swapped.

## Task

Implement `find_swapped_values_bst(root)`: perform an inorder traversal to detect the inversion(s) where `prev["val"] > curr["val"]`. Return the two inverted values [min_val, max_val].

<Solution>

```python
def find_swapped_values_bst(root):
    first, second, prev = None, None, None
    curr = root
    stack = []
    while stack or curr:
        while curr:
            stack.append(curr)
            curr = curr.get('left')
        curr = stack.pop()
        if prev and prev['val'] > curr['val']:
            if not first:
                first = prev
                second = curr
            else:
                second = curr
        prev = curr
        curr = curr.get('right')
    res = [first['val'], second['val']]
    res.sort()
    return res
```

Perform an iterative inorder traversal. An error creates one or two inversions where `prev.val > curr.val`. The first mistake is prev and the second mistake is curr.
