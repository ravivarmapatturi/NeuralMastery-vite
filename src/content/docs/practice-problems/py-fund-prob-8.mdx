# #508. Python & Programming Fundamentals Module 2: Problem 8

**Track**: Python & Programming Fundamentals | **Rank**: #508 of 1072 | **Points**

## Overview

Verify whether an array is monotonic (monotonically non-decreasing or non-increasing).

## Task

Implement `is_monotonic(nums)`: return `True` if `nums` is monotonic (either all elements satisfy `nums[i] <= nums[i+1]` or all satisfy `nums[i] >= nums[i+1]`), and `False` otherwise. Arrays of length 2 or fewer are always monotonic.

<PracticePlayground problemId="py-fund-prob-8" />

<Solution>

```python
def is_monotonic(nums):
    if len(nums) <= 2:
        return True
    increasing = True
    decreasing = True
    for i in range(len(nums) - 1):
        if nums[i] > nums[i + 1]:
            increasing = False
        if nums[i] < nums[i + 1]:
            decreasing = False
    return increasing or decreasing
```

Checking adjacent direction changes simultaneously validates monotonicity in a single O(n) pass.

</Solution>
