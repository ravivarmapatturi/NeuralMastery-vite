# #049. JSON Structure Token Filter

**Track**: LLM Inference & Decoding | **Rank**: #49 of 1072 | **Points**: 60 XP

## Overview

Guarantee syntactically valid JSON output by validating bracket and quote balance across candidate tokens. Autoregressive language models generate sequences token by token, evaluating next-token probability distributions at each decoding step.

## Task

Implement `filter_valid_json_tokens(partial_json, candidate_tokens)`. For each candidate token, evaluate whether `partial_json + candidate_token` preserves structural validity: track string literal state (toggled by unescaped `"` and respecting `\\` escapes) and verify delimiter matching (`{` with `}` and `[` with `]`). Reject any candidate that closes an unopened delimiter or mismatches closing bracket types when outside of a string literal. Return the list of valid candidate tokens in their original order.
