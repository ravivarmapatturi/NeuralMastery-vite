## Overview

Partition collections into binary truth buckets via named predicate dispatch.

## Task

Implement `group_by_predicate(items, predicate_name)`: partition `items` into `{"true": [...], "false": [...]}` based on named rules: `"is_even"` (integers with `item % 2 == 0`), `"is_positive"` (numeric values with `item > 0`), and `"is_nonempty_str"` (strings with `len(item) > 0`). Preserves order within partitioned lists.

<Solution>

```python
def group_by_predicate(items, predicate_name):
    groups = {'true': [], 'false': []}
    for item in items:
        val = False
        if predicate_name == 'is_even':
            val = (isinstance(item, int) and item % 2 == 0)
        elif predicate_name == 'is_positive':
            val = (isinstance(item, (int, float)) and item > 0)
        elif predicate_name == 'is_nonempty_str':
            val = (isinstance(item, str) and len(item) > 0)
        if val:
            groups['true'].append(item)
        else:
            groups['false'].append(item)
    return groups
```

Type-safe conditional dispatch routes items into distinct truth partitions in a single O(n) pass.
