# #669. Dynamic Programming & Greedy Module 4: Problem 19

**Track**: Dynamic Programming & Greedy | **Rank**: #669 of 1072 | **Points**

## Overview

Find the starting gas station to complete a clockwise circuit in O(n) time using greedy prefix balance tracking.

## Task

Implement `gas_station_start(gas, cost)`: if `sum(gas) < sum(cost)`, return -1. Otherwise whenever current fuel tank drops below 0, reset start to i + 1 and curr_tank to 0.

<PracticePlayground problemId="dp-greedy-prob-19" />

<Solution>

```python
def gas_station_start(gas, cost):
    total_tank = 0
    curr_tank = 0
    start_station = 0
    for i in range(len(gas)):
        diff = gas[i] - cost[i]
        total_tank += diff
        curr_tank += diff
        if curr_tank < 0:
            start_station = i + 1
            curr_tank = 0
    return start_station if total_tank >= 0 else -1
```

Track total net gas and current tank balance. If current tank dips below zero, all stations up to current cannot be starting points, so advance start station to i + 1.
