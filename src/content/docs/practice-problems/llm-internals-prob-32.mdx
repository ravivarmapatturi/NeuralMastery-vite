# Min-P Sampling Probability Threshold Filter

**Track**: transformers-llms | **Points**: 40 XP

## Overview

Filter candidate next tokens using Min-P dynamic thresholding relative to top token probability.

## Task

Implement `min_p_filter(probs, min_p=0.05)` which determines the cutoff `threshold = min_p * max(probs)`. Returns original indices of all tokens with `prob >= threshold`, sorted in descending order of their probability. Return empty list if `probs` is empty.
