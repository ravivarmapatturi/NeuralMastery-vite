# #040. Multi-Condition Stopping Criteria

**Track**: LLM Inference & Decoding | **Rank**: #40 of 1072 | **Points**: 40 XP

## Overview

Evaluate multifaceted termination criteria during autoregressive token generation. Autoregressive language models generate sequences token by token, evaluating next-token probability distributions at each decoding step.

## Task

Implement `check_stopping_criteria(generated_tokens, stop_token_ids, stop_sequences, max_tokens)`. Check termination conditions in priority order: (1) if the last token in `generated_tokens` is in `stop_token_ids`, return `should_stop: True`, `reason: 'stop_token'`, `matched_sequence: [last_token]`; (2) if any sequence in `stop_sequences` matches the suffix of `generated_tokens`, return `should_stop: True`, `reason: 'stop_sequence'`, `matched_sequence: sequence`; (3) if `len(generated_tokens) >= max_tokens`, return `should_stop: True`, `reason: 'max_tokens'`, `matched_sequence: None`. Otherwise return `should_stop: False`, `reason: None`, `matched_sequence: None`. If `max_tokens <= 0`, raise `ValueError`.
