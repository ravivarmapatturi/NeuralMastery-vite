# Token-Level F1 Score for Answer Matching

**Track**: Agent Evaluation & Observability | **Points**: 40 XP

## Overview

Implement token-level F1 score, the standard soft-matching metric (as used in SQuAD-style QA evaluation) for comparing a free-text agent answer against a reference answer.

## Task

Implement `token_f1(prediction, reference)`. Tokenize both (lowercase, split on whitespace). Compute the multiset intersection of tokens (a token appearing twice in both counts as 2 shared). `precision = shared/len(pred_tokens)`, `recall = shared/len(ref_tokens)`. Return `2*precision*recall/(precision+recall)`, or `0.0` if either token list is empty or precision+recall is 0.
