# #053. Multi-Query & Grouped-Query KV Footprint

**Track**: LLM Inference & Decoding | **Rank**: #53 of 1072 | **Points**: 90 XP

## Overview

Quantify KV cache memory savings enabled by Grouped-Query Attention (GQA) and Multi-Query Attention (MQA). Autoregressive language models generate sequences token by token, evaluating next-token probability distributions at each decoding step.

## Task

Implement `calculate_kv_cache_memory(num_layers, seq_len, batch_size, hidden_dim, num_query_heads, num_kv_heads, dtype_bytes=2)`. Compute head dimension `d_k = \text{hidden\_dim} / \text{num\_query\_heads}`. KV elements per token across all layers is `2 \times \text{num\_layers} \times \text{num\_kv\_heads} \times d_k`. Total cache bytes is elements `\times \text{batch\_size} \times \text{seq\_len} \times \text{dtype\_bytes}`. Compute baseline MHA cache size where `\text{num\_kv\_heads} = \text{num\_query\_heads}`. Calculate `memory_savings_percent` as `(1.0 - \text{total\_kv\_bytes} / \text{mha\_baseline}) \times 100.0`, rounded to 2 decimal places. Raise `ValueError` if arguments are non-positive or if dimensions are not cleanly divisible.
