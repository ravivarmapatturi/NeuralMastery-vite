# #742. Vectorized Matrix Kronecker Product

**Track**: NumPy & Vectorized Computation | **Rank**: #742 of 1072 | **Points**: 40 XP

## Overview

Compute the tensor block Kronecker product between two matrices.

## Task

Implement `kronecker_product(A, B)`: given matrix `A` of shape `(m, n)` and matrix `B` of shape `(p, q)`, return their Kronecker product `A (x) B` of shape `(m*p, n*q)` where block `(i, j)` is `A[i][j] * B`. Round entries to 4 decimals.

<PracticePlayground problemId="numpy-vec-prob-2" />

<Solution>

```python
def kronecker_product(A, B):
    m, n = len(A), len(A[0])
    p, q = len(B), len(B[0])
    res = [[round(float(A[i][j] * B[k][l]), 4) for j in range(n) for l in range(q)] for i in range(m) for k in range(p)]
    return res
```

Each entry of A scales matrix B into an expanded sub-block.

</Solution>
