# Graphs: Clone Graph

## Overview

Implement `clone_graph(adj, start)` -- graph cloning via BFS. The adjacency-list representation makes both DFS and BFS solutions straightforward.

## Task

Implement the function `clone_graph(adj, start)`. `adj` is a dict `{node_id: [neighbor_ids]}`. Return a new adjacency dict that is a deep clone.

<Solution>

```python
from collections import deque

def clone_graph(adj, start):
    if not adj:
        return {}
    cloned = {}
    q = deque([start])
    cloned[start] = []
    while q:
        node = q.popleft()
        for nbr in adj[node]:
            if nbr not in cloned:
                cloned[nbr] = []
                q.append(nbr)
            cloned[node].append(nbr)
    return cloned
```

BFS from start, building the cloned adjacency list. Track visited nodes in `cloned` to avoid revisiting. O(V+E) time and space.
