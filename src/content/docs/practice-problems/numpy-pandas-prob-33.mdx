# Streaming systems Module 33: Problem 213

**Rank #213** · Difficulty: **Medium** · Stage: **Stage 4: NumPy & Vectorized Data Processing** · Category: **NumPy & Pandas**

## Overview

Identify heavy hitters in a streaming sequence using the Misra-Gries summary algorithm.

## Task

Implement `misra_gries_frequent_items(stream, k)`: maintain a dictionary of at most `k - 1` tracked candidates. If item exists, increment count. Else if size `<` `k - 1`, insert with count 1. Else decrement all counts by 1, removing any reaching 0. Return the final candidate dictionary.

<PracticePlayground problemId="numpy-pandas-prob-33" />

<Solution>

```python
def misra_gries_frequent_items(stream, k):
    counts = {}
    cap = k - 1
    for item in stream:
        if item in counts:
            counts[item] += 1
        elif len(counts) < cap:
            counts[item] = 1
        else:
            to_delete = []
            for key in list(counts.keys()):
                counts[key] -= 1
                if counts[key] == 0:
                    to_delete.append(key)
            for key in to_delete:
                del counts[key]
    return counts
```

Misra-Gries guarantees that any item occurring more than N/k times in a stream of N elements will remain in the candidate set.

</Solution>
