## Overview

Count vowels and consonants across text strings ignoring non-alphabetic symbols.

## Task

Implement `count_vowels_and_consonants(text)`: scan `text` and return `{"vowels": v, "consonants": c}` where `v` is the count of vowels (a, e, i, o, u case-insensitive) and `c` is the count of alphabetic consonants. Digits, whitespace, and punctuation are ignored.

<PracticePlayground problemId="py-fund-prob-1" />

<Solution>

```python
def count_vowels_and_consonants(text):
    vowels = set("aeiouAEIOU")
    v_count = 0
    c_count = 0
    for ch in text:
        if ch.isalpha():
            if ch in vowels:
                v_count += 1
            else:
                c_count += 1
    return {'vowels': v_count, 'consonants': c_count}
```

Testing character membership against an O(1) set yields a linear time pass over the string.
