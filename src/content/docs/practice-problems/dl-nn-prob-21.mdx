# #881. Binary Focal Loss Calculation

**Track**: Deep Learning & Neural Networks | **Rank**: #881 of 1072 | **Points**: 60 XP

## Overview

Down-weight easy examples and focus learning on hard negatives using Lin et al.'s Focal Loss.

## Task

Implement `focal_loss_binary(y_pred, y_true, alpha=0.25, gamma=2.0, eps=1e-7)`: for each sample, define `p_t = p` if `y == 1` else `1 - p`, and `alpha_t = alpha` if `y == 1` else `1 - alpha`. Clamp `p_t` into `[eps, 1.0 - eps]`. The focal loss is `FL(p_t) = -alpha_t * (1 - p_t)^gamma * log(p_t)`. Return the mean across `N` samples rounded to 4 decimal places.

```python
def focal_loss_binary(y_pred: list[float], y_true: list[float], alpha: float = 0.25, gamma: float = 2.0, eps: float = 1e-7) -> float:
    N = len(y_pred)
    total = 0.0
    for p, y in zip(y_pred, y_true):
        p_c = max(min(p, 1.0 - eps), eps)
        if y == 1.0:
            p_t = p_c
            alpha_t = alpha
        else:
            p_t = 1.0 - p_c
            alpha_t = 1.0 - alpha
        loss_i = -alpha_t * ((1.0 - p_t) ** gamma) * math.log(p_t)
        total += loss_i
    return round(total / N, 4)
```

Focal Loss applies a dynamic modulating factor that prevents easily classified background examples from overwhelming the gradient during dense detection.
