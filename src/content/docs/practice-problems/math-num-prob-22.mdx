# #732. Nesterov Accelerated Gradient Step

**Track**: Mathematics & Numerical Computing | **Rank**: #732 of 1072 | **Points**: 60 XP

## Overview

Apply Nesterov accelerated gradient update using lookahead gradient evaluation.

## Task

Implement `nesterov_momentum_step(w, grad_lookahead, v, lr=0.01, beta=0.9)`: given the gradient evaluated at the lookahead point `w - beta * v`, calculate `v_next = beta * v + lr * grad_lookahead` and `w_next = w - v_next`. Return `{"w": list[float], "v": list[float]}` rounded to 4 decimals.

<PracticePlayground problemId="math-num-prob-22" />

<Solution>

```python
def nesterov_momentum_step(w, grad_lookahead, v, lr=0.01, beta=0.9):
    v_next = [beta * vi + lr * gi for vi, gi in zip(v, grad_lookahead)]
    w_next = [wi - v_ni for wi, v_ni in zip(w, v_next)]
    return {'w': [round(float(x), 4) for x in w_next], 'v': [round(float(x), 4) for x in v_next]}
```

Applies lookahead gradient correction to suppress momentum overshoot.
