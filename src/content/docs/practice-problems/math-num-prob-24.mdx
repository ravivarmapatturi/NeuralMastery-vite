# #734. RMSprop Exponential Moving Average Step

**Track**: Mathematics & Numerical Computing | **Rank**: #734 of 1072 | **Points**: 60 XP

## Overview

Apply leaky exponential moving average scaling to prevent AdaGrad's diminishing learning rates.

## Task

Implement `rmsprop_step(w, grad, v, lr=0.001, beta=0.9, eps=1e-8)`: update variance `v_next[i] = beta * v[i] + (1 - beta) * grad[i]^2` and weights `w_next[i] = w[i] - (lr / (sqrt(v_next[i]) + eps)) * grad[i]`. Return `{"w": list[float], "v": list[float]}` rounded to 4 decimals.

<Solution>

```python
import math

def rmsprop_step(w, grad, v, lr=0.001, beta=0.9, eps=1e-8):
    v_next = [beta * vi + (1.0 - beta) * (g ** 2) for vi, g in zip(v, grad)]
    w_next = [wi - (lr / (math.sqrt(vi_n) + eps)) * g for wi, vi_n, g in zip(w, v_next, grad)]
    return {'w': [round(float(x), 4) for x in w_next], 'v': [round(float(x), 4) for x in v_next]}
```

Weights recent squared gradients exponentially heavier to maintain responsive step sizes.
