# Correlate Metric Anomaly With Deploy Event

**Track**: Agent Evaluation & Observability | **Points**: 40 XP

## Overview

Implement deploy-correlation checking, a real, first diagnostic step whenever an observability system flags an anomaly -- was this caused by a recent deploy, or something else entirely.

## Task

Implement `anomaly_correlates_with_deploy(anomaly_ts, deploy_timestamps, correlation_window_s)`: return `True` if ANY deploy timestamp is within `correlation_window_s` BEFORE `anomaly_ts` (i.e. `0 <= anomaly_ts - deploy_ts <= correlation_window_s`).
