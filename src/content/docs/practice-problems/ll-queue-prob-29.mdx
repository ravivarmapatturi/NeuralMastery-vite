## Overview

Compute the maximal rectangular area bounding contiguous histogram columns in strict linear time.

## Task

Implement `largest_rectangle_area(heights)`: find the area of the largest rectangle that can be formed within the given histogram bar heights. Must run in O(n) time using a monotonic increasing stack.

<PracticePlayground problemId="ll-queue-prob-29" />

<Solution>

```python
def largest_rectangle_area(heights):
    stack = []
    max_area = 0
    extended = heights + [0]
    for i, h in enumerate(extended):
        while stack and extended[stack[-1]] > h:
            top_h = extended[stack.pop()]
            width = i if not stack else i - stack[-1] - 1
            max_area = max(max_area, top_h * width)
        stack.append(i)
    return max_area
```

Popping bars strictly taller than the current index discovers their maximal left and right boundaries in O(n) amortized steps.
