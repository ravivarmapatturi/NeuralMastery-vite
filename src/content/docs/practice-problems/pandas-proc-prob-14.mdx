# #784. Deterministic Stratified Data Partitioning

**Track**: Pandas & Data Processing Pipelines | **Rank**: #784 of 1072 | **Points**: 60 XP

## Overview

Partition dataset indices into train, validation, and test subsets while preserving exact categorical class balance.

## Task

Implement `stratified_split_dataset(labels, train_ratio, val_ratio)`: group sample indices by unique label. For each class `c`, allocate `n_train = round(n * train_ratio)` and `n_val = round(n * val_ratio)` (ensuring `n_train + n_val <= n`), with the remainder placed in `test`. Combine and sort indices. Return `{"train": list[int], "validation": list[int], "test": list[int]}`.

```python
from collections import defaultdict

def stratified_split_dataset(labels, train_ratio=0.7, val_ratio=0.15):
    class_map = defaultdict(list)
    for i, l in enumerate(labels):
        class_map[l].append(i)
    train, val, test = [], [], []
    for l in sorted(class_map.keys()):
        idxs = class_map[l]
        n = len(idxs)
        nt = int(round(n * train_ratio))
        nv = int(round(n * val_ratio))
        if nt + nv > n: nv = n - nt
        train.extend(idxs[:nt])
        val.extend(idxs[nt:nt + nv])
        test.extend(idxs[nt + nv:])
    return {'train': sorted(train), 'validation': sorted(val), 'test': sorted(test)}
```

Splits each class independently according to requested proportions and aggregates sorted indices.
