# Detect Anomalous Tool Call Frequency Spike

**Track**: Agent Security & Reliability | **Points**: 40 XP

## Overview

Implement z-score-based anomaly detection on tool-call frequency, a real statistical guardrail for catching an agent that's gone into an unexpected runaway calling pattern.

## Task

Implement `is_frequency_anomalous(current_rate, baseline_mean, baseline_std, z_threshold)`. Compute `z = (current_rate - baseline_mean) / baseline_std` (return `False` if `baseline_std` is 0 and `current_rate == baseline_mean`, else treat any nonzero deviation with zero std as anomalous). Return `True` if `abs(z) > z_threshold`.
