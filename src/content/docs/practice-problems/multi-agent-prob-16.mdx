# Gossip Protocol Convergence Check

**Track**: Multi-Agent Systems | **Points**: 40 XP

## Overview

Implement gossip-protocol convergence detection: whether all nodes' locally-averaged values have settled close enough to agree.

## Task

Implement `has_converged(node_values, tolerance)`: return `True` if `(max(node_values.values()) - min(node_values.values())) <= tolerance`, else `False`.
