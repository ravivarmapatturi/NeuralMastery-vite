# Count Item Frequencies

**Rank #1** · Difficulty: **Easy** · Stage: **Stage 1: AI Foundations & Python Programming** · Category: **Python & Fundamentals** | **Points**: 40 XP

## Overview

Implement `count_frequencies(items)`, counting occurrences of elements in a list using a dictionary -- the foundational primitive behind token counting, vocabulary construction, and categorical frequency analysis in machine learning.

## Task

Implement the function `count_frequencies(items)`: return a dictionary mapping each distinct item in `items` to the number of times it appears. If `items` is empty, return an empty dictionary `{}`.

<PracticePlayground problemId="py-foundations-prob-1" />

<Solution>

```python
def count_frequencies(items):
    freq = {}
    for item in items:
        freq[item] = freq.get(item, 0) + 1
    return freq
```

Counting frequencies is the core building block for vocabulary building, TF-IDF, bag-of-words representations, and categorical probability distributions.

</Solution>
