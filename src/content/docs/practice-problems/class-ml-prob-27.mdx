## Overview

Identify density-reachable core points in spatial datasets under the DBSCAN definition.

## Task

Implement `dbscan_core_points(X, eps, min_samples)`: for each point i, count how many points lie within Euclidean distance eps. If , point i is a core point.

<PracticePlayground problemId="class-ml-prob-27" />

<Solution>

```python
def dbscan_core_points(X, eps, min_samples):
    core_points = []
    eps_sq = eps ** 2
    for i, p1 in enumerate(X):
        count = sum(1 for p2 in X if sum((a - b) ** 2 for a, b in zip(p1, p2)) <= eps_sq)
        if count >= min_samples:
            core_points.append(i)
    return core_points
```

Measure Euclidean distance from each candidate point to all other points. If the cardinality of the eps-ball equals or exceeds min_samples, designate it as a core point.
