# Temporal Fact Validity Check

**Track**: Knowledge Graph & GraphRAG | **Points**: 40 XP

## Overview

Implement temporal fact-validity checking, a real requirement for a knowledge graph that must model facts changing over time (e.g. 'CEO of X' has a different value at different points in history).

## Task

Implement `is_fact_valid_at(valid_from, valid_to, query_time)`. `valid_to` is either a float or `None` (meaning 'still currently valid, no end date'). Return `True` if `valid_from <= query_time` AND (`valid_to is None` OR `query_time < valid_to`).
