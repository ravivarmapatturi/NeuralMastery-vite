# #772. Multi-Column Conditional Imputation Pipeline

**Track**: Pandas & Data Processing Pipelines | **Rank**: #772 of 1072 | **Points**: 40 XP

## Overview

Impute missing values across heterogeneous tabular columns using column-specific statistical aggregations.

## Task

Implement `impute_dataframe_columns(records, strategies)`: for each column in `strategies`, compute the fill value from non-null values. Supported strategies: `'mean'` (arithmetic average), `'median'` (50th percentile), and `'mode'` (most frequent value; tie break by lexicographically smallest). Replace missing / `None` values and return updated records.

```python
from collections import defaultdict

def impute_dataframe_columns(records, strategies):
    fill_values = {}
    for col, strat in strategies.items():
        vals = [r[col] for r in records if col in r and r[col] is not None]
        if strat == 'mean':
            fill_values[col] = round(float(sum(vals) / len(vals)), 4) if vals else 0.0
        elif strat == 'median':
            s = sorted(vals)
            n = len(s)
            fill_values[col] = round(float(s[n//2] if n % 2 == 1 else (s[n//2 - 1] + s[n//2]) / 2.0), 4) if vals else 0.0
        elif strat == 'mode':
            counts = defaultdict(int)
            for v in vals: counts[v] += 1
            fill_values[col] = min(counts.keys(), key=lambda k: (-counts[k], k)) if vals else None
    out = []
    for r in records:
        row = dict(r)
        for col, fv in fill_values.items():
            if col not in row or row[col] is None:
                row[col] = fv
        out.append(row)
    return out
```

Precomputes summary metrics across valid column entries and fills missing entries.
