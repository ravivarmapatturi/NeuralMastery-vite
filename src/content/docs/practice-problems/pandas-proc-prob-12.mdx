# #782. Nested JSON Schema Flattening Engine

**Track**: Pandas & Data Processing Pipelines | **Rank**: #782 of 1072 | **Points**: 60 XP

## Overview

Recursively flatten hierarchical nested JSON trees into normalized 1D relational column schemas.

## Task

Implement `flatten_json_payload(payload, sep)`: recursively traverse `payload`. Concatenate parent and child dictionary keys joined by delimiter `sep` (e.g. `'user_profile_city'`). Primitive values (ints, floats, strings, booleans, lists) are assigned directly. Return flattened key-value dictionary.

<PracticePlayground problemId="pandas-proc-prob-12" />

<Solution>

```python
def flatten_json_payload(payload, sep='_'):
    flat = {}
    def recurse(d, prefix=''):
        for k in sorted(d.keys()):
            v = d[k]
            new_k = f'{prefix}{sep}{k}' if prefix else k
            if isinstance(v, dict):
                recurse(v, new_k)
            else:
                flat[new_k] = v
    recurse(payload)
    return flat
```

Recursively expands nested key paths and builds flattened relational record.
