# Advanced DS: Design Twitter (Simplified Feed)

**Rank #105** · Difficulty: **Medium** · Stage: **Stage 2: Data Structures & Algorithmic Foundations** · Category: **Data Structures & Algorithms**

## Overview

Implement a simplified Twitter-style feed -- a practical application of heaps, hash maps, and ordered event streams. The full solution uses a k-way merge heap for O(10 log k) getNewsFeed.

## Task

Implement the function `twitter_ops(operations)`. Simulate Twitter with `postTweet(userId, tweetId)`, `getNewsFeed(userId)` (10 most recent from self+followees), `follow`, and `unfollow`.

<Solution>

```python
def twitter_ops(operations):
    time_counter = [0]
    tweets = {}    # userId -> [(timestamp, tweetId)]
    following = {} # userId -> set of followeeIds

    def post_tweet(userId, tweetId):
        if userId not in tweets:
            tweets[userId] = []
        tweets[userId].append((time_counter[0], tweetId))
        time_counter[0] += 1

    def get_news_feed(userId):
        followees = following.get(userId, set()) | {userId}
        all_tweets = []
        for uid in followees:
            all_tweets.extend(tweets.get(uid, []))
        all_tweets.sort(key=lambda x: -x[0])
        return [tid for _, tid in all_tweets[:10]]

    def follow(followerId, followeeId):
        if followerId not in following:
            following[followerId] = set()
        following[followerId].add(followeeId)

    def unfollow(followerId, followeeId):
        if followerId in following:
            following[followerId].discard(followeeId)

    results = []
    for op in operations:
        name = op[0]
        if name == 'postTweet':
            post_tweet(op[1], op[2])
            results.append(None)
        elif name == 'getNewsFeed':
            results.append(get_news_feed(op[1])[:10])
        elif name == 'follow':
            follow(op[1], op[2])
            results.append(None)
        elif name == 'unfollow':
            unfollow(op[1], op[2])
            results.append(None)
    return results
```

Store tweets with timestamps; getNewsFeed merges all followee tweet lists and sorts by recency, taking top 10. For large scale: a k-way merge heap on per-user iterators gives O(10 log k) per query.
