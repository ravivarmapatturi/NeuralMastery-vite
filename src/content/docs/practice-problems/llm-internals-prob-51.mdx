# Estimate Memory Saved by Gradient Checkpointing

**Track**: Transformers & LLMs | **Points**: 40 XP

## Overview

Implement a real gradient-checkpointing memory-savings estimate, quantifying the actual memory/compute tradeoff of not storing every layer's activations for backpropagation.

## Task

Implement `checkpointing_memory_saved(num_layers, activation_mb_per_layer, checkpoint_every_n)`. Without checkpointing, all `num_layers` layers' activations are stored. With checkpointing, only every `checkpoint_every_n`-th layer's activations are kept: `kept_layers = ceil(num_layers / checkpoint_every_n)`. Return `(num_layers - kept_layers) * activation_mb_per_layer` (the MB saved).
