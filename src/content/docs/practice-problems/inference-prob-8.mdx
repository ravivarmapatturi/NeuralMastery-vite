# #038. Typical Sampling Filtering

**Track**: LLM Inference & Decoding | **Rank**: #38 of 1072 | **Points**: 40 XP

## Overview

Select tokens whose information content matches the conditional entropy of the model using Typical Sampling. Autoregressive language models generate sequences token by token, evaluating next-token probability distributions at each decoding step.

## Task

Implement `typical_sampling_filter(logits, mass, filter_value=-float('inf'))`. Compute softmax probabilities `P`. Compute sequence entropy `H = -\sum P_i \log_2 P_i`. For each token, compute deviation `\Delta_i = |-\log_2 P_i - H|`. Sort tokens ascending by `\Delta_i` (breaking ties by lower index). Accumulate tokens until cumulative probability is `\ge mass`. Mask unselected tokens with `filter_value`. If `mass \le 0.0` or `mass > 1.0`, raise `ValueError`.
