# Compute BLEU-1 Score with Brevity Penalty

**Track**: transformers-llms | **Points**: 40 XP

## Overview

Implement unigram BLEU score with exponential Brevity Penalty to evaluate machine translation and generation conciseness.

## Task

Implement `compute_bleu_1(reference, candidate)`. Calculate modified unigram precision `p_1` and brevity penalty `BP = exp(1 - r/c)` when `c <= r` (`1.0` if `c > r`). Return `BLEU = BP * p_1` rounded to 4 decimal places.
