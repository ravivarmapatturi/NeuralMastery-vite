# Streaming Exponential Moving Average (EMA) Series

**Rank #186** · Difficulty: **Easy** · Stage: **Stage 4: NumPy & Vectorized Data Processing** · Category: **NumPy & Pandas**

Track real-time streaming series values with an online Exponential Moving Average filter. Prerequisite: `numpy-pandas-prob-5`.

<PracticePlayground problemId="numpy-pandas-prob-6" />

<Solution>

```python
def streaming_ema_series(stream, alpha):
    if not stream:
        return []
    res = [stream[0]]
    for x in stream[1:]:
        s_prev = res[-1]
        s_curr = alpha * x + (1.0 - alpha) * s_prev
        res.append(s_curr)
    return [round(float(x), 4) for x in res]
```

Online EMA maintains recursive state with O(1) space per update, enabling bounded-memory low-latency trend tracking over unbounded data streams.
