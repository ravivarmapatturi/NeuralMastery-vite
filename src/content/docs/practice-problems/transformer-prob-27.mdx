# #027. Transformer Internals Module 6: Problem 27

**Track**: Transformer Internals | **Rank**: #27 of 1072 | **Points**: 90 XP

## Overview

Estimate GPU memory consumption for Key-Value (KV) caches in autoregressive LLM inference deployments. Accurately budgeting KV cache memory is crucial for determining maximum concurrency and context window sizes on serving infrastructure.

## Task

Implement `kv_cache_memory_bytes(seq_len, num_layers, num_kv_heads, head_dim, precision_bytes=2)`: compute total KV cache memory as `2 * seq_len * num_layers * num_kv_heads * head_dim * precision_bytes` (accounting for both Key and Value tensors across all layers). Return the integer byte count.
