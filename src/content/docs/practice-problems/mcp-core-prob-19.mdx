# Coerce String Arguments to Declared Types

**Track**: MCP Core Engineering | **Points**: 40 XP

## Overview

Implement argument type coercion, converting a raw string-typed argument map (e.g. from a CLI or URL query) into the properly-typed values a tool's schema expects.

## Task

Implement `coerce_arguments(raw_args, schema)`. `schema` maps arg name -> target type (`'int'`,`'float'`,`'bool'`,`'str'`). For each key in `schema` present in `raw_args`, convert: `'int'`->`int(v)`, `'float'`->`float(v)`, `'bool'`-> `True` if `v.lower()=='true'` else `False`, `'str'`-> unchanged. Return the coerced dict (only keys present in both).
