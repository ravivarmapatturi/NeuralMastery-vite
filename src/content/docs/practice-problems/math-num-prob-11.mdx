# #721. Quadratic Form Gradient

**Track**: Mathematics & Numerical Computing | **Rank**: #721 of 1072 | **Points**: 60 XP

## Overview

Compute the exact analytical gradient vector of a multivariable quadratic objective.

## Task

Implement `quadratic_form_gradient(A, b, x)`: for symmetric matrix A and linear coefficient vector b, compute the gradient `nabla f(x) = A x - b`. Round each coordinate to 4 decimal places.

<PracticePlayground problemId="math-num-prob-11" />

<Solution>

```python
def quadratic_form_gradient(A, b, x):
    n = len(x)
    Ax = [sum(A[i][j] * x[j] for j in range(n)) for i in range(n)]
    grad = [Ax[i] - b[i] for i in range(n)]
    return [round(float(g), 4) for g in grad]
```

Computes matrix-vector product Ax and subtracts b according to vector calculus rules.
