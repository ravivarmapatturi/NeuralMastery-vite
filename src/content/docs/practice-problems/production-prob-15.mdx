# Retry Budget Enforcement

**Track**: Agent Performance & Production | **Points**: 40 XP

## Overview

Implement retry-budget enforcement, a real, system-wide safeguard preventing retries themselves from becoming the cause of an overload cascade during a partial outage.

## Task

Implement `has_retry_budget(retries_used, requests_in_window, max_retry_ratio)`: return `True` (retry allowed) if `requests_in_window == 0` OR `(retries_used / requests_in_window) < max_retry_ratio`.
