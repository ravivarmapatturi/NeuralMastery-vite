# NDCG@K Ranking Quality

**Track**: Clustering & Recommender Systems | **Points**: 40 XP

## Overview

Implement NDCG@K, the standard graded-relevance ranking metric used to evaluate recommendation and search result ordering.

## Task

Implement `ndcg_at_k(relevances, k)`. `relevances` is the list of relevance scores IN THE ORDER they were ranked/returned. DCG@k = `sum(rel_i / log2(i+2) for i in range(min(k,len(relevances))))` (0-indexed i). IDCG@k is the same formula applied to `relevances` sorted descending. Return `DCG/IDCG`, or `0.0` if IDCG is 0.
