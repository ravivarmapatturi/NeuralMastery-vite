**Track**: Linked Lists / Stacks / Queues | **Rank**: #584 of 1072 | **Points**: 90 XP

## Overview

Implement a real ring-buffer circular queue -- a fixed-size array where the logical front/rear positions wrap around via modular arithmetic, so enqueue/dequeue are O(1) with zero shifting and zero resizing.

## Task

Implement the function `run_circular_queue_ops(capacity, ops, args)`: simulate a fixed-capacity circular queue processing `enqueue`/`dequeue`/`front`/`rear`/`isEmpty`/`isFull` operations, returning one result per operation.
