## Overview

Aggregate 2D matrix elements column-wise along axis 0 in pure Python.

## Task

Implement `matrix_column_sums(matrix)`: given an `m x n` numerical matrix (list of row lists), compute the vertical sum of each column across all rows. Round results to 4 decimal places. Return `[]` if `matrix` is empty or has zero rows.

<PracticePlayground problemId="py-fund-prob-3" />

<Solution>

```python
def matrix_column_sums(matrix):
    if not matrix or not matrix[0]:
        return []
    cols = len(matrix[0])
    sums = [0.0] * cols
    for row in matrix:
        for c in range(cols):
            sums[c] += float(row[c])
    return [round(s, 4) for s in sums]
```

Accumulating column coordinates across rows executes in O(rows * cols) time with O(cols) memory.
