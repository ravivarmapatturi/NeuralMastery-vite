# Extract Most Relevant Sentence Span

**Track**: RAG Production Engineering | **Points**: 40 XP

## Overview

Implement extractive-span selection, picking the single most relevant sentence from a retrieved chunk to show as a highlighted snippet.

## Task

Implement `extractive_span(query, chunk_sentences)`. Tokenize `query` into a lowercase word set. For each sentence, score it by the count of query words it contains (lowercase word match). Return the sentence with the HIGHEST score; ties broken by earliest position in the list.
