# #746. Vectorized Softmax with Temperature Scaling

**Track**: NumPy & Vectorized Computation | **Rank**: #746 of 1072 | **Points**: 40 XP

## Overview

Apply temperature-scaled softmax normalization across batch logit matrices.

## Task

Implement `temperature_softmax(logits, temperature)`: for each row `x`, scale logits by `1 / temperature`, subtract the row maximum for numerical stability, exponentiate, and normalize by row sum. Round probabilities to 4 decimals.

<PracticePlayground problemId="numpy-vec-prob-6" />

<Solution>

```python
import math

def temperature_softmax(logits, temperature):
    out = []
    for row in logits:
        scaled = [x / temperature for x in row]
        m = max(scaled)
        exps = [math.exp(x - m) for x in scaled]
        s = sum(exps)
        out.append([round(float(e / s), 4) for e in exps])
    return out
```

Scales logits, shifts by max for stability, exponentiates and divides by sum.
