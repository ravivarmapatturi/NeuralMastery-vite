# Polynomial Feature Expansion

**Rank #249** · Difficulty: **Easy** · Stage: **Stage 5: Classical Machine Learning & Optimization** · Category: **Classical ML** | **Points**: 40 XP

## Overview

Implement `polynomial_features_deg2(x, include_bias=True)`, mapping input features into a higher-dimensional polynomial Hilbert space so linear models can capture non-linear relationships.

## Task

Implement `polynomial_features_deg2(x, include_bias=True)`: generate bias (if enabled), all first-order linear features, and all second-order combinations `x_i * x_j` in lexicographical order (`i <= j`).

<PracticePlayground problemId="classical-ml-prob-9" />

<Solution>

```python
def polynomial_features_deg2(x, include_bias=True):
    res = [1.0] if include_bias else []
    d = len(x)
    for val in x:
        res.append(float(val))
    for i in range(d):
        for j in range(i, d):
            res.append(round(x[i] * x[j], 6))
    return res
```

Polynomial expansion underlies the polynomial kernel trick in Support Vector Machines and basis function expansion in linear regression.

</Solution>
