# #195. Reciprocal Rank Fusion (RRF)

**Track**: RAG Fundamentals | **Rank**: #195 of 1072 | **Points**: 60 XP

## Overview

Implement Reciprocal Rank Fusion (RRF) to merge heterogeneously scaled retrieval rankings.

## Task

Implement `reciprocal_rank_fusion_rrf(ranked_lists, k=60)`. For each document `d` across all ranked lists, compute its RRF score: `score(d) = sum(1.0 / (k + rank))` where `rank` is the 1-based position of document `d` in each list it appears in. Return a list of dictionaries with `doc_id` and `rrf_score` (rounded to 6 decimal places), sorted descending by `rrf_score`, breaking ties alphabetically by `doc_id`.
