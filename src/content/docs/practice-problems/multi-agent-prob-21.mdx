# Token Ring Mutex Passing

**Track**: Multi-Agent Systems | **Points**: 40 XP

## Overview

Implement token-ring mutex passing, the real distributed-mutual-exclusion protocol where a single token circulates and only its holder may access the shared resource.

## Task

Implement `pass_token(ring_order, current_holder, want_token)`. Starting from the position AFTER `current_holder` in `ring_order` (wrapping around), find the first agent whose `want_token` value is `True`. If none want it, return `current_holder` unchanged (token stays put).
