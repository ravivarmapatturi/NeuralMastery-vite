# Two-Agent Shapley Value Contribution

**Track**: Multi-Agent Systems | **Points**: 40 XP

## Overview

Implement the exact Shapley value for a 2-agent coalition, the real, principled way to fairly attribute a joint outcome's value to each contributing agent.

## Task

Implement `shapley_two_agents(v_empty, v_a, v_b, v_ab)` where `v_X` is the value the coalition `X` achieves. For 2 players, agent A's Shapley value is the average of its marginal contribution across both possible join orders: `0.5*(v_a - v_empty) + 0.5*(v_ab - v_b)`. Agent B's is symmetric: `0.5*(v_b - v_empty) + 0.5*(v_ab - v_a)`. Return `(shapley_a, shapley_b)`.
