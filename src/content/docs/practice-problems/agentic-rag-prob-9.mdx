# Answer Verification Loop Decision

**Track**: Advanced RAG & Agentic RAG | **Points**: 40 XP

## Overview

Implement a real answer-verification decision, an agentic RAG loop's self-check step deciding whether to accept a generated answer, regenerate it, or retrieve fresh context.

## Task

Implement `verification_action(faithfulness_score, relevance_score, faithfulness_threshold, relevance_threshold)`. If both scores meet their thresholds, return `'accept'`. If faithfulness fails but relevance is fine (the retrieved context is good but the generation didn't use it well), return `'regenerate'`. Otherwise (relevance itself is poor), return `'retrieve_again'`.
