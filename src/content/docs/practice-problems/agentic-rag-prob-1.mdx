# Self-RAG: Parse Reflection Tokens Into a Retrieval Decision

**Track**: Advanced RAG & Agentic RAG | **Points**: 40 XP

## Overview

Implement Self-RAG's real reflection-token decision, letting the model itself decide whether a given generation step needs retrieval at all.

## Task

Implement `should_retrieve(reflection_token)`. Return `True` if `reflection_token == '[Retrieve]'`, `False` if it's `'[No Retrieve]'`. For any other value, default to `True` (retrieve when uncertain).
