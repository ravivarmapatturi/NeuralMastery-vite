# Linked Lists: Linked List Cycle Detection

**Rank #71** · Difficulty: **Easy** · Stage: **Stage 2: Data Structures & Algorithmic Foundations** · Category: **Data Structures & Algorithms**

## Overview

Implement Linked List Cycle Detection using Floyd's tortoise-and-hare algorithm -- O(n) time, O(1) space cycle detection.

## Task

Implement the function `has_cycle(vals, pos)`. Construct the linked list and detect a cycle using Floyd's two-pointer algorithm. Return `True` if a cycle exists.

<PracticePlayground problemId="ds-algo-prob-11" />

<Solution>

```python
def has_cycle(vals, pos):
    if not vals:
        return False
    nodes = [{'val': v, 'next': None} for v in vals]
    for i in range(len(nodes) - 1):
        nodes[i]['next'] = nodes[i + 1]
    if pos != -1:
        nodes[-1]['next'] = nodes[pos]
    slow = fast = nodes[0]
    while fast and fast['next']:
        slow = slow['next']
        fast = fast['next']['next']
        if slow is fast:
            return True
    return False
```

Floyd's algorithm: slow advances 1, fast advances 2. In a cycle they must meet. O(n) time, O(1) extra space -- no visited set needed.
