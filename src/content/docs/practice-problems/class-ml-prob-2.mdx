# #802. Classical Machine Learning Module 1: Problem 2

**Track**: Classical Machine Learning | **Rank**: #802 of 1072 | **Points**: 40 XP

## Overview

Implement `regularized_loss(mse, weights, l1, l2)`, the actual arithmetic Ridge (L2), Lasso (L1), and Elastic Net regularization add on top of a base loss -- the concrete mechanism behind "regularization shrinks weights," made computational rather than conceptual.

## Task

Implement the function `regularized_loss(mse, weights, l1=0.0, l2=0.0)`, returning `mse + l1 * sum(abs(w) for w in weights) + l2 * sum(w**2 for w in weights)`.
