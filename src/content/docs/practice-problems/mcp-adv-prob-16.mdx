# Check Plan Step Dependencies Satisfied

**Track**: MCP Advanced & Agent Integration | **Points**: 40 XP

## Overview

Implement plan-step readiness checking, deciding whether an agent's multi-step tool-call plan can execute a given step yet.

## Task

Implement `step_ready(step_id, dependencies, completed_steps)`. `dependencies` maps step id -> list of step ids it depends on. A step is ready if ALL of its dependencies (if any) are present in `completed_steps`. A step with no listed dependencies is always ready.
