## Overview

Unpack arbitrarily nested repeat strings using dual multiplier and string accumulator stacks.

## Task

Implement `decode_string(s)`: decode an encoded string of the pattern `k[encoded_string]`. Digits precede brackets and indicate the repeat count `k`. Brackets may be nested arbitrarily deep (e.g. `"3[a2[c]]"` -`>` `"accaccacc"`).

```python
def decode_string(s):
    count_stack = []
    str_stack = []
    curr_str = ""
    curr_k = 0
    for ch in s:
        if ch.isdigit():
            curr_k = curr_k * 10 + int(ch)
        elif ch == '[':
            count_stack.append(curr_k)
            str_stack.append(curr_str)
            curr_str = ""
            curr_k = 0
        elif ch == ']':
            k = count_stack.pop()
            prev = str_stack.pop()
            curr_str = prev + curr_str * k
        else:
            curr_str += ch
    return curr_str
```

Dual stacks capture nested scoping by pushing parent string contexts before recursing into bracket blocks.
