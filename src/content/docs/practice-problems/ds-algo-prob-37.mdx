# Trees: Validate Binary Search Tree

**Rank #97** · Difficulty: **Medium** · Stage: **Stage 2: Data Structures & Algorithmic Foundations** · Category: **Data Structures & Algorithms**

## Overview

Implement `is_valid_bst(root)` -- pass down valid ranges (min_val, max_val) at each node rather than just comparing children, which is a common wrong approach.

## Task

Implement the function `is_valid_bst(root)`. Each node is `{'val', 'left', 'right'}`. Return `True` if the tree is a valid BST (left subtree values `< root.val < right subtree values` at every node).

<PracticePlayground problemId="ds-algo-prob-37" />

<Solution>

```python
def is_valid_bst(root, min_val=float('-inf'), max_val=float('inf')):
    if not root:
        return True
    if root['val'] <= min_val or root['val'] >= max_val:
        return False
    return (is_valid_bst(root['left'], min_val, root['val'])
            and is_valid_bst(root['right'], root['val'], max_val))
```

Pass the valid range (min_val, max_val) down. Each node must be strictly inside that range. Left subtree receives (min_val, root.val), right receives (root.val, max_val). O(n) time.

</Solution>
