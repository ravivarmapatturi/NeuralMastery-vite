# Speculative RAG: Select the Best-Supported Draft Answer

**Track**: Advanced RAG & Agentic RAG | **Points**: 40 XP

## Overview

Implement Speculative RAG's real verification step: generate multiple candidate draft answers from different chunk subsets, then pick whichever draft is most supported by the actually-retrieved facts.

## Task

Implement `select_best_draft(drafts, retrieved_facts)`. For each draft, count how many of `retrieved_facts` (as whole-word matches, case-insensitive) appear as a substring-of-words within it. Return the draft with the HIGHEST count; ties broken by whichever draft appears FIRST in `drafts`.
