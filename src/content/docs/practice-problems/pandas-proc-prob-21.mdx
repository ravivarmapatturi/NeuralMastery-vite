# #791. Polynomial Interaction Cross-Terms Generator

**Track**: Pandas & Data Processing Pipelines | **Rank**: #791 of 1072 | **Points**: 60 XP

## Overview

Expand tabular features by synthesizing non-linear polynomial cross-product interaction terms.

## Task

Implement `generate_polynomial_interactions(records, feature_cols)`: for each record, iterate over all feature pairs `(f1, f2)` where `0 <= i <= j < len(feature_cols)`. Compute product `f1 * f2` and add new key `f'{f1}*{f2}'`. Retain all existing attributes. Round product floats to 4 decimals.

<Solution>

```python
def generate_polynomial_interactions(records, feature_cols):
    out = []
    n = len(feature_cols)
    for r in records:
        row = dict(r)
        for i in range(n):
            for j in range(i, n):
                f1, f2 = feature_cols[i], feature_cols[j]
                val = float(r.get(f1, 0.0)) * float(r.get(f2, 0.0))
                row[f'{f1}*{f2}'] = round(float(val), 4)
        out.append(row)
    return out
```

Iterates over upper-triangular index pairs and injects cross-product interaction columns.
