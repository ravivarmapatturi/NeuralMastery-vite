# Classical ML Module 21: Problem 261

**Rank #261** · Difficulty: **Easy** · Stage: **Stage 5: Classical Machine Learning & Optimization** · Category: **Classical ML**

## Overview

Evaluate the closed-form coordinate descent update for L1 penalized Lasso coefficients.

## Task

Implement `lasso_subgradient_step(rho, z_j, alpha)`: if `z_j == 0.0`, return 0.0. Otherwise apply soft-thresholding: if `rho < -alpha`, return `(rho + alpha) / z_j`; if `rho > alpha`, return `(rho - alpha) / z_j`; else return 0.0. Round result to 4 decimal places.

<PracticePlayground problemId="classical-ml-prob-21" />

<Solution>

```python
def lasso_subgradient_step(rho, z_j, alpha):
    if z_j == 0.0:
        return 0.0
    if rho < -alpha:
        w_j = (rho + alpha) / z_j
    elif rho > alpha:
        w_j = (rho - alpha) / z_j
    else:
        w_j = 0.0
    return round(float(w_j), 4)
```

The soft-thresholding operator zeroes out partial correlations smaller than alpha, establishing exact sparsity in Lasso linear models.

</Solution>
