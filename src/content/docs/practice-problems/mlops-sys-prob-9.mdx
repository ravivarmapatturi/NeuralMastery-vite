# Data Quality: Null Rate Check

**Track**: MLOps & Data Systems | **Points**: 40 XP

## Overview

Implement a null-rate data quality check, one of the real automated gates a feature pipeline runs before letting data flow to training or serving.

## Task

Implement `null_rate(values)`: return the fraction of entries in `values` that are `None`, as a float. Return `0.0` for an empty list.
