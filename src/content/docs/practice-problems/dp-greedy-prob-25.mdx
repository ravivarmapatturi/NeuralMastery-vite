# #675. Dynamic Programming & Greedy Module 5: Problem 25

**Track**: Dynamic Programming & Greedy | **Rank**: #675 of 1072 | **Points**

## Overview

Implement wildcard string matching with "?" and arbitrary sequence "*" using 2D dynamic programming.

## Task

Implement `is_wildcard_match(s, p)`: if p[j-1] == "*", dp[i][j] = dp[i-1][j] (star matches current char of s) or dp[i][j-1] (star matches empty sequence).

<Solution>

```python
def is_wildcard_match(s, p):
    m, n = len(s), len(p)
    dp = [[False] * (n + 1) for _ in range(m + 1)]
    dp[0][0] = True
    for j in range(1, n + 1):
        if p[j - 1] == '*':
            dp[0][j] = dp[0][j - 1]
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if p[j - 1] == '*':
                dp[i][j] = dp[i - 1][j] or dp[i][j - 1]
            elif p[j - 1] == '?' or p[j - 1] == s[i - 1]:
                dp[i][j] = dp[i - 1][j - 1]
    return dp[m][n]
```

Wildcard stars match either an empty sequence (dp[i][j-1]) or any prefix character (dp[i-1][j]). Question marks match exactly one character diagonally (dp[i-1][j-1]).
