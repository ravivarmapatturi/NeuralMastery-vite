# Bellman Equation for Value Iteration

**Difficulty: Medium** · Topic: Reinforcement Learning

Implement the Bellman optimality update equation for state value iteration.

<PracticePlayground problemId="bellman-value-iteration" />

<Solution>

```python
def bellman_update(state, transitions, V, gamma):
    action_values = []
    for action, outcome_list in transitions[state].items():
        val = sum(prob * (reward + gamma * V[next_s]) for prob, next_s, reward in outcome_list)
        action_values.append(val)
    return max(action_values) if action_values else 0.0
```

Value Iteration iteratively applies the Bellman Optimality Operator until state values converge to optimal policy V*.
