# #610. Trees / Binary Search Module 4: Problem 20

**Track**: Trees / Binary Search | **Rank**: #610 of 1072 | **Points**

## Overview

Find a local peak index in an array in O(log n) time using binary search on slope direction.

## Task

Implement `find_peak_element(nums)`: compare `nums[mid]` to `nums[mid + 1]`. If `nums[mid] < nums[mid + 1]`, an uphill slope guarantees a peak exists to the right; otherwise search the left.

<PracticePlayground problemId="tree-bs-prob-20" />

<Solution>

```python
def find_peak_element(nums):
    lo, hi = 0, len(nums) - 1
    while lo < hi:
        mid = (lo + hi) // 2
        if nums[mid] < nums[mid + 1]:
            lo = mid + 1
        else:
            hi = mid
    return lo
```

By comparing nums[mid] with nums[mid + 1], we determine whether the local slope rises or falls. Walking uphill is guaranteed to terminate at a peak.
