# #202. Embedding Cache Layer

**Track**: RAG Fundamentals | **Rank**: #202 of 1072 | **Points**: 60 XP

## Overview

Implement an LRU embedding cache layer to save latency and inference cost on repeated search queries.

## Task

Implement `embedding_cache_layer(queries, precomputed_embeddings, max_cache_size=3)`. Process queries sequentially. Normalize each query via `query.strip().lower()`. If the normalized query is in cache, record a cache hit and move it to the most recently used position. Otherwise, record a cache miss; if the cache has reached `max_cache_size`, evict the least recently used item (`evictions += 1`) and add the query. Return `{"results": {q_norm: embedding}, "hits": hits, "misses": misses, "evictions": evictions, "cached_queries": list(cache)}`.
