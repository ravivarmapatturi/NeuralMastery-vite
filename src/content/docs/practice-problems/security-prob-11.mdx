# Detect Contradictory Agent Responses

**Track**: Agent Security & Reliability | **Points**: 40 XP

## Overview

Implement a real, simple contradiction check between two agent responses to the same question, a basic consistency signal for a reliability monitor.

## Task

Implement `responses_contradict(response_a, response_b)`. Lowercase both. Return `True` if one contains `'yes'` and the other contains `'no'` (as whole words), OR if one contains `'true'` and the other contains `'false'`. Otherwise `False`.
