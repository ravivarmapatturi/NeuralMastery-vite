# DP: Word Break II (All Sentences)

**Rank #109** · Difficulty: **Hard** · Stage: **Stage 2: Data Structures & Algorithmic Foundations** · Category: **Data Structures & Algorithms**

## Overview

Implement `word_break_ii(s, word_dict)` -- enumerate all valid segmentations using top-down memoization. Exponential output size is unavoidable but memoization avoids recomputing subproblems.

## Task

Implement the function `word_break_ii(s, word_dict)`. Return all possible sentences formed by inserting spaces in `s` so that each word is in `word_dict`.

<PracticePlayground problemId="ds-algo-prob-49" />

<Solution>

```python
def word_break_ii(s, word_dict):
    word_set = set(word_dict)
    memo = {}

    def dp(start):
        if start in memo:
            return memo[start]
        if start == len(s):
            return [[]]
        results = []
        for end in range(start + 1, len(s) + 1):
            word = s[start:end]
            if word in word_set:
                for rest in dp(end):
                    results.append([word] + rest)
        memo[start] = results
        return results

    return [' '.join(path) for path in dp(0)]
```

Top-down DP: memo[start] = all valid segmentation lists from position start. The memoization avoids exponential recomputation. Output construction can still be large. O(n^2 * 2^n) worst case.

</Solution>
