# Linked Lists: Swap Nodes in Pairs

**Rank #106** · Difficulty: **Medium** · Stage: **Stage 2: Data Structures & Algorithmic Foundations** · Category: **Data Structures & Algorithms**

## Overview

Implement `swap_pairs(head)` -- swap every consecutive pair of nodes. A clean recursive or iterative solution with a dummy head.

## Task

Implement the function `swap_pairs(head)`. Each node is `{'val', 'next'}`. Swap every two adjacent nodes and return the new head. Do not modify node values.

<PracticePlayground problemId="ds-algo-prob-46" />

<Solution>

```python
def swap_pairs(head):
    dummy = {'val': 0, 'next': head}
    prev = dummy
    while prev['next'] and prev['next']['next']:
        a = prev['next']
        b = prev['next']['next']
        prev['next'] = b
        a['next'] = b['next']
        b['next'] = a
        prev = a
    return dummy['next']
```

Iterative: prev -> a -> b -> rest becomes prev -> b -> a -> rest. Advance prev to a (the new second node). Dummy head handles the first pair. O(n) time, O(1) space.
