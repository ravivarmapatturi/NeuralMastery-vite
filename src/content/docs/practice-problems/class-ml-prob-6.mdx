## Overview

Rescale multivariate feature matrices column-wise to the unit interval [0, 1].

## Task

Implement `feature_min_max_normalize(X)`: for each feature column j, compute `(x[i][j] - min_j) / (max_j - min_j)`. Return matrix with entries rounded to 4 decimal places.

```python
def feature_min_max_normalize(X):
    n_rows, n_cols = len(X), len(X[0])
    mins = [min(X[i][j] for i in range(n_rows)) for j in range(n_cols)]
    maxs = [max(X[i][j] for i in range(n_rows)) for j in range(n_cols)]
    res = []
    for row in X:
        new_row = []
        for j in range(n_cols):
            rng = maxs[j] - mins[j]
            val = (row[j] - mins[j]) / rng if rng != 0 else 0.0
            new_row.append(round(val, 4))
        res.append(new_row)
    return res
```
