# Classical ML Module 37: Problem 277

**Rank #277** · Difficulty: **Medium** · Stage: **Stage 5: Classical Machine Learning & Optimization** · Category: **Classical ML**

## Overview

Compute the aggregate exponential loss function minimized by AdaBoost ensembles.

## Task

Implement `adaboost_exp_loss(y_true, f_x)`: given labels `y_true in {-1, 1}` and ensemble real scores `f_x`, compute `(1/N) * sum(exp(-y_true[i] * f_x[i]))`. Round float to 4 decimal places.

<PracticePlayground problemId="classical-ml-prob-37" />

<Solution>

```python
import math

def adaboost_exp_loss(y_true, f_x):
    n = len(y_true)
    if n == 0:
        return 0.0
    total = sum(math.exp(-yt * fx) for yt, fx in zip(y_true, f_x))
    return round(float(total / n), 4)
```

Exponential loss acts as a smooth, convex upper bound on 0-1 misclassification error, heavily penalizing confident wrong predictions.

</Solution>
