# Compute p50/p95/p99 Agent Response Latency

**Track**: Agent Performance & Production | **Points**: 40 XP

## Overview

Implement latency-percentile computation for agent response times, the real metric a production agent's SLO is actually measured against.

## Task

Implement `agent_latency_percentile(samples_ms, p)`. Sort ascending. Using the nearest-rank method, index is `ceil(p/100 * n) - 1`, clamped to `[0, n-1]`. Return the value there.
