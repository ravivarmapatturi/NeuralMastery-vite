# Calculate KV-Cache Memory Footprint

**Rank #371** · Difficulty: **Easy** · Stage: **Stage 7: Transformers, LLMs & Foundation Models** · Category: **Transformers & LLMs**

Calculate the exact VRAM footprint in bytes required by an LLM KV-cache during multi-turn autoregressive serving. Prerequisite: `llm-internals-prob-10`.

<PracticePlayground problemId="llm-internals-prob-11" />

<Solution>

```python
def calculate_kv_cache_bytes(num_layers, num_kv_heads, head_dim, seq_len, batch_size, bytes_per_param=2):
    for arg in (num_layers, num_kv_heads, head_dim, seq_len, batch_size, bytes_per_param):
        if arg <= 0:
            raise ValueError("All parameters must be positive integers")
    return 2 * num_layers * num_kv_heads * head_dim * seq_len * batch_size * bytes_per_param
```

At inference time, transformer decoders store past Key and Value tensors in memory to avoid recalculating self-attention on prior tokens; KV-cache memory scales linearly with sequence length and batch size.

</Solution>
