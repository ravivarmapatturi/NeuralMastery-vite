# #714. Cosine Distance Matrix

**Track**: Mathematics & Numerical Computing | **Rank**: #714 of 1072 | **Points**: 40 XP

## Overview

Compute the pairwise cosine distance matrix between rows of a feature matrix.

## Task

Implement `cosine_distance_matrix(matrix)`: given an n x d matrix, return an n x n matrix of pairwise cosine distances where `D[i][j] = 1 - (u . v) / (||u|| * ||v||)`. Round each float to 4 decimal places.

<Solution>

```python
import math

def cosine_distance_matrix(matrix):
    n = len(matrix)
    norms = [math.sqrt(sum(x ** 2 for x in row)) for row in matrix]
    dist_mat = []
    for i in range(n):
        row = []
        for j in range(n):
            if norms[i] == 0 or norms[j] == 0:
                sim = 0.0
            else:
                dot = sum(a * b for a, b in zip(matrix[i], matrix[j]))
                sim = dot / (norms[i] * norms[j])
            dist = 1.0 - sim
            row.append(round(float(dist), 4))
        dist_mat.append(row)
    return dist_mat
```

Precomputes Euclidean norms for all rows, then computes dot products to evaluate 1 - sim.
