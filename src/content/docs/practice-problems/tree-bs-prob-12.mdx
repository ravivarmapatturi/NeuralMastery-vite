# #602. Trees / Binary Search Module 3: Problem 12

**Track**: Trees / Binary Search | **Rank**: #602 of 1072 | **Points**: 60 XP

## Overview

Implement Kth Smallest Element in a BST by exploiting the single most useful BST property: an inorder traversal visits every value in ascending sorted order, for free.

## Task

Implement the function `kth_smallest_in_bst(root, k)`: `k` is 1-indexed (`k=1` is the smallest value). Return the kth smallest value via an early-stopping inorder traversal. Raise `ValueError` if `k` exceeds the number of nodes.
