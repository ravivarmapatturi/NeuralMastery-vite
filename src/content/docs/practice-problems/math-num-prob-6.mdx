## Overview

Implement matrix-matrix multiplication without third-party numerical packages.

## Task

Implement `matrix_multiply(A, B)`: given an n x m matrix A and an m x k matrix B, return their product C = A x B of dimension n x k. Round each element to 4 decimal places.

<PracticePlayground problemId="math-num-prob-6" />

<Solution>

```python
def matrix_multiply(A, B):
    n = len(A)
    m = len(A[0]) if n > 0 else 0
    k = len(B[0]) if len(B) > 0 else 0
    C = []
    for i in range(n):
        row = []
        for j in range(k):
            val = sum(A[i][p] * B[p][j] for p in range(m))
            row.append(round(float(val), 4))
        C.append(row)
    return C
```

Three nested loops accumulate the dot product of row i of A and column j of B.
