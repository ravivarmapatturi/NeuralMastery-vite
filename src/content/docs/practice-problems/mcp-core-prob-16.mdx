# Track Progress From Token Updates

**Track**: MCP Core Engineering | **Points**: 40 XP

## Overview

Implement MCP progress-token percentage computation, converting a raw progress/total pair from a long-running tool call into a displayable percentage.

## Task

Implement `progress_percentage(progress, total)`. Return `(progress/total)*100`, clamped to the range `[0, 100]`. If `total` is 0, return `0.0`.
