# Layer Normalization Forward Pass

**Rank #377** · Difficulty: **Easy** · Stage: **Stage 7: Transformers, LLMs & Foundation Models** · Category: **Transformers & LLMs**

Implement `layer_norm(x, eps=1e-5)` which normalizes a 1D feature vector by subtracting its mean and dividing by its standard deviation (plus epsilon for numerical stability). Return values rounded to 4 decimal places. Prerequisite: `llm-internals-prob-16`.

<PracticePlayground problemId="llm-internals-prob-17" />

<Solution>

```python
import math

def layer_norm(x, eps=1e-5):
    if not x:
        return []
    n = len(x)
    mean = sum(x) / n
    var = sum((xi - mean) ** 2 for xi in x) / n
    std = math.sqrt(var + eps)
    return [round((xi - mean) / std, 4) for xi in x]
```

Layer Norm computes statistics across the *feature* dimension (not batch), making it independent of batch size -- crucial for autoregressive decoding where sequences are generated one token at a time. Adding `eps` prevents division by zero on constant inputs.

</Solution>
