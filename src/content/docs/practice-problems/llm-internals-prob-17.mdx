# Layer Normalization Forward Pass

**Track**: transformers-llms | **Points**: 40 XP

## Overview

Implement the Layer Normalization forward pass: normalize each vector to zero mean and unit variance along the feature dimension.

## Task

Implement `layer_norm(x, eps=1e-5)` which normalizes a 1D feature vector by subtracting its mean and dividing by its standard deviation (plus epsilon for numerical stability). Return values rounded to 4 decimal places. If x is empty, return empty list.
