# Confidence-Gated Human Confirmation

**Track**: MCP Advanced & Agent Integration | **Points**: 40 XP

## Overview

Implement confidence-gated human-in-the-loop escalation, a real policy deciding when an autonomous agent should pause and ask for human confirmation before proceeding.

## Task

Implement `should_ask_human(agent_confidence, action_is_destructive, confidence_threshold)`. Return `True` (ask a human) if `action_is_destructive` is `True` AND `agent_confidence < confidence_threshold`. A non-destructive action never needs to ask, regardless of confidence.
