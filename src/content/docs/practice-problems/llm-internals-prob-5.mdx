# Temperature-Scaled Softmax Distribution

**Track**: transformers-llms | **Points**: 40 XP

## Overview

Implement temperature-scaled softmax probability computation with numerical stability for LLM sampling and decoding control.

## Task

Implement `temperature_softmax(logits, temperature)`. Apply `(z_i - max(z)) / T` before exponentiation, normalize by sum of exponentials, and return probabilities rounded to 4 decimal places.
