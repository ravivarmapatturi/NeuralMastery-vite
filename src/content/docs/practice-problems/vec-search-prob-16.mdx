# Max Inner Product Search (MIPS) Top-K

**Track**: Vector Search & Index Optimization | **Points**: 40 XP

## Overview

Implement Max Inner Product Search ranking, the similarity metric behind most modern dense retrieval systems (unlike cosine, it rewards vector magnitude too).

## Task

Implement `mips_topk(query, vectors, k)`. Compute the dot product between `query` and every vector in `vectors`, and return the `k` ids with the HIGHEST dot product, sorted descending by score. Ties broken by id ascending.
