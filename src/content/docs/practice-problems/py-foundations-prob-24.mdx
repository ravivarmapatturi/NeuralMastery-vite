# Flatten Nested Dictionary with Delimiters

**Rank #24** · Difficulty: **Medium** · Stage: **Stage 1: AI Foundations & Python Programming** · Category: **Python & Fundamentals**

## Overview

Convert deeply nested JSON dictionaries into flat dot-delimited key-value maps for serialization and tabular export.

## Task

Implement `flatten_dict(nested, sep=".")`: recursively traverse `nested`, constructing keys by concatenating path segments with `sep`. Return a flat dictionary mapping leaf values to full dotted path strings. Empty sub-dictionaries map to `{}`.

<PracticePlayground problemId="py-foundations-prob-24" />

<Solution>

```python
def flatten_dict(nested, sep="."):
    flat = {}
    def recurse(curr, prefix):
        for k, v in curr.items():
            new_key = f"{prefix}{sep}{k}" if prefix else str(k)
            if isinstance(v, dict) and v:
                recurse(v, new_key)
            else:
                flat[new_key] = v
    recurse(nested, "")
    return flat
```

A depth-first recursive walk records concatenated string paths for leaf values while visiting every sub-branch.

</Solution>
