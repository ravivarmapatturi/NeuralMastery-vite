# RAG-Fusion: Reciprocal Rank Fusion Across Query Variants

**Track**: Advanced RAG & Agentic RAG | **Points**: 40 XP

## Overview

Implement RAG-Fusion's Reciprocal Rank Fusion, combining retrieval results from MULTIPLE generated query variants of the same original question into one robust ranked list.

## Task

Implement `rag_fusion_rrf(result_lists, k)`. Each inner list is one query variant's ranked document ids (best first). Score `doc_id` = `sum(1/(k + rank) for each list it appears in)`, where `rank` is its 0-indexed position in that list. Return document ids sorted by total score descending, ties broken by id ascending.
