# Scheduled Sampling Teacher Forcing Ratio Decay

**Track**: Deep Learning & Vision/NLP | **Points**: 40 XP

## Overview

Calculate scheduled sampling teacher forcing probability across training steps to combat exposure bias in autoregressive generation.

## Task

Implement `teacher_forcing_ratio_decay(initial_ratio, decay_rate, step, mode)`. If `mode == 'exponential'`, ratio is `initial_ratio * (decay_rate ** step)`. If `mode == 'linear'`, ratio is `max(0.0, initial_ratio - decay_rate * step)`. If `mode == 'inverse_sigmoid'`, ratio is `decay_rate / (decay_rate + math.exp(step / decay_rate))`. Clamp the output to `[0.0, 1.0]` and round to 4 decimal places.
