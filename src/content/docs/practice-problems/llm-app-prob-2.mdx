# #062. Few-Shot Demonstration Formatter

**Track**: LLM Application Engineering | **Rank**: #62 of 1072 | **Points**: 40 XP

## Overview

Compose few-shot in-context learning prompts with consistent prefixes, demonstrations, and trailing completion prefixes. In production LLM application engineering, reliable system components, deterministic interfaces, and defensive validation are paramount for production stability and cost efficiency.

## Task

Implement `format_few_shot_prompt(system_instruction, examples, query, example_prefix='Input: ', example_suffix='Output: ')`. Assemble a prompt starting with `system_instruction` (if non-empty), followed by each demonstration formatted as `{example_prefix}{input}\n{example_suffix}{output}`, and concluding with the final test case `{example_prefix}{query}\n{example_suffix}`. Separate all top-level sections with double newlines `\n\n`. Raise `ValueError` if `query` is empty.
