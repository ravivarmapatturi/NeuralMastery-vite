# Categorical Cross-Entropy Loss From Scratch

**Difficulty: Easy** · Concept: [Loss Functions — Classification Losses](/docs/deep-learning/loss-functions#classification-losses)

$$\mathcal{L} = -\frac{1}{N}\sum_{n=1}^{N} \log p_n[y_n]$$

Categorical cross-entropy measures how much probability a model's softmax output assigns to the *correct* class — the lower the probability given to the true label, the higher the loss, with a genuinely unbounded penalty as that probability approaches 0. This is the loss behind every multi-class classifier, and it's exactly what trains an LLM's next-token prediction: each token in a sequence is one classification decision over the whole vocabulary.

**Your task**: implement `categorical_cross_entropy(y_pred, y_true_idx)` where `y_pred` is a `(batch, num_classes)` array of predicted probabilities (already softmaxed) and `y_true_idx` is a `(batch,)` array of the correct class index per example.

<Solution>

```python
import numpy as np

def categorical_cross_entropy(y_pred, y_true_idx, eps=1e-12):
    n = y_pred.shape[0]
    p = np.clip(y_pred[np.arange(n), y_true_idx], eps, 1.0)
    return -np.mean(np.log(p))
```

`y_pred[np.arange(n), y_true_idx]` is NumPy's fancy indexing doing the "gather the true class's probability, per row" step in one line — `np.arange(n)` picks row `0, 1, 2, ...` and `y_true_idx` picks the column within each of those rows, so the result is exactly `[y_pred[0, y_true_idx[0]], y_pred[1, y_true_idx[1]], ...]`, one probability per example.

The `eps` clip is not defensive boilerplate: `log(0)` is `-inf` in floating point, and a model that's initially very wrong (assigning near-zero probability to the correct class, the third test case above) really can produce a probability that underflows to exactly `0.0`. Clipping to `[eps, 1.0]` keeps the loss a real, large, finite number instead of `-inf` or `nan` — the same numerical-safety instinct as [softmax's max-subtraction trick](/practice/softmax), applied to the other end of the pipeline.
