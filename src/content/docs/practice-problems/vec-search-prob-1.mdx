# #976. Vector Search & Index Optimization Module 1: Problem 1

**Track**: Vector Search & Index Optimization | **Rank**: #976 of 1072 | **Points**: 40 XP

## Overview

Implement `euclidean_distance(a, b)`, the L2 distance metric that flat (brute-force) vector indexes and the L2 index type in FAISS/pgvector use to rank candidate vectors against a query embedding. This is the foundational distance metric behind exact vector search, and the baseline every faster approximate index (HNSW, IVF, LSH) is measured against.

## Task

Implement the function `euclidean_distance(a, b)`, returning `sqrt(sum((a_i - b_i)**2))` over two equal-length numeric vectors `a` and `b`. Raise `ValueError` if `len(a) != len(b)`.
