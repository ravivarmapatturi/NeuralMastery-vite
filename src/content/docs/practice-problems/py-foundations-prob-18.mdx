# Valid Anagram Verification

**Rank #18** · Difficulty: **Easy** · Stage: **Stage 1: AI Foundations & Python Programming** · Category: **Python & Fundamentals**

## Overview

Verify whether two strings contain the identical multiset of characters regardless of word order, case, or whitespace.

## Task

Implement `is_anagram(s, t)`: return `True` if `s` and `t` are anagrams of each other (ignoring whitespace and letter case), and `False` otherwise.

<PracticePlayground problemId="py-foundations-prob-18" />

<Solution>

```python
def is_anagram(s, t):
    s_clean = [c.lower() for c in s if not c.isspace()]
    t_clean = [c.lower() for c in t if not c.isspace()]
    if len(s_clean) != len(t_clean):
        return False
    counts = {}
    for c in s_clean:
        counts[c] = counts.get(c, 0) + 1
    for c in t_clean:
        if c not in counts or counts[c] == 0:
            return False
        counts[c] -= 1
    return True
```

Cleaning whitespace and case gives the canonical character set; a frequency dictionary verifies exact multiset equality in O(n) time.

</Solution>
