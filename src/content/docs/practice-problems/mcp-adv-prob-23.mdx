# Count Subtasks in a Decomposed Plan

**Track**: MCP Advanced & Agent Integration | **Points**: 40 XP

## Overview

Implement a real, simple plan-step counter for an agent's task-decomposition output, parsing a numbered-list plan format.

## Task

Implement `count_plan_steps(plan_text)`. Count the number of lines that start (after stripping leading whitespace) with a digit followed by a period, e.g. `'1. Do X'`. Lines not matching this pattern are ignored.
