# Directed Graph Cycle Detection (3-Color DFS)

**Rank #57** · Difficulty: **Hard** · Stage: **Stage 1: AI Foundations & Python Programming** · Category: **Python & Fundamentals**

## Overview

Detect cycles in directed dependency networks using the classical white-gray-black tri-color DFS.

## Task

Implement `has_cycle(num_nodes, edges)`: return `True` if the directed graph with nodes `0` to `num_nodes - 1` and directed edges `[u, v]` contains at least one cycle, and `False` otherwise.

<PracticePlayground problemId="py-foundations-prob-57" />

<Solution>

```python
from collections import defaultdict

def has_cycle(num_nodes, edges):
    adj = defaultdict(list)
    for u, v in edges:
        adj[u].append(v)
    state = [0] * num_nodes
    def dfs(u):
        state[u] = 1
        for v in adj[u]:
            if state[v] == 1:
                return True
            if state[v] == 0 and dfs(v):
                return True
        state[u] = 2
        return False
    for i in range(num_nodes):
        if state[i] == 0 and dfs(i):
            return True
    return False
```

Differentiating actively exploring nodes (state 1) from finished subtrees (state 2) detects back-edges without false positives from cross-edges.

</Solution>
