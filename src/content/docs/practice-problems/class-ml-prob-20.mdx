# #820. Classical Machine Learning Module 4: Problem 20

**Track**: Classical Machine Learning | **Rank**: #820 of 1072 | **Points**

## Overview

Expand 1D feature vectors into polynomial basis features.

## Task

Implement `polynomial_features_1d(x, degree)`: map each scalar feature `x_i` to powers `x_i^1` through `x_i^degree`, rounding each entry to 4 decimal places.

<PracticePlayground problemId="class-ml-prob-20" />

<Solution>

```python
def polynomial_features_1d(x, degree):
    return [[round(val ** d, 4) for d in range(1, degree + 1)] for val in x]
```

Construct powers of the input feature from 1 to degree for each sample to build the polynomial design matrix.

</Solution>
