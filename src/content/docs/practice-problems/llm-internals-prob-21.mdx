# Beam Search Length Penalty Score

**Track**: transformers-llms | **Points**: 40 XP

## Overview

Apply Google length penalty to a beam search raw log-probability score to prevent length bias.

## Task

Implement `length_penalty_score(raw_log_prob, length, alpha=0.6)` using the formula: `score = raw_log_prob / lp` where `lp = ((5 + length) ** alpha) / (6 ** alpha)`. Return the score rounded to 4 decimal places. Raise `ValueError` if `length <= 0`.
