# Sandboxed Execution Permission Check

**Track**: MCP Advanced & Agent Integration | **Points**: 40 XP

## Overview

Implement a real, hierarchical permission check for a sandboxed MCP tool execution environment, supporting wildcard grants.

## Task

Implement `has_permission(requested_permission, granted_permissions)`. `requested_permission` is a dotted path like `'fs.write'`. It's granted if it's LITERALLY in `granted_permissions`, OR if a WILDCARD ancestor grant exists: `'fs.*'` covers `'fs.write'` and `'fs.read'`; `'*'` covers everything.
