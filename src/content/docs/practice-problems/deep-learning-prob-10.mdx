# Discrete Laplacian 2D Edge Filtering

**Track**: Deep Learning & Vision/NLP | **Points**: 40 XP

## Overview

Apply the standard 3x3 discrete Laplacian second-derivative kernel to detect edges and rapid intensity changes.

## Task

Implement `laplacian_kernel_filter(image)`. Convolve a 2D image matrix of size `H x W` with the 3x3 Laplacian kernel `[[0, 1, 0], [1, -4, 1], [0, 1, 0]]` using valid padding (resulting in output size `(H - 2) x (W - 2)`). Round each output value to 4 decimal places.
