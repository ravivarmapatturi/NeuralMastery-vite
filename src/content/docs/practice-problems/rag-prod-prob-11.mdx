# RAG Answer Confidence Blending

**Track**: RAG Production Engineering | **Points**: 40 XP

## Overview

Implement a real confidence-blending formula combining retrieval quality and generation certainty into one usable RAG answer-confidence score.

## Task

Implement `answer_confidence(top_retrieval_score, generation_logprob, w_retrieval)`. Convert `generation_logprob` to a probability via `exp(generation_logprob)` (clip the log-prob to a max of 0 first, since logprobs are always `<= 0`). Return `w_retrieval*top_retrieval_score + (1-w_retrieval)*generation_probability`.
