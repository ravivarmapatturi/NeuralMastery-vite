# Arithmetic Expression Evaluator

**Rank #41** · Difficulty: **Medium** · Stage: **Stage 1: AI Foundations & Python Programming** · Category: **Python & Fundamentals**

## Overview

Parse and evaluate arithmetic expressions respecting operator precedence without using eval().

## Task

Implement `evaluate_expression(expr)`: evaluate an arithmetic string containing integers, spaces, and operators `+`, `-`, `*`, `/`. Multiplication and division have higher precedence than addition and subtraction. Division truncates toward zero (e.g. `int(-3 / 2) == -1`). Do NOT use Python eval().

<PracticePlayground problemId="py-foundations-prob-41" />

<Solution>

```python
def evaluate_expression(expr):
    s = expr.replace(" ", "")
    stack = []
    num = 0
    sign = '+'
    for i, ch in enumerate(s):
        if ch.isdigit():
            num = num * 10 + int(ch)
        if not ch.isdigit() or i == len(s) - 1:
            if sign == '+':
                stack.append(num)
            elif sign == '-':
                stack.append(-num)
            elif sign == '*':
                stack.append(stack.pop() * num)
            elif sign == '/':
                prev = stack.pop()
                stack.append(int(prev / num))
            sign = ch
            num = 0
    return sum(stack)
```

Applying multiplication and division eagerly onto the stack reduces all terms to additive components that sum up in O(n) time.
