# Binary Cross-Entropy Loss

**Rank #243** · Difficulty: **Easy** · Stage: **Stage 5: Classical Machine Learning & Optimization** · Category: **Classical ML** | **Points**: 40 XP

## Overview

Implement `binary_cross_entropy(y_true, y_pred, eps=1e-15)`, the standard loss function for binary classification models (logistic regression, gradient boosted trees, neural binary classifiers).

## Task

Implement `binary_cross_entropy(y_true, y_pred, eps=1e-15)`: calculate BCE = -1/N * sum(y * ln(p) + (1 - y) * ln(1 - p)) where each prediction `p` is clamped to `[eps, 1.0 - eps]`. Return `0.0` when inputs are empty.

<Solution>

```python
import math

def binary_cross_entropy(y_true, y_pred, eps=1e-15):
    if not y_true:
        return 0.0
    n = len(y_true)
    total = 0.0
    for y, p in zip(y_true, y_pred):
        p_clipped = max(eps, min(1.0 - eps, float(p)))
        total += -(y * math.log(p_clipped) + (1.0 - y) * math.log(1.0 - p_clipped))
    return round(total / n, 6)
```

Probability clipping prevents log(0) which yields -inf or NaN, ensuring robust optimization in classification pipelines.

</Solution>
