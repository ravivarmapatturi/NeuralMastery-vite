# #056. Tensor Parallel Communication Volume

**Track**: LLM Inference & Decoding | **Rank**: #56 of 1072 | **Points**: 90 XP

## Overview

Calculate inter-GPU interconnect bandwidth overheads for Megatron-style Tensor Parallel decoding. Autoregressive language models generate sequences token by token, evaluating next-token probability distributions at each decoding step.

## Task

Implement `compute_tensor_parallel_comm(batch_size, seq_len, hidden_dim, num_layers, tp_size, dtype_bytes=2)`. If `tp_size == 1`, return 0 communication. Otherwise, Megatron-style tensor parallelism performs 2 All-Reduces per layer (one after attention row-parallel projection, one after MLP row-parallel projection). Each ring All-Reduce transfers `2 \times \frac{tp\_size - 1}{tp\_size} \times (\text{batch\_size} \times \text{seq\_len} \times \text{hidden\_dim} \times \text{dtype\_bytes})` bytes per GPU. Calculate total communication bytes across all layers. Return dict with `all_reduces_per_forward_pass`, `bytes_per_all_reduce`, `total_communication_bytes`, and `comm_to_comp_ratio` (comm bytes / tokens, rounded to 2 decimals). Raise `ValueError` on non-positive arguments.
