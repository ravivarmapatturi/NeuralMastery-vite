# Top-P (Nucleus) Token Selection

**Track**: transformers-llms | **Points**: 40 XP

## Overview

Implement Top-P (Nucleus) sampling token selection -- dynamically sizing candidate token sets based on cumulative probability mass.

## Task

Implement `top_p_filter(probabilities, p)`. Sort tokens in descending probability order, include tokens until cumulative probability is `>= p`, and return their original indices.
