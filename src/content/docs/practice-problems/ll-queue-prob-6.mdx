# #566. Linked Lists / Stacks / Queues Module 2: Problem 6

**Track**: Linked Lists / Stacks / Queues | **Rank**: #566 of 1072 | **Points**

## Overview

Delete all occurrences of a target value from a singly linked list using a dummy sentinel node.

## Task

Implement `remove_elements(head, val)`: remove all nodes of the linked list that have `node["val"] == val`. Return the new head of the list.

<PracticePlayground problemId="ll-queue-prob-6" />

<Solution>

```python
def remove_elements(head, val):
    dummy = {'val': 0, 'next': head}
    curr = dummy
    while curr.get('next'):
        if curr['next']['val'] == val:
            curr['next'] = curr['next']['next']
        else:
            curr = curr['next']
    return dummy['next']
```

Preceding head with a dummy node allows deleting any node, including the original head, with identical pointer rewiring logic.

</Solution>
