# Linear-Chain CRF Sequence Path Score

**Track**: Deep Learning & Vision/NLP | **Points**: 40 XP

## Overview

Compute the unnormalized path score combining emission and state transition matrices in a linear-chain CRF.

## Task

Implement `crf_sequence_score(emissions, tags, transitions)`. Given sequence emissions `emissions` of shape `T x K`, tag sequence `tags` of length `T`, and transition matrix `transitions` of shape `K x K` (where `transitions[i][j]` is transition from tag `i` to `j`). Path score is `sum_{t=0}^{T-1} emissions[t][tags[t]] + sum_{t=0}^{T-2} transitions[tags[t]][tags[t+1]]`. Return scalar float rounded to 4 decimal places.
