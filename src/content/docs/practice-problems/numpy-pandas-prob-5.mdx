# Pandas GroupBy Metric Aggregation

**Rank #185** · Difficulty: **Easy** · Stage: **Stage 4: NumPy & Vectorized Data Processing** · Category: **NumPy & Pandas**

Group tabular records by category and compute aggregate metrics (count, sum, mean) using Pandas. Prerequisite: `numpy-pandas-prob-4`.

<PracticePlayground problemId="numpy-pandas-prob-5" />

<Solution>

```python
import pandas as pd

def groupby_aggregate(records, group_col, val_col):
    if not records:
        return {}
    df = pd.DataFrame(records)
    grouped = df.groupby(group_col)[val_col]
    res = {}
    for name, grp in grouped:
        res[str(name)] = {
            "count": int(grp.count()),
            "sum": round(float(grp.sum()), 2),
            "mean": round(float(grp.mean()), 2)
        }
    return res
```

Pandas groupby partitions index row subsets into hash buckets, enabling vectorized multi-metric reduction over column slices without iterating row by row.
