# Sort Characters By Frequency

**Rank #21** · Difficulty: **Easy** · Stage: **Stage 1: AI Foundations & Python Programming** · Category: **Python & Fundamentals**

## Overview

Reorganize characters by frequency of occurrence with deterministic tie-breaking.

## Task

Implement `frequency_sort(s)`: count occurrences of each character in `s`, then return a new string where characters appear grouped by descending frequency. Ties in frequency should be broken by alphabetical (ASCII) order.

<PracticePlayground problemId="py-foundations-prob-21" />

<Solution>

```python
def frequency_sort(s):
    counts = {}
    for c in s:
        counts[c] = counts.get(c, 0) + 1
    sorted_chars = sorted(counts.keys(), key=lambda c: (-counts[c], c))
    return "".join(c * counts[c] for c in sorted_chars)
```

Python sorted with tuple key `(-counts[c], c)` naturally sorts primarily by highest frequency and secondarily by alphabetical order.

</Solution>
