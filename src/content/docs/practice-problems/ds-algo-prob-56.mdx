# Linked Lists: Merge K Sorted Lists

**Rank #116** · Difficulty: **Hard** · Stage: **Stage 2: Data Structures & Algorithmic Foundations** · Category: **Data Structures & Algorithms**

## Overview

Implement `merge_k_lists(lists)` -- use a min-heap to always extend with the globally smallest current node. O(n log k) where k is the number of lists.

## Task

Implement the function `merge_k_lists(lists)`. Each element is a linked-list head `{'val', 'next'}` or None. Return the head of the merged sorted list.

<PracticePlayground problemId="ds-algo-prob-56" />

<Solution>

```python
import heapq

def merge_k_lists(lists):
    dummy = {'val': 0, 'next': None}
    cur = dummy
    heap = []
    counter = 0
    for lst in lists:
        if lst:
            heapq.heappush(heap, (lst['val'], counter, lst))
            counter += 1
    while heap:
        val, _, node = heapq.heappop(heap)
        cur['next'] = node
        cur = cur['next']
        if node['next']:
            counter += 1
            heapq.heappush(heap, (node['next']['val'], counter, node['next']))
    return dummy['next']
```

Min-heap of (node_val, tiebreaker, node). Pop the smallest, append it to result, push its successor. O(n log k) time where n = total nodes, k = number of lists. Tiebreaker counter avoids comparing dicts.
