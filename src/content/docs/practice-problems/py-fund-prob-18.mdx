## Overview

Verify multiset equivalence across sparse frequency maps with explicit zero-count handling.

## Task

Implement `frequency_map_equality(freq_a, freq_b)`: return `True` if two frequency dictionaries represent identical multisets. Keys with frequency `0` must be treated as non-existent (e.g. `{"x": 2, "y": 0}` equals `{"x": 2}`).

<PracticePlayground problemId="py-fund-prob-18" />

<Solution>

```python
def frequency_map_equality(freq_a, freq_b):
    clean_a = {k: v for k, v in freq_a.items() if v != 0}
    clean_b = {k: v for k, v in freq_b.items() if v != 0}
    return clean_a == clean_b
```

Pruning zero-valued keys standardizes sparse counters for direct dictionary equivalence testing.
