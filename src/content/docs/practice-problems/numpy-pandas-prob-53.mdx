## Overview

Compute a two-way contingency table of co-occurrence frequencies between categorical series.

## Task

Implement `contingency_table(row_labels, col_labels)`: count joint occurrences of pairs `(r, c)`. Return a dictionary mapping sorted unique row labels to dictionaries of sorted unique column labels with integer counts (0 for non-occurring combinations).

<PracticePlayground problemId="numpy-pandas-prob-53" />

<Solution>

```python
def contingency_table(row_labels, col_labels):
    rows = sorted(list(set(row_labels)))
    cols = sorted(list(set(col_labels)))
    table = {r: {c: 0 for c in cols} for r in rows}
    for r, c in zip(row_labels, col_labels):
        table[r][c] += 1
    return table
```

Two-way cross-tabulation analyzes dependency and interaction between two categorical variables, forming the basis of Chi-squared tests.
