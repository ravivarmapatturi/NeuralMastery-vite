# Token Generation Throughput and Latency

**Track**: transformers-llms | **Points**: 40 XP

## Overview

Compute TTFT, total latency, average inter-token latency, and token throughput (TPS).

## Task

Implement `compute_generation_metrics(time_to_first_token_ms, inter_token_latencies_ms)`. Calculate: `'ttft_ms'` (rounded to 2 decimals), `'total_latency_ms'` = `time_to_first_token_ms + sum(inter_token_latencies_ms)` (rounded to 2 decimals), `'avg_itls_ms'` = average inter-token latency (0.0 if empty, rounded to 2 decimals), and `'tokens_per_second'` = `(1 + len(inter_token_latencies_ms)) / (total_latency_ms / 1000.0)` (0.0 if total_ms `<= 0`, rounded to 2 decimals).
