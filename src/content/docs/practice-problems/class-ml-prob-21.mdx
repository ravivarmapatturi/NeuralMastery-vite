# #821. Classical Machine Learning Module 5: Problem 21

**Track**: Classical Machine Learning | **Rank**: #821 of 1072 | **Points**

## Overview

Update and renormalize sample weights in AdaBoost based on classifier error.

## Task

Implement `adaboost_weight_update(weights, y_true, y_pred, alpha)`: multiply weights by `exp(-alpha * y_true * y_pred)` and normalize so sum equals 1.0, rounded to 4 decimal places.

<PracticePlayground problemId="class-ml-prob-21" />

<Solution>

```python
import math

def adaboost_weight_update(weights, y_true, y_pred, alpha):
    new_weights = [w * math.exp(-alpha * yt * yp) for w, yt, yp in zip(weights, y_true, y_pred)]
    total = sum(new_weights)
    return [round(w / total, 4) for w in new_weights]
```
