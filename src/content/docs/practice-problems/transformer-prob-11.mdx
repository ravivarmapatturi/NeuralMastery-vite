# #011. Transformer Internals Module 3: Problem 11

**Track**: Transformer Internals | **Rank**: #11 of 1072 | **Points**: 60 XP

## Overview

Implement the complete Scaled Dot-Product Attention mechanism across multiple sequence positions. Scaled Dot-Product Attention maps queries and keys to attention weights via softmax, then uses these weights to form a weighted sum over value vectors.

## Task

Implement `scaled_dot_product_attention(Q, K, V)`: compute raw attention scores `S = (Q @ K.T) / sqrt(d_k)`, apply softmax along each row to obtain attention weights `A`, and compute context representations `A @ V`. Return the resulting 2D matrix rounded to 4 decimal places.
