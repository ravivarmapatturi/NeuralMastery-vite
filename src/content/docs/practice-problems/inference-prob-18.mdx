# #048. Grammar-Constrained Token Mask

**Track**: LLM Inference & Decoding | **Rank**: #48 of 1072 | **Points**: 60 XP

## Overview

Enforce deterministic grammar constraints and structured JSON/code schemas via state-machine token filtering. Autoregressive language models generate sequences token by token, evaluating next-token probability distributions at each decoding step.

## Task

Implement `filter_tokens_by_dfa(current_state, transitions, vocab)`. Check `transitions` for `current_state`. If not present, raise `ValueError`. For each token in `vocab` (mapping token ID string to token string), check if the token string exists as an outgoing transition from `current_state`. Collect all matching integer token IDs (sorted ascending) and record their mapped target states in `next_state_map`. Set `is_terminal: True` if the current state has no outgoing transitions. Return dict with `valid_token_ids`, `next_state_map`, and `is_terminal`.
