# #582. Linked Lists / Stacks / Queues Module 5: Problem 22

## Overview

Simulate 1D kinetic collision cascades using stack-based momentum resolution.

## Task

Implement `asteroid_collision(asteroids)`: asteroids move along a 1D line: positive integers move right, negative integers move left. Their absolute value represents size. When moving toward each other, the smaller asteroid explodes; if sizes are equal, both explode. Asteroids moving in the same direction never meet. Return the state of surviving asteroids.

<Solution>

```python
def asteroid_collision(asteroids):
    stack = []
    for ast in asteroids:
        alive = True
        while alive and ast < 0 and stack and stack[-1] > 0:
            if stack[-1] < -ast:
                stack.pop()
            elif stack[-1] == -ast:
                stack.pop()
                alive = False
            else:
                alive = False
        if alive:
            stack.append(ast)
    return stack
```

Stacking surviving right-moving asteroids and resolving incoming negative asteroids in LIFO order processes collisions in O(n) time.
