## Overview

Standardize features to zero mean and unit variance column-wise.

## Task

Implement `z_score_normalize(X)`: compute population mean and population standard deviation `sqrt(sum((x - mean)^2) / n)` per column, transforming each value into `(x - mean) / std`.

<Solution>

```python
import math

def z_score_normalize(X):
    n_rows, n_cols = len(X), len(X[0])
    means = [sum(X[i][j] for i in range(n_rows)) / n_rows for j in range(n_cols)]
    stds = [math.sqrt(sum((X[i][j] - means[j]) ** 2 for i in range(n_rows)) / n_rows) for j in range(n_cols)]
    res = []
    for row in X:
        new_row = []
        for j in range(n_cols):
            s = stds[j]
            val = (row[j] - means[j]) / s if s > 0 else 0.0
            new_row.append(round(val, 4))
        res.append(new_row)
    return res
```

Compute the sample population mean and standard deviation for each feature column, then center and divide by standard deviation.
