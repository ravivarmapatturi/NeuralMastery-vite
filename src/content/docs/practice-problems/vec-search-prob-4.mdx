# #979. Vector Search & Index Optimization Module 1: Problem 4

**Track**: Vector Search & Index Optimization | **Rank**: #979 of 1072 | **Points**: 40 XP

## Overview

Implement `normalize_vector(v)`, L2 normalization -- the preprocessing step that lets an inner-product (dot-product) vector index behave identically to a cosine-similarity search, which is exactly why libraries like FAISS's `IndexFlatIP` expect pre-normalized vectors.

## Task

Implement the function `normalize_vector(v)`, returning `[x / ||v|| for x in v]` where `||v||` is the L2 norm of `v`. Raise `ValueError` if `v` is the zero vector.
