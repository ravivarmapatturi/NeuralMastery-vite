# #506. Python & Programming Fundamentals Module 2: Problem 6

**Track**: Python & Programming Fundamentals | **Rank**: #506 of 1072 | **Points**

## Overview

Split long strings into fixed-character text segments for chunked embedding generation.

## Task

Implement `chunk_string(s, size)`: partition string `s` into consecutive substrings of length `size`. The final substring contains the remaining characters if `len(s)` is not an exact multiple of `size`. If `size <= 0` or `s == ""`, return `[]`.

<PracticePlayground problemId="py-fund-prob-6" />

<Solution>

```python
def chunk_string(s, size):
    if size <= 0 or not s:
        return []
    return [s[i:i + size] for i in range(0, len(s), size)]
```

Python string slice step-iteration produces chunks in linear time without extra copies.

</Solution>
