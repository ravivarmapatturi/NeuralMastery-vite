# Pipeline Stage Latency Percentage Breakdown

**Track**: RAG Production Engineering | **Points**: 40 XP

## Overview

Implement latency percentage breakdown, the real diagnostic every team runs to find which stage of a RAG pipeline is actually the bottleneck.

## Task

Implement `latency_breakdown(stage_latencies_ms)`: return a new dict mapping each stage to its percentage of the TOTAL latency (`stage_latency / total * 100`). Return all zeros if total latency is 0.
