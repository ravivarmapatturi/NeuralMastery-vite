# Select the Largest Community for Summarization

**Track**: Knowledge Graph & GraphRAG | **Points**: 40 XP

## Overview

Implement largest-community selection, a real prioritization step deciding which GraphRAG community summary to generate first when compute is limited.

## Task

Implement `largest_community(communities)`: return the community (list of entity names) with the MOST members. Ties broken by whichever appears FIRST in `communities`. Return the sorted version of that community.
