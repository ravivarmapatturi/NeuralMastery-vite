# Check Tool Annotations for Destructive Hints

**Track**: MCP Core Engineering | **Points**: 40 XP

## Overview

Implement destructive-tool-call gating based on MCP tool annotations, a real safety check before letting an agent auto-execute a risky tool.

## Task

Implement `requires_confirmation(annotations)`. `annotations` may contain `readOnlyHint` and `destructiveHint` (both booleans, default `False` if absent). Return `True` (needs human confirmation) if `destructiveHint` is `True` AND `readOnlyHint` is `False`. Otherwise `False`.
