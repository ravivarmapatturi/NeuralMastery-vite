# Elbow Method: Detect the Knee in a WCSS Curve

**Track**: Clustering & Recommender Systems | **Points**: 40 XP

## Overview

Implement a real, deterministic knee-detection rule for the elbow method, turning a subjective visual heuristic into a reproducible function.

## Task

Implement `elbow_k(wcss_values)`. `wcss_values[i]` is the WCSS for `k=i+1` clusters (i.e. index 0 is k=1). For each interior index `i` from `1` to `len-2` inclusive, compute the second difference `wcss[i-1] - 2*wcss[i] + wcss[i+1]`. Return the k (i.e. `i+1`) with the LARGEST second difference (the sharpest bend). If `len(wcss_values) < 3`, return `1`.
