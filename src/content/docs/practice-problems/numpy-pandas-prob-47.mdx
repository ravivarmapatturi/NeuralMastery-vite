# Pandas Module 47: Problem 227

**Rank #227** · Difficulty: **Medium** · Stage: **Stage 4: NumPy & Vectorized Data Processing** · Category: **NumPy & Pandas**

## Overview

Group low-frequency categorical levels into a consolidated rare label.

## Task

Implement `encode_with_rare_grouping(categories, min_count, rare_label)`: count the occurrences of each category string. Replace any category whose frequency is strictly less than `min_count` with `rare_label`. Return the transformed list.

<PracticePlayground problemId="numpy-pandas-prob-47" />

<Solution>

```python
from collections import defaultdict

def encode_with_rare_grouping(categories, min_count, rare_label):
    counts = defaultdict(int)
    for c in categories:
        counts[c] += 1
    return [c if counts[c] >= min_count else rare_label for c in categories]
```

Rare category grouping prevents high-cardinality explosion and protects models against overfitting to sparse categories.

</Solution>
