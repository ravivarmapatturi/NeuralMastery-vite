# #033. Repetition Penalty Scaling

**Track**: LLM Inference & Decoding | **Rank**: #33 of 1072 | **Points**: 40 XP

## Overview

Prevent repetitive degenerative loops in generated text using Keskar multiplicative repetition penalty. Autoregressive language models generate sequences token by token, evaluating next-token probability distributions at each decoding step.

## Task

Implement `apply_repetition_penalty(logits, context_tokens, penalty)`. For each unique token index `i` in `context_tokens` that lies within `[0, len(logits)-1]`: if `logits[i] > 0`, update to `logits[i] / penalty`; otherwise update to `logits[i] * penalty`. Return updated logits rounded to 4 decimal places. If `penalty <= 0.0`, raise `ValueError`.
