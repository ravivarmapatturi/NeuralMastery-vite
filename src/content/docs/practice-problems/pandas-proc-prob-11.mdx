# #781. Hierarchical Multi-Index DataFrame Unstacking

**Track**: Pandas & Data Processing Pipelines | **Rank**: #781 of 1072 | **Points**: 60 XP

## Overview

Unstack innermost categorical hierarchy levels from rows into column attributes.

## Task

Implement `unstack_multilevel_index(rows)`: given a list of tuples `(entity, date, metric, value)`, unstack the `metric` level into a columnar dictionary. Return nested dictionary structure `{entity: {date: {metric: value}}}` sorted by entity name with float values rounded to 4 decimals.

<PracticePlayground problemId="pandas-proc-prob-11" />

<Solution>

```python
from collections import defaultdict

def unstack_multilevel_index(rows):
    res = defaultdict(lambda: defaultdict(dict))
    for entity, date, metric, val in rows:
        res[entity][date][metric] = round(float(val), 4)
    return {k: {dk: dict(dv) for dk, dv in v.items()} for k, v in sorted(res.items())}
```

Pivots long relational multi-index tuples into a nested dictionary.
