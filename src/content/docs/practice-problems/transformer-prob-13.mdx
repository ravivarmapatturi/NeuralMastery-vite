# #013. Transformer Internals Module 3: Problem 13

**Track**: Transformer Internals | **Rank**: #13 of 1072 | **Points**: 60 XP

## Overview

Construct a causal (lower-triangular) binary attention mask matrix. Causal masking ensures autoregressive language models obey the temporal constraint that prediction at position `i` depends only on tokens at positions `j <= i`.

## Task

Implement `create_causal_mask(seq_len)`: return an `seq_len x seq_len` matrix where element `[i][j]` is `1` if `j <= i` and `0` if `j > i`. If `seq_len <= 0`, raise `ValueError`.
