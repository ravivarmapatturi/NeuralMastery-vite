# #010. Transformer Internals Module 2: Problem 10

**Track**: Transformer Internals | **Rank**: #10 of 1072 | **Points**: 40 XP

## Overview

Update the key-value cache (KV cache) during autoregressive token generation. Caching keys and values from prior decoding steps avoids recomputing attention states for already generated tokens, drastically reducing inference latency.

## Task

Implement `update_kv_cache(keys, values, new_key, new_value)`: append `new_key` to `keys` and `new_value` to `values`. Return the updated `(keys, values)` tuple. If dimensions of `new_key` and `new_value` do not match existing cached vectors, raise `ValueError`.
