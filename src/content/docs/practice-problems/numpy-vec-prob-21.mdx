# #761. Vectorized Multi-Head Attention Reshape and Transpose

**Track**: NumPy & Vectorized Computation | **Rank**: #761 of 1072 | **Points**: 60 XP

## Overview

Reshape and permute token hidden representations to isolate parallel multi-head attention streams.

## Task

Implement `split_multi_head_projections(hidden_states, num_heads, head_dim)`: transform a 3D tensor of shape `(B, S, num_heads * head_dim)` into a 4D tensor of shape `(B, num_heads, S, head_dim)` by splitting the last dimension into heads and swapping sequence and head dimensions.

<Solution>

```python
def split_multi_head_projections(hidden_states, num_heads, head_dim):
    B = len(hidden_states)
    S = len(hidden_states[0]) if B > 0 else 0
    out = []
    for b in range(B):
        heads = [[] for _ in range(num_heads)]
        for s in range(S):
            token = hidden_states[b][s]
            for h in range(num_heads):
                heads[h].append(token[h * head_dim:(h + 1) * head_dim])
        out.append(heads)
    return out
```

Iterates through tokens, slices head segments, and organizes by batch and head.
