# Levenshtein Minimum Edit Distance

**Track**: Deep Learning & Vision/NLP | **Points**: 40 XP

## Overview

Compute parameterized Levenshtein edit distance using 2D dynamic programming for NLP spelling and evaluation.

## Task

Implement `levenshtein_distance(s1, s2, ins_cost, del_cost, sub_cost)`. Compute the minimum cost to transform string `s1` into string `s2` using character insertions (`ins_cost`), deletions (`del_cost`), and substitutions (`sub_cost`). If characters match, cost is 0. Return the minimum integer cost.
