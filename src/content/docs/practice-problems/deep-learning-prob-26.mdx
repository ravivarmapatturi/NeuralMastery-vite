# Pad Variable-Length Sequence Batch

**Track**: Deep Learning & Vision/NLP | **Points**: 40 XP

## Overview

Pad ragged text sequences into a rectangular tensor and generate corresponding binary attention masks.

## Task

Implement `pad_sequence_batch(sequences, pad_val)`. For a list of variable-length integer token lists `sequences`, find the maximum sequence length `max_len`. Right-pad each sequence with `pad_val` so all have length `max_len`. Also construct an attention mask matrix where real tokens are `1` and padding positions are `0`. Return tuple `(padded_sequences, attention_masks)`.
