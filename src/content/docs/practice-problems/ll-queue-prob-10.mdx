## Overview

Simulate keystroke editor backspace operations using LIFO stack buffering.

## Task

Implement `backspace_compare(s, t)`: return `True` if `s` and `t` result in identical text after interpreting `#` as a backspace deleting the previous character. If the editor is empty, `#` does nothing.

<PracticePlayground problemId="ll-queue-prob-10" />

<Solution>

```python
def backspace_compare(s, t):
    def build(st):
        stack = []
        for ch in st:
            if ch == '#':
                if stack: stack.pop()
            else:
                stack.append(ch)
        return "".join(stack)
    return build(s) == build(t)
```

Pushing characters and popping on "#" generates the exact final typed buffer in linear time.
