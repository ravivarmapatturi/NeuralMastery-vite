# CBOW Context Vector Mean Aggregator

**Track**: Deep Learning & Vision/NLP | **Points**: 40 XP

## Overview

Compute the averaged context representation vector for Word2Vec Continuous Bag-Of-Words (CBOW) architecture.

## Task

Implement `cbow_context_averaging(context_indices, embedding_matrix)`. Look up the embedding row in `embedding_matrix` for each index in `context_indices`. Compute the element-wise arithmetic mean vector across all context words. Return the list of floats rounded to 4 decimal places.
