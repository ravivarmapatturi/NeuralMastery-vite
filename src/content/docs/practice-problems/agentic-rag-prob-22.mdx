# Calibrate Answer Confidence From Retrieval Score Distribution

**Track**: Advanced RAG & Agentic RAG | **Points**: 40 XP

## Overview

Implement retrieval-margin-based confidence calibration, a real signal distinguishing 'one document is a clear, confident match' from 'several documents are similarly, ambiguously relevant.'

## Task

Implement `calibrated_confidence(top_score, second_score)`. Return `top_score * (top_score - second_score)` -- combining the top score's absolute magnitude with its MARGIN over the runner-up (both matter: a high top score with a small margin is less trustworthy than the same top score with a large margin).
