# #024. Transformer Internals Module 5: Problem 24

**Track**: Transformer Internals | **Rank**: #24 of 1072 | **Points**: 90 XP

## Overview

Compute the forward pass of a LoRA (Low-Rank Adaptation) linear layer. LoRA decomposes weight updates into two low-rank matrices `A` and `B`, drastically reducing trainable parameters while maintaining the capabilities of pretrained base weights.

## Task

Implement `lora_linear(x, W, A, B, r, alpha)`: compute output `y = W @ x + (alpha / r) * (B @ (A @ x))`. `W` is the base weight matrix, `A` maps from input dimension to rank `r`, and `B` maps from `r` to output dimension. Return the resulting vector rounded to 4 decimal places.
