# #030. Transformer Internals Module 6: Problem 30

**Track**: Transformer Internals | **Rank**: #30 of 1072 | **Points**: 90 XP

## Overview

Calculate head-specific slope parameters for Attention with Linear Biases (ALiBi). ALiBi introduces a non-learned geometric slope to attention logits based on token distance, enabling models to extrapolate seamlessly to sequence lengths longer than seen during training.

## Task

Implement `alibi_slopes(num_heads)`: compute slope `2 ** (-8 * h / num_heads)` for each head `h = 1, 2, ..., num_heads`. Return the list of slopes rounded to 6 decimal places. If `num_heads <= 0`, raise `ValueError`.
