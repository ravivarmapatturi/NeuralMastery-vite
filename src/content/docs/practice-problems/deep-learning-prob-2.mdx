# Center Crop 2D Image Matrix

**Track**: Deep Learning & Vision/NLP | **Points**: 40 XP

## Overview

Extract the center spatial crop from an image matrix, the standard evaluation preprocessing in vision pipelines.

## Task

Implement `center_crop_2d(image, crop_h, crop_w)`. For an input 2D image matrix of size `H x W`, extract a centered window of size `crop_h x crop_w`. The top-left starting indices are `start_r = (H - crop_h) // 2` and `start_c = (W - crop_w) // 2`.
