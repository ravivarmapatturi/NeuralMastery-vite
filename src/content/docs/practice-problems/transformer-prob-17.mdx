# #017. Transformer Internals Module 4: Problem 17

**Track**: Transformer Internals | **Rank**: #17 of 1072 | **Points**: 60 XP

## Overview

Construct a smoothed target probability distribution for classification and language modeling regularization. Label smoothing distributes a small probability mass `epsilon` uniformly across incorrect classes to prevent overconfidence and improve generalization.

## Task

Implement `label_smoothed_targets(target, num_classes, epsilon=0.1)`: return a probability distribution of length `num_classes` where the true `target` index receives `(1.0 - epsilon) + (epsilon / num_classes)` and all other classes receive `epsilon / num_classes`. Return floats rounded to 4 decimal places. If inputs are invalid, raise `ValueError`.
