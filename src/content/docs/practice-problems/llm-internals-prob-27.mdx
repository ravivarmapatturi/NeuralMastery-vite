# GELU Activation Function

**Track**: transformers-llms | **Points**: 40 XP

## Overview

Implement the GELU (Gaussian Error Linear Unit) activation using the tanh approximation.

## Task

Implement `gelu(x)` using the tanh approximation: `0.5 * x * (1.0 + tanh(sqrt(2/pi) * (x + 0.044715 * x**3)))`. Return the result rounded to 4 decimal places.
