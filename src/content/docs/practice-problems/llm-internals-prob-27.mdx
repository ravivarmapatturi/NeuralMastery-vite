# GELU Activation Function

**Rank #387** · Difficulty: **Medium** · Stage: **Stage 7: Transformers, LLMs & Foundation Models** · Category: **Transformers & LLMs**

Implement `gelu(x)` using the tanh approximation: `0.5 * x * (1 + tanh(sqrt(2/pi) * (x + 0.044715 * x**3)))`. Return the result rounded to 4 decimal places. This approximation, used in GPT-2 and BERT, closely matches the exact GELU which involves the Gaussian CDF. Prerequisite: `llm-internals-prob-26`.

<PracticePlayground problemId="llm-internals-prob-27" />

<Solution>

```python
import math

def gelu(x):
    coeff = math.sqrt(2.0 / math.pi)
    return round(0.5 * x * (1.0 + math.tanh(coeff * (x + 0.044715 * x ** 3))), 4)
```

GELU multiplies the input by its own CDF under a standard normal distribution: `GELU(x) = x * Phi(x)`. Unlike ReLU which hard-zeros negative inputs, GELU smoothly attenuates them in proportion to how likely they are under the Gaussian distribution. This "probabilistic" gating improves gradient flow and is why GELU became the standard activation in transformer FFN layers.

</Solution>
