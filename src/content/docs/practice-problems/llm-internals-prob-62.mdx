# Build a Padding Attention Mask From Sequence Lengths

**Track**: Transformers & LLMs | **Points**: 40 XP

## Overview

Implement padding-mask construction, telling attention which positions in a batched, padded set of variable-length sequences are real tokens versus padding to ignore.

## Task

Implement `padding_attention_mask(seq_lengths, max_len)`. Return one boolean row per sequence in `seq_lengths`, each of length `max_len`, where position `j` is `True` (real token) if `j < seq_lengths[i]`, else `False` (padding).
