# #587. Linked Lists / Stacks / Queues Module 6: Problem 27

## Overview

Merge K independently sorted linked lists in O(N log K) time using a priority queue min-heap.

## Task

Implement `merge_k_sorted_lists(lists)`: given an array of `k` sorted linked lists, merge all nodes into a single sorted linked list in ascending order. Must run in O(N log k) time where N is the total count of nodes across all lists.

<PracticePlayground problemId="ll-queue-prob-27" />

<Solution>

```python
import heapq

def merge_k_sorted_lists(lists):
    heap = []
    entry_id = 0
    for h in lists:
        if h:
            heapq.heappush(heap, (h['val'], entry_id, h))
            entry_id += 1
    dummy = {'val': 0, 'next': None}
    curr = dummy
    while heap:
        val, _, node = heapq.heappop(heap)
        curr['next'] = {'val': val, 'next': None}
        curr = curr['next']
        if node.get('next'):
            nxt = node['next']
            heapq.heappush(heap, (nxt['val'], entry_id, nxt))
            entry_id += 1
    return dummy['next']
```

A min-heap of size K retrieves the smallest available node across all lists in O(log K) per step.
