# Mathematics Module 48: Problem 168

**Rank #168** · Difficulty: **Medium** · Stage: **Stage 3: Mathematics & Numerical Computing** · Category: **Math & Numerical**

## Overview

Simulate the discrete state-space trajectory of a linear time-invariant dynamical system.

## Task

Implement `linear_system_rollout(A, B, x0, U)`: starting from state `x0` at t=0, sequentially compute `x_{t+1} = A * x_t + B * u_t` for each control vector in `U`. Return the full state trajectory `[x0, x1, ..., xT]` with coordinates rounded to 4 decimals.

<Solution>

```python
def linear_system_rollout(A, B, x0, U):
    trajectory = [list(x0)]
    curr_x = list(x0)
    n = len(x0)
    for u in U:
        m = len(u)
        Ax = [sum(A[i][j] * curr_x[j] for j in range(n)) for i in range(n)]
        Bu = [sum(B[i][j] * u[j] for j in range(m)) for i in range(n)]
        next_x = [Ax[i] + Bu[i] for i in range(n)]
        curr_x = next_x
        trajectory.append([round(float(v), 4) for v in curr_x])
    return trajectory
```

Iterates forward in discrete time applying linear state and control transitions.
