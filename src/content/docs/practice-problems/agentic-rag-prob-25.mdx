# Compute Pipeline Ablation Score Delta

**Track**: Advanced RAG & Agentic RAG | **Points**: 40 XP

## Overview

Implement ablation-score-delta computation, the real, standard way to measure how much a specific RAG pipeline component (reranking, query rewriting, compression) actually contributes to overall quality.

## Task

Implement `ablation_delta(full_pipeline_score, ablated_pipeline_score)`: return `full_pipeline_score - ablated_pipeline_score` (a positive delta means the ablated component genuinely helps; negative or near-zero means it may not be worth its added cost/latency).
