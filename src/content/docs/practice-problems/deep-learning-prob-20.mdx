# BLEU Clipped N-gram Precision Calculator

**Track**: Deep Learning & Vision/NLP | **Points**: 40 XP

## Overview

Compute the clipped n-gram overlap counts used to calculate modified n-gram precision in BLEU score evaluation.

## Task

Implement `bleu_clipped_ngram_counts(candidate, references, n)`. Extract all `n`-grams from `candidate` and compute each unique n-gram's frequency. For each unique n-gram, clip its count to the maximum frequency it achieves in ANY single reference sentence. Return `[clipped_count, total_candidate_ngrams]`. If candidate has fewer than `n` tokens, return `[0, 0]`.
