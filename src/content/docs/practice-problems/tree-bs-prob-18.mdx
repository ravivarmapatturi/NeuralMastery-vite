## Overview

Traverse a binary tree level by level, alternating horizontal scan direction between left-to-right and right-to-left.

## Task

Implement `zigzag_level_order(root)`: perform BFS level-order traversal, alternating the order of elements appended to each level list depending on whether the level index is even or odd.

<Solution>

```python
def zigzag_level_order(root):
    if not root:
        return []
    result = []
    queue = [root]
    left_to_right = True
    while queue:
        vals = [n['val'] for n in queue]
        if not left_to_right:
            vals.reverse()
        result.append(vals)
        left_to_right = not left_to_right
        next_queue = []
        for n in queue:
            if n.get('left'):
                next_queue.append(n['left'])
            if n.get('right'):
                next_queue.append(n['right'])
        queue = next_queue
    return result
```
