# #749. Vectorized 1D Moving Average Filter

**Track**: NumPy & Vectorized Computation | **Rank**: #749 of 1072 | **Points**: 40 XP

## Overview

Apply a uniform rolling moving average filter to smooth 1D sequential data.

## Task

Implement `moving_average_1d(signal, window_size)`: calculate rolling average over consecutive windows of size `window_size` in valid mode (length `len(signal) - window_size + 1`). Return values rounded to 4 decimals.

<PracticePlayground problemId="numpy-vec-prob-9" />

<Solution>

```python
def moving_average_1d(signal, window_size):
    n = len(signal)
    if window_size > n or window_size <= 0:
        return []
    curr_sum = sum(signal[:window_size])
    res = [round(float(curr_sum / window_size), 4)]
    for i in range(window_size, n):
        curr_sum += signal[i] - signal[i - window_size]
        res.append(round(float(curr_sum / window_size), 4))
    return res
```

Updates sliding window sum in O(1) time per element and divides by window width.
