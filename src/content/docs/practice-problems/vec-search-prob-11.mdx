**Track**: Vector Search & Index Optimization | **Rank**: #986 of 1072 | **Points**: 60 XP

## Overview

Implement `range_query(query, vectors, radius)`, the 'find everything within distance r' query mode vector databases expose alongside top-k search -- used for near-duplicate detection and density-based clustering algorithms like DBSCAN.

## Task

Implement the function `range_query(query, vectors, radius)`: return the indices of every vector whose Euclidean distance to `query` is `<= radius`, ordered nearest-first with ties broken by ascending index. Return an empty list if none qualify.
