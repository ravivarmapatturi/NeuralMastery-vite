# Beam Search Hypothesis Expansion Step

**Track**: Deep Learning & Vision/NLP | **Points**: 40 XP

## Overview

Expand current active beam hypotheses by token log-probabilities and retain the top-K highest scoring paths.

## Task

Implement `beam_search_step(candidates, next_token_logprobs, beam_width)`. `candidates` is a list of `B` hypotheses, each `[tokens_list, cumulative_logprob]`. `next_token_logprobs[i]` is a list of log-probabilities for all vocabulary tokens given hypothesis `i`. Form all `B * V` new hypotheses: `[tokens + [v], round(cum_logprob + logprob[v], 4)]`. Sort descending by score (ties broken by lower token index at the newest position), and return the top `beam_width` hypotheses.
