# Proportional Token Budget Allocation

**Track**: RAG Production Engineering | **Points**: 40 XP

## Overview

Implement proportional token-budget allocation across multiple retrieval sources (e.g. docs, code, chat history) in a multi-source RAG system.

## Task

Implement `allocate_token_budget(source_weights, total_budget)`. Each source's allocated tokens is `floor(total_budget * weight / sum(all_weights))`. Any leftover tokens (from flooring) go to the source with the LARGEST weight (ties broken alphabetically by source name). Return a dict of source -> allocated tokens; all allocations must sum to exactly `total_budget`.
