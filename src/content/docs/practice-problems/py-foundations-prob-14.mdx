# Top K Frequent Elements

**Rank #14** · Difficulty: **Easy** · Stage: **Stage 1: AI Foundations & Python Programming** · Category: **Python & Fundamentals** | **Points**: 40 XP

## Overview

Implement `top_k_frequent(items, k)`: identify the k most frequent items with deterministic tie-breaking, raising ValueError if k is out of bounds.

## Task

Implement the function `top_k_frequent(items, k)`: return a list of the `k` most common elements sorted by descending frequency, breaking ties by `str(x)` ascending. If `k < 0` or `k` exceeds the number of distinct elements, raise `ValueError`.

<Solution>

```python
def top_k_frequent(items, k):
    if k < 0:
        raise ValueError('k cannot be negative')
    if not items:
        if k == 0:
            return []
        raise ValueError('k exceeds number of unique elements')
    freq = {}
    for x in items:
        freq[x] = freq.get(x, 0) + 1
    if k > len(freq):
        raise ValueError('k exceeds number of unique elements')
    sorted_items = sorted(freq.keys(), key=lambda x: (-freq[x], str(x)))
    return sorted_items[:k]
```

Filtering datasets down to top-K frequent categories or tokens prevents high-cardinality explosion and prunes long-tail noise in ML pipelines.
