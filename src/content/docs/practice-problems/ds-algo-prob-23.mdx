# Graphs: Number of Connected Components (Union-Find)

## Overview

Implement `count_components(n, edges)` using Union-Find -- the canonical disjoint-set problem. Introduces path compression and union by rank.

## Task

Implement the function `count_components(n, edges)`. Nodes are `0..n-1`. Return the number of connected components in the undirected graph.

<Solution>

```python
def count_components(n, edges):
    parent = list(range(n))

    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]  # path compression (halving)
            x = parent[x]
        return x

    def union(x, y):
        px, py = find(x), find(y)
        if px == py:
            return
        parent[px] = py

    for u, v in edges:
        union(u, v)
    return len(set(find(i) for i in range(n)))
```

Union-Find with path-compression halving. After processing all edges, count distinct roots. O(E * alpha(n)) time where alpha is the inverse Ackermann function (essentially O(1)).
