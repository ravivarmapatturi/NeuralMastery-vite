# #665. Dynamic Programming & Greedy Module 3: Problem 15

**Track**: Dynamic Programming & Greedy | **Rank**: #665 of 1072 | **Points**

## Overview

Determine if the end of an array is reachable using a greedy farthest-reach window scan.

## Task

Implement `can_jump(nums)`: track the maximum reachable index max_reach. If current index `i > max_reach`, return False; otherwise update `max_reach = max(max_reach, i + nums[i])`.

<PracticePlayground problemId="dp-greedy-prob-15" />

<Solution>

```python
def can_jump(nums):
    max_reach = 0
    for i, jump in enumerate(nums):
        if i > max_reach:
            return False
        if i + jump > max_reach:
            max_reach = i + jump
    return True
```

Scan through the array while maintaining the farthest index reachable. If the current index exceeds max_reach, jumping is blocked; otherwise expand max_reach.
