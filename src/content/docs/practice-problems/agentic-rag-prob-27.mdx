# Compute Real Retrieval Diversity via MMR-Style Redundancy Penalty

**Track**: Advanced RAG & Agentic RAG | **Points**: 40 XP

## Overview

Implement a real redundancy-penalty computation, the diversity half of any MMR-style diverse-retrieval selection, measuring how similar a candidate chunk is to what's already been chosen.

## Task

Implement `redundancy_penalty(candidate_embedding, selected_embeddings)`. Return the MAXIMUM cosine similarity between `candidate_embedding` and any vector in `selected_embeddings`. Return `0.0` if `selected_embeddings` is empty (nothing selected yet means zero redundancy).
