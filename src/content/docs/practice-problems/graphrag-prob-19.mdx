# Filter Extracted Triples by Confidence Threshold

**Track**: Knowledge Graph & GraphRAG | **Points**: 40 XP

## Overview

Implement confidence-based triple filtering, a real quality gate before a low-confidence LLM-extracted fact is committed to the permanent knowledge graph.

## Task

Implement `filter_by_confidence(triples, min_confidence)`. Each triple has a `confidence` field. Return the sublist of triples with `confidence >= min_confidence`, preserving order.
