# #026. Transformer Internals Module 6: Problem 26

**Track**: Transformer Internals | **Rank**: #26 of 1072 | **Points**: 90 XP

## Overview

Compute the acceptance probability of speculative tokens in Speculative Decoding. Speculative decoding speeds up LLM inference by generating draft tokens with a small model and verifying them in parallel with a larger target model.

## Task

Implement `speculative_acceptance_prob(draft_probs, target_probs, draft_token)`: given draft and target probability distributions over the vocabulary, compute acceptance probability `min(1.0, target_probs[draft_token] / draft_probs[draft_token])`. Return the probability float rounded to 4 decimal places.
