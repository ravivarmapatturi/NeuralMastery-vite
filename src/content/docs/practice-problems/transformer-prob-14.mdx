# #014. Transformer Internals Module 3: Problem 14

**Track**: Transformer Internals | **Rank**: #14 of 1072 | **Points**: 60 XP

## Overview

Compute the cross-entropy loss between predicted model logits and a ground truth target token. Cross-entropy loss measures the negative log-probability of the true target token under the predicted probability distribution.

## Task

Implement `cross_entropy_loss(logits, target)`: compute `-log(softmax(logits)[target])` using numerically stable log-sum-exp arithmetic: `loss = max(logits) + log(sum(exp(l_i - max(logits)))) - logits[target]`. Return the loss rounded to 4 decimal places. If `target` is out of bounds or `logits` is empty, raise `ValueError`.
