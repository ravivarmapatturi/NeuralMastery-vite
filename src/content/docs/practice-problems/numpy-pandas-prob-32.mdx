# Pandas Module 32: Problem 212

**Rank #212** · Difficulty: **Medium** · Stage: **Stage 4: NumPy & Vectorized Data Processing** · Category: **NumPy & Pandas**

## Overview

Unpivot tabular records from wide format to tidy long format.

## Task

Implement `melt_dataframe(records, id_vars, value_vars, var_name, value_name)`: for each row, retain keys in `id_vars`, and unpivot each column in `value_vars` into a new row with `var_name` set to the column name and `value_name` set to the value.

<PracticePlayground problemId="numpy-pandas-prob-32" />

<Solution>

```python
def melt_dataframe(records, id_vars, value_vars, var_name, value_name):
    out = []
    for r in records:
        base = {k: r[k] for k in id_vars if k in r}
        for vcol in value_vars:
            if vcol in r:
                c = dict(base)
                c[var_name] = vcol
                c[value_name] = r[vcol]
                out.append(c)
    return out
```

Melting transforms columns into key-value observations, enabling tidy data manipulation and faceted visualizations.
