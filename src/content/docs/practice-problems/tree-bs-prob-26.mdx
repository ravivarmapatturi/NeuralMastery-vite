# #616. Trees / Binary Search Module 6: Problem 26

**Track**: Trees / Binary Search | **Rank**: #616 of 1072 | **Points**

## Overview

Reconstruct the original binary tree structure from its serialized preorder string representation containing null markers.

## Task

Implement `deserialize_tree(data)`: tokenize the string by commas into an iterator. Recursively consume tokens: if token is "#", return None; otherwise construct a node with int(val) and recursively build left and right children.

<PracticePlayground problemId="tree-bs-prob-26" />

<Solution>

```python
def deserialize_tree(data):
    tokens = iter(data.split(','))
    def helper():
        val = next(tokens, None)
        if val is None or val == '#':
            return None
        node = {'val': int(val), 'left': None, 'right': None}
        node['left'] = helper()
        node['right'] = helper()
        return node
    return helper()
```

Iterate through tokens. In preorder order, the first token is the root; its left subtree consumes tokens until it completes, after which the right subtree consumes its tokens.

</Solution>
