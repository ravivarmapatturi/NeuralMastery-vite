# Hard Negative Triplet Mining

**Track**: Deep Learning & Vision/NLP | **Points**: 40 XP

## Overview

Identify the hardest negative sample violating the triplet margin constraint for efficient contrastive training.

## Task

Implement `mine_hard_triplet(anchor, positive, negatives, margin)`. Let `d(u, v) = sqrt(sum((u - v)^2))`. Compute `d_pos = d(anchor, positive)`. A negative `negatives[k]` violates the margin if `d(anchor, negatives[k]) < d_pos + margin`. Find the index `k` among all violating negatives that MINIMIZES `d(anchor, negatives[k])` (the hardest negative closest to anchor; ties broken by smallest index). If no negative violates the margin, return `-1`.
