# User-Based Collaborative Filtering Prediction

**Track**: Clustering & Recommender Systems | **Points**: 40 XP

## Overview

Implement the real user-based collaborative filtering prediction formula: a similarity-weighted average of neighbors' ratings for an unseen item.

## Task

Implement `predict_rating_user_cf(target_ratings, neighbor_ratings, similarities, item)`. Among neighbors (keys of `neighbor_ratings`) who have rated `item`, predicted rating is `sum(sim[n] * neighbor_ratings[n][item]) / sum(abs(sim[n]))` over those neighbors. If no neighbor has rated `item`, return `0.0`.
