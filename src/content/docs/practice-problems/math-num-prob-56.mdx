# Mathematics Module 56: Problem 176

**Rank #176** · Difficulty: **Medium** · Stage: **Stage 3: Mathematics & Numerical Computing** · Category: **Math & Numerical**

## Overview

Apply a projected gradient descent update constrained to an L2 Euclidean ball.

## Task

Implement `projected_gradient_descent_step(w, grad, lr=0.1, radius=1.0)`: compute unconstrained update `u = w - lr * grad`. If `||u||_2 > radius`, project to boundary `w_next = (radius / ||u||_2) * u`; otherwise `w_next = u`. Return `w_next` rounded to 4 decimals.

<PracticePlayground problemId="math-num-prob-56" />

<Solution>

```python
import math

def projected_gradient_descent_step(w, grad, lr=0.1, radius=1.0):
    unproj = [wi - lr * gi for wi, gi in zip(w, grad)]
    norm = math.sqrt(sum(x ** 2 for x in unproj))
    if norm > radius and norm > 1e-12:
        proj = [x * (radius / norm) for x in unproj]
    else:
        proj = unproj
    return [round(float(x), 4) for x in proj]
```

Takes gradient step in unconstrained space and projects radial excess onto the boundary.
