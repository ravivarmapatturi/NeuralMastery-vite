# Anchor Box Target Assignment

**Track**: Deep Learning & Vision/NLP | **Points**: 40 XP

## Overview

Assign training labels to candidate anchor boxes based on Intersection-over-Union thresholds against ground truth.

## Task

Implement `anchor_matching(anchors, gt_boxes, pos_thresh, neg_thresh)`. For each anchor box, compute its IoU with every ground-truth box. If the maximum IoU is `>= pos_thresh`, assign the index of the ground truth box with highest IoU (ties broken by lowest gt index). If maximum IoU is `< neg_thresh`, assign `-1` (background). Otherwise, assign `-2` (neutral / ignore). Return list of assignments.
