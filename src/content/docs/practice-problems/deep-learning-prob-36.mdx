# Lucas-Kanade Optical Flow 2x2 Solver

**Track**: Deep Learning & Vision/NLP | **Points**: 40 XP

## Overview

Solve the 2x2 normal equations for local optical flow velocity vector (u, v) from spatial and temporal image gradients.

## Task

Implement `lucas_kanade_2x2_flow(Ix, Iy, It)`. In a local window of N pixels, spatial gradients `Ix, Iy` and temporal gradient `It` satisfy `[sum(Ix^2), sum(Ix*Iy); sum(Ix*Iy), sum(Iy^2)] * [u, v]^T = -[sum(Ix*It), sum(Iy*It)]^T`. Compute determinant `det = sum(Ix^2)*sum(Iy^2) - sum(Ix*Iy)^2`. If `abs(det) < 1e-7`, system is degenerate / aperture problem: return `[0.0, 0.0]`. Otherwise solve via 2x2 inverse and return `[round(u, 4), round(v, 4)]`.
