# Prefix Autocomplete Search Ranking

**Rank #58** · Difficulty: **Hard** · Stage: **Stage 1: AI Foundations & Python Programming** · Category: **Python & Fundamentals**

## Overview

Filter and rank autocomplete search query candidates with multi-attribute tie-breaking.

## Task

Implement `autocomplete(words_with_scores, prefix, top_k)`: given pairs of `(word, score)`, find all words starting with `prefix`. Rank them by descending popularity score, breaking ties alphabetically. Return at most `top_k` word strings.

<PracticePlayground problemId="py-foundations-prob-58" />

<Solution>

```python
def autocomplete(words_with_scores, prefix, top_k):
    matches = []
    for word, score in words_with_scores:
        if word.startswith(prefix):
            matches.append((score, word))
    matches.sort(key=lambda x: (-x[0], x[1]))
    return [w for _, w in matches[:top_k]]
```

Filtering on prefix followed by sorting with composite key `(-score, word)` cleanly ranks candidate queries.

</Solution>
