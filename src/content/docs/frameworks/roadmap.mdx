# Frameworks — Roadmap

The tools you'll actually type into a terminal.

## 1. [Core ML/DL](/docs/frameworks/core-ml-dl-frameworks)
- [x] PyTorch — tensors, autograd, `nn.Module`, training loops
- [x] Hugging Face `transformers` and `datasets`
- [x] Experiment tracking: Weights & Biases / MLflow

## 2. [LLM / Agent Frameworks](/docs/frameworks/llm-agent-frameworks)
- [x] LangChain — chains, retrievers, agents
- [x] LlamaIndex — data indexing and retrieval for RAG
- [x] An MCP SDK (Python or TypeScript) — building MCP servers/clients
- [x] An agent framework (e.g. LangGraph, CrewAI) for multi-agent orchestration

## 3. [Serving & MLOps / LLMOps](/docs/frameworks/serving-mlops)
- [x] Model serving: vLLM, TorchServe, Triton
- [x] Containerization & deployment basics (Docker)
- [x] CI/CD for ML: automated retraining and evaluation pipelines
- [x] Observability for LLM apps: tracing prompts/responses, cost tracking
