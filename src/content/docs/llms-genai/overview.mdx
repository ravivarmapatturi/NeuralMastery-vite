# LLMs & GenAI Overview

This is where the Transformer architecture from [Deep Learning](/docs/deep-learning/roadmap) turns into systems like GPT, Claude, and LLaMA: how they're built internally, how they're trained to be helpful and aligned, how to prompt and ground them effectively, and how to serve them efficiently in production.

Follow the [roadmap](/docs/llms-genai/roadmap) for the full ordered path, or jump straight to a topic:

- [Foundation Model & Transformer Internals](/docs/llms-genai/foundation-model-internals) — tokenization, embeddings, KV cache, MoE, architecture families
- [Training Pipeline](/docs/llms-genai/training-pipeline) — pretraining, SFT, RLHF, DPO, GRPO, PEFT/LoRA, distillation, quantization
- [Prompt Engineering](/docs/llms-genai/prompt-engineering) — few-shot, chain-of-thought, ReAct, prompt injection defenses
- [Retrieval-Augmented Generation (RAG)](/docs/llms-genai/rag) — chunking, hybrid search, re-ranking, GraphRAG, evaluation
- [Evaluation & Serving](/docs/llms-genai/evaluation-and-serving) — benchmarks, LLM-as-judge, batching, speculative decoding, Paged Attention
- [Multimodal & Generative Models](/docs/llms-genai/multimodal-generative-models) — VLMs, VLAs, diffusion models
