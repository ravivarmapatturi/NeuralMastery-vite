# Databases Overview

Every AI system needs somewhere to put data — and increasingly, that means three different kinds of database working together, not one.

- **[Relational (MySQL, Postgres)](/docs/databases/relational/overview)** — structured data, transactions, ML metadata
- **[Vector Databases](/docs/databases/vector/overview)** — embeddings and similarity search, the backbone of RAG
- **[Graph Databases (Neo4j)](/docs/databases/graph/overview)** — relationships and multi-hop reasoning, GraphRAG

See the [roadmap](/docs/databases/roadmap) for the full ordered path through this section.
