## 4. [NoSQL Databases](/docs/databases/nosql/overview)
- [x] Why NoSQL exists: relaxing the relational model's schema/joins/transactions for scale and flexibility

- [x] Wide-column stores (Cassandra) — massive, distributed write throughput

## Common Problems & SOTA Solutions
- [x] **Vector search doesn't scale past X million vectors** → approximate indexing (HNSW/IVF), sharding
- [x] **Pure vector search misses exact keyword matches** → hybrid search + re-ranking
- [x] **Stale embeddings after content updates** → versioned re-indexing pipelines (see [RAG — Common Failure Modes](/docs/llms-genai/rag#common-failure-modes))
- [x] **Multi-hop reasoning fails with flat vector retrieval** → GraphRAG / knowledge graph augmentation
