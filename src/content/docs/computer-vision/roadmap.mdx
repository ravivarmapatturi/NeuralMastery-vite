# Computer Vision — Roadmap

## 1. [Vision Fundamentals](/docs/computer-vision/vision-fundamentals)
- [x] Image representation: pixels, channels, color spaces
- [x] Convolution as classical filtering (before it's a neural network layer)
- [x] Morphological operations: erosion, dilation, opening, closing
- [x] Edge detection: Sobel, Canny
- [x] Classical feature extraction: SIFT/ORB, HOG
- [x] Data augmentation for vision

## 2. [Vision Tasks & Models](/docs/computer-vision/vision-tasks-and-models)
- [x] Classification, detection, segmentation (recap — see [Vision Architectures](/docs/deep-learning/vision-architectures) for the models)
- [x] Pose estimation
- [x] OCR (Optical Character Recognition)
- [x] Object tracking
- [x] Depth estimation
- [x] Optical flow

## 3. [Modern Vision & Multimodal](/docs/computer-vision/modern-vision-and-multimodal)
- [x] Vision Transformers in production (see [Vision Architectures](/docs/deep-learning/vision-architectures))
- [x] Vision-language models and image-text alignment (CLIP)
- [x] Image generation (see [Generative Models](/docs/deep-learning/generative-models))
- [x] Video understanding
- [x] Video generation
- [x] 3D vision: point clouds, NeRF, 3D reconstruction
