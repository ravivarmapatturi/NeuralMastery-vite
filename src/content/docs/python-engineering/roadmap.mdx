# Python Engineering for AI — Roadmap

## 1. [Language Fundamentals: OOP, Functional & Modern Python](/docs/python-engineering/language-fundamentals-and-oop)
- [x] OOP: classes, inheritance, composition, magic methods
- [x] Functional programming in Python: `map`/`filter`/`reduce`, pure functions, immutability
- [x] Iterators and generators, `yield`, lazy evaluation
- [x] Decorators: how they work, writing your own
- [x] Context managers: `with`, `__enter__`/`__exit__`, `contextlib`
- [x] Type hints, `typing`, static type checking with `mypy`
- [x] `dataclasses`

## 2. [Concurrency, Memory & Performance](/docs/python-engineering/concurrency-memory-and-performance)
- [x] `async`/`await`, the event loop, when async actually helps
- [x] `multiprocessing` vs. `threading` in practice (see the GIL in [CS Fundamentals](/docs/cs-fundamentals/operating-systems-and-concurrency))
- [x] Reference counting and the cyclic garbage collector
- [x] Profiling Python code: `cProfile`, `py-spy`, `memory_profiler`
- [x] Performance optimization: vectorization over loops, avoiding unnecessary copies

## 3. [Packaging, Testing & Tooling](/docs/python-engineering/packaging-testing-and-tooling)
- [x] `pyproject.toml`, dependency pinning, lockfiles
- [x] Virtual environments: `venv`, `uv`, why isolation matters
- [x] `pytest`: fixtures, parametrization, marks, `conftest.py`
- [x] Logging: the `logging` module vs. `print`
- [x] Debugging: `pdb`, breakpoints, post-mortem debugging
