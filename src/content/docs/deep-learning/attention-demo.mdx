## Math

Self-attention's core formula, rendered by KaTeX at MDX build time:

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right) V$$

## Code

Shiki-highlighted, rendered by the `VisualizationCode` primitive at runtime:

```python
def softmax(x):
    e = np.exp(x - np.max(x, axis=-1, keepdims=True))
    return e / e.sum(axis=-1, keepdims=True)
```
