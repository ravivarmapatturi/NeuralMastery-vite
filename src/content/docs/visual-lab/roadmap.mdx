# Visual Lab — Roadmap

## Shipped
- [x] [Gradient Descent Explorer](/docs/visual-lab/gradient-descent-explorer) — SGD / Momentum / Adam on a live, clickable loss surface
- [x] [Neural Network Playground](/docs/visual-lab/neural-network-playground) — configurable toy-dataset classifier, trained live in-browser
- [x] [Attention Step-Through](/docs/visual-lab/attention-step-through) — live QKV/softmax attention heatmap and per-token breakdown, multi-head
- [x] [RAG Pipeline Simulator](/docs/visual-lab/rag-pipeline-simulator) — adjustable chunking/top-k/reranking, live retrieved-chunk results
- [x] [Agent Execution Graph](/docs/visual-lab/agent-execution-graph) — step through a scripted, clickable ReAct loop trace
- [x] [LLM Inference Flow Visualizer](/docs/visual-lab/inference-flow-visualizer) — clickable tokenizer-to-sampling pipeline with a real live sampling playground
- [x] [Decision Boundary Playground](/docs/visual-lab/decision-boundary-playground) — click-to-add-points KNN / decision tree / k-means explorer
- [x] [Embedding Space Explorer](/docs/visual-lab/embedding-space-explorer) — real from-scratch PCA projection, cosine-similarity nearest neighbors, and word-vector analogy, live
- [x] [Linear Regression Studio](/docs/visual-lab/linear-regression-studio) — drag-the-line fitting, MSE/outlier experiment, and a real gradient descent lab with a live loss surface, on a real dataset
- [x] [Logistic Regression Studio](/docs/visual-lab/logistic-regression-studio) — real sigmoid fitting plus a live cross-entropy vs. MSE-on-sigmoid convexity comparison
- [x] [Ridge Regression Studio](/docs/visual-lab/ridge-regression-studio) — real closed-form ridge solve on a multicollinear dataset, live regularization path
- [x] [Lasso Regression Studio](/docs/visual-lab/lasso-regression-studio) — real coordinate-descent soft-thresholding on the same dataset as Ridge, directly comparable regularization path
- [x] `PredictFirst` widget — predict-then-reveal questions wired into all four Studios so far
- [x] [Algorithm Selector](/docs/visual-lab/algorithm-selector) — a real branching decision tool over this site's own ML pages
- [x] [Learning Path map](/docs/learning-path) — a clickable, progress-aware dependency graph of the whole curriculum, plus a full structured breakdown
- [x] [Two Pointers & Sliding Window, Step by Step](/docs/visual-lab/two-pointers-sliding-window) — editable array/string, real two-pointer and sliding-window algorithms stepped through one move at a time, the first DSA-focused (not ML/DL) piece in Visual Lab

## Planned, in order
Nothing queued right now. Future additions will follow the same batch-by-batch, build-verified discipline as everything else on this site — candidates include Decision Trees and SVM (which need a genuinely different, non-gradient-descent visualization approach than the regression Studios so far), and more DSA-pattern visualizations (monotonic stack, BFS/DFS on a graph) now that the first one has established the pattern.
