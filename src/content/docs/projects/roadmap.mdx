# Projects — Roadmap

## 1. [The Project Ladder](/docs/projects/the-project-ladder)
- [x] Level 1 — tiny projects (an afternoon each)
- [x] Level 2 — intermediate projects (a weekend each)
- [x] Level 3 — advanced projects (one to two weeks each)
- [x] Level 4 — production systems (real deployment, monitoring, cost tracking)
- [x] Level 5 — research reproductions (reproduce a paper's headline result)
- [x] Level 6 — frontier capstones (a genuine portfolio centerpiece)
