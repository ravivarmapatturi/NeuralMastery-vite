# Projects — Roadmap

## 1. [The Project Ladder](/docs/projects/the-project-ladder)
- [ ] Level 1 — tiny projects (an afternoon each)
- [ ] Level 2 — intermediate projects (a weekend each)
- [ ] Level 3 — advanced projects (one to two weeks each)
- [ ] Level 4 — production systems (real deployment, monitoring, cost tracking)
- [ ] Level 5 — research reproductions (reproduce a paper's headline result)
- [ ] Level 6 — frontier capstones (a genuine portfolio centerpiece)

## 2. [Problem Statement Atlas](/docs/projects/problem-statement-atlas)
- [ ] Pick a domain (production RAG, agentic RAG, multi-agent orchestration, ranking/recommendation, search, LLM serving, model routing, fine-tuning, MLOps/CI-CD, AI security, agent evaluation)
- [ ] Check its status — not started, content only, or an already-built real project to learn from
- [ ] Scope your pick against [The Project Ladder](/docs/projects/the-project-ladder)'s levels
