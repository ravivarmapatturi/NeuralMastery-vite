# Build From Scratch — Roadmap

## 1. [The Build List](/docs/build-from-scratch/the-build-list)
- [x] NumPy-level array operations (understand what a tensor library actually does)
- [x] An autodiff engine (reverse-mode automatic differentiation, `micrograd`-style)
- [x] A neural network (forward pass, backprop, training loop, from the autodiff engine up)
- [x] A CNN (convolution and pooling as explicit operations, not a library call)
- [x] A BPE tokenizer
- [x] Self-attention (the QKV mechanism, from the matrix operations up)
- [x] A Transformer block (attention + MLP + residuals + normalization, composed)
- [x] A small GPT (`nanoGPT`-style, trained on a small corpus)
- [x] LoRA (low-rank adapter injection into a pretrained model)
- [x] A vector database (embedding storage + nearest-neighbor search, from scratch)
- [x] A RAG pipeline (chunk, embed, retrieve, generate — no framework)
- [x] An agent (a ReAct loop with real tool calls, no agent framework)
- [x] A minimal inference server (batching, a KV cache, a simple API)
- [x] A minimal distributed trainer (data parallelism across multiple processes/GPUs)

Next: [Projects](/docs/projects/roadmap) — larger, more complete systems that combine several of the above into something closer to a real, deployable project.
